VPS Ping คือเวลาที่ข้อมูลใช้เดินทางจาก MT5 บนเครื่อง VPS ไปถึงเซิร์ฟเวอร์เทรดของโบรกเกอร์แล้วกลับมา วัดเป็นมิลลิวินาที (ms) ตัวเลขนี้เป็นหนึ่งในเกณฑ์ที่คนดูมากที่สุดเวลาเลือก VPS สำหรับ EA แต่ก็เป็นตัวเลขที่ถูกอ่านผิดบ่อยที่สุดเช่นกัน หน้านี้อธิบายว่าควรวัดจากเครื่องไหน ค่าเท่าไหร่ถือว่าพอ และความหน่วงแบบไหนที่กระทบการทำงานของ EA จริง

สรุปสั้น: ให้ดูค่า Ping ที่ MT5 บนตัว VPS แสดง ไม่ใช่ค่าบนคอมที่บ้าน · ค่าต่ำสุดถูกกำหนดด้วยระยะทางถึงเซิร์ฟเวอร์โบรกเกอร์ VPS ที่อยู่ใกล้จึงได้เปรียบ · Ping ต่ำช่วยให้คำสั่งถึงเร็วขึ้น แต่ไม่ได้ลบ Slippage ช่วงข่าว ไม่ได้ลดสเปรด และไม่ได้ทำให้กลยุทธ์ดีขึ้น

Ping กับ Latency ต่างกันตรงไหน

สองคำนี้มักใช้แทนกัน แต่ความหมายไม่เท่ากันทีเดียว และการแยกให้ออกช่วยให้ไม่ตั้งความหวังผิดที่

  • Latency คือความหน่วงโดยรวมของทั้งเส้นทาง ตั้งแต่ EA ตัดสินใจส่งคำสั่ง จนถึงเห็นผลว่าออเดอร์เปิดแล้ว ในวงการ latency forex รวมทั้งเวลาเดินทางของข้อมูลและเวลาที่ฝั่งโบรกเกอร์ใช้จัดการคำสั่ง
  • Ping คือการวัดเฉพาะส่วนเครือข่าย ส่งข้อมูลก้อนเล็กไปแล้วจับเวลาจนได้คำตอบกลับ จึงเป็นเวลาไปกลับ (round trip) ไม่ใช่ทางเดียว

พูดง่าย ๆ Ping เป็นชิ้นหนึ่งของ Latency และเป็นชิ้นเดียวที่การเลือกที่ตั้ง VPS เปลี่ยนได้ ส่วนเวลาที่โบรกเกอร์ใช้ประมวลผลหรือหาราคาให้ เราควบคุมไม่ได้เลย

เส้นทางของคำสั่งหนึ่งไม้ ความหน่วงเกิดตรงไหนบ้าง

ลองไล่ดูว่าตั้งแต่ราคาขยับจนออเดอร์เปิด ข้อมูลผ่านจุดไหนบ้าง แล้วจะเห็นว่า vps ping ครอบคลุมแค่บางช่วง

ช่วงเกิดอะไรขึ้นใครควบคุมได้
1. ราคาใหม่มาถึง MT5เซิร์ฟเวอร์ส่ง tick ใหม่มาที่เครื่องระยะทางของ VPS (คุณเลือกได้)
2. EA คำนวณEA อ่านราคาแล้วตัดสินใจความแรงของเครื่องและจำนวนโปรแกรมที่เปิด
3. คำสั่งเดินทางออกไปMT5 ส่งคำสั่งไปยังจุดเชื่อมต่อของโบรกเกอร์ระยะทางของ VPS (คุณเลือกได้)
4. โบรกเกอร์จัดการคำสั่งตรวจ Margin หาราคา และเปิดออเดอร์โบรกเกอร์
5. ผลกลับมาที่ MT5ออเดอร์ขึ้นในแท็บ Tradeระยะทางของ VPS (คุณเลือกได้)

ช่วง 1, 3 และ 5 คือส่วนที่ค่า Ping สะท้อน ช่วง 2 ขึ้นกับสเปกเครื่อง ถ้า CPU ทำงานเต็มตลอด EA ก็ประมวลผลช้าลงแม้เครือข่ายจะเร็ว เรื่องนี้แยกไปอ่านได้ในสเปก VPS สำหรับ MT5 ส่วนช่วง 4 ขึ้นกับโบรกเกอร์ล้วน ๆ

วัด vps ping ใน MT5 ให้ถูกเครื่อง

ความผิดพลาดที่พบบ่อยคือดูตัวเลขบน MT5 ที่คอมบ้าน แล้วคิดว่าเป็นค่าของ VPS ตัวเลขที่ MT5 แสดงเป็นของเครื่องที่ MT5 ตัวนั้นรันอยู่เท่านั้น

  1. รีโมตเข้า VPS ก่อน

    เปิด Remote Desktop เข้าเครื่อง VPS แล้วดู MT5 ที่ติดตั้งอยู่บนนั้น ไม่ใช่ MT5 บนเครื่องที่คุณนั่งอยู่

  2. ดูตัวเลขมุมขวาล่าง

    แถบสถานะด้านล่างขวาแสดงค่าความหน่วงของการเชื่อมต่อปัจจุบันเป็นมิลลิวินาที ถ้าเห็นข้อความว่าไม่มีการเชื่อมต่อแทนตัวเลข ปัญหาอยู่ที่การเชื่อมต่อ ไม่ใช่ความเร็ว

  3. คลิกที่ตัวเลขเพื่อดูรายการเซิร์ฟเวอร์

    จะเห็นจุดเชื่อมต่อของโบรกเกอร์พร้อมค่า Ping ของแต่ละจุด และคำสั่ง Rescan servers ให้ MT5 วัดใหม่และเลือกจุดที่ตอบเร็ว

  4. วัดหลายช่วงเวลา

    จดค่าในช่วงเช้า บ่าย และช่วงตลาดยุโรปกับอเมริกาเปิด ค่าที่ดีควรนิ่งทั้งวัน ไม่ใช่ต่ำแค่ตอนตลาดเงียบ

ถ้าอยากรู้ว่าตัวเลขนี้มาจากไหนในทางเทคนิค เอกสารของ MQL5 ระบุว่าโปรแกรมใน MT5 อ่านค่า Ping ล่าสุดถึงเซิร์ฟเวอร์เทรดได้ผ่านคุณสมบัติ TERMINAL_PING_LAST ซึ่งเก็บเป็นไมโครวินาที ตัวเลขบนแถบสถานะจึงเป็นค่าที่เทอร์มินัลวัดเองจากการเชื่อมต่อจริง

จอรีโมตหน่วง ไม่ได้แปลว่า EA หน่วง

อีกเรื่องที่สับสนกันบ่อย เวลาเปิด Remote Desktop จากมือถือหรือเน็ตบ้านแล้วภาพกระตุก นั่นคือความหน่วงระหว่างคุณกับ VPS ซึ่งไม่เกี่ยวกับเส้นทางระหว่าง VPS กับโบรกเกอร์เลย EA บน VPS ยังส่งคำสั่งด้วยความเร็วเท่าเดิม ถ้าภาพหลุดบ่อยจนเข้าเครื่องไม่ได้ ให้ดูวิธีแก้ในบทความเข้า VPS ไม่ได้หรือ Remote Desktop หลุด

ใช้คำสั่ง ping ของ Windows แทนได้ไหม

Windows มีคำสั่ง ping ที่ส่งข้อความ ICMP ไปหาปลายทางแล้วแสดงเวลาไปกลับ ใช้ได้ดีสำหรับเช็กว่าเน็ตของ VPS ออกอินเทอร์เน็ตได้ไหม แต่มีข้อจำกัดสองข้อเมื่อใช้กับการเทรด

  • เซิร์ฟเวอร์เทรดหลายแห่งไม่ตอบข้อความประเภทนี้ ผลที่ขึ้นว่า Request timed out จึงไม่ได้แปลว่าเซิร์ฟเวอร์ล่ม
  • เส้นทางที่ MT5 ใช้จริงอาจเป็นจุดเชื่อมต่อคนละตัวกับที่คุณพิมพ์ไป ค่าที่ได้จึงเทียบกันตรง ๆ ไม่ได้

สรุปคือใช้คำสั่ง ping เช็กเน็ตทั่วไป แต่ใช้ตัวเลขใน MT5 เป็นค่าหลักในการตัดสินใจ

VPS Ping เท่าไหร่ถือว่าดี: คิดจากระยะทาง

คำถาม "Ping เท่าไหร่ถึงดี" ไม่มีตัวเลขเดียวที่ถูกสำหรับทุกคน เพราะค่าต่ำสุดถูกล็อกไว้ด้วยฟิสิกส์ สัญญาณในสายใยแก้วนำแสงเดินทางได้ราว 200 กิโลเมตรต่อมิลลิวินาที เมื่อต้องไปและกลับ ระยะห่างทุก 100 กิโลเมตรจึงเพิ่มค่า Ping อย่างน้อยราว 1 ms

ระยะห่างจาก VPS ถึงเซิร์ฟเวอร์โบรกเกอร์ (ตัวอย่าง)Ping ต่ำสุดตามทฤษฎีค่าที่มักเห็นจริง
ศูนย์ข้อมูลเดียวกันหรือเมืองเดียวกัน (ไม่เกิน 50 กม.)ต่ำกว่า 1 msหลักหน่วย ms
ประเทศใกล้เคียง (ราว 1,500 กม.)ราว 15 msสูงกว่านั้นพอสมควร
ข้ามทวีป (ราว 9,000 กม.)ราว 90 msมักเกินร้อยมิลลิวินาที

ค่าจริงสูงกว่าค่าทฤษฎีเสมอ เพราะสายเคเบิลไม่ได้วิ่งเป็นเส้นตรงและข้อมูลต้องผ่านอุปกรณ์เครือข่ายหลายตัว ตารางนี้จึงใช้ดูทิศทาง ไม่ใช่คำสัญญาของผู้ให้บริการรายไหน

บทเรียนจากตารางคือ ถ้าเซิร์ฟเวอร์ของโบรกเกอร์อยู่อีกทวีป จะซื้อ VPS แพงแค่ไหนในไทยก็ไม่มีทางได้ค่าต่ำ ตัวแปรที่สำคัญที่สุดคือที่ตั้งของศูนย์ข้อมูล ไม่ใช่ราคาแพ็กเกจ วิธีเทียบผู้ให้บริการจากเกณฑ์นี้และเกณฑ์อื่นอยู่ในบทความVPS Forex เจ้าไหนดี

สำหรับผู้ใช้ EA WING ข้อแนะนำของทีมงานเหมือนผู้ใช้ EA ทั่วไป คือเลือก VPS ที่เปิดได้ต่อเนื่องและอยู่ใกล้เซิร์ฟเวอร์ของโบรกเกอร์เท่าที่ทำได้ ถ้าไม่แน่ใจว่าเซิร์ฟเวอร์อยู่ที่ไหน ถามฝ่ายบริการลูกค้าของ [eawing_broker] หรือถามทีมงานทาง LINE

Latency forex กระทบ EA แบบไหนมาก แบบไหนน้อย

ผลของความหน่วงขึ้นกับว่าระบบเทรดหวังกำไรต่อไม้ระยะสั้นแค่ไหน ยิ่งเป้าต่อไม้แคบ เวลาไม่กี่สิบมิลลิวินาทีก็มีน้ำหนักมากขึ้น

ลักษณะการเทรดความไวต่อ Latencyเหตุผล
เข้าออกเร็ว เป้าต่อไม้ไม่กี่จุดสูงราคาที่ได้ต่างไปนิดเดียวก็กินสัดส่วนใหญ่ของกำไรที่คาดไว้
ถือออเดอร์เป็นชั่วโมงปานกลางความหน่วงยังมีผลช่วงราคาวิ่งแรง แต่เป็นสัดส่วนเล็กของระยะทั้งไม้
ถือเป็นวันหรือสัปดาห์ต่ำสิ่งที่สำคัญกว่าคือเครื่องเปิดอยู่ตลอด ไม่ใช่ความเร็วระดับมิลลิวินาที

ตัวอย่างสมมติ: ช่วงข่าวสำคัญ ราคาทองอาจขยับหลายสิบเซนต์ภายในเสี้ยววินาที คำสั่งที่ใช้เวลาไปกลับ 250 ms มีช่องว่างให้ราคาเปลี่ยนมากกว่าคำสั่งที่ใช้ 5 ms ผลที่เห็นคือ Slippage หรือคำสั่งถูกเสนอราคาใหม่ ระบบที่เน้นเข้าออกเร็วจะรู้สึกผลนี้ชัดที่สุด ภาพรวมของ EA ประเภทนี้อธิบายไว้ในบทความEA แบบ Scalping และข้อจำกัด

สิ่งที่ Ping ต่ำแก้ไม่ได้

ผู้ให้บริการบางรายโฆษณาค่า Ping ต่ำเหมือนเป็นทางลัดสู่ผลเทรดที่ดีกว่า ซึ่งไม่จริง ความเร็วแก้ได้แค่ปัญหาความเร็ว

  • สเปรดกว้างช่วงข่าวหรือช่วงเปิดตลาด เป็นเงื่อนไขของตลาดและโบรกเกอร์ ไม่เกี่ยวกับระยะทาง
  • Slippage ตอนราคากระโดด Ping ต่ำลดช่องว่างได้บ้าง แต่ถ้าราคาข้ามไปแล้ว ทุกคนได้ราคาใหม่เหมือนกัน
  • กลยุทธ์ที่ขาดทุน ส่งคำสั่งเร็วขึ้นไม่ได้ทำให้กติกาที่ขาดทุนกลายเป็นกำไร
  • เครื่องที่ช้าเพราะโปรแกรมล้น ถ้า CPU เต็ม ความหน่วงเกิดในเครื่องก่อนข้อมูลจะออกเน็ตด้วยซ้ำ
  • ไฟดับหรือเครื่องรีสตาร์ต ค่า Ping ดีแค่ไหนก็ไม่มีความหมายถ้า MT5 ไม่ได้เปิดอยู่

ข้อสุดท้ายสำคัญกว่าที่หลายคนคิด สำหรับคนที่ยังรันบนคอมที่บ้าน ความเสี่ยงหลักมักเป็นเครื่องดับหรือเน็ตหลุด มากกว่าตัวเลขมิลลิวินาที เพราะฉะนั้นก่อนจะไล่ลดค่า Ping ให้แน่ใจก่อนว่าเครื่องที่รัน EA เปิดอยู่ได้ตลอดจริง

ลดค่า Ping ทำอะไรได้บ้าง

ถ้าวัดแล้วค่าสูงหรือแกว่งมาก ไล่ทำตามลำดับนี้ เริ่มจากสิ่งที่ไม่มีค่าใช้จ่าย

  1. สั่ง Rescan servers

    บางครั้ง MT5 ค้างอยู่กับจุดเชื่อมต่อที่ไม่ใช่ตัวที่เร็วที่สุด การสแกนใหม่ให้มันเลือกใหม่

  2. ปิดโปรแกรมที่ไม่จำเป็นบน VPS

    เบราว์เซอร์ที่เปิดหลายแท็บหรือโปรแกรมดาวน์โหลดกินทั้ง CPU และแบนด์วิดท์ เปิด Task Manager ดูว่าอะไรใช้ทรัพยากรมาก

  3. ถามโบรกเกอร์ว่าเซิร์ฟเวอร์อยู่เมืองไหน

    ข้อมูลนี้ทำให้รู้ว่าค่าต่ำสุดที่เป็นไปได้ประมาณเท่าไหร่ และควรเลือกศูนย์ข้อมูลที่ไหน

  4. ทดลองก่อนเช่ายาว

    ถ้าผู้ให้บริการมีหลายศูนย์ข้อมูล เช่ารายเดือนก่อนแล้ววัดจริงสักหนึ่งสัปดาห์ ค่อยตัดสินใจเรื่องสัญญารายปี

  5. ย้ายเมื่อมีเหตุผลชัด

    ถ้าตัวเลขยังสูงเพราะอยู่ไกลจริง การย้ายไปเครื่องใหม่ที่ใกล้กว่าเป็นทางแก้ที่ตรงจุด แต่ต้องวางแผนย้ายให้ดี

ถ้าเห็นค่ากระโดดเป็นช่วง ๆ ให้เปิดแท็บ Journal ดูว่าช่วงเดียวกันมีการหลุดและต่อใหม่หรือไม่ ถ้า MT5 ขึ้นว่าไม่มีการเชื่อมต่อเลย นั่นเป็นอีกปัญหาหนึ่ง ดูวิธีไล่สาเหตุในบทความMT5 ขึ้น No connection

คำเตือนความเสี่ยง: VPS ที่เร็วและเสถียรช่วยให้ EA ส่งคำสั่งได้ทันเวลา แต่ไม่ได้ลดความเสี่ยงของตลาด และไม่ได้รับประกันว่าจะได้ราคาตามที่เห็น การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ความเสี่ยงของการเทรดด้วยระบบอัตโนมัติ ก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่อง VPS Ping

MT5 บนคอมบ้านขึ้น Ping สูง แต่บน VPS ต่ำมาก ต้องเชื่อค่าไหน?

เชื่อค่าของเครื่องที่ EA รันอยู่ ถ้า EA อยู่บน VPS ค่าบน VPS คือค่าที่มีผลกับคำสั่งเทรด ส่วนค่าบนคอมบ้านเป็นของ MT5 ที่คุณใช้ดูเฉย ๆ ไม่ได้ส่งคำสั่งแทน EA

พิมพ์ ping ใส่ชื่อเซิร์ฟเวอร์โบรกเกอร์แล้วขึ้น Request timed out แปลว่าเซิร์ฟเวอร์ล่มหรือเปล่า?

ไม่จำเป็น เซิร์ฟเวอร์เทรดหลายแห่งตั้งไม่ให้ตอบคำสั่ง ping โดยตั้งใจ ถ้า MT5 ยังแสดงตัวเลขมิลลิวินาทีที่มุมขวาล่างและราคายังขยับ แปลว่าการเชื่อมต่อของ MT5 ปกติ

ต้องได้ Ping ต่ำกว่า 1 ms ไหม EA ถึงจะทำงานได้ดี?

ไม่จำเป็นสำหรับ EA ส่วนใหญ่ ค่าที่ต่ำมากจะเกิดได้เมื่อ VPS อยู่ในศูนย์ข้อมูลเดียวกับเซิร์ฟเวอร์โบรกเกอร์ ซึ่งมักแพงกว่า ให้ถามตัวเองว่าระบบของคุณไวต่อความหน่วงแค่ไหน แล้วชั่งกับค่าใช้จ่าย ความเสถียรของเครื่องมักสำคัญกว่าตัวเลขที่ต่ำที่สุด

ค่า Ping ขึ้นลงทั้งวัน ผิดปกติไหม?

แกว่งเล็กน้อยเป็นเรื่องปกติของอินเทอร์เน็ต แต่ถ้ากระโดดสูงบ่อยหรือมีช่วงหลุดการเชื่อมต่อ ให้จดเวลาไว้แล้วแจ้งผู้ให้บริการ VPS พร้อมภาพแท็บ Journal ช่วงนั้น จะช่วยให้เขาตรวจเครือข่ายได้ตรงจุด

อ่านต่อ

  • คู่มือเลือกและดูแล VPS สำหรับ EA
  • เกณฑ์เลือก VPS Forex โดยไม่ต้องดูยี่ห้อ
  • สเปก VPS ที่พอดีกับ MT5
  • แก้ MT5 ไม่มีการเชื่อมต่อ

ถ้ายังไม่มี VPS หรือเพิ่งเช่าเครื่องแรก เริ่มจากคู่มือเข้า Windows VPS ด้วย Remote Desktop แล้ววัดค่า Ping จาก MT5 บนเครื่องนั้นตามขั้นตอนข้างบน สงสัยตรงไหนส่งภาพมุมขวาล่างของ MT5 มาถามทีมงานได้
