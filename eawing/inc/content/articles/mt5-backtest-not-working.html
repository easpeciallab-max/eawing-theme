Backtest MT5 ไม่ได้มักออกมาในห้าหน้าตา คือกด Start แล้วไม่เริ่ม เริ่มแล้วจบทันที ค้างที่การเตรียมข้อมูล วันที่ทดสอบเลื่อนเอง และทดสอบจบแต่ไม่มีออเดอร์สักไม้ ทุกแบบมีเหตุผลที่อ่านได้จากหน้าต่าง Strategy Tester เอง ถ้ารู้ว่าต้องดูตรงไหน คู่มือนี้ไล่ทีละอาการ พร้อมเช็กลิสต์ก่อนกด Start ส่วนภาพรวมของหน้าต่างอื่นในโปรแกรม ดูได้ในคู่มือโปรแกรม MT5 ฉบับเต็ม

สรุปสั้น: ก่อนกด Start ให้ล็อกอินและเชื่อมต่ออยู่ สัญลักษณ์ที่ใช้แสดงใน Market Watch เลือก EA สัญลักษณ์ และกรอบเวลาให้ถูก และติ๊ก Allow DLL imports ใน Tools → Options ถ้า EA ต้องใช้ · มีปัญหาเมื่อไร อ่านแท็บ Journal ของ Strategy Tester ก่อน เพราะบอกเหตุผลที่หยุดเกือบทุกครั้ง · การทดสอบครั้งแรกด้วย tick จริงช้าเป็นเรื่องปกติ เพราะต้องดาวน์โหลดข้อมูลจำนวนมาก

Backtest MT5 ไม่ได้ มีอาการแบบไหนบ้าง

จับคู่สิ่งที่เห็นกับตารางนี้ก่อน แล้วข้ามไปหัวข้อที่ตรงกับอาการ

อาการสาเหตุที่พบบ่อยไปที่หัวข้อ
กด Start แล้วจบภายในไม่กี่วินาทีEA โหลดไม่ขึ้น หรือหยุดตัวเองตั้งแต่เริ่มเริ่มแล้วจบทันที
แถบความคืบหน้าค้างที่การเตรียมข้อมูลนานมากดาวน์โหลดข้อมูลราคาย้อนหลังครั้งแรกค้างที่เตรียมข้อมูล
วันที่เริ่มในรายงานไม่ตรงกับที่ตั้งข้อมูลย้อนหลังของช่วงนั้นมีไม่พอวันที่เริ่มเลื่อนเอง
ทดสอบจบแต่ไม่มีออเดอร์เลยสัญลักษณ์ กรอบเวลา เงินทุน หรือโหมดจำลองไม่เหมาะไม่มีออเดอร์
ติ๊ก Visualization ไม่ได้ หรือหน้าต่างไม่เปิดเปิด Optimization ไว้ หรือใช้ agent ระยะไกลโหมด Visualization
ผลไม่ตรงกับที่คนอื่นได้ข้อมูลราคาและเงื่อนไขการทดสอบต่างกันผลทดสอบไม่ตรง

เช็ก 7 ข้อก่อนกด Start

ปัญหาส่วนใหญ่ของ Strategy Tester ไม่ทำงาน ป้องกันได้ตั้งแต่ก่อนเริ่ม เปิดตัวทดสอบด้วย Ctrl+R หรือคลิกขวาที่ชื่อ EA ใน Navigator แล้วเลือก Test จากนั้นไล่ดูทีละข้อ

  • ล็อกอินและเชื่อมต่ออยู่ ตัวทดสอบดึงแท่ง M1 และข้อมูล tick ของสัญลักษณ์จากเซิร์ฟเวอร์ของโบรกเกอร์ ถ้ายังไม่เชื่อมต่อจะไม่มีข้อมูลให้ทดสอบ
  • สัญลักษณ์แสดงอยู่ใน Market Watch โดยเฉพาะ EA ที่ใช้หลายสัญลักษณ์ ทุกตัวต้องถูกเลือกไว้ ถ้าหาไม่เจอ ดูวิธีในเพิ่มสัญลักษณ์ใน Market Watch
  • ช่อง Expert เป็น EA ตัวที่ตั้งใจ ถ้ามีหลายเวอร์ชันในโฟลเดอร์ ชื่อคล้ายกันอาจเลือกผิดได้ง่าย
  • Symbol และ Period ตรงกับคู่มือของ EA รวมถึงตัวต่อท้ายชื่อสัญลักษณ์ของบัญชีคุณ
  • ช่วงวันที่สมเหตุสมผล ไม่สั้นจนไม่มีจังหวะให้ EA ทำงาน และไม่ย้อนไกลกว่าข้อมูลที่โบรกเกอร์มี
  • ทุนเริ่มต้นและ Leverage ใกล้บัญชีจริง Leverage มีผลกับ Margin ที่ถูกกันไว้ ถ้าตั้งต่างจากบัญชีจริงมาก ผลเรื่องเงินไม่พอจะต่างจากที่เจอจริง
  • ติ๊ก Allow DLL imports ใน Tools → Options ถ้า EA ต้องใช้ DLL ตัวทดสอบอ้างอิงการอนุญาตระดับโปรแกรม ไม่ได้ผ่านแท็บ Common บนกราฟ รายละเอียดอยู่ในAllow DLL imports ติ๊กตรงไหนใน MT5

คำอธิบายทุกช่องของหน้าตั้งค่าจากผู้พัฒนาอยู่ในคู่มือ Strategy Tester ของ MetaTrader 5 (ภาษาอังกฤษ) ส่วนขั้นตอนตั้งค่าทดสอบทีละช่องแบบภาษาไทย อยู่ในหน้าBacktest EA

เริ่มแล้วจบทันที: อ่าน Journal ของ Strategy Tester

Strategy Tester มีแท็บ Journal ของตัวเอง แยกจาก Journal หลักของโปรแกรม แท็บนี้บันทึกทุกขั้นของการทดสอบ ตั้งแต่เตรียมข้อมูล เชื่อมต่อ agent สร้าง tick ไปจนถึงผลสุดท้าย และบอกด้วยว่าการทดสอบหยุดก่อนกำหนดเพราะอะไร หลายคนมองข้ามไปเพราะคิดว่าต้องดู Journal ที่ด้านล่างของหน้าต่างหลัก

สิ่งที่พบใน Journal ของตัวทดสอบความหมายแก้อย่างไร
บรรทัดที่มีคำว่า DLL ว่าไม่ได้รับอนุญาต หรือโหลดไลบรารีไม่ได้EA ต้องใช้ DLL แต่โปรแกรมยังไม่อนุญาตติ๊ก Allow DLL imports ใน Tools → Options แล้วเริ่มใหม่
การเริ่มต้นของ EA (OnInit) ไม่ผ่านEA ตรวจเงื่อนไขของตัวเองแล้วไม่ยอมเริ่ม เช่น ค่าตั้งไม่ถูก หรือตรวจสิทธิ์ไม่ผ่านอ่านข้อความของ EA ในบรรทัดใกล้กัน แล้วตรวจค่าในแท็บ Inputs หรือถามผู้ขาย
หยุดเพราะ Stop Outเงินทุนจำลองหมดระหว่างทางไม่ใช่ข้อผิดพลาดของโปรแกรม แต่เป็นผลการทดสอบที่ต้องนำไปคิดเรื่องความเสี่ยง
ข้อผิดพลาดร้ายแรง เช่น array out of range หรือหารด้วยศูนย์โค้ดของ EA ทำงานผิดพลาดส่งบรรทัดนั้นให้ผู้พัฒนา EA

ถ้าต้องการรายละเอียดมากกว่านั้น คลิกขวาในแท็บ Journal ของตัวทดสอบแล้วเปิด Log ของ agent ในเครื่อง จะเห็นสถิติละเอียดเช่นจำนวน tick และหน่วยความจำที่ใช้ ส่วนรหัสตัวเลขที่ EA พิมพ์ออกมาระหว่างทดสอบ เช่น 10019 หรือ 4752 มีความหมายเดียวกับตอนใช้งานจริง ดูได้ในรวม Error MT5 ที่เจอบ่อยและวิธีแก้

EA ที่มีระบบสิทธิ์ใช้งานอาจต้องตรวจสิทธิ์ก่อนเริ่มทดสอบ ให้ล็อกอินบัญชีที่ได้รับสิทธิ์และต่ออินเทอร์เน็ตไว้ ถ้าทดสอบ [eawing_brand] แล้วเริ่มไม่ได้ ส่งภาพแท็บ Journal ของ Strategy Tester ให้ทีมงานทาง LINE

ค้างที่เตรียมข้อมูล หรือช้ามาก

ครั้งแรกที่ทดสอบสัญลักษณ์หนึ่ง โปรแกรมจะดาวน์โหลดประวัติราคาทั้งหมดที่มีของสัญลักษณ์นั้นจากเซิร์ฟเวอร์ ถ้าเลือกโหมด Every tick based on real ticks ข้อมูลยิ่งใหญ่ การรันครั้งแรกจึงช้ากว่าปกติมาก ทั้งหมดนี้เกิดครั้งเดียว ข้อมูลถูกเก็บแบบบีบอัดไว้ใช้ซ้ำในครั้งต่อไป

  • รอให้รอบแรกจบ ดูความคืบหน้าในแท็บ Journal ว่ายังดาวน์โหลดอยู่ ไม่ได้ค้างจริง
  • ใช้อินเทอร์เน็ตที่เสถียร ถ้าหลุดกลางทาง อาจต้องเริ่มดาวน์โหลดส่วนที่ขาดใหม่
  • เช็กพื้นที่ดิสก์ ข้อมูล tick ของหลายเดือนกินพื้นที่มาก บน VPS ดิสก์เล็กอาจเต็มก่อน วิธีประเมินสเปกอยู่ในVPS สเปกเท่าไหร่พอสำหรับ MT5
  • ลองโหมดที่เบากว่าก่อน ใช้ 1 minute OHLC เพื่อตรวจว่าตั้งค่าถูกและ EA ทำงาน แล้วค่อยรันด้วย tick จริงเป็นรอบสุดท้าย

ลำดับการดาวน์โหลดและที่เก็บข้อมูลของตัวทดสอบ อธิบายไว้ในหน้าอธิบายการเตรียมข้อมูลของ Strategy Tester (ภาษาอังกฤษ)

วันที่เริ่มทดสอบเลื่อนเอง

ถ้าตั้งวันที่เริ่มไว้ แต่รายงานกลับเริ่มช้ากว่านั้น และใน Journal มีบรรทัดแจ้งว่าเวลาเริ่มถูกเปลี่ยน แปลว่าข้อมูลก่อนหน้านั้นมีไม่พอ ตัวทดสอบต้องการแท่งเทียนขั้นต่ำจำนวนหนึ่งก่อนวันเริ่ม เพื่อให้การคำนวณถูกต้อง เมื่อไม่พอจึงเลื่อนวันเริ่มไปข้างหน้าเอง ผู้พัฒนาระบุว่านี่เป็นกลไกในตัว ไม่ใช่ข้อผิดพลาด

ทางแก้คือเลือกวันเริ่มที่ช้าลง หรือยอมรับวันที่ถูกเลื่อน ถ้าเป็นสัญลักษณ์ที่มีตัวต่อท้ายชื่อซึ่งเพิ่งเปิดให้เทรด ประวัติราคาอาจสั้นกว่าชื่อมาตรฐาน ตรวจได้จากการเลื่อนกราฟ D1 ของสัญลักษณ์นั้นย้อนไปดูว่าแท่งแรกเริ่มเมื่อไร

ทดสอบจบ แต่ไม่มีออเดอร์เลย

ตัวทดสอบทำงานครบ แต่แท็บ Result ว่างเปล่า สาเหตุอยู่ในกลุ่มนี้

  • สัญลักษณ์หรือกรอบเวลาไม่ตรงกับที่ EA ออกแบบ EA หลายตัวไม่ทำงานเลยถ้าไม่ได้อยู่บนกราฟที่ระบุ
  • ทุนเริ่มต้นน้อยเกินสำหรับ Lot ขั้นต่ำ คำสั่งถูกปฏิเสธว่าเงินไม่พอตั้งแต่ไม้แรก ดูใน Journal ว่ามีรหัส 10019 หรือไม่
  • เลือกโหมด Math calculations โหมดนี้ไม่ใช้ข้อมูลราคาเลย EA จึงไม่มี tick ให้ตัดสินใจ
  • ค่าตั้งในแท็บ Inputs ปิดการเทรดไว้ หรือกรอกค่าที่ทำให้เงื่อนไขไม่มีวันเป็นจริง
  • ช่วงทดสอบสั้นเกินไป ตลาดอาจไม่ให้จังหวะตามเงื่อนไขของ EA ในช่วงนั้นเลย ซึ่งเป็นพฤติกรรมปกติ ไม่ใช่ความผิดพลาด

โหมด Visualization ไม่เปิด หรือเปิดแล้วช้า

โหมด Visualization ให้ดู EA เปิดปิดออเดอร์บนกราฟจำลองแบบเห็นภาพ แต่มีเงื่อนไขที่ทำให้ติ๊กไม่ได้

  • ปิด Optimization ก่อน โหมดดูภาพใช้ไม่ได้ระหว่างหาค่าตั้งที่เหมาะสม
  • ใช้ agent ในเครื่อง โหมดนี้รันได้เฉพาะ agent ในเครื่อง ไม่ใช่ agent ระยะไกล
  • รอการโหลดครั้งแรก ก่อนเริ่ม โปรแกรมจะดาวน์โหลดข้อมูลราคาทั้งหมดของสัญลักษณ์หลัก ถ้าเน็ตช้าจะรอนาน แต่เกิดครั้งเดียว

ในหน้าต่างจำลองปรับความเร็ว หยุดชั่วคราว หรือข้ามไปวันที่ต้องการได้ แต่เปลี่ยนกรอบเวลาของกราฟไม่ได้

ผลทดสอบไม่ตรงกับคนอื่นหรือกับบัญชีจริง

EA ตัวเดียวกัน ช่วงวันที่เดียวกัน อาจให้ผลต่างกันได้มาก เพราะข้อมูลราคาของแต่ละโบรกเกอร์ไม่เหมือนกัน รวมถึง Spread ค่าคอมมิชชัน ความหน่วงที่จำลอง (Delays) โหมดสร้าง tick และสกุลเงินของทุนเริ่มต้น ตัวทดสอบเปิดให้จำลองเงื่อนไขเหล่านี้ได้ แต่ถ้าตั้งไม่ตรงกับบัญชีจริง ผลก็จะไม่ตรงตาม

สิ่งที่ควรจำคือผลทดสอบย้อนหลังบอกได้แค่ว่าระบบทำอะไรกับข้อมูลในอดีต ไม่ได้บอกว่าอนาคตจะเป็นอย่างไร ภาพผลทดสอบที่สวยเกินจริงยังเป็นเครื่องมือขายที่พบบ่อย ดูวิธีสังเกตในบอทเทรดหลอก: 10 สัญญาณเตือนก่อนเสียเงิน สำหรับ [eawing_brand] ชุดติดตั้งแนะนำให้ทดสอบช่วง 2026.01.01 ถึง 2026.08.31 บนสัญลักษณ์ทองของบัญชีคุณ กรอบเวลา M1

คำถามที่พบบ่อย

Strategy Tester ไม่ทำงานบน MT5 มือถือ ใช่ไหม?

ใช่ แอปมือถือไม่มีตัวทดสอบและรัน EA ไม่ได้ ต้องทดสอบบน MT5 เวอร์ชันคอมพิวเตอร์บน Windows หรือบน Windows VPS ที่รีโมตเข้าไปจากมือถือได้

ต้องต่ออินเทอร์เน็ตตลอดตอน Backtest ไหม?

ต้องต่ออย่างน้อยตอนเตรียมข้อมูล เพราะตัวทดสอบซิงก์ประวัติราคากับเซิร์ฟเวอร์ก่อนเริ่ม และ EA ที่มีระบบสิทธิ์อาจต้องตรวจสิทธิ์ผ่านอินเทอร์เน็ตด้วย การต่อไว้ตลอดจึงปลอดภัยที่สุด

Backtest MT5 ไม่ได้เพราะเครื่องสเปกต่ำหรือเปล่า?

สเปกต่ำทำให้ช้า แต่ไม่ค่อยทำให้เริ่มไม่ได้ ถ้ากดแล้วจบทันที สาเหตุมักอยู่ที่การอนุญาต DLL ค่าตั้ง หรือสัญลักษณ์ ให้อ่าน Journal ของตัวทดสอบก่อน ส่วนอาการช้ามาก ลองลดช่วงวันที่หรือใช้โหมดที่เบากว่า

ผลทดสอบดี แปลว่าใช้กับบัญชีจริงได้เลยไหม?

ยังไม่ใช่ ผลทดสอบย้อนหลังเป็นแค่ข้อมูลประกอบ ควรทดสอบต่อบนบัญชีเดโมหรือบัญชีเล็กในสภาพตลาดจริงก่อน และวางแผนเรื่องเงินที่รับการขาดทุนได้ไว้ล่วงหน้า

คำเตือนความเสี่ยง: Backtest เป็นการจำลองด้วยข้อมูลในอดีต ผลที่ได้ไม่ใช่ผลการเทรดจริง และไม่ได้รับประกันผลลัพธ์ในอนาคต การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ช่วงขาดทุนติดต่อกันในบัญชีจริงอาจลึกกว่าที่เห็นในผลทดสอบ อ่านความเสี่ยงที่ต้องรู้ก่อนใช้ EAก่อนใช้เงินจริง
