MT5 บน Mac ใช้ได้ MetaQuotes มีตัวติดตั้งสำหรับ macOS ที่ห่อโปรแกรมเวอร์ชัน Windows ไว้ให้ทำงานบน Mac ได้ทันที ดูกราฟ เทรดมือ และทดสอบย้อนหลังได้ แต่ถ้าเป้าหมายคือรัน EA ทั้งวันทั้งคืน มีข้อจำกัดหลายข้อที่ควรรู้ก่อนลงมือ ภาพรวมของโปรแกรมทั้งหมดอ่านได้ในMT5 คืออะไร

สรุปสั้น: ติดตั้ง MT5 บน Mac ได้จากตัวติดตั้ง macOS ซึ่งใช้ Wine อยู่เบื้องหลัง รองรับ macOS Catalina 10.15.7 ขึ้นไปและชิป Apple ทุกรุ่น · ใช้ดูกราฟและเทรดมือได้ดี · EA ที่ต้องเรียก DLL ของ Windows อาจทำงานไม่ครบ และ Mac ต้องเปิดไม่ให้หลับตลอดเวลา · ทางที่ตรงที่สุดสำหรับคนใช้ Mac ที่จะรัน EA คือเช่า Windows VPS แล้วควบคุมจาก Mac ด้วยแอป Windows App

MT5 Mac ทำงานยังไง

MT5 ถูกพัฒนาเป็นโปรแกรมของ Windows ตัวติดตั้งสำหรับ macOS จึงไม่ใช่โปรแกรมที่เขียนใหม่สำหรับ Mac แต่ใช้ Wine ซึ่งเป็นชั้นแปลที่ทำให้โปรแกรม Windows ทำงานบน macOS ได้ ตัวติดตั้งจะดาวน์โหลดและตั้งค่า Wine ให้เอง คุณไม่ต้องตั้งค่าอะไรเพิ่ม ข้อมูลนี้มาจากคู่มือติดตั้ง MT5 บน macOS ของ MetaTrader 5 (ภาษาอังกฤษ)

ติดตั้ง MT5 บน Mac ทีละขั้น

  1. ดาวน์โหลดตัวติดตั้งสำหรับ macOS

    ดาวน์โหลดจากเว็บของโบรกเกอร์ที่คุณใช้ หรือจากเว็บของ MetaTrader 5 โดยตรง ไม่ควรดาวน์โหลดจากเว็บฝากไฟล์หรือลิงก์ที่คนอื่นส่งมา

  2. ลากโปรแกรมเข้า Applications

    เปิดไฟล์ที่ดาวน์โหลดมา แล้วลากไอคอน MetaTrader 5 ไปไว้ในโฟลเดอร์ Applications

  3. เปิดครั้งแรกและรอให้ติดตั้ง Wine

    ครั้งแรกจะใช้เวลานานกว่าปกติ เพราะตัวติดตั้งกำลังเตรียม Wine ถ้ามีหน้าต่างถามเรื่อง Mono หรือ Gecko ให้กดติดตั้ง เพราะโปรแกรมต้องใช้

  4. ล็อกอินบัญชี

    ไปที่ File → Login to Trade Account ใส่เลขบัญชี รหัสผ่าน และเลือกชื่อเซิร์ฟเวอร์ของโบรกเกอร์ ถ้ายังไม่มีบัญชี ลองเปิดบัญชีเดโม MT5ก่อนได้

  5. เช็กการเชื่อมต่อ

    มุมขวาล่างควรแสดงค่าความหน่วงเป็นมิลลิวินาที และราคาใน Market Watch ต้องขยับ

เคยลง MT5 บน Mac รุ่นเก่ามาก่อน: MetaQuotes แนะนำให้ดูเวอร์ชัน Wine ใน Journal ตอนเปิดโปรแกรม ถ้าต่ำกว่า 8.0.1 ควรถอนการติดตั้งแล้วลงใหม่ โดยลบโฟลเดอร์ Metatrader 5 และ net.metaquotes.wine.metatrader5 ใน ~/Library/Application Support/ ด้วย ก่อนลบให้สำรอง Template ตัวชี้วัด และไฟล์ EA ไว้ก่อน

MT5 บน MacBook ทำอะไรได้ดี

  • ดูกราฟและวิเคราะห์ราคา กราฟ ตัวชี้วัด และเครื่องมือวาดใช้ได้ครบ
  • เทรดมือ เปิด ปิด และแก้ Stop Loss กับ Take Profit ได้เหมือนบน Windows
  • ติดตามบัญชีที่ EA รันอยู่ที่อื่น ล็อกอินบัญชีเดียวกันเพื่อดูออเดอร์และตัวเลขบัญชี โดยไม่ต้องรัน EA บน Mac
  • ฝึกใช้โปรแกรม ลองเมนู คีย์ลัด และหน้าต่างต่าง ๆ ก่อนไปตั้งค่าบนเครื่อง Windows หรือ VPS

ข้อจำกัดเมื่อรัน EA บน Mac

EA บน Mac ลากลงกราฟได้เหมือนบน Windows แต่การรันให้เสถียรทั้งสัปดาห์เป็นอีกเรื่องหนึ่ง มีสามข้อหลักที่ต้องชั่งน้ำหนัก

1. EA ที่ต้องใช้ DLL

EA บางตัวเรียกใช้ไฟล์ DLL ซึ่งเป็นไลบรารีของ Windows สำหรับงานอย่างตรวจสิทธิ์ใช้งานหรือเชื่อมต่อภายนอก ใน Wine ไลบรารีเหล่านี้อาจทำงานได้ ทำงานได้บางส่วน หรือไม่ทำงานเลย ขึ้นกับว่า DLL ตัวนั้นพึ่งความสามารถของ Windows มากแค่ไหน และผู้พัฒนา EA ส่วนใหญ่ทดสอบบน Windows เท่านั้น ถ้า EA ของคุณต้องติ๊ก Allow DLL imports ให้ถามผู้พัฒนาก่อนว่ารองรับ Mac หรือไม่ พื้นฐานเรื่องนี้อยู่ในAllow DLL imports คืออะไร

2. Mac ต้องตื่นตลอดเวลาที่ตลาดเปิด

EA ทำงานเฉพาะตอนโปรแกรม MT5 เปิดอยู่และเชื่อมต่ออินเทอร์เน็ต ถ้า MacBook หลับเพราะพับฝาจอ แบตเตอรี่ต่ำ หรือถึงเวลาพักเครื่องตามที่ตั้งไว้ EA จะหยุดทันที ต้องตั้งไม่ให้เครื่องหลับในส่วนพลังงานหรือแบตเตอรี่ของ System Settings เสียบสายชาร์จไว้ และระวังการอัปเดต macOS ที่สั่งรีสตาร์ตเครื่องเอง

3. ประสิทธิภาพและการอัปเดต

การแปลผ่าน Wine ใช้ทรัพยากรมากกว่ารันบน Windows ตรง ๆ ถ้าเปิดหลายกราฟพร้อมกัน เครื่องอาจหน่วงหรือโปรแกรมค้างเป็นช่วง และเมื่อ macOS อัปเดตครั้งใหญ่ บางครั้งต้องรอตัวติดตั้งรุ่นใหม่ให้รองรับ

ทางเลือกสำหรับคนใช้ Mac ที่อยากรัน EA

ทางเลือกEA ที่ใช้ DLLMac ต้องเปิดตลอดไหมข้อสังเกต
MT5 สำหรับ macOSไม่แน่นอน ขึ้นกับ EAต้องเปิดติดตั้งง่ายที่สุด เหมาะกับดูกราฟและเทรดมือ
Windows ในเครื่องเสมือนบน Macใกล้เคียง Windows แต่ต้องทดสอบต้องเปิดต้องมีโปรแกรมเครื่องเสมือนและไลเซนส์ Windows กินแรมและแบตมาก
Boot Campเป็น Windows จริงต้องเปิดและบูตเป็น Windowsมีเฉพาะ Mac ชิป Intel ใช้กับ Mac ชิป Apple ไม่ได้
Windows VPSเป็น Windows จริงไม่ต้อง ปิด Mac ได้มีค่าเช่ารายเดือน แต่ทำงานต่อเนื่องที่สุด
MT5 บนเว็บเบราว์เซอร์รัน EA ไม่ได้ไม่เกี่ยวใช้ดูบัญชีและเทรดมือเท่านั้น

Windows บน Mac ชิป Apple

หน้าช่วยเหลือของ Microsoft ระบุว่า Mac ชิป M1 M2 M3 ใช้ Windows 11 รุ่น Arm ผ่าน Parallels Desktop ได้ หรือใช้ Windows 365 ซึ่งเป็นคอมพิวเตอร์ Windows บนคลาวด์แบบรายเดือน และระบุว่าโปรแกรมแบบ x64 ใช้งานบน Windows รุ่นนี้ได้ผ่านการจำลอง ทั้งสองทางยังต้องทดสอบ EA ของคุณจริงก่อนใช้เงินจริง และถ้าเป็นเครื่องเสมือนบน Mac ตัว Mac ก็ยังต้องเปิดตลอดเหมือนเดิม

Windows VPS: ทางที่ตรงที่สุดสำหรับ EA บน Mac

Windows VPS คือคอมพิวเตอร์ Windows ที่เปิดอยู่ในศูนย์ข้อมูลตลอด 24 ชั่วโมง คุณติดตั้ง MT5 และ EA บนเครื่องนั้นครั้งเดียว แล้วใช้ Mac แค่เปิดดูหรือแก้ค่าเมื่อจำเป็น ปิด Mac หรือพกออกไปข้างนอกได้โดยที่ EA ยังทำงาน หลักการเลือกและดูแล VPS อยู่ในคู่มือ VPS สำหรับ EA

  1. ติดตั้ง Windows App บน Mac

    ดาวน์โหลด Windows App ของ Microsoft จาก Mac App Store แอปนี้คือชื่อใหม่ของ Microsoft Remote Desktop ต้องใช้ macOS 12.0 ขึ้นไปตามคู่มือเริ่มต้น Windows App ของ Microsoft (ภาษาอังกฤษ)

  2. เพิ่มเครื่อง VPS

    ใส่ที่อยู่ IP ชื่อผู้ใช้ และรหัสผ่านที่ได้จากผู้ให้บริการ VPS แล้วเชื่อมต่อ

  3. ติดตั้ง MT5 และ EA บน VPS

    ทำตามขั้นตอนเดียวกับคอม Windows ทุกอย่าง ทั้งการล็อกอิน การวางไฟล์ EA และการติ๊กตัวเลือกที่ EA ต้องใช้

  4. ออกจากหน้าจอโดยไม่ปิด MT5

    ปิดหน้าต่าง Windows App ได้เลย อย่าสั่ง Sign out หรือ Shut down ใน Windows เพราะ MT5 จะถูกปิดไปด้วย

ขั้นตอนเข้า VPS แบบละเอียดพร้อมภาพอยู่ในหน้าใช้ VPS จากคอมพิวเตอร์ ซึ่งใช้หลักเดียวกันกับ Mac

เลือกทางไหนดี: ดูจากสิ่งที่คุณจะทำ

ไม่ใช่ทุกคนที่ใช้ MT5 Mac ต้องเช่า VPS ลองจับคู่การใช้งานของคุณกับคำแนะนำด้านล่าง

  • ดูกราฟ เทรดมือ เรียนรู้โปรแกรม ใช้ MT5 สำหรับ macOS ได้เลย ไม่ต้องลงทุนเพิ่ม
  • ทดสอบ EA ย้อนหลังเป็นครั้งคราว ลองบน MT5 Mac ได้ถ้า EA ไม่ต้องใช้ DLL ถ้าต้องใช้ ให้ทดสอบบนเครื่อง Windows หรือ VPS เพื่อให้ผลตรงกับเครื่องที่จะใช้จริง
  • รัน EA กับเงินจริงทั้งสัปดาห์ ใช้ Windows VPS แล้วใช้ Mac เป็นหน้าจอควบคุม
  • มีคอม Windows ที่บ้านอยู่แล้ว รันบนเครื่องนั้นได้ แต่ต้องเปิดเครื่องและต่อเน็ตตลอดเหมือนกัน ลองเทียบกับ VPS ก่อนตัดสินใจ

สิ่งที่ไม่ควรทำคือรัน EA บน MacBook ที่พกไปทำงานทุกวัน เพราะทุกครั้งที่พับฝา ย้ายเครือข่าย Wi-Fi หรือแบตใกล้หมด EA จะหยุดหรือหลุดการเชื่อมต่อโดยที่คุณอาจไม่รู้ตัว ผลคือคุณอาจเปิดดูบัญชีทีหลังแล้วพบว่าออเดอร์ไม่ได้ถูกจัดการตามที่ตั้งใจ

EA WING กับผู้ใช้ Mac

EA WING ออกแบบให้รันบน MT5 ใน Windows หรือ Windows VPS ใช้ไฟล์ .ex5 ไฟล์เดียว วางบนกราฟ XAUUSD M1 และต้องติ๊ก Allow DLL imports ผู้ใช้ Mac จึงควรรัน EA WING บน Windows VPS แล้วใช้ Mac หรือมือถือไว้เปิดดู ถ้าอยากใช้วิธีอื่น ให้คุยกับทีมงานทาง LINE ก่อนเริ่ม จะได้ไม่เสียเวลาแก้ปัญหาที่เลี่ยงได้

ส่วนการติดตามผลระหว่างวัน ใช้ MT5 สำหรับ macOS หรือแอปบนมือถือล็อกอินบัญชีเดียวกันได้เลย จำไว้ว่าแอปมือถือและ iPad รัน EA ไม่ได้ เหตุผลอธิบายไว้ในEA รันบนมือถือได้ไหม

คำเตือนความเสี่ยง: เครื่องที่หลับ หลุดเน็ต หรือปิดไปเองระหว่างที่ EA มีออเดอร์เปิดอยู่ อาจทำให้ระบบจัดการออเดอร์ไม่ได้ตามที่ออกแบบ การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ทดสอบการตั้งค่าบนบัญชีเดโมก่อน และอ่าน ความเสี่ยงของการรัน EA ก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่อง MT5 บน Mac

MT5 บน MacBook ชิป M1 หรือ M2 ใช้ได้ไหม?

ใช้ได้ คู่มือของ MetaTrader 5 ระบุว่าตัวติดตั้ง macOS รองรับชิป Apple ทุกรุ่นตั้งแต่ M1 ส่วนการรัน EA ยังมีข้อจำกัดเรื่อง DLL และเครื่องที่ต้องเปิดตลอดเหมือน Mac รุ่นอื่น

วางไฟล์ EA ไว้ที่ไหนบน Mac?

ใน MT5 ไปที่ File → Open Data Folder แล้วเข้า MQL5 → Experts เหมือนบน Windows ถ้าเมนูนี้ไม่เปิดหน้าต่างให้ ใน Finder กด Cmd+Shift+G แล้วไปที่โฟลเดอร์ของโปรแกรมใน ~/Library/Application Support/ ตามตารางด้านบน

ใช้แอป MT5 ของ iPhone บน Mac ชิป Apple แทนได้ไหม?

ถึงจะเปิดได้ ก็มีความสามารถเท่าแอปมือถือ คือดูราคา ดูบัญชี และเทรดมือ แอปมือถือรัน EA ไม่ได้ ถ้าต้องการรัน EA ต้องใช้ MT5 เวอร์ชันคอมพิวเตอร์บน Windows หรือ VPS

เช่า VPS แล้วยังต้องเปิด Mac ทิ้งไว้ไหม?

ไม่ต้อง MT5 และ EA ทำงานอยู่บน VPS เอง Mac เป็นแค่หน้าจอที่ใช้เข้าไปดู ปิดหน้าต่าง Windows App หรือปิด Mac ได้ ตราบใดที่ไม่ได้สั่ง Sign out หรือ Shut down เครื่อง VPS

อ่านต่อ

  • คู่มือใช้งาน MT5 ตั้งแต่เริ่มต้น
  • VPS สำหรับ EA: คู่มือเลือก ตั้งค่า และดูแล
  • Allow DLL imports คืออะไร
  • ตั้ง MT5 เป็นภาษาไทย
