อัปเดต EA ให้ปลอดภัยมีหลักง่าย ๆ สามข้อ เปลี่ยนไฟล์ในจังหวะที่ไม่มีออเดอร์ค้าง สำรองค่าตั้งเดิมไว้ก่อน และตรวจให้แน่ใจว่าเวอร์ชันใหม่ทำงานจริงหลังเปลี่ยน ปัญหาที่เจอบ่อยมักไม่ได้อยู่ที่ตัวไฟล์ใหม่ แต่อยู่ที่ช่วงรอยต่อระหว่างเวอร์ชันเก่ากับเวอร์ชันใหม่ ถ้ายังไม่แน่ใจว่าEA หรือบอทเทรดทำงานยังไงบนกราฟ อ่านพื้นฐานตรงนั้นก่อนจะเข้าใจขั้นตอนด้านล่างได้ง่ายขึ้น

สรุปสั้น: รอให้ EA ไม่มีออเดอร์เปิดอยู่ · ปิด Algo Trading · สำรองไฟล์เก่าและค่า Inputs · ถอด EA เก่าออกจากกราฟ · วางไฟล์ใหม่ใน MQL5 → Experts · ลาก EA ใหม่ลงกราฟเดิมแล้วตั้งค่าให้ครบ · เปิด Algo Trading แล้วดูแท็บ Experts ถ้ามีออเดอร์ค้างและจำเป็นต้องเปลี่ยนจริง ให้ถามผู้พัฒนาก่อนว่าเวอร์ชันใหม่รับช่วงออเดอร์เดิมได้ไหม

ทำไมการอัปเดต EA ถึงทำให้ออเดอร์ค้างได้

ออเดอร์ที่เปิดอยู่เก็บไว้ที่เซิร์ฟเวอร์ของโบรกเกอร์ ถอด EA ออกจากกราฟแล้วออเดอร์ไม่หายไปไหน แต่งานดูแลที่ EA ทำอยู่ เช่น ปิดตามเงื่อนไข เลื่อนจุดตัดขาดทุน หรือคุมชุดออเดอร์ จะหยุดทันที ช่วงที่ไม่มี EA บนกราฟ ออเดอร์จึงอยู่ในสภาพไม่มีใครดูแล

ปัญหาที่หนักกว่าคือเวอร์ชันใหม่อาจจำออเดอร์เดิมไม่ได้ ซึ่งเกิดได้หลายทาง

  • เลขประจำออเดอร์เปลี่ยน ถ้าเวอร์ชันใหม่ใช้ Magic Number ไม่เหมือนเดิม มันจะมองข้ามออเดอร์ของเวอร์ชันเก่า อ่านกลไกเรื่องเลขประจำออเดอร์ Magic Number
  • ค่าตั้งกลับเป็นค่าเริ่มต้น ไฟล์ใหม่ที่ลากลงกราฟจะเริ่มด้วยค่าเริ่มต้นของเวอร์ชันนั้น ไม่ได้ดึงค่าที่คุณเคยปรับไว้มาให้
  • ข้อมูลภายในไม่ต่อเนื่อง EA บางตัวจำสถานะของตัวเองไว้ในไฟล์หรือตัวแปรของเทอร์มินัล เวอร์ชันใหม่อาจอ่านรูปแบบเดิมไม่ได้
  • เขียนทับไฟล์ขณะ EA ยังติดอยู่บนกราฟ อาจทำให้ EA ถูกโหลดใหม่กลางคันในจังหวะที่คุณยังไม่ได้ตรวจค่า

ตัวอย่างสมมติ: เปลี่ยนไฟล์คืนวันศุกร์

เทรดเดอร์คนหนึ่งได้ไฟล์เวอร์ชันใหม่ตอนดึกวันศุกร์ ขณะที่ยังมีออเดอร์ทองคำเปิดอยู่สามไม้ เขาถอดตัวเก่า ลากตัวใหม่ลงกราฟ แล้วเข้านอน เวอร์ชันใหม่ใช้เลขประจำออเดอร์ไม่เหมือนเดิม จึงไม่ได้ดูแลสามไม้นั้นเลยตลอดช่วงที่ตลาดยังเปิด เขามารู้ตัวตอนเปิดดูมือถือวันเสาร์ เรื่องนี้แต่งขึ้นเพื่ออธิบายวิธีคิด แต่แบบแผนของปัญหาเกิดขึ้นจริงได้ทุกเมื่อ ถ้ารอจนออเดอร์ปิดครบ หรือถามผู้พัฒนาก่อน ปัญหานี้จะไม่เกิด

เลือกจังหวะเปลี่ยนเวอร์ชัน EA ให้ถูก

ขั้นตอนเปลี่ยนไฟล์ใช้เวลาไม่กี่นาที สิ่งที่ตัดสินว่าจะราบรื่นหรือไม่คือจังหวะที่เลือก

สถานะตอนจะเปลี่ยนความเสี่ยงข้อแนะนำ
ไม่มีออเดอร์ของ EA เปิดอยู่ ตลาดเปิดต่ำที่สุดจังหวะที่ดีที่สุด เปลี่ยนแล้วเห็นผลในแท็บ Experts ทันที
ไม่มีออเดอร์ ตลาดปิดช่วงสุดสัปดาห์ต่ำเปลี่ยนไฟล์ได้ แต่ต้องกลับมาตรวจอีกครั้งตอนตลาดเปิด
มีออเดอร์ที่มีจุดตัดขาดทุนตั้งไว้ฝั่งโบรกเกอร์ปานกลางรอให้ปิดก่อนถ้ารอได้
มีชุดออเดอร์ที่ EA กำลังดูแลสูงรอให้ปิดครบ หรือถามผู้พัฒนาก่อนว่ารับช่วงต่อได้ไหม
ใกล้ข่าวแรงหรือราคากำลังผันผวนสูงเลื่อนออกไป ช่วงนี้ไม่ควรมีช่องว่างที่ไม่มีใครดูแลออเดอร์

เตรียมตัวก่อนเปลี่ยนไฟล์

ใช้เวลาเตรียมสิบนาที ดีกว่ามานั่งแก้ปัญหาทั้งคืน

  • อ่านหมายเหตุของเวอร์ชันใหม่ มีค่าตั้งใหม่ไหม ค่าเดิมเปลี่ยนชื่อหรือความหมายไหม ต้องตั้งอะไรเพิ่ม
  • รับไฟล์จากช่องทางของผู้พัฒนาเท่านั้น ไฟล์ที่ส่งต่อกันในกลุ่มแชตอาจไม่ใช่เวอร์ชันจริง
  • สำรองไฟล์ .ex5 เวอร์ชันเก่า เก็บไว้ในโฟลเดอร์นอก MQL5 เพื่อย้อนกลับได้
  • บันทึกค่า Inputs กด Save เป็นไฟล์ .set หรืออย่างน้อยถ่ายภาพหน้าจอทุกแท็บ วิธีอยู่ในSet File ของ EA คืออะไร
  • นับเครื่องและบัญชีที่ต้องเปลี่ยน คอมที่บ้าน VPS และทุกบัญชีที่รัน EA ตัวนี้
  • อัปเดต MT5 ให้เป็น build ปัจจุบัน ถ้าผู้พัฒนาแจ้งว่าเวอร์ชันใหม่ต้องการ

ขั้นตอนอัปเดต EA ทีละขั้น

  1. ยืนยันว่าไม่มีออเดอร์ของ EA เปิดอยู่

    เปิด Toolbox (Ctrl+T) แท็บ Trade ดูรายการออเดอร์ ถ้ารัน EA หลายตัวในบัญชีเดียว ชี้เมาส์ที่ออเดอร์เพื่อดูเลขประจำ EA

  2. ปิด Algo Trading

    กดปุ่ม Algo Trading บนแถบเครื่องมือให้ดับ หรือกด Ctrl+E กันไม่ให้มีคำสั่งใหม่ออกไประหว่างเปลี่ยน

  3. ถอด EA เก่าออกจากกราฟ

    คลิกขวาที่ชื่อหรือไอคอน EA มุมขวาบนของกราฟแล้วเลือกคำสั่งถอด EA หรือใช้หน้าต่าง Expert List แล้วกด Remove ไม่ต้องปิดกราฟ เพราะจะใช้กราฟเดิมต่อ

  4. ย้ายไฟล์เก่าออกจากโฟลเดอร์ Experts

    เลือก File → Open Data Folder → MQL5 → Experts ย้ายไฟล์ .ex5 เวอร์ชันเก่าไปเก็บที่โฟลเดอร์สำรอง ไม่ให้ Navigator มีสองเวอร์ชันวางคู่กันจนลากผิดตัว

  5. วางไฟล์ใหม่แล้วรีเฟรช

    คัดลอกไฟล์ .ex5 เวอร์ชันใหม่ลงโฟลเดอร์ Experts แล้วคลิกขวาใน Navigator (Ctrl+N) เลือก Refresh

  6. ลาก EA ใหม่ลงกราฟเดิม

    ตรวจว่ากราฟยังเป็นสัญลักษณ์และกรอบเวลาเดิม ติ๊กอนุญาตการเทรดอัตโนมัติ และอนุญาต DLL ถ้า EA ต้องใช้ แล้วโหลดหรือกรอกค่า Inputs ให้ตรงกับที่บันทึกไว้

  7. เปิด Algo Trading แล้วตรวจ

    ไอคอนข้างชื่อ EA ต้องเป็นสีฟ้า แท็บ Experts ต้องมีข้อความว่าโหลดสำเร็จและไม่มีข้อผิดพลาด ชื่อหรือเวอร์ชันที่ EA แสดงบนกราฟต้องเป็นตัวใหม่

วิธีถอด EA ออกจากกราฟแบบต่าง ๆ ดูเพิ่มได้ในคู่มือ Algo Trading ของ MetaTrader 5 (ภาษาอังกฤษ) ถ้าข้อความในแท็บ Experts อ่านไม่ออก ดูวิธีอ่านในMT5 Journal และแท็บ Experts

ถ้ามีออเดอร์ค้าง แต่จำเป็นต้องอัปเดต

บางครั้งผู้พัฒนาแจ้งให้อัปเดตเร่งด่วน หรือ EA ไม่เคยว่างจากออเดอร์นานพอ ให้ไล่ตามลำดับนี้

  • ถามผู้พัฒนาก่อน เวอร์ชันใหม่ใช้เลขประจำออเดอร์เดิมไหม และรับช่วงดูแลออเดอร์ที่เปิดจากเวอร์ชันเก่าได้หรือเปล่า
  • ถ้ารับช่วงได้ ใช้กราฟเดิม ค่าตั้งเดิม ทำให้เสร็จเร็วในช่วงตลาดเงียบ แล้วตรวจว่า EA ใหม่มองเห็นออเดอร์เดิมจริง
  • ถ้ารับช่วงไม่ได้ รอให้ออเดอร์ปิดตามปกติ หรือจัดการตามกฎในแผนการเทรดของคุณ อย่าตัดสินใจปิดเพราะรีบอัปเดต
  • อย่าลบไฟล์เวอร์ชันเก่า จนกว่าออเดอร์จากเวอร์ชันนั้นจะปิดครบ เผื่อต้องย้อนกลับ

มีหลายเครื่องหรือหลายบัญชี ต้องทำครบทุกที่

MT5 แต่ละตัวมีโฟลเดอร์ของตัวเอง เปลี่ยนไฟล์บนคอมที่บ้านแล้ว MT5 บน VPS ยังใช้เวอร์ชันเก่าอยู่ ต้องทำทีละเครื่องทีละเทอร์มินัล และจดไว้ว่าเปลี่ยนที่ไหนไปแล้วบ้าง ภาพรวมการดูแลเครื่องที่รันตลอดเวลาอยู่ในการดูแล VPS ที่รัน EA

ระวังอีกเรื่องหนึ่ง ระหว่างย้ายหรืออัปเดต อย่าปล่อยให้ EA ตัวเดียวกันรันพร้อมกันสองเครื่องบนบัญชีเดียว เพราะทั้งสองอาจส่งคำสั่งซ้อนกัน ถ้าคุณดูแลหลายบัญชี การทำรายการบัญชีกับเครื่องที่รันไว้ช่วยได้มาก ดูแนวทางในรัน EA หลายบัญชีพร้อมกัน

หลังอัปเดต: เช็กอะไรใน 24 ชั่วโมงแรก

  • ชื่อและเวอร์ชันของ EA บนกราฟเป็นตัวใหม่ และไอคอนเป็นสีฟ้า
  • แท็บ Experts และ Journal ไม่มีข้อความผิดพลาดซ้ำ ๆ
  • ค่าใน Inputs ตรงกับที่บันทึกไว้ หรือตรงกับค่าที่ผู้พัฒนาแนะนำสำหรับเวอร์ชันใหม่
  • ออเดอร์แรกหลังอัปเดตมีขนาดและพฤติกรรมตามที่คาดไว้
  • แจ้งเตือนเข้ามือถือยังทำงานตามปกติ

ถ้ามีอะไรผิดปกติ ให้ปิด Algo Trading แล้วถ่ายภาพกราฟกับแท็บ Experts ส่งให้ผู้พัฒนา ก่อนจะลองแก้เอง

ย้อนกลับเวอร์ชันเดิมเมื่อจำเป็น

ถ้าเวอร์ชันใหม่มีปัญหาและผู้พัฒนาแนะนำให้ย้อนกลับ ให้ทำขั้นตอนเดียวกันแบบกลับด้าน รอจังหวะที่ไม่มีออเดอร์ ปิด Algo Trading ถอด EA ใหม่ ย้ายไฟล์ใหม่ออก นำไฟล์เก่าจากโฟลเดอร์สำรองกลับมา แล้วโหลดค่าตั้งชุดเดิม นี่คือเหตุผลที่ต้องเก็บไฟล์เก่าและไฟล์ .set ไว้ก่อนเริ่ม

ผู้ใช้ EA WING เปลี่ยนเวอร์ชันอย่างไร

[eawing_brand] เวอร์ชันปัจจุบันคือ 4.2 เป็นไฟล์ EA_WING_V4.2.ex5 ไฟล์เดียว โหมด Lite และ Full อยู่ในไฟล์ ไม่มีไฟล์ .set ให้ต้องย้าย เมื่อมีเวอร์ชันใหม่ ให้รับไฟล์จากทีมงานโดยตรงและถามทีมงานทาง LINE ก่อนเปลี่ยน หลังวางไฟล์ใหม่ ให้ตรวจสามจุด

  • EA อยู่บนกราฟ XAUUSD กรอบเวลา M1 (ชื่อสัญลักษณ์อาจมีตัวต่อท้ายตามโบรกเกอร์)
  • ปุ่ม Algo Trading เปิด และติ๊ก Allow DLL imports แล้ว
  • การ์ดล็อกอินบนกราฟเป็นสีเขียว ถ้าเป็นสีเหลืองคือกำลังตรวจหรืออยู่ในช่วงผ่อนผัน ถ้าเป็นสีแดงให้ส่งภาพการ์ดให้ทีมงาน

ตรวจโหมดบนแดชบอร์ดให้ตรงกับที่ตั้งใจด้วย ถ้าจะสลับโหมด การสลับจะมีผลหลังชุดออเดอร์ที่เปิดอยู่ปิดครบแล้ว ขั้นตอนติดตั้งทั้งหมดอยู่ในหน้าวิธีลง EA WING ใน MT5

คำเตือนความเสี่ยง: เวอร์ชันใหม่ไม่ได้แปลว่าผลจะดีขึ้นเสมอ และช่วงเปลี่ยนไฟล์มีความเสี่ยงเพิ่มถ้ามีออเดอร์เปิดอยู่ การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตของเวอร์ชันใดก็ตามไม่ได้รับประกันผลในอนาคต อ่านความเสี่ยงของการเทรดด้วย EAก่อนใช้เงินจริง

ไม่จำเป็นต้องทันที ให้อ่านว่าเวอร์ชันใหม่แก้อะไร ถ้าเป็นการแก้ปัญหาสำคัญ ผู้พัฒนามักแจ้งให้เปลี่ยนเร็ว ถ้าเป็นการเพิ่มความสามารถ เลือกจังหวะที่ไม่มีออเดอร์ค้างได้ แต่ไม่ควรค้างเวอร์ชันเก่าไว้นานจนผู้พัฒนาไม่ดูแลแล้ว

อัปเดต MT5 กับอัปเดต EA ต่างกันยังไง?

อัปเดต MT5 คือการเปลี่ยนตัวโปรแกรมเทรด ซึ่ง MetaQuotes ปล่อยเป็นระยะและมักติดตั้งตอนเปิดโปรแกรมใหม่ ส่วนการเปลี่ยนเวอร์ชัน EA คือการเปลี่ยนไฟล์ .ex5 ของผู้พัฒนา หลัง MT5 รีสตาร์ตจากการอัปเดต ให้ตรวจว่า EA ยังอยู่บนกราฟและไอคอนยังเป็นสีฟ้า

อัปเดตแล้วต้องขอสิทธิ์ใช้งานใหม่ไหม?

ขึ้นกับระบบของผู้ขายแต่ละราย ควรถามก่อนเปลี่ยน สำหรับ EA WING ดูได้จากการ์ดล็อกอินบนกราฟหลังวางไฟล์ใหม่ ถ้าเป็นสีเขียวแปลว่าตรวจสิทธิ์ผ่าน ถ้าไม่ใช่ ส่งเลขบัญชีและชื่อเซิร์ฟเวอร์ให้ทีมงานตรวจได้

วางไฟล์ใหม่ชื่อเดิมทับไฟล์เก่าเลยได้ไหม?

ทำได้ แต่ไม่แนะนำให้ทำขณะ EA ยังติดอยู่บนกราฟ เพราะคุณคุมจังหวะที่ EA ถูกโหลดใหม่ไม่ได้ และไม่มีไฟล์เก่าเหลือไว้ย้อนกลับ ถอด EA ออกก่อนแล้วย้ายไฟล์เก่าไปเก็บจะปลอดภัยกว่า

อ่านต่อ

  • Magic Number ใน EA คืออะไร
  • Set File ของ EA: บันทึกค่าก่อนอัปเดต
  • MT5 Journal และแท็บ Experts: อ่าน Log หาสาเหตุ
  • VPS สำหรับ EA: เลือกและดูแลให้รันต่อเนื่อง

ถ้าอยากให้ทีมงานช่วยดูการติดตั้งและการตั้งค่าตั้งแต่ต้น ดูราคาแพ็กเกจของ EA WING ซึ่งมีแบบที่รวมการช่วยติดตั้ง แล้วทักทีมงานคนไทยมาถามก่อนได้
