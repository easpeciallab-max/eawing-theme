Windows Update VPS ที่ปล่อยไว้ตามค่าเริ่มต้น อาจติดตั้งอัปเดตแล้วรีสตาร์ทเครื่องในเวลาที่ตลาดยังเปิดอยู่ MT5 ปิดตาม EA หยุดกลางคัน และคุณมักรู้ตัวตอนเช้า ทางแก้ไม่ใช่ปิดอัปเดตทิ้ง แต่ทำให้การรีสตาร์ทเกิดในเวลาที่คุณเลือก หน้านี้รวมวิธีตั้งทั้งบน Windows Server และ Windows 11 ส่วนภาพรวมการดูแลเครื่องอยู่ในคู่มือ VPS สำหรับ EA ฉบับเต็ม

สรุปสั้น: อย่าปิด Windows Update · ตั้งโซนเวลาของ VPS เป็นเวลาไทยก่อน เพราะตารางอัปเดตอิงเวลาเครื่อง · ตั้งให้ดาวน์โหลดอย่างเดียวหรือแจ้งก่อนติดตั้ง แล้วติดตั้งและรีสตาร์ทเองช่วงตลาดปิดสุดสัปดาห์ · หลังรีสตาร์ททุกครั้ง เช็กว่า MT5 และ EA กลับมาครบ

ทำไม Windows Update ทำให้ EA หยุด

การอัปเดตส่วนใหญ่ของ Windows ต้องรีสตาร์ทเครื่องเพื่อให้มีผล และการรีสตาร์ทปิดโปรแกรมทุกตัว รวมถึง MT5 ปัญหาไม่ได้อยู่ที่การอัปเดต แต่อยู่ที่จังหวะเวลา

  • Windows เลือกเวลาเอง ระบบพยายามรีสตาร์ทนอกช่วง Active hours แต่ตลาด Forex และทองคำเปิดเกือบตลอดวันในวันทำการ ช่วงนอก Active hours จึงยังตรงกับตลาดเปิดอยู่ดี
  • ระหว่างติดตั้งเข้าเครื่องไม่ได้ ช่วงที่ Windows กำลังติดตั้งและบูตใหม่ Remote Desktop ใช้ไม่ได้ชั่วคราว คนที่ไม่รู้มักคิดว่า VPS เสีย อาการนี้อธิบายไว้ในบทความเข้า VPS ไม่ได้
  • ไม่มีใครเปิด MT5 กลับมา ถ้าไม่ได้ตั้งให้ MT5 เปิดเองหลังบูต EA จะหยุดจนกว่าคุณจะรีโมตเข้าไป

อย่าปิด Windows Update ทิ้ง

วิธีที่หลายคนเลือกคือปิดบริการ Windows Update ไปเลย ฟังดูง่ายแต่แลกกับความเสี่ยงที่ใหญ่กว่า VPS เปิดรับการเชื่อมต่อจากอินเทอร์เน็ตตลอดเวลา และล็อกอินบัญชีเทรดค้างไว้ เครื่องที่ไม่ได้รับแพตช์ความปลอดภัยเป็นเป้าที่ง่ายขึ้นทุกเดือน การดูแลด้านนี้ทั้งหมดรวมไว้ในบทความตั้งรหัสและความปลอดภัย VPS

เป้าหมายที่ถูกของการตั้ง Windows Update VPS คือ ให้อัปเดตยังเข้ามาครบ แต่การติดตั้งและรีสตาร์ทเกิดตอนที่ตลาดปิดและคุณพร้อมตรวจเครื่อง

ตั้งโซนเวลาของ VPS เป็นเวลาไทยก่อน

ขั้นนี้สั้นแต่สำคัญที่สุด ตารางเวลาของ Windows Update ทุกแบบอิงนาฬิกาของเครื่อง ไม่ใช่เวลาที่คุณอยู่ VPS ที่ตั้งอยู่ต่างประเทศมักมากับโซนเวลาของประเทศนั้นหรือเวลาสากล

ตัวอย่าง: บน Windows Server ถ้าเลือกอัปเดตอัตโนมัติผ่าน SConfig ระบบจะตรวจและติดตั้งทุกวันตอนตี 3 ตามเวลาของเครื่อง ถ้าเครื่องตั้งเป็นเวลาสากล (UTC) ตี 3 ของเครื่องคือ 10 โมงเช้าตามเวลาไทย ตรงกับตลาดเปิดพอดี

  1. เปิดหน้าตั้งเวลา

    บน VPS เปิด Settings → Time & Language → Date & time

  2. เลือกโซนเวลา

    ในช่อง Time zone เลือก (UTC+07:00) Bangkok, Hanoi, Jakarta ประเทศไทยไม่มีการปรับเวลาตามฤดูกาล ตัวเลขนี้จึงคงที่ทั้งปี

  3. ตรวจนาฬิกามุมขวาล่าง

    ต้องตรงกับนาฬิกาบนมือถือของคุณ ไฟล์ Log ของ MT5 ก็จะเทียบกับเหตุการณ์จริงได้ง่ายขึ้นด้วย

อย่าสับสนระหว่างนาฬิกาของ VPS กับเวลาบนกราฟ MT5 เวลาบนกราฟคือเวลาเซิร์ฟเวอร์ของโบรกเกอร์ ซึ่งต่างจากเวลาไทยและอาจเลื่อนตามฤดูกาล วิธีอ่านอยู่ในบทความเวลาใน MT5 ไม่ตรงเวลาไทย

ตั้ง Windows Update VPS ตามรุ่นของ Windows

หน้าจอและเครื่องมือต่างกันตามรุ่น ดูก่อนว่า VPS ของคุณเป็นรุ่นไหน กด Windows + R พิมพ์ winver แล้วกด Enter

Windows Server: ใช้ SConfig

SConfig เป็นเครื่องมือตั้งค่าของ Windows Server ที่ใช้ได้ทั้งเครื่องแบบ Server Core และแบบมีหน้าจอ Desktop ตามเอกสารSConfig ของ Microsoft เมนู Update setting มีสามค่า

  • Automatic ตรวจและติดตั้งทุกวันตอนตี 3 ตามเวลาของเครื่อง ไม่เหมาะกับ VPS ที่รัน EA
  • Download only ตรวจและดาวน์โหลดไว้ แล้วแจ้งว่าพร้อมติดตั้ง ค่านี้เหมาะที่สุดสำหรับคนส่วนใหญ่
  • Manual ไม่ตรวจเองเลย คุณต้องสั่งตรวจเองทุกครั้ง เหมาะกับคนที่มีวินัยทำรอบประจำสัปดาห์จริง

วิธีตั้ง: คลิกขวาที่ปุ่ม Start เปิด PowerShell แบบผู้ดูแลระบบ พิมพ์ SConfig แล้วกด Enter เลือกเมนู 5 (Update setting) แล้วพิมพ์ D เพื่อเลือก Download only

Group Policy: Configure Automatic Updates

ถ้าอยากตั้งละเอียดกว่านั้น ใช้ gpedit.msc ไปที่ Computer Configuration → Administrative Templates → Windows Components → Windows Update แล้วเปิดนโยบาย Configure Automatic Updates (ในบางรุ่นอยู่ในโฟลเดอร์ย่อย Manage end user experience) ตามเอกสารการตั้งค่า Windows Update ตัวเลือกที่เกี่ยวข้องมีดังนี้

Windows 11: Active hours และการหยุดชั่วคราว

ถ้า VPS เป็น Windows 11 ไปที่ Settings → Windows Update → Advanced options → Active hours เลือก Manually แล้วตั้งช่วงที่ไม่ต้องการให้รีสตาร์ท ส่วนปุ่ม Pause updates หยุดอัปเดตได้สูงสุด 35 วัน และเมื่อใช้ครบแล้วต้องติดตั้งอัปเดตล่าสุดก่อนจึงหยุดได้อีก จึงเหมาะกับช่วงสั้น ๆ ที่ไม่สะดวก ไม่ใช่วิธีถาวร

ช่วงไหนปลอดภัยสำหรับการรีสตาร์ท

ช่วงที่ดีที่สุดคือหลังตลาดปิดสัปดาห์ ซึ่งสำหรับโบรกเกอร์ส่วนใหญ่ตรงกับช่วงเช้ามืดวันเสาร์ตามเวลาไทย ไปจนถึงก่อนตลาดเปิดอีกครั้งช่วงเช้ามืดวันจันทร์ เวลาที่แน่นอนต่างกันตามโบรกเกอร์และสัญลักษณ์

  • ดูเวลาซื้อขายจริงที่ Market Watch คลิกขวาที่ XAUUSD เลือก Specification แล้วดูหัวข้อ Sessions เวลาในหน้านี้เป็นเวลาเซิร์ฟเวอร์ ต้องแปลงเป็นเวลาไทยเอง
  • สหรัฐฯ ปรับเวลาตามฤดูกาล สิ้นสุดวันอาทิตย์แรกของเดือนพฤศจิกายน และเริ่มวันอาทิตย์ที่สองของเดือนมีนาคม ช่วงเปิดปิดตลาดตามเวลาไทยจึงเลื่อนไปหนึ่งชั่วโมงในสองช่วงนี้
  • เผื่อเวลาให้ตัวเองตรวจเครื่องหลังรีสตาร์ท อย่าติดตั้งตอนใกล้ตลาดเปิดวันจันทร์

รอบอัปเดตประจำสัปดาห์ที่ใช้ได้จริง

อัปเดตความปลอดภัยประจำเดือนของ Microsoft มักออกในวันอังคารที่สองของเดือนตามเวลาสหรัฐฯ ถ้าตั้งเป็นดาวน์โหลดอย่างเดียว ไฟล์จะรออยู่ในเครื่อง แล้วคุณติดตั้งในวันเสาร์ถัดไป ทำแบบนี้ทุกสัปดาห์ก็ได้ ใช้เวลาไม่เกินครึ่งชั่วโมง และเป็นวิธีดูแล Windows Update VPS ที่คุมได้มากที่สุด

  1. รีโมตเข้า VPS หลังตลาดปิด

    เช้าวันเสาร์ตามเวลาไทย ดูให้แน่ใจว่าตลาดปิดแล้วจริงจากเวลาใน Specification

  2. เปิดหน้า Windows Update แล้วติดตั้ง

    กด Check for updates ให้ระบบดึงรายการล่าสุด แล้วติดตั้งทั้งหมดที่รออยู่

  3. รีสตาร์ทเอง

    สั่ง Restart ทันทีที่ติดตั้งเสร็จ ดีกว่าปล่อยให้ระบบเลือกเวลาเองในวันทำการ

  4. รอแล้วรีโมตกลับเข้าไป

    ตรวจว่า MT5 เปิดอยู่ ล็อกอินถูกบัญชี กราฟและ EA อยู่ครบ ปุ่ม Algo Trading เป็นสีเขียว ถ้า MT5 ยังไม่เปิดเอง ดูวิธีตั้งในบทความตั้งให้ MT5 เปิดเองหลัง VPS รีสตาร์ต

  5. จดผลไว้

    วันที่ จำนวนอัปเดต และสิ่งผิดปกติที่เห็น ถ้าวันหนึ่งเครื่องมีปัญหาหลังอัปเดต จะย้อนดูได้ทันที

ผู้ใช้ EA WING ดูการ์ดล็อกอินบนแดชบอร์ดหลังรีสตาร์ทด้วย สีเขียวคือตรวจสิทธิ์ผ่านแล้ว ถ้ายังเป็นสีเหลือง รอสักครู่ให้ระบบตรวจเสร็จ

ข้อผิดพลาดที่พบบ่อย

  • ปิดบริการ Windows Update ถาวร แล้วลืมไปหลายเดือน
  • กด Pause แล้วลืมจนครบกำหนด ระบบติดตั้งและรีสตาร์ทเองกลางสัปดาห์
  • ตั้ง Active hours อย่างเดียวแล้วคิดว่าพอ ทั้งที่ช่วงนอก Active hours ยังตรงกับตลาดเปิด
  • ตั้งตารางติดตั้งโดยไม่ได้แก้โซนเวลาของเครื่อง ตารางจึงคลาดไปหลายชั่วโมง
  • ติดตั้งอัปเดตเช้าวันจันทร์ก่อนตลาดเปิดเพียงไม่นาน แล้วเครื่องบูตไม่ทัน
  • รีสตาร์ทแล้วไม่ได้เข้าไปตรวจ MT5 จนพบว่า EA หยุดไปทั้งวัน

คำเตือนความเสี่ยง: การจัดเวลาอัปเดตช่วยลดโอกาสที่ EA หยุดกลางตลาดเปิด แต่ไม่ได้ป้องกันการรีสตาร์ทจากสาเหตุอื่น และไม่ได้ลดความเสี่ยงของตลาด ออเดอร์ที่ถือข้ามสุดสัปดาห์ยังเจอราคากระโดดตอนเปิดตลาดได้ การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน รายละเอียดความเสี่ยงของการเทรดด้วย EA ก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่อง Windows Update บน VPS

ปิด Windows Update บน VPS ถาวรได้ไหม?

ทำได้ในทางเทคนิค แต่ไม่แนะนำ VPS เปิดรับการเชื่อมต่อจากอินเทอร์เน็ตตลอดเวลา ช่องโหว่ที่ไม่ได้ปิดเป็นความเสี่ยงต่อทั้งเครื่องและบัญชีเทรด ตั้งให้ดาวน์โหลดอย่างเดียวแล้วติดตั้งเองตามรอบปลอดภัยกว่า

เครื่องรีสตาร์ทไปกลางสัปดาห์แล้ว ควรทำอะไรก่อน?

รีโมตเข้าไปเปิด MT5 และตรวจว่า EA กลับมาทำงาน แล้วเปิด Settings → Windows Update ดูประวัติการอัปเดตว่ารีสตาร์ทเพราะอัปเดตหรือไม่ ถ้าใช่ แปลว่าค่าที่ตั้งไว้ยังไม่ครอบคลุม ให้ทบทวนตามหน้านี้อีกครั้ง

การอัปเดต MT5 เกี่ยวกับ Windows Update ไหม?

ไม่เกี่ยวกัน MT5 อัปเดตตัวเองแยกจาก Windows และอาจรีสตาร์ทเฉพาะโปรแกรม MT5 ส่วนการอัปเดตตัว EA เป็นอีกเรื่องหนึ่งที่ต้องวางแผนเรื่องออเดอร์ที่เปิดค้าง อ่านได้ในบทความอัปเดต EA เวอร์ชันใหม่

ผู้ให้บริการ VPS ตั้งค่าเหล่านี้มาให้แล้วหรือยัง?

แต่ละรายไม่เหมือนกัน บางรายตั้งมาสำหรับงานเทรดแล้ว บางรายปล่อยค่าเริ่มต้นของ Windows ตรวจเองด้วยวิธีในหน้านี้ใช้เวลาไม่กี่นาที และควรตรวจซ้ำหลังผู้ให้บริการติดตั้งระบบใหม่ให้

อ่านต่อ

  • VPS สำหรับ EA: เลือก ตั้งค่า และดูแล
  • MT5 เปิดอัตโนมัติหลังรีสตาร์ต
  • ดูแลความปลอดภัย VPS
  • อ่านเวลาเซิร์ฟเวอร์ใน MT5

ถ้ายังไม่ได้ตั้ง VPS หรือยังไม่แน่ใจว่าเครื่องพร้อมรันระยะยาว เริ่มจากคู่มือ Windows VPS สำหรับรัน EA แล้วตั้งค่าอัปเดตตามหน้านี้ สงสัยตรงไหนส่งภาพหน้า Windows Update มาถามทีมงานได้
