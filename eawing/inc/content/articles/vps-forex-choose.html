ด่านที่ 3: ทดลองใช้จริงก่อนเช่ายาว

ตัวเลขบนหน้าเว็บบอกได้แค่ส่วนหนึ่ง ช่วงทดลองหรือเดือนแรกคือเวลาที่ได้เห็นของจริง ใช้รายการนี้เป็นแผนทดสอบ

  • วันแรก: รีโมตเข้าเครื่อง ติดตั้ง MT5 ล็อกอินบัญชีเดโมหรือบัญชีจริงโดยยังไม่เปิด EA แล้วจดค่า Ping จากมุมขวาล่างของ MT5 ในหลายช่วงเวลา ถ้า MT5 ขึ้นข้อความว่าไม่มีการเชื่อมต่อ ไล่ตามเรื่องMT5 ขึ้น No connection
  • วันที่สองถึงห้า: เปิดกราฟและ EA บนบัญชีเดโมในจำนวนเท่ากับที่จะใช้จริง แล้วดู Memory และ CPU ใน Task Manager ช่วงตลาดคึกคัก
  • ระหว่างสัปดาห์: ลองรีโมตจากมือถือ และลองถามซัพพอร์ตหนึ่งคำถามเพื่อดูเวลาตอบจริง
  • สุดสัปดาห์: สั่งรีสตาร์ตเองหนึ่งรอบ ดูว่าเครื่องกลับมาเร็วแค่ไหน แล้วอ่านแท็บ Journal ว่ามีช่วงหลุดการเชื่อมต่อหรือไม่

ค่า Ping ที่ดีมีความหมายแค่ไหนกับ EA แต่ละแบบ และควรวัดอย่างไรให้ได้ตัวเลขที่เชื่อได้ อธิบายไว้ในเรื่องPing และ Latency ของ VPS

  • รีโมตหลุดหรือเครื่องค้างบ่อย ทั้งที่การใช้ RAM และ CPU ยังไม่เต็ม

  • ราคาต่ออายุขึ้นมากจนไม่สมเหตุสมผลกับสิ่งที่ได้
  • ซัพพอร์ตตอบช้าลงเรื่อย ๆ หรือตอบไม่ตรงคำถาม

ก่อนย้าย ให้เช่าเครื่องใหม่และตั้งค่าให้เสร็จก่อน แล้วค่อยถอด EA จากเครื่องเดิม อย่าเปิด EA ตัวเดียวกันบนบัญชีเดียวกันพร้อมกันสองเครื่อง เพราะอาจส่งคำสั่งซ้อนกัน ถ้ารันหลายบัญชี การแยกบัญชีไว้คนละเครื่องหรือรวมไว้เครื่องเดียวมีข้อดีต่างกัน อ่านแนวคิดในแยกหรือรวมบัญชี EA ไว้เครื่องเดียว

คำถามที่พบบ่อย

VPS ที่ศูนย์ข้อมูลอยู่ในไทยดีกว่าไหม?

ไม่เสมอไป ตัวที่สำคัญคือระยะจาก VPS ถึงเซิร์ฟเวอร์ของโบรกเกอร์ ไม่ใช่ระยะจากบ้านคุณ ถ้าเซิร์ฟเวอร์เทรดอยู่ต่างประเทศ ศูนย์ข้อมูลในเมืองเดียวกับเซิร์ฟเวอร์นั้นมักได้ Ping ต่ำกว่า ส่วนการรีโมตจากไทยไปดูหน้าจออาจหน่วงขึ้นเล็กน้อย ซึ่งไม่กระทบการทำงานของ EA

VPS ที่โบรกเกอร์แนะนำ ดีกว่าเช่าเองไหม?

ใช้เกณฑ์เดียวกันวัด ถ้าเป็น Windows ที่ติดตั้ง MT5 เองได้ อยู่ใกล้เซิร์ฟเวอร์ และเงื่อนไขชัด ก็เป็นตัวเลือกที่ดีได้ แต่ถ้าเป็นบริการฟรีที่มีเงื่อนไขปริมาณการเทรดหรือยอดเงินฝาก ให้อ่านว่าถ้าไม่ผ่านเงื่อนไขแล้วเครื่องจะถูกปิดเมื่อไร

แพ็กเกจ Linux ราคาถูกกว่า ใช้รัน MT5 ได้ไหม?
