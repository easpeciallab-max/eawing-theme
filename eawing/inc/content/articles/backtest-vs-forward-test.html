Backtest กับ Forward Test เป็นการทดสอบ EA สองแบบที่ตอบคำถามคนละข้อ แบบแรกถามว่าระบบจะทำอะไรถ้าย้อนกลับไปเจอราคาในอดีต แบบหลังถามว่าระบบทำอะไรได้จริงกับราคาที่ยังไม่เคยเห็น บทความนี้อธิบายวิธีทำทั้งสองแบบใน MT5 จุดบอดของแต่ละแบบ วิธีอ่านผลแบบไม่หลอกตัวเอง และวิธีตรวจผลงานที่คนอื่นนำมาแสดง

สรุปสั้น: Backtest เร็วและครอบคลุมช่วงยาว แต่เป็นการจำลองที่ปรับให้สวยได้ง่าย · Forward Test ช้าแต่สะท้อนต้นทุนและการส่งคำสั่งจริง · ดูจำนวนเทรด Drawdown สูงสุด และความสม่ำเสมอ มากกว่ากำไรรวม · ใช้ทั้งสองแบบต่อกัน ไม่ใช่เลือกแบบใดแบบหนึ่ง · ผลของคนอื่นให้เชื่อเฉพาะที่ตรวจย้อนได้

Backtest กับ Forward Test คืออะไร

Backtest คือการทดสอบย้อนหลัง ให้ EA เทรดกับข้อมูลราคาในอดีตภายในเครื่องจำลอง ใน MT5 ใช้เครื่องมือชื่อ Strategy Tester ผลที่ได้คือรายงานว่าถ้าใช้ระบบนี้ในช่วงเวลานั้น จะเกิดออเดอร์อะไรบ้าง และเส้นทุนขึ้นลงอย่างไร ทั้งหมดเสร็จได้ในไม่กี่นาทีถึงไม่กี่ชั่วโมง

Forward Test คือการปล่อยให้ EA เทรดกับราคาสดไปข้างหน้าทีละวัน บนบัญชีเดโมหรือบัญชีเงินจริงขนาดเล็ก ผลเกิดขึ้นตามเวลาจริง ไม่มีใครย้อนกลับไปเลือกช่วงหรือจูนค่าให้ตรงกับราคาที่รู้แล้วได้

เปรียบง่าย ๆ Backtest คือการซ้อมกับข้อสอบเก่าที่มีเฉลย ส่วน Forward Test คือห้องสอบจริง คนที่จำเฉลยได้ไม่จำเป็นต้องสอบจริงได้ดี

เทียบ Backtest กับ Forward Test ในตารางเดียว

หัวข้อBacktestForward Test
ข้อมูลราคาราคาในอดีตที่รู้ผลแล้วราคาสดที่ยังไม่เกิด
เวลาที่ใช้นาทีถึงชั่วโมง ครอบคลุมได้หลายเดือนหรือหลายปีต้องรอตามปฏิทินจริง หลายสัปดาห์ถึงหลายเดือน
Spread และ Slippageประมาณจากข้อมูลประวัติ อาจไม่ตรงทุกจังหวะเจอค่าจริงของบัญชีและช่วงเวลานั้น
การส่งคำสั่งเครื่องจำลองจับคู่ราคาให้ ไม่มีคิวคำสั่งจริงผ่านเซิร์ฟเวอร์โบรกเกอร์จริง มีความหน่วงและการปฏิเสธคำสั่ง
ความเสี่ยงต่อเงินไม่มีไม่มีในบัญชีเดโม มีจริงในบัญชีเงินจริง
จุดอ่อนหลักOverfitting และคุณภาพข้อมูลจำนวนเทรดน้อยในช่วงแรก และใช้เวลานาน

วิธีทำ Backtest ใน MT5

ขั้นตอนพื้นฐานเหมือนกันทุก EA ส่วนรายละเอียดแต่ละช่องอธิบายไว้ในคู่มือ ทดสอบ EA ย้อนหลังใน MT5

  1. เปิด Strategy Tester

    กด Ctrl+R หรือเลือกจากเมนู View แท็บ Settings คือที่ตั้งค่าทั้งหมด

  2. เลือก EA สัญลักษณ์ และกรอบเวลา

    เลือกไฟล์ EA ในช่อง Expert แล้วตั้ง Symbol กับ Timeframe ให้ตรงกับที่จะใช้จริง ชื่อสัญลักษณ์ต้องตรงกับในบัญชีของคุณ

  3. ตั้งช่วงวันที่

    เลือก Custom period แล้วกำหนดวันเริ่มและวันจบ ช่วงที่ยาวพอจะครอบคลุมตลาดหลายสภาวะ ทั้งช่วงขึ้นแรง ลงแรง และแกว่งในกรอบ

  4. เลือก Modelling เป็น Every tick based on real ticks

    โหมดนี้ใช้ tick จริงที่โบรกเกอร์เก็บไว้ ใกล้ความจริงที่สุดแต่ช้าที่สุด โหมดอื่นสร้าง tick จำลองจากแท่งเทียน เหมาะแค่สำรวจรอบแรก

  5. ตั้งทุน Leverage และความหน่วง

    ใส่ Deposit และ Leverage ให้เท่าบัญชีที่จะใช้จริง ช่อง Delays เลือกให้มีความหน่วงแบบสุ่มได้ เพื่อจำลองว่าคำสั่งไม่ได้ถึงเซิร์ฟเวอร์ทันทีเสมอ

  6. กด Start แล้วอ่านรายงาน

    ดูแท็บ Backtest สำหรับตัวเลขสรุป แท็บ Graph สำหรับเส้นทุน และแท็บ Journal ถ้าการทดสอบไม่เริ่ม

เรื่อง Spread ใน Strategy Tester ของ MT5

MT5 ไม่มีช่องให้พิมพ์ Spread ตายตัวแบบ MT4 ค่า Spread มาจากข้อมูลประวัติของเซิร์ฟเวอร์ที่ใช้ทดสอบ โหมด real ticks ใช้ Spread ของแต่ละ tick ส่วนโหมดที่จำลองจากแท่งเทียนใช้ค่าระดับแท่ง จึงพลาดจังหวะที่ Spread ถ่างชั่วคราว ข้อมูลแต่ละโบรกเกอร์ต่างกัน ผลของ EA ตัวเดียวกันจึงต่างกันได้

เงื่อนไขเฉพาะของ EA WING

ถ้าทดสอบ [eawing_brand] ใน Strategy Tester ต้องล็อกอิน MT5 ด้วยบัญชีที่ได้รับสิทธิ์และต่อเน็ตไว้ ติ๊ก Allow DLL imports ใน Tools → Options ตั้ง Symbol เป็น XAUUSD ตามชื่อในบัญชีของคุณ (บางโบรกเกอร์มีตัวต่อท้าย) กรอบเวลา M1 และตั้งช่วงวันที่เป็น 2026.01.01 ถึง 2026.08.31 ซึ่งเป็นช่วงมาตรฐานที่ทุกคนใช้ทดสอบเหมือนกัน รายละเอียดอยู่ในหน้า Backtest ข้างต้น

วิธีทำ Forward Test ให้ได้ข้อมูลที่ใช้ได้

Forward Test ไม่มีปุ่มให้กด หัวใจคือวินัยในการรันและจดบันทึก แนวทางเต็มอยู่ในหน้า Forward Test EA ส่วนนี้สรุปหลักที่ต้องไม่พลาด

  • เลือกบัญชีให้เหมาะ บัญชีเดโมไม่เสี่ยงเงินแต่การจับคู่คำสั่งอาจดีกว่าจริง บัญชีเงินจริงขนาดเล็กให้ภาพต้นทุนที่ตรงกว่า
  • ใช้ค่าตั้งชุดเดียวกับที่ทดสอบย้อนหลัง ถ้าเปลี่ยนค่ากลางทาง ผลก่อนและหลังเปลี่ยนต้องแยกเป็นคนละชุด
  • รันบนเครื่องที่เปิดตลอดเวลา เช่น Windows VPS ถ้าคอมดับบ่อย ผลที่ได้จะปนกับปัญหาเครื่อง ไม่ใช่ฝีมือระบบ
  • ให้เวลามากพอ ไม่มีตัวเลขตายตัว แต่ควรนานพอให้มีจำนวนเทรดที่มีความหมาย และผ่านสภาวะตลาดมากกว่าหนึ่งแบบ
  • จดเหตุการณ์รอบตัว วันที่ VPS รีสตาร์ต เน็ตหลุด หรือฝากถอนเงิน เพื่อใช้อธิบายจุดแปลกในเส้นทุน

ระหว่างทดสอบ ใช้รายงาน MT5 History สรุปผลเป็นรอบ ๆ และถ้าวันไหนระบบเงียบผิดสังเกต ไล่เช็กสาเหตุได้ตามบทความEA ไม่เปิดออเดอร์

จุดแข็งและข้อจำกัดของ Backtest

จุดแข็งของ Backtest คือความเร็วและความครอบคลุม ภายในบ่ายเดียวเห็นได้ว่าระบบเคยติดลบลึกแค่ไหนและเทรดบ่อยหรือห่าง แต่มีกับดักสามข้อที่ทำให้ตัวเลขดูดีเกินจริง

Overfitting: จูนจนจำเฉลย

ถ้าปรับค่าตั้งซ้ำจนเส้นทุนในอดีตสวยที่สุด ระบบอาจแค่จำรูปแบบเฉพาะของช่วงนั้น ไม่ได้มีข้อได้เปรียบจริง สัญญาณเตือนคือผลพังทันทีเมื่อขยับช่วงวันที่ไปนิดเดียว ช่อง Forward ใน Strategy Tester ช่วยกันข้อมูลช่วงท้ายไว้ไม่ให้ใช้จูน เพื่อเช็กว่าค่าที่ได้ยังใช้ได้กับข้อมูลที่ไม่เคยเห็น

คุณภาพข้อมูลราคา

ข้อมูลที่ขาดช่วง มีราคาผิดปกติ หรือเป็น tick จำลอง ทำให้ผลเพี้ยนได้ โดยเฉพาะระบบที่ทำงานบนกรอบเวลาเล็กอย่าง M1 ซึ่งราคาภายในแท่งมีผลมาก

ต้นทุนและการส่งคำสั่ง

เครื่องจำลองไม่มีคิวคำสั่ง ไม่มีโบรกเกอร์ปฏิเสธคำสั่ง และอาจประเมิน Slippage ต่ำกว่าจริง ระบบที่หวังกำไรต่อไม้เพียงไม่กี่จุดจะได้รับผลจากช่องว่างนี้มากที่สุด

จุดแข็งและข้อจำกัดของ Forward Test

จุดแข็งของ Forward Test คือความซื่อตรง ผลเกิดกับราคาที่ไม่มีใครรู้ล่วงหน้า และรวมต้นทุนที่ Backtest มองไม่เห็น ตั้งแต่ Spread ช่วงข่าว ความหน่วงของ VPS จนถึงความผิดพลาดของคนดูแลบัญชี

  • ช้า ต้องรอตามปฏิทินจริง ไม่มีทางเร่งได้
  • ตัวอย่างน้อยในช่วงแรก ผลไม่กี่สัปดาห์อาจเป็นแค่โชคดีหรือโชคร้าย ยังสรุปไม่ได้
  • เดโมไม่เท่าบัญชีจริง การจับคู่คำสั่งในบัญชีเดโมอาจราบรื่นกว่า และไม่มีแรงกดดันทางใจเมื่อเห็นเงินจริงลดลง

อ่านผลอย่างซื่อตรง: จำนวนเทรด Drawdown และความสม่ำเสมอ

ไม่ว่าจะเป็นผลจาก Backtest หรือ Forward Test กำไรรวมเป็นตัวเลขที่บอกน้อยที่สุด ให้ดูสามเรื่องนี้ก่อน

จำนวนเทรดพอหรือยัง

ผลจากเทรดไม่กี่สิบไม้แกว่งเพราะโชคได้มาก ยิ่งมีเทรดมากและผ่านหลายสภาวะ ผลยิ่งมีน้ำหนัก ระบบที่เทรดห่างจึงต้องใช้ช่วงทดสอบยาวกว่า

Drawdown สูงสุด

Drawdown คือระยะที่เส้นทุนร่วงลงจากจุดสูงสุดก่อนหน้า ตัวอย่างสมมติเพื่ออธิบายวิธีคิดเท่านั้น: ทุนเริ่ม 1,000 USD ขึ้นไปถึง 1,300 USD แล้วร่วงลงมาที่ 1,040 USD ก่อนจะฟื้น Drawdown ช่วงนั้นคือ 260 USD หรือ 20% ของจุดสูงสุด ไม่ใช่ 4% ที่ได้จากการเทียบกับทุนเริ่ม คำถามที่ต้องถามตัวเองคือ ถ้าเจอช่วงแบบนี้กับเงินจริง จะทนอยู่กับแผนได้ไหม ลองคำนวณว่าต้องฟื้นกี่เปอร์เซ็นต์จึงกลับมาที่เดิมได้ด้วยเครื่องคำนวณ Drawdown และอ่านความต่างของยอดเงินสองแบบในบทความEquity กับ Balance

ความสม่ำเสมอ

เส้นทุนที่ค่อย ๆ ขึ้น บอกอะไรได้มากกว่าเส้นที่ผลทั้งหมดมาจากเทรดใหญ่ไม่กี่ไม้ ลองแบ่งผลเป็นรายเดือนดูว่ามีเดือนไหนแบกผลรวมไว้คนเดียวหรือไม่ และเทียบความถี่ ขนาดออเดอร์ และระยะเวลาถือใน Forward Test กับ Backtest

ตัวเลขทั้งหมดในหัวข้อนี้เป็นตัวอย่างสมมติเพื่ออธิบายวิธีคำนวณ ไม่ใช่ผลของ EA WING หรือ EA ตัวใด

ทำไมต้องใช้ Backtest กับ Forward Test ทั้งคู่

สองวิธีนี้ปิดจุดบอดของกันและกัน Backtest ให้ภาพกว้างที่ Forward Test ต้องใช้เวลาหลายปีกว่าจะเห็น ส่วน Forward Test ยืนยันว่าภาพนั้นไม่ได้มาจากการจูน ลำดับที่นิยมใช้คือ

  1. Backtest ด้วยโหมด real ticks

    ดูพฤติกรรม ช่วงติดลบที่ลึกที่สุด และจังหวะการเทรด

  2. Forward Test บนบัญชีเดโม

    ใช้ค่าตั้งเดิม เช็กว่าพฤติกรรมใกล้กับ Backtest หรือไม่ และฝึกดูแลระบบให้คล่อง

  3. บัญชีเงินจริงขนาดเล็ก

    เห็นต้นทุนจริงและแรงกดดันทางใจ โดยเสี่ยงเงินในระดับที่รับได้

  4. ทบทวนก่อนเพิ่มทุน

    เพิ่มทุนเมื่อผลจริงสอดคล้องกับที่คาดไว้ และมีแผนรับมือช่วงติดลบชัดเจน ดูแนวทางวางแผนในบทความแผนเทรดสำหรับคนใช้ EA

ถ้าผลสองแบบห่างกันมาก ให้ไล่หาสาเหตุก่อนสรุป เช่น ค่าตั้งไม่ตรงกัน Spread จริงสูงกว่าข้อมูลทดสอบ หรือเครื่องหยุดทำงานบางช่วง

ตรวจผลงานที่คนอื่นนำมาแสดงอย่างไร

ภาพหน้าจอกำไรตกแต่งได้ง่าย และรายงาน Backtest ที่ไม่บอกเงื่อนไขก็ตรวจซ้ำไม่ได้ ก่อนเชื่อผลของใคร ให้ขอสิ่งที่ตรวจย้อนได้

  • สิทธิ์ดูบัญชีแบบ Investor รหัส Investor เปิดดูประวัติได้ครบแต่สั่งเทรดหรือถอนเงินไม่ได้ เจ้าของผลงานที่มั่นใจมักให้ได้โดยไม่เสี่ยง
  • เว็บติดตามผลอิสระ บริการอย่าง Myfxbook หรือ FX Blue ดึงประวัติจากโบรกเกอร์โดยตรงผ่านสิทธิ์ดูอย่างเดียว ให้ดูว่ามีสถานะยืนยันประวัติการเทรดหรือไม่
  • วันเริ่มและประวัติฝากถอน บัญชีที่เพิ่งเปิดไม่กี่สัปดาห์ หรือมีการเติมเงินกลางทางบ่อย ทำให้อ่านผลยาก
  • เงื่อนไขของ Backtest ถ้าเป็นผลทดสอบย้อนหลัง ต้องบอกช่วงวันที่ โหมด Modelling ทุน Leverage และค่าตั้ง ให้คุณลองทำซ้ำได้
  • มีแต่ภาพหน้าจอ ไม่มีลิงก์ตรวจสอบ
  • ขอรหัสผ่านหลักของคุณเพื่อ "ช่วยดูผล" ซึ่งไม่จำเป็นเลย เพราะรหัส Investor ก็ดูได้ครบ
  • ใช้คำว่ากำไรแน่นอนหรือการันตีผลตอบแทน

หลักเดียวกันใช้กับ [eawing_brand] ด้วย หน้า Backtest และ Forward Test ของเว็บนี้อธิบายวิธีทดสอบและเงื่อนไขที่ทำซ้ำได้ และจะไม่ใช้ตัวเลขที่ตรวจย้อนไม่ได้มาแสดง

คำถามที่พบบ่อย

Backtest ผลดีมาก ข้าม Forward Test ไปใช้เงินจริงเลยได้ไหม?

ไม่แนะนำ ผล Backtest ที่ดีมากอาจมาจาก Overfitting หรือข้อมูลที่ดีเกินจริง Forward Test บนบัญชีเดโมหรือบัญชีเล็กคือด่านที่ช่วยยืนยันก่อนเสี่ยงเงินก้อนใหญ่

Forward Test บนเดโมได้ผลดี แต่บัญชีจริงแย่กว่า เป็นเพราะอะไร?

สาเหตุที่พบบ่อยคือ Spread และ Slippage ของบัญชีจริงต่างจากเดโม ประเภทบัญชีไม่เหมือนกัน หรือค่าตั้งและขนาดออเดอร์ไม่ตรงกัน ให้เทียบรายละเอียดทีละไม้ด้วยรายงาน History ของทั้งสองบัญชี

ทดสอบใน Strategy Tester ไม่ยอมเริ่ม ต้องดูอะไร?

ดูแท็บ Journal ของ Strategy Tester ก่อน สาเหตุที่พบบ่อยคือข้อมูลราคายังโหลดไม่ครบ ช่วงวันที่ไม่ตรงกับที่ EA รองรับ หรือ EA ต้องใช้ DLL แต่ยังไม่ได้ติ๊ก สำหรับ EA WING ต้องล็อกอินบัญชีที่ได้รับสิทธิ์และต่อเน็ตไว้ด้วย ขั้นตอนติดตั้งอยู่ใน ติดตั้ง EA WING บน MT5

คำเตือนความเสี่ยง: การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ทั้งผล Backtest และ Forward Test เป็นผลในอดีต ไม่ได้รับประกันผลลัพธ์ในอนาคต การทดสอบช่วยให้เข้าใจระบบดีขึ้น แต่ไม่ได้ทำให้ความเสี่ยงหายไป อ่าน ความเสี่ยงการใช้ EA ก่อนใช้เงินจริง

อ่านต่อ

  • ทดสอบ EA ย้อนหลังใน MT5 ด้วย Strategy Tester
  • Forward Test EA ทดสอบกับตลาดจริง
  • รายงาน MT5 History สำหรับทบทวนพอร์ต
  • EA ไม่เปิดออเดอร์: เช็กลิสต์ 10 ข้อ
