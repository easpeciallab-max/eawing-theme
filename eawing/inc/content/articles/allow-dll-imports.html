Allow DLL imports คือช่องอนุญาตใน MT5 ที่ให้ EA เรียกใช้ไฟล์ DLL ซึ่งอยู่นอกตัวโปรแกรม EA บางตัวต้องใช้ ถ้าไม่ได้ติ๊กไว้ EA จะโหลดไม่ขึ้นหรือหลุดออกจากกราฟทันที บทความนี้อธิบายว่าช่องนี้คืออะไร อยู่ตรงไหนสองจุด อาการเมื่อลืมติ๊ก และวิธีอนุญาตอย่างระมัดระวัง

สรุปสั้น: ติ๊ก Allow DLL imports ที่ Tools → Options แท็บ Expert Advisors และที่หน้าต่างคุณสมบัติของ EA ตอนลากลงกราฟ (กด F7 บนกราฟเพื่อเปิดซ้ำ) อนุญาตเฉพาะ EA ที่ได้มาจากผู้ขายที่คุณไว้ใจ และอย่าลืมติ๊กใหม่ทุกครั้งที่ย้ายเครื่องหรือลง MT5 ชุดใหม่

DLL คืออะไรในบริบทของ MT5

DLL ย่อมาจาก Dynamic Link Library เป็นไฟล์ไลบรารีของ Windows ที่เก็บชุดคำสั่งไว้ให้โปรแกรมอื่นเรียกใช้ โปรแกรมทั่วไปบนคอมพิวเตอร์ใช้ DLL กันเป็นปกติ ตัว Windows เองก็มี DLL ของระบบอยู่หลายร้อยไฟล์

สำหรับ MT5 ภาษา MQL5 ที่ใช้เขียน EA มีความสามารถในตัวค่อนข้างครบ แต่ก็มีงานบางอย่างที่ต้องพึ่งความสามารถของ Windows หรือไลบรารีภายนอก ผู้พัฒนาจึงเขียนให้ EA "นำเข้า" (import) ฟังก์ชันจากไฟล์ DLL ได้ ตรงนี้เองที่ MT5 ถือว่ามีความเสี่ยง เพราะโค้ดใน DLL ทำงานนอกการควบคุมของ MT5 และทำได้แทบทุกอย่างที่โปรแกรมทั่วไปบน Windows ทำได้ ค่าเริ่มต้นของ MT5 จึงปิดช่องนี้ไว้ และให้ผู้ใช้เป็นคนตัดสินใจเปิดเอง

ทำไม EA บางตัวต้องใช้ DLL

เหตุผลขึ้นกับผู้พัฒนาแต่ละราย ตัวอย่างงานที่พบได้ทั่วไปในวงการ เช่น

  • เรียกใช้ฟังก์ชันของ Windows ที่ MQL5 ไม่มีให้โดยตรง
  • เชื่อมต่อกับโปรแกรมหรือบริการอื่นนอกตัว MT5
  • คำนวณงานหนักด้วยไลบรารีที่เขียนด้วยภาษาอื่น

EA บางตัวมาพร้อมไฟล์ .dll ที่ต้องวางไว้ในโฟลเดอร์ MQL5 → Libraries ส่วนบางตัวเรียกใช้ DLL ที่มีอยู่แล้วใน Windows จึงไม่มีไฟล์ให้วางเพิ่ม ทั้งสองแบบต้องติ๊ก Allow DLL imports เหมือนกัน ให้ทำตามคู่มือของ EA ตัวที่ใช้เป็นหลัก

สำหรับ [eawing_brand] ทีมงานแจ้งไว้ชัดว่า EA WING ต้องใช้ DLL ในการทำงาน ชุดไฟล์มี EA_WING_V4.2.ex5 ไฟล์เดียวที่ต้องวางในโฟลเดอร์ Experts แล้วติ๊กอนุญาตตามขั้นตอนด้านล่าง

ติ๊ก Allow DLL imports สองจุด

MT5 แยกการอนุญาตเป็นสองระดับ คือระดับโปรแกรมที่คุม EA ทุกตัว และระดับ EA แต่ละตัวบนกราฟ ต้องเปิดทั้งสองจุดให้ตรงกัน

  1. จุดที่ 1: Tools → Options แท็บ Expert Advisors

    กด Ctrl+O หรือเปิดเมนู Tools แล้วเลือก Options คลิกแท็บ Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports แล้วกด OK ข้างช่อง DLL อาจมีข้อความเตือนว่าอาจเป็นอันตรายและควรเปิดเฉพาะโปรแกรมที่เชื่อถือได้ ซึ่งเป็นคำเตือนมาตรฐานของ MT5

  2. จุดที่ 2: หน้าต่างคุณสมบัติของ EA

    ลาก EA จาก Navigator (Ctrl+N) ลงกราฟ หน้าต่างคุณสมบัติจะเด้งขึ้นมา ในแท็บ Common ให้ติ๊ก Allow Algo Trading และ Allow DLL imports แล้วกด OK ถ้าไม่เห็นช่อง DLL ในแท็บ Common ให้ดูแท็บ Dependencies ซึ่ง MT5 บางรุ่นใช้แสดงรายชื่อไลบรารีที่ EA เรียกใช้พร้อมช่องอนุญาต

  3. ตรวจว่าเปิดครบ

    ปุ่ม Algo Trading บนแถบเครื่องมือด้านบนต้องเป็นสีเขียว และไอคอนเล็กข้างชื่อ EA ที่มุมขวาบนของกราฟต้องเป็นสีฟ้า ถ้าเป็นสีเทาแปลว่ายังมีสวิตช์ใดปิดอยู่

EA ที่ติดกราฟอยู่ก่อนแล้ว: ถ้าคุณเพิ่งไปติ๊กใน Options ทีหลัง ให้กด F7 บนกราฟนั้นเพื่อเปิดคุณสมบัติของ EA แล้วตรวจแท็บ Common อีกรอบ หรือถอด EA ออกแล้วลากลงใหม่ จะชัวร์กว่าการรอให้ระบบรับค่าเอง

คำอธิบายตัวเลือกทั้งหมดของแท็บนี้จากผู้พัฒนาแพลตฟอร์ม ดูได้ที่หน้าอธิบาย Platform Settings ของ MetaTrader 5 (ภาษาอังกฤษ)

ถ้าไม่ติ๊ก Allow DLL imports จะเกิดอะไรขึ้น

EA ที่ต้องใช้ DLL จะเริ่มทำงานไม่ได้ อาการที่เห็นขึ้นกับว่าลืมติ๊กจุดไหน และผู้พัฒนาเขียนให้ EA แจ้งเตือนแบบใด

สิ่งที่เห็นดูต่อที่ไหนแก้อย่างไร
ลาก EA ลงกราฟแล้วหลุดออกเองทันทีแท็บ Experts และ Journal ใน Toolbox (Ctrl+T)ติ๊กทั้งสองจุด แล้วลากลงกราฟใหม่
มีชื่อ EA บนกราฟ แต่ไม่มีแผงหรือข้อความใดขึ้นมาบรรทัดล่าสุดในแท็บ Expertsกด F7 ตรวจแท็บ Common หรือ Dependencies
ข้อความทำนองว่าไม่อนุญาตให้เรียกใช้ DLL หรือโหลดไลบรารีไม่ได้แท็บ Experts หรือ Journalตรวจช่อง Allow DLL imports ใน Options และไฟล์ .dll (ถ้า EA ตัวนั้นมี) ว่าอยู่ใน MQL5 → Libraries
Strategy Tester เริ่มแล้วจบทันทีหรือไม่ยอมเริ่มแท็บ Journal ของหน้าต่าง Strategy Testerติ๊กใน Tools → Options แล้วเริ่มทดสอบใหม่

ข้อความจริงใน MT5 เป็นภาษาอังกฤษ และถ้อยคำอาจต่างกันตามรุ่นของโปรแกรม ให้สังเกตคำว่า DLL ในบรรทัดเป็นหลัก วิธีอ่านแต่ละแท็บอย่างละเอียดอธิบายไว้ในอ่าน MT5 Journal และแท็บ Experts

อนุญาต DLL อย่างปลอดภัย

คำเตือนข้างช่อง Allow DLL imports ไม่ได้เขียนไว้เล่น ๆ โค้ดใน DLL ทำงานด้วยสิทธิ์เดียวกับโปรแกรม MT5 บนเครื่องของคุณ หมายความว่ามันอ่านไฟล์ เข้าถึงเครือข่าย หรือทำอย่างอื่นนอกเหนือจากการเทรดได้ ถ้าคนเขียนมีเจตนาไม่ดี การติ๊กช่องนี้ก็เท่ากับเปิดประตูให้

สิ่งที่ควรทำ

  • ใช้ไฟล์ EA และไฟล์ .dll ที่ได้จากผู้ขายโดยตรงเท่านั้น และเก็บไฟล์ต้นฉบับไว้เทียบเสมอ
  • ติ๊ก Allow DLL imports ในแท็บ Common เฉพาะ EA ที่จำเป็นต้องใช้ ตัวอื่นที่ไม่ต้องใช้ไม่ต้องติ๊ก
  • ใช้ VPS หรือเครื่องที่แยกไว้รัน EA โดยเฉพาะ ไม่เก็บไฟล์ส่วนตัว รหัสผ่านธนาคาร หรือกระเป๋าเงินดิจิทัลไว้ในเครื่องเดียวกัน
  • เปิดโปรแกรมป้องกันไวรัสของ Windows ไว้ตามปกติ

สิ่งที่ไม่ควรทำ

  • ดาวน์โหลด EA จากกลุ่มแจกฟรี เว็บฝากไฟล์ หรือคนที่อ้างว่า "ปลดล็อกสิทธิ์" ให้แล้ว ไฟล์แบบนี้เสี่ยงทั้งโค้ดแอบแฝงและการผิดเงื่อนไขของผู้พัฒนา
  • วางไฟล์ .dll ที่ไม่รู้ที่มาลงในโฟลเดอร์ Libraries เพราะมีคนบอกให้วาง
  • ปิดโปรแกรมป้องกันไวรัสทั้งเครื่องเพื่อให้ EA ทำงานได้ ถ้าไฟล์ถูกแจ้งเตือน ให้ถามผู้ขายก่อน

Strategy Tester ก็ต้องติ๊กเหมือนกัน

หลายคนติ๊กช่อง DLL ในแท็บ Common ตอนลากลงกราฟแล้ว EA ทำงานปกติ แต่พอเปิด Strategy Tester (Ctrl+R) เพื่อทดสอบย้อนหลัง กลับเริ่มไม่ได้ เพราะการทดสอบไม่ได้ผ่านหน้าต่างคุณสมบัติบนกราฟ ตัวทดสอบอ้างอิงการอนุญาตระดับโปรแกรมใน Tools → Options แท็บ Expert Advisors ถ้าช่องนั้นว่าง EA ที่ใช้ DLL จะโหลดไม่ขึ้นในการทดสอบ เหตุผลจะอยู่ในแท็บ Journal ของหน้าต่าง Strategy Tester ไม่ใช่ Journal หลักของโปรแกรม

EA ที่ผูกสิทธิ์กับเลขบัญชี มักต้องตรวจสิทธิ์ผ่านก่อนทดสอบเช่นกัน ดังนั้นถ้าติ๊ก DLL แล้วยังเริ่มไม่ได้ ให้ดูว่า MT5 ล็อกอินบัญชีที่ได้รับสิทธิ์และต่อเน็ตอยู่ แนวทางการทดสอบย้อนหลังอยู่ในหน้าBacktest EA

ย้ายไป VPS หรือลง MT5 ใหม่ ต้องติ๊กอีกรอบ

ค่าใน Tools → Options ถูกเก็บแยกตาม MT5 แต่ละชุด ไม่ได้ติดไปกับบัญชีเทรด สถานการณ์ต่อไปนี้จึงต้องติ๊ก Allow DLL imports ใหม่ทุกครั้ง

  • เช่า VPS เครื่องใหม่ หรือย้ายจากคอมที่บ้านไป VPS
  • ติดตั้ง MT5 ชุดที่สองบนเครื่องเดิม เช่น แยกชุดละโบรกเกอร์
  • ถอนการติดตั้งแล้วลง MT5 ใหม่ หรือรีเซ็ต VPS กลับเป็นค่าเริ่มต้น

ตัวอย่างสมมติ: เทรดเดอร์คนหนึ่งเปลี่ยนผู้ให้บริการ VPS ช่วงสุดสัปดาห์ ติดตั้ง MT5 วางไฟล์ .ex5 เปิดปุ่ม Algo Trading แล้วลาก EA ลงกราฟ แต่ EA หลุดออกจากกราฟทุกครั้ง สาเหตุคือเขาจำได้แค่ปุ่มสีเขียวบนแถบเครื่องมือ แต่ลืมว่า MT5 ชุดใหม่ปิดช่อง DLL ไว้เป็นค่าเริ่มต้น เคล็ดลับคือทำรายการตรวจสอบของตัวเองไว้ครั้งเดียว แล้วใช้ซ้ำทุกครั้งที่ตั้งเครื่องใหม่ ขั้นตอนเตรียม VPS อยู่ในคู่มือ VPS รัน EA

เช็กลิสต์ไล่แก้ปัญหา Allow DLL imports

ถ้า EA ยังไม่ทำงาน ให้ไล่ตามลำดับนี้ ส่วนใหญ่จะเจอสาเหตุภายในไม่กี่ข้อแรก

  • เปิด MT5 ชุดที่ใช้จริง ไม่ใช่ชุดอื่นบนเครื่องเดียวกัน
  • Tools → Options แท็บ Expert Advisors ติ๊กทั้ง Allow algorithmic trading และ Allow DLL imports
  • กด F7 บนกราฟ แท็บ Common (หรือ Dependencies) ติ๊ก Allow Algo Trading และ Allow DLL imports
  • ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว และไอคอนข้างชื่อ EA บนกราฟเป็นสีฟ้า
  • ถ้า EA มีไฟล์ .dll มาด้วย ไฟล์อยู่ใน MQL5 → Libraries ของชุดเดียวกัน
  • อ่านบรรทัดล่าสุดในแท็บ Experts และ Journal แล้วจดเวลาที่เกิดปัญหา
  • ถอด EA ออกแล้วลากลงกราฟใหม่ หลังแก้ทุกจุดแล้ว

ถ้าทำครบแล้วยังไม่ได้ ให้แคปภาพแท็บ Experts กับ Journal ส่งให้ผู้ขาย EA โดยไม่ต้องส่งรหัสผ่านใด ๆ สำหรับอาการที่ EA ขึ้นกราฟแล้วแต่ไม่เปิดออเดอร์ ซึ่งเป็นคนละเรื่องกับ DLL ดูหัวข้อไล่แก้ในหน้าวิธีลง EA ใน MT5

คำถามที่พบบ่อยเรื่อง Allow DLL imports

ติ๊ก Allow DLL imports แล้วเครื่องจะติดไวรัสไหม?

การติ๊กช่องนี้ไม่ได้ทำให้เครื่องติดไวรัสเอง แต่เปิดทางให้ EA เรียกใช้ DLL ได้ ความปลอดภัยจึงขึ้นกับว่าไฟล์ EA และไฟล์ .dll มาจากไหน ใช้เฉพาะไฟล์จากผู้ขายที่ไว้ใจได้ และแยกเครื่องรัน EA ออกจากข้อมูลสำคัญ

ติ๊กใน Options แล้ว ทำไมยังต้องติ๊กในแท็บ Common อีก?

เพราะ MT5 แยกการอนุญาตเป็นระดับโปรแกรมกับระดับ EA แต่ละตัว ช่องใน Options คือการยอมให้ใช้ DLL ได้ในโปรแกรมนี้ ส่วนช่องในแท็บ Common คือการยอมให้ EA ตัวนั้นบนกราฟนั้นใช้ ต้องเปิดทั้งสองจุด

แอป MT5 บนมือถือมีช่อง Allow DLL imports ไหม?

ไม่มี เพราะแอปมือถือทั้ง Android และ iOS รัน EA ไม่ได้ ช่องนี้มีเฉพาะ MT5 รุ่นคอมพิวเตอร์บน Windows หรือบน VPS ส่วนมือถือใช้ดูผลและรีโมตเข้า VPS ด้วย Windows App

EA WING ต้องติ๊ก Allow DLL imports ไหม?

ต้องติ๊ก EA WING ต้องใช้ DLL ในการทำงาน ติ๊กทั้งใน Tools → Options แท็บ Expert Advisors และในแท็บ Common ตอนลากลงกราฟ XAUUSD M1 ถ้าไม่ติ๊ก EA จะโหลดไม่ขึ้นทั้งบนกราฟและใน Strategy Tester

คำเตือนความเสี่ยง: การติ๊ก Allow DLL imports แก้ได้แค่ปัญหาทางเทคนิค ไม่ได้ลดความเสี่ยงของตลาด การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด และผลในอดีตไม่ได้รับประกันผลในอนาคต อ่านความเสี่ยงการใช้ EAก่อนใช้เงินจริง

อ่านต่อ

  • EA คืออะไร บอทเทรดใน MT5 ทำงานอย่างไร
  • อ่าน MT5 Journal และแท็บ Experts
  • วิธีลง EA ใน MT5 ทีละขั้น
  • VPS Windows สำหรับรัน EA

ติดตั้ง EA WING แล้วติดขั้นตอนไหน ส่งภาพหน้าต่าง Options แท็บ Common หรือแท็บ Experts ให้ทีมงานคนไทยช่วยดูทาง LINE ได้เลย
