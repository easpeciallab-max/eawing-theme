ถ้า EA ไม่เปิดออเดอร์หรือหยุดทำงานกลางคัน ให้กด Ctrl+T เปิด Toolbox แล้วอ่าน MT5 Journal ซึ่งบันทึกเหตุการณ์ของโปรแกรมและผลคำสั่งเทรด คู่กับแท็บ Experts ที่แสดงข้อความจาก EA โดยตรง สองแท็บนี้มักบอกสาเหตุได้ในไม่กี่บรรทัด และควรเปิดดูทุกครั้งหลังลง EA ใน MT5

สรุปสั้น: แท็บ Journal เก็บเหตุการณ์ของเทอร์มินัล ส่วนแท็บ Experts เก็บข้อความที่ EA พิมพ์ออกมาเอง ให้อ่านทั้งสองแท็บในช่วงเวลาเดียวกัน จับรหัสผลคำสั่ง เช่น 10019 หรือ 10027 แล้วไล่เช็กทีละข้อ ถ้ายังไม่เจอ ให้แคปเฉพาะบรรทัดที่เกี่ยวข้องส่งทีมซัพพอร์ต โดยไม่ส่งรหัสผ่านใด ๆ

เปิด Toolbox แล้วหาแท็บ MT5 Journal กับ Experts

Toolbox คือหน้าต่างแถบล่างของ MT5 เวอร์ชันคอมพิวเตอร์ เปิดปิดได้ด้วย Ctrl+T หรือจากเมนู View ภายในมีแท็บ Trade, History, News, Mailbox, Alerts, Experts และ Journal ดูหน้าที่ของแต่ละหน้าต่างได้จากคู่มือหน้าต่าง Toolbox ของ MetaTrader 5

EA ทำงานบนคอมพิวเตอร์หรือ VPS ที่เปิด MT5 ค้างไว้เท่านั้น แอปมือถือก็มีหน้า Journal แต่เป็นบันทึกของแอปเอง ไม่มีข้อความของ EA ถ้าต้องการอ่าน MT5 Journal ที่เกี่ยวกับ EA จึงต้องรีโมตเข้าไปดูที่เครื่องที่รัน EA

Journal กับ Experts ต่างกันอย่างไร

หัวข้อแท็บ Journalแท็บ Experts
ใครเขียนตัวโปรแกรม MT5EA หรือสคริปต์ที่กำลังรัน
เหตุการณ์ที่พบการเชื่อมต่อและล็อกอิน การโหลดหรือถอด EA คำสั่งเทรดที่ส่งไปและผลตอบกลับ ข้อผิดพลาดของระบบข้อความที่ผู้พัฒนาตั้งให้ EA พิมพ์ เช่น สถานะเริ่มทำงาน เหตุผลที่ยังไม่เข้าออเดอร์
ใช้ตอบคำถามคำสั่งถึงเซิร์ฟเวอร์ไหม ได้ผลอะไรEA ติดเงื่อนไขข้อไหน

หลักจำง่าย ๆ คือ Journal ตอบว่าเกิดอะไรกับโปรแกรมและคำสั่ง ส่วน Experts ตอบว่า EA พูดอะไรออกมา ความละเอียดของแท็บ Experts ขึ้นกับผู้พัฒนา บางตัวพิมพ์ละเอียด บางตัวแทบไม่พิมพ์เลย

อ่าน Log หนึ่งบรรทัด: เวลา แหล่งที่มา และข้อความ

ทุกบรรทัดมีสามช่อง คือ Time (เวลาละเอียดถึงเสี้ยววินาที), Source (แหล่งที่มา) และ Message (ข้อความ) ในแท็บ Journal ช่อง Source บอกหมวดของเหตุการณ์ เช่น เครือข่าย คำสั่งเทรด หรือ EA ส่วนในแท็บ Experts มักเป็นชื่อ EA พร้อมสัญลักษณ์และไทม์เฟรมของกราฟที่มันติดอยู่

รหัสผลคำสั่งเทรดที่เจอบ่อย และสิ่งที่ควรเช็ก

เมื่อ EA ส่งคำสั่ง เซิร์ฟเวอร์จะตอบด้วยรหัสผล (return code) ซึ่งเป็นมาตรฐานของ MQL5 จึงมีความหมายเหมือนกันทุก EA

รหัสความหมายสิ่งที่ควรเช็ก
10004Requoteช่วงราคาวิ่งเร็ว และความหน่วงไปยังเซิร์ฟเวอร์
10006คำสั่งถูกปฏิเสธบรรทัดรอบ ๆ ใน Journal ถ้าเกิดซ้ำให้ถามโบรกเกอร์
10014Volume ไม่ถูกต้องLot ต่ำกว่าขั้นต่ำ เกินสูงสุด หรือไม่ตรง volume step ดูได้ใน Specification ของสัญลักษณ์
10016ระยะ Stop ไม่ถูกต้องStop Loss หรือ Take Profit ใกล้ราคาเกินระยะขั้นต่ำของโบรกเกอร์
10017การเทรดถูกปิดสัญลักษณ์หรือบัญชีถูกจำกัดการเทรด
10018ตลาดปิดเวลาซื้อขายของสัญลักษณ์ วันหยุด หรือสุดสัปดาห์
10019เงินไม่พอFree Margin เทียบกับ Lot และ Leverage
10026เซิร์ฟเวอร์ปิด Algo Tradingบัญชีได้รับอนุญาตให้ใช้ EA หรือไม่ ต้องถามโบรกเกอร์
10027เทอร์มินัลปิด Algo Tradingปุ่ม Algo Trading และตัวเลือกใน Tools > Options

บรรทัดใน Journal มักเป็นคำอธิบายภาษาอังกฤษสั้น ๆ มากกว่าตัวเลข ส่วนตัวเลขรหัสมักอยู่ในแท็บ Experts ถ้าเจอรหัสที่ไม่อยู่ในตาราง ให้จดไว้แล้วถามทีมซัพพอร์ตของ EA ที่ใช้

EA ไม่เปิดออเดอร์: ไล่เช็กทีละขั้น

ถ้าไม่มีบรรทัดคำสั่งเทรดใน Journal เลย มักแปลว่าคำสั่งยังไม่ถูกส่งออกไปด้วยซ้ำ ให้เช็กตามลำดับนี้

  1. ปุ่ม Algo Trading ต้องเปิดอยู่

    ปุ่มบนแถบเครื่องมือนี้ (เวอร์ชันเก่าชื่อ AutoTrading) เป็นสวิตช์หลัก ถ้าปิด EA ทุกตัวส่งคำสั่งไม่ได้ ตรงกับรหัส 10027 ดูคู่มือ Algo Trading ของ MetaTrader 5

  2. EA ตัวนั้นได้รับอนุญาตให้เทรด

    คลิกขวาบนกราฟ เลือก Expert Advisors แล้ว Properties (หรือกด F7) ในแท็บ Common ต้องติ๊ก Allow Algo Trading ไว้

  3. EA ติดอยู่บนกราฟที่ถูกต้อง

    มุมขวาบนของกราฟต้องมีชื่อ EA และเป็นสัญลักษณ์กับไทม์เฟรมตามคู่มือ บางคนเปิดกราฟใหม่หลังรีสตาร์ต VPS แล้วลืมใส่ EA กลับ

  4. เทอร์มินัลเชื่อมต่ออยู่

    แถบสถานะมุมขวาล่างควรแสดงค่าความหน่วงเป็นมิลลิวินาที ถ้าหลุดจะเห็นข้อความแจ้งว่าไม่มีการเชื่อมต่อ

  5. ล็อกอินด้วยรหัสผ่านหลัก ไม่ใช่รหัส investor

    รหัส investor ดูได้อย่างเดียว ถ้าใช้ล็อกอินบน VPS จะเห็นราคาและออเดอร์ปกติ แต่ EA ส่งคำสั่งไม่ได้

  6. ตลาดเปิดอยู่

    Forex เปิดราวเช้าวันจันทร์และปิดเช้ามืดวันเสาร์ตามเวลาไทย เวลาบนกราฟเป็นเวลาเซิร์ฟเวอร์ซึ่งมักไม่ตรงเวลาไทย นอกเวลาซื้อขายจะได้รหัส 10018

  7. ตัวเลือกใน Options ไม่ได้ปิดระบบเอง

    ถ้าปุ่ม Algo Trading กลับมาปิดเองบ่อย ๆ ให้ดูหัวข้อถัดไป

ตัวเลือกใน Options ที่ปิด Algo Trading โดยไม่รู้ตัว

ใน Tools > Options แท็บ Expert Advisors มีช่อง Allow algorithmic trading และตัวเลือกให้ปิดการเทรดอัตโนมัติเองเมื่อเปลี่ยนบัญชี เปลี่ยนโปรไฟล์ หรือเปลี่ยนสัญลักษณ์หรือไทม์เฟรมของกราฟ ตัวเลือกเหล่านี้มีไว้เพื่อความปลอดภัย ติ๊กไว้ได้ แต่ต้องรู้ผลของมัน

ตัวอย่างสมมติ: พนักงานออฟฟิศสลับไปล็อกอินบัญชีเดโมบน VPS ตัวเดียวกับที่รัน EA ช่วงพักเที่ยง แล้วสลับกลับบัญชีจริงตอน 12:50 ถ้าติ๊กตัวเลือกปิดเมื่อเปลี่ยนบัญชีไว้ ปุ่ม Algo Trading จะถูกปิดทันที และ Journal จะมีบรรทัดแจ้งว่าการเทรดอัตโนมัติถูกปิดเพราะเปลี่ยนบัญชี EA จึงไม่เทรดทั้งบ่าย วิธีกันคือมองปุ่ม Algo Trading ทุกครั้งหลังสลับบัญชี หรือติดตั้ง MT5 แยกอีกชุดไว้ดูบัญชีอื่น

ไฟล์ Log เก็บอยู่ที่ไหน

ข้อความใน MT5 Journal และแท็บ Experts ถูกบันทึกเป็นไฟล์ข้อความแยกวันละไฟล์ ตั้งชื่อตามวันที่ จึงย้อนดูได้แม้ VPS รีสตาร์ตไปกลางดึก

  • Log ของ Journal: File > Open Data Folder แล้วเข้าโฟลเดอร์ Logs
  • Log ของ Experts: File > Open Data Folder แล้วเข้า MQL5 > Logs
  • เปิดด้วย Notepad แล้วค้นด้วยเวลา ถ้าจะส่งให้ใครให้คัดลอกไฟล์ออกมาก่อน

ส่ง Log ให้ทีมซัพพอร์ตทาง LINE อย่างปลอดภัย

ไม่ว่าจะใช้ EA WING หรือ EA ตัวอื่น ทีมซัพพอร์ตช่วยได้เร็วขึ้นมากถ้าเห็นบรรทัดจริง ผู้ใช้ EA WING ส่งภาพบรรทัดจากแท็บ Experts และ Journal ให้ทีมงานคนไทยทาง LINE ได้โดยตรง ควรแนบสิ่งเหล่านี้

  • เวลาไทยโดยประมาณที่เห็นปัญหา และโซนเวลาที่ตั้งไว้บนเครื่องหรือ VPS
  • ภาพแท็บ Experts และ Journal ช่วงนั้น โดยขยายช่อง Message ให้เห็นครบบรรทัด
  • สิ่งที่เปลี่ยนไปก่อนเกิดปัญหา เช่น ถอนเงิน เปลี่ยน Lot หรือรีสตาร์ต VPS

ห้ามส่ง: รหัสผ่านหลัก รหัส investor หรือภาพหน้าต่างล็อกอินที่มีรหัสผ่าน การอ่าน Log ไม่ต้องใช้รหัสผ่าน และแรเงาเลขบัญชีในภาพก่อนส่งได้

ระหว่างวันที่ไม่ได้อยู่หน้าจอ การตั้งแจ้งเตือน MT5 เข้ามือถือ ช่วยให้รู้ตัวเร็วขึ้นเมื่อออเดอร์เปิดหรือปิด ไม่ต้องรอไปเจอปัญหาตอนเย็น

คำถามที่พบบ่อย

ทำไมหน้า Journal ในแอปมือถือไม่มีข้อความของ EA?

เพราะแอป MT5 บนมือถือรัน EA ไม่ได้ หน้า Journal ในแอปจึงเป็นบันทึกของแอปเอง ข้อความของ EA อยู่บนเครื่องที่เปิด MT5 ไว้ ส่วนการดูผล EA บนมือถือเหมาะกับการดูยอดและออเดอร์มากกว่า

แท็บ Experts ว่างเปล่า แปลว่า EA เสียหรือไม่?

ไม่เสมอไป EA บางตัวพิมพ์ข้อความน้อยโดยตั้งใจ ให้ดูใน Journal ว่ามีบรรทัดโหลด EA สำเร็จ และมุมขวาบนของกราฟมีชื่อ EA ถ้าไม่มีทั้งคู่ แปลว่า EA ยังไม่ได้ติดบนกราฟ

เจอรหัส 10027 แต่ปุ่ม Algo Trading เปิดอยู่แล้ว ต้องดูอะไรต่อ?

ตรวจช่อง Allow Algo Trading ในแท็บ Common ของ EA ตัวนั้น และตัวเลือกใน Tools > Options > Expert Advisors ถ้ายังไม่หาย ลองถอด EA แล้วใส่ใหม่ จากนั้นส่งภาพ Log ให้ทีมซัพพอร์ต

คำเตือนความเสี่ยง: การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต การอ่าน Log ช่วยแก้ปัญหาทางเทคนิค แต่ไม่ได้ลดความเสี่ยงของตลาด อ่าน ความเสี่ยงการใช้ EA ก่อนใช้เงินจริง

อ่านต่อ

  • ตั้งแจ้งเตือน MT5 เข้ามือถือ
  • รายงาน MT5 History สำหรับทบทวนพอร์ต
  • VPS Windows สำหรับรัน EA
