EA มือถือ เป็นสิ่งที่หลายคนอยากได้ คือให้บอทเทรดทำงานจากโทรศัพท์โดยไม่ต้องเปิดคอม คำตอบตรง ๆ คือแอป MT5 บน Android และ iPhone รัน EA ไม่ได้ มือถือใช้ดูผล รับแจ้งเตือน และสั่งงานเครื่องที่อยู่ไกลได้ แต่ตัว EA ต้องทำงานใน MT5 บน Windows ที่เปิดอยู่ตลอด ถ้าอยากเข้าใจภาพรวมตั้งแต่ต้น อ่านคู่มือบอทเทรด EA ฉบับเต็มก่อน

สรุปสั้น: รัน EA บนมือถือไม่ได้ เพราะแอป MT5 บนมือถือไม่รองรับโปรแกรมที่เขียนเพิ่มอย่าง EA · ให้ EA อยู่บนคอม Windows หรือ Windows VPS แล้วใช้มือถือดูผลและรีโมตเข้าเครื่องด้วย Windows App · ปิดแอปบนมือถือไม่ทำให้ EA หยุด และเปิดแอปไว้ก็ไม่ได้ทำให้ EA ทำงาน

EA มือถือ: แอป MT5 ทำอะไรได้และไม่ได้

แอป MT5 บนมือถือกับ MT5 บน Windows ใช้บัญชีเดียวกันได้ แต่ความสามารถไม่เท่ากัน ตารางนี้สรุปงานที่คนใช้ EA เจอบ่อย

ที่มือถือเห็นออเดอร์ของ EA ได้แทบทันที เพราะทั้งสองฝั่งดึงข้อมูลจากเซิร์ฟเวอร์ของโบรกเกอร์ตัวเดียวกัน ไม่ใช่เพราะ EA ทำงานอยู่ในโทรศัพท์

ทำไม EA ต้องอยู่บนเครื่องที่เปิดตลอด

EA เป็นโปรแกรมที่ทำงานอยู่ภายใน MT5 บนเครื่องของคุณ ทุกครั้งที่ราคาใหม่เข้ามา MT5 จะเรียกให้ EA คิดและตัดสินใจ ถ้าปิดโปรแกรม ปิดเครื่อง หรือเครื่องเข้าโหมดพัก EA ก็หยุดคิดทันที เซิร์ฟเวอร์ของโบรกเกอร์มีหน้าที่รับคำสั่ง ไม่ได้รัน EA แทนคุณ

ต่อให้มีแอปมือถือที่รัน EA ได้ ระบบปฏิบัติการของโทรศัพท์ก็มักพักแอปที่อยู่เบื้องหลังเพื่อประหยัดแบตเตอรี่ และสัญญาณเน็ตมือถือสลับไปมาตลอดวัน ซึ่งไม่เหมาะกับงานที่ต้องเฝ้าราคาต่อเนื่อง นี่คือเหตุผลที่คำตอบเรื่อง EA MT5 มือถือ จบที่ "ใช้ดู ไม่ได้ใช้รัน"

เลือกเครื่องที่รัน EA: คอมที่บ้าน Windows VPS หรือ VPS ของ MT5

ทางเลือกข้อดีข้อจำกัด
คอม Windows ที่บ้านไม่มีค่าเช่าเพิ่ม เริ่มได้ทันทีไฟดับ เน็ตหลุด Windows รีสตาร์ตเองหลังอัปเดต และต้องตั้งไม่ให้เครื่องเข้าโหมดพัก
Windows VPSเปิด 24 ชั่วโมงในศูนย์ข้อมูล เลือกที่ตั้งใกล้เซิร์ฟเวอร์ของโบรกเกอร์ได้มีค่าเช่ารายเดือน และต้องดูแลรหัสผ่านกับการอัปเดตเอง
VPS ที่มากับ MT5 (Virtual Hosting)ย้าย EA จากในโปรแกรมได้เลยคู่มือของ MetaTrader 5 ระบุว่าห้ามเรียกใช้ DLL บนแพลตฟอร์มเสมือนโดยสิ้นเชิง EA ที่ต้องใช้ DLL จึงรันที่นี่ไม่ได้

ข้อดีข้อเสียแบบละเอียดของสองทางแรกอยู่ในรัน EA บนคอมที่บ้านหรือ VPS ดีกว่า และถ้าอยากรู้ว่าค่าเช่า VPS มีน้ำหนักแค่ไหนในต้นทุนรวม ดูค่า VPS และค่าใช้จ่ายอื่นของการใช้ EA

ถ้าเลือกคอมที่บ้าน ตั้งสามอย่างนี้ก่อน

  • ไม่ให้เครื่องเข้าโหมดพัก ใน Settings ของ Windows หมวด System ตั้งเวลาเข้าโหมด Sleep เป็น Never เมื่อเสียบไฟ
  • กำหนดช่วงเวลาอัปเดต ตั้ง Active hours ใน Windows Update ให้ครอบคลุมช่วงที่ต้องการให้เครื่องทำงาน และกลับมาเปิด MT5 ทุกครั้งหลังรีสตาร์ต
  • ลดโอกาสเน็ตและไฟหลุด ใช้สาย LAN แทน Wi-Fi ถ้าทำได้ และพิจารณาเครื่องสำรองไฟสำหรับช่วงไฟกระพริบ

สำหรับ EA WING ต้องรันบน MT5 ใน Windows หรือ Windows VPS และต้องติ๊ก Allow DLL imports ภาพด้านล่างสรุปการใช้งานแบบ VPS ตั้งแต่เช่าเครื่องจนปิดคอมของตัวเองได้

คุม VPS จากมือถือด้วย Windows App

แอปเดสก์ท็อประยะไกลของ Microsoft บนมือถือปัจจุบันชื่อ Windows App ใช้ได้ทั้ง iPhone, iPad และ Android ตามหน้าอธิบายของ Microsoft (ภาษาอังกฤษ) ขั้นตอนหลักเป็นแบบนี้

  1. ติดตั้ง Windows App

    ดาวน์โหลดจาก App Store หรือ Google Play ให้ตรวจว่าผู้พัฒนาคือ Microsoft

  2. เพิ่มเครื่อง VPS

    ใส่ IP address ชื่อผู้ใช้ และรหัสผ่านที่ได้จากผู้ให้บริการ VPS ตั้งชื่อเครื่องให้จำง่าย

  3. เชื่อมต่อแล้วตรวจ MT5

    ดูว่าปุ่ม Algo Trading เป็นสีเขียว มุมขวาล่างแสดงค่าความหน่วงเป็นมิลลิวินาที และ EA ยังอยู่บนกราฟ

  4. ออกด้วยการตัดการเชื่อมต่อ

    ปิดหน้าต่างหรือกด Disconnect ในแอป อย่ากด Sign out ใน Windows เพราะจะปิด Session และปิด MT5 ไปด้วย

ขั้นตอนพร้อมภาพของแต่ละเครื่องอยู่ในคู่มือใช้ VPS จากมือถือ Android และใช้ VPS จาก iPhone และ iPad หน้าจอมือถือเล็ก ให้หมุนเป็นแนวนอนและซูมก่อนกดปุ่มเล็ก ๆ บน MT5 เพื่อกันกดพลาด

Chromebook และเว็บเบราว์เซอร์ใช้ได้ไหม

ตามตารางในหน้าเดียวกันของ Microsoft Windows App มีเวอร์ชัน Android และ Chrome OS ซึ่งเชื่อมต่อเครื่อง Windows ระยะไกลได้ ส่วน Windows App แบบเปิดในเว็บเบราว์เซอร์ยังไม่รองรับการเชื่อมต่อเครื่องแบบ Remote PC ถ้าจะเข้า VPS จากเครื่องที่ไม่ใช่ Windows จึงควรติดตั้งแอปไว้ ไม่ใช่หวังพึ่งเบราว์เซอร์

ตัวอย่างสมมติ: วันที่ไฟดับที่บ้าน

เทรดเดอร์คนหนึ่งรัน EA บน Windows VPS ระหว่างวันเขาเปิดแอป MT5 บนมือถือดู Equity และออเดอร์สองครั้ง ตอนเย็นไฟดับที่บ้านทั้งย่าน แต่ EA ยังทำงานต่อเพราะเครื่องอยู่ในศูนย์ข้อมูล ดึกคืนนั้นเขาสังเกตว่าบัญชีเงียบนานผิดจากที่เคยเห็น จึงใช้ Windows App บนมือถือรีโมตเข้าไป พบว่า Windows รีสตาร์ตหลังอัปเดตและ MT5 ยังไม่ถูกเปิดกลับ เขาเปิด MT5 ตรวจว่า EA อยู่บนกราฟครบ ทั้งหมดใช้เวลาไม่กี่นาที เรื่องนี้แต่งขึ้นเพื่ออธิบายการแบ่งหน้าที่ระหว่างเครื่องกับมือถือ

สิ่งที่มือถือทำได้ดี: ดูผลและรับแจ้งเตือน

บทบาทที่เหมาะที่สุดของมือถือคือเป็นหน้าปัดของระบบ ล็อกอินบัญชีเดียวกันในแอป MT5 แล้วดู Equity, Margin Level และออเดอร์ที่เปิดอยู่เป็นรอบ ๆ ส่วนการแจ้งเตือน ให้ใส่ MetaQuotes ID ของมือถือใน Tools → Options แท็บ Notifications ของ MT5 บนเครื่องที่รัน EA

เครื่องมือบนมือถือใช้ทำอะไร
แอป MT5ดูยอดเงิน ออเดอร์ ประวัติ และรับแจ้งเตือน
Windows Appเข้าไปดูและแก้ไขที่เครื่องที่รัน EA โดยตรง
แอปแชตกับผู้ขายส่งภาพหน้าจอและถามเมื่อมีอาการผิดปกติ

สิ่งที่ต้องจำคือมือถือบอกไม่ได้ว่า EA บน VPS ยังทำงานอยู่ ถ้าบัญชีเงียบผิดจากปกติ ให้รีโมตเข้าไปดูแท็บ Experts โดยตรง รูทีนดูผลแบบเช้าและเย็นอยู่ในวิธีดูผล EA มือถือแบบไม่พลาดจุดสำคัญ และถ้าดูแลหลายบัญชี วิธีจัดระบบอยู่ในรัน EA หลายบัญชีพร้อมกัน

ระวังการกดจากมือถือที่ไปรบกวน EA

แอปมือถือส่งคำสั่งเข้าบัญชีเดียวกับที่ EA ใช้ ทุกการกดจึงมีผลจริง

  • ปิดออเดอร์ของ EA เองโดยไม่มีแผน EA หลายตัวคิดต่อจากออเดอร์ที่มีอยู่ การปิดกลางทางอาจทำให้ระบบทำงานต่างจากที่ออกแบบ ถามผู้ขายก่อนแทรกแซง
  • เปิดออเดอร์มือในบัญชีเดียวกัน ใช้ Free Margin ก้อนเดียวกับ EA และทำให้ความเสี่ยงรวมสูงกว่าแผน
  • ล็อกอินรหัสผ่านหลักบนเครื่องที่คนอื่นใช้ร่วม ถ้าแค่อยากดู ใช้รหัส Investor ซึ่งส่งคำสั่งเทรดไม่ได้

วิธีลัดที่ไม่ควรใช้

  • โปรแกรมจำลอง Windows บนมือถือ ช้า ร้อน กินแบตเตอรี่ และถูกระบบพักได้ทุกเมื่อ ไม่เหมาะกับเงินจริง
  • แอปที่อ้างว่าเป็น "EA บนมือถือ" แล้วขอรหัสผ่านหลักของบัญชี เป็นรูปแบบที่ควรสงสัยทันที ดูสัญญาณอื่นในสัญญาณเตือนของบอทเทรดหลอก
  • โน้ตบุ๊กที่พับจอแล้วเครื่องเข้าโหมดพัก EA หยุดทันทีที่เครื่องพัก แม้หน้าจอมือถือจะยังแสดงยอดเงินตามปกติ

เช็กลิสต์: EA อยู่บนเครื่อง มือถือไว้ดู

  • MT5 บน Windows หรือ Windows VPS เปิดอยู่ตลอด และไม่เข้าโหมดพัก
  • EA อยู่บนกราฟที่คู่มือกำหนด ปุ่ม Algo Trading เป็นสีเขียว
  • มือถือล็อกอินบัญชีเดียวกันในแอป MT5 เพื่อดูผล
  • ตั้งแจ้งเตือน Push ด้วย MetaQuotes ID แล้วทดสอบว่ามาถึงจริง
  • ติดตั้ง Windows App และลองเชื่อมต่อ VPS ไว้ก่อนวันที่ต้องใช้จริง
  • ตกลงกับตัวเองว่าจะไม่ปิดหรือเปิดออเดอร์จากมือถือโดยไม่มีแผน

คำเตือนความเสี่ยง: การดูผลจากมือถือไม่ได้ลดความเสี่ยงของการเทรด และการกดสั่งงานจากหน้าจอเล็กอาจทำให้พลาดได้ การเทรด Forex ทองคำ และ CFD ด้วย EA อาจทำให้สูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่านความเสี่ยงของการใช้ EAก่อนใช้เงินจริง

คำถามที่พบบ่อย

iPad หรือแท็บเล็ต Android รัน EA ได้ไหม?

ไม่ได้ แอป MT5 บนแท็บเล็ตมีข้อจำกัดเดียวกับบนมือถือ ยกเว้นแท็บเล็ตที่เป็น Windows เต็มรูปแบบ ซึ่งนับเป็นคอม Windows เครื่องหนึ่ง ติดตั้ง MT5 รุ่นคอมพิวเตอร์ได้ แต่ต้องเปิดไว้ตลอดและไม่ให้เข้าโหมดพัก

ปิดแอป MT5 บนมือถือแล้ว EA หยุดไหม?

ไม่หยุด EA ทำงานบนเครื่องที่ติดตั้งไว้ แอปมือถือเป็นแค่หน้าจอดูบัญชีเดียวกัน ปิดแอปหรือออกจากระบบบนมือถือจึงไม่กระทบ EA

ใช้มือถือเครื่องเก่าแทน VPS ได้ไหม?

ไม่ได้ เพราะมือถือติดตั้ง MT5 รุ่นที่รัน EA ไม่ได้ ถ้าไม่อยากเช่า VPS ทางเลือกคือคอม Windows ที่เปิดได้ตลอด แต่ต้องรับความเสี่ยงเรื่องไฟดับและเน็ตหลุดเอง

ให้ EA ส่งแจ้งเตือนเข้ามือถือได้ไหม?

ได้ถ้า EA ตัวนั้นเขียนให้ส่งข้อความแจ้งเตือน ฝั่งเครื่องที่รัน EA ต้องใส่ MetaQuotes ID ของมือถือใน Tools → Options แท็บ Notifications และเปิดการแจ้งเตือนไว้ ส่วนจะแจ้งเรื่องอะไรบ้าง ขึ้นกับการออกแบบของ EA แต่ละตัว ให้ดูคู่มือหรือถามผู้ขาย

ดูผล EA หลายบัญชีบนมือถือเครื่องเดียวได้ไหม?

ได้ แอป MT5 บันทึกหลายบัญชีและสลับดูได้ แต่ดูได้ทีละบัญชี ตั้งชื่อบัญชีให้ชัดและไล่ดูให้ครบทุกบัญชีในรอบเดียวกัน

อ่านต่อ

  • รัน EA บนคอมที่บ้านหรือ VPS ดีกว่า
  • ดูผล EA มือถือผ่านแอป MT5
  • ใช้ VPS จากมือถือ Android
