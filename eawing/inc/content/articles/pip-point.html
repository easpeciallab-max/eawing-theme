Pip คือหน่วยมาตรฐานที่เทรดเดอร์ใช้นับว่าราคาขยับไปกี่ขั้น ส่วน Point คือขั้นที่เล็กที่สุดที่ราคาเปลี่ยนได้ตามจำนวนทศนิยมที่โบรกเกอร์แสดง ในคู่เงินส่วนใหญ่ 1 pip เท่ากับ 10 point การนับผิดหน่วยเพียงครั้งเดียวทำให้ระยะตัดขาดทุนหรือขนาดไม้ผิดไปสิบเท่าได้ทันที หน้านี้รวบวิธีนับของคู่เงิน คู่เยน และทองคำไว้ที่เดียว เพื่อให้ตัวเลขที่ใช้ในการบริหารเงินถูกตั้งแต่ต้น

สรุปสั้น: Point = ขั้นเล็กที่สุดของราคา ดูจากจำนวนทศนิยม (Digits) · Pip = หน่วยนับที่นิยมใช้ ใหญ่กว่า Point 10 เท่าในคู่เงินทศนิยม 5 ตำแหน่งและคู่เยน 3 ตำแหน่ง · ทองคำนับ Pip ต่างกันตามแหล่ง ให้ระบุเป็นราคา USD เสมอ · MT5 ใช้ Point ใน Spread และระยะขั้นต่ำของ Stop · แปลงเป็นเงินด้วย Tick value ในหน้า Specification

Pip คืออะไร และ Point คืออะไร

ราคาคู่เงิน EURUSD ที่ 1.08523 มีทศนิยม 5 ตำแหน่ง ตัวเลขหลักสุดท้ายขยับได้ทีละ 0.00001 นี่คือ 1 Point ของสัญลักษณ์นี้ ส่วน Pip คือหน่วยที่ตลาดใช้กันมาตั้งแต่สมัยที่ราคาแสดงแค่ 4 ตำแหน่ง คือ 0.0001 เมื่อโบรกเกอร์เพิ่มทศนิยมอีกหนึ่งตำแหน่ง Pip จึงเท่ากับ 10 Point และหลักที่ห้าซึ่งเล็กกว่า Pip นี้ บางคนเรียกว่า Pipette หรือเศษของ Pip

สรุปให้จำง่าย Point เป็นหน่วยของเครื่อง เพราะ MT5 คำนวณระยะต่าง ๆ เป็น Point ส่วน Pip เป็นหน่วยที่คนใช้คุยกัน บทความ คู่มือ และสัญญาณเทรดส่วนใหญ่พูดเป็น Pip เวลาย้ายตัวเลขระหว่างสองโลกนี้จึงต้องแปลงทุกครั้ง

ตารางนับ Pip และ Point ของสินค้าที่เจอบ่อย

ตารางนี้ใช้จำนวนทศนิยมที่พบบ่อย บางโบรกเกอร์แสดงทศนิยมต่างจากนี้ ให้ดูช่อง Digits ในหน้า Specification ของบัญชีคุณ

ถ้าโบรกเกอร์แสดงราคาทองด้วยทศนิยม 3 ตำแหน่ง 1 Point จะเล็กลงเป็น 0.001 ทั้งที่ราคาทองเหมือนเดิม ระยะที่วัดเป็น Point จึงต่างกันระหว่างโบรกเกอร์ได้ถึงสิบเท่า นี่คือเหตุผลที่ไม่ควรลอกตัวเลขระยะเป็น Point จากบัญชีหนึ่งไปใช้อีกบัญชีโดยไม่เช็ก

ทองคำ: จุดที่คนสับสนมากที่สุด

คู่เงินมีนิยาม Pip ที่ตลาดใช้ตรงกันค่อนข้างมาก แต่ทองคำไม่ใช่ ในการพูดคุยทั่วไปจะเจออย่างน้อยสามแบบ

  • 1 pip = 0.10 USD นิยามที่พบบ่อยในเครื่องคำนวณและบทความ Forex เครื่องคำนวณ Lot ของเว็บนี้ก็ใช้แบบนี้
  • 1 pip = 0.01 USD นับตามขั้นราคาเล็กที่สุด ซึ่งก็คือ Point ของบัญชีทศนิยม 2 ตำแหน่ง
  • 1 จุด = 1 USD ภาษาพูดที่ได้ยินบ่อยในกลุ่มเทรดทอง เช่น ทองขึ้น 10 จุด หมายถึงราคาขยับ 10 USD

ทางออกที่ง่ายที่สุดคือแปลงทุกอย่างเป็นระยะราคา USD ก่อน เช่น ระยะตัดขาดทุน 3 USD แล้วค่อยแปลงเป็นหน่วยที่เครื่องมือแต่ละตัวต้องการ ตัวอย่างการคิดกำไรขาดทุนของทองทีละขั้นอยู่ในคำนวณกำไรขาดทุนทองคำ XAUUSD

MT5 ใช้ Point ตรงไหนบ้าง

ทุกครั้งที่ MT5 แสดงระยะหรือส่วนต่างของราคาเป็นตัวเลขเต็ม มักเป็นหน่วย Point ไม่ใช่ Pip

  • Spread ใน Market Watch ตัวเลข 20 ของ EURUSD หมายถึง 20 Point หรือ 2 Pip ไม่ใช่ 20 Pip เรื่องต้นทุนนี้อ่านเพิ่มได้ในSpread คืออะไร
  • Stops level ใน Specification ระยะขั้นต่ำระหว่างราคาตลาดกับ Stop Loss หรือ Take Profit นับเป็น Point
  • ค่า Deviation ตอนส่งคำสั่ง ระยะที่ยอมให้ราคาคลาดได้ ซึ่งเกี่ยวกับSlippage ก็นับเป็น Point
  • ค่าที่ตั้งใน EA EA จำนวนมากรับระยะเป็น Point แต่บางตัวรับเป็น Pip ต้องอ่านคำอธิบายของแต่ละช่องให้ชัดก่อนใส่ตัวเลข

วัดระยะเป็น Point บนกราฟ MT5

ไม่ต้องคำนวณด้วยมือทุกครั้ง MT5 รุ่นคอมพิวเตอร์มีเครื่องมือ Crosshair สำหรับวัดระยะบนกราฟ ใช้เช็กได้เร็วว่าราคาเข้ากับระดับที่สนใจห่างกันเท่าไร

  1. เปิด Crosshair

    กด Ctrl+F หรือคลิกปุ่มกลางของเมาส์บนกราฟ เคอร์เซอร์จะเปลี่ยนเป็นเส้นกากบาท

  2. ลากจากจุดเริ่มไปจุดปลาย

    กดค้างที่ราคาเริ่มต้น เช่น ราคาเข้า แล้วลากไปยังราคาที่ต้องการวัด เช่น ระดับตัดขาดทุน ป้ายเล็กข้างเคอร์เซอร์จะแสดงจำนวนแท่งเทียน ระยะเป็น Point และส่วนต่างของราคา

  3. แปลงเป็น Pip แล้วปิดเครื่องมือ

    นำระยะที่เป็น Point หารด้วย 10 สำหรับคู่เงินทศนิยม 5 ตำแหน่ง คู่เยน 3 ตำแหน่ง และทองที่แสดงทศนิยม 2 ตำแหน่งเมื่อนับ 1 pip = 0.10 จากนั้นกด Esc หรือคลิกขวาเพื่อปิด Crosshair

แอป MT5 บนมือถือก็มีโหมด Crosshair ให้วัดระยะได้เช่นกัน เหมาะกับการเช็กคร่าว ๆ ระหว่างวัน

ทำไมเรื่องหน่วยสำคัญกับคนใช้ EA

EA ไม่ได้รู้ว่าคุณคิดเป็น Pip หรือ Point มันใช้ตัวเลขตามที่ผู้พัฒนาเขียนไว้ ถ้าช่องตั้งค่าหนึ่งรับระยะเป็น Point ตัวเลข 300 บนทองที่แสดงทศนิยม 2 ตำแหน่งคือราคา 3.00 USD แต่ถ้าย้ายไปบัญชีที่แสดงทองด้วยทศนิยม 3 ตำแหน่ง ตัวเลขเดียวกันกลายเป็นแค่ 0.30 USD ระยะหดลงสิบเท่าโดยไม่มีใครแก้อะไรเลย

ทุกครั้งที่ย้ายโบรกเกอร์ เปลี่ยนประเภทบัญชี หรือเปลี่ยนจากบัญชีทดลองไปบัญชีจริง ให้เทียบ Digits และ Contract size ของสัญลักษณ์ก่อนเปิด EA และถ้าไม่แน่ใจว่าช่องไหนใช้หน่วยอะไร ให้ถามผู้พัฒนาหรือทีมงานของ EA ตัวนั้นก่อน ไม่ควรเดาเอง

แปลง Pip เป็นเงิน: Pip value

Pip บอกระยะ แต่ยังไม่บอกเงิน ต้องคูณกับขนาดไม้และขนาดสัญญาก่อน

Pip value ต่อ 1 Lot = ขนาดของ 1 Pip × Contract size (ได้เป็นสกุลเงินฝั่งราคา แล้วแปลงเป็นสกุลเงินของบัญชีถ้าไม่ตรงกัน)

สินค้า (Contract size ที่พบบ่อย)คำนวณPip value ต่อ 1 Lot
EURUSD (100,000)0.0001 × 100,00010 USD
USDJPY (100,000)0.01 × 100,000 = 1,000 JPY ที่ราคาสมมติ 145ราว 6.90 USD
XAUUSD (100 ออนซ์) นับ 1 pip = 0.100.10 × 10010 USD

คู่ที่ USD อยู่ด้านหลัง เช่น EURUSD มี Pip value คงที่ในบัญชีสกุล USD แต่คู่อย่าง USDJPY เปลี่ยนตามราคา เพราะต้องแปลงเงินเยนกลับเป็นดอลลาร์ วิธีที่แม่นที่สุดคือใช้ช่อง Tick size กับ Tick value ในหน้า Specification ซึ่งบอกว่าราคาขยับหนึ่งขั้นแล้วเงินเปลี่ยนเท่าไรต่อ 1 Lot แล้วคูณด้วยจำนวนขั้นใน 1 Pip ความหมายของแต่ละค่าดูได้จากเอกสารคุณสมบัติสัญลักษณ์ของ MQL5 (ภาษาอังกฤษ) ส่วนความหมายของ Lot และ Contract size อยู่ในLot คืออะไร

ตัวอย่างสมมติ: นับระยะและเงินของออเดอร์จริงหนึ่งไม้

ทองคำ 0.05 Lot

เปิด Buy XAUUSD ที่ 3,012.40 แล้วราคาลงมาที่ 3,009.90 บัญชีแสดงทศนิยม 2 ตำแหน่ง Contract size 100 ออนซ์ ระยะคือ 2.50 USD เท่ากับ 250 Point หรือ 25 Pip ถ้านับ 1 pip = 0.10 ไม้ขนาด 0.05 Lot คือทอง 5 ออนซ์ ขาดทุน 2.50 × 5 = 12.50 USD ตรวจย้อนด้วย Pip value: 0.05 × 10 USD = 0.50 USD ต่อ Pip คูณ 25 Pip ได้ 12.50 USD เท่ากัน

EURUSD 0.20 Lot

เปิด Sell ที่ 1.08355 แล้วราคาขึ้นไปที่ 1.08520 ระยะคือ 0.00165 เท่ากับ 165 Point หรือ 16.5 Pip ไม้ 0.20 Lot มี Pip value 2 USD ขาดทุน 16.5 × 2 = 33 USD ถ้าเผลอใส่ 165 เป็น Pip ในเครื่องคำนวณ ตัวเลขจะออกมา 330 USD ผิดไปสิบเท่า

ตัวอย่างทั้งสองยังไม่รวม Spread และค่าคอมมิชชัน ซึ่งทำให้ผลจริงแย่กว่านี้เล็กน้อย เมื่อนับระยะเป็นแล้ว ขั้นต่อไปคือดูว่าระยะทำกำไรคุ้มกับระยะตัดขาดทุนหรือไม่ ซึ่งอธิบายไว้ในRisk Reward Ratio คืออะไร

ข้อผิดพลาดเรื่อง Pip ที่ทำให้ตัวเลขผิดสิบเท่า

  • ใส่ Point ในช่องที่ต้องการ Pip หรือกลับกัน ระยะ Stop Loss จึงสั้นหรือยาวผิดไปสิบเท่า
  • ใช้นิยาม Pip ของคู่เงินกับทองคำ ทองไม่มี 0.0001 ระยะที่ลอกมาจาก EURUSD ใช้กับทองไม่ได้
  • คิดว่า Pip value เท่ากับ 10 USD ทุกคู่ ใช้ได้กับบางคู่ในบัญชีสกุล USD เท่านั้น
  • ลอกตัวเลขจากโบรกเกอร์หนึ่งไปอีกที่ จำนวนทศนิยมและ Contract size อาจต่างกัน
  • อ่าน Spread ใน Market Watch เป็น Pip ทำให้คิดว่าต้นทุนสูงกว่าความจริงสิบเท่า

คำถามที่พบบ่อยเรื่อง Pip และ Point

1 Pip เท่ากับกี่บาท?

ขึ้นกับสินค้า ขนาดไม้ และสกุลเงินของบัญชี ตัวอย่างเช่น EURUSD 0.01 Lot ในบัญชีสกุล USD มีค่าราว 0.10 USD ต่อ Pip แล้วค่อยแปลงเป็นบาทตามอัตราแลกเปลี่ยนวันนั้น ถ้าเป็นทองหรือคู่เงินอื่นต้องคำนวณใหม่ตามขนาดสัญญา

Pipette คืออะไร?

คือเศษหนึ่งในสิบของ Pip ซึ่งก็คือหลักทศนิยมตัวสุดท้ายในราคาแบบ 5 ตำแหน่ง ในบัญชีส่วนใหญ่ Pipette มีขนาดเท่ากับ 1 Point

ทอง 1 Pip เท่ากับเท่าไร?

ไม่มีคำตอบเดียว นิยามที่พบบ่อยคือราคาขยับ 0.10 USD แต่บางแหล่งนับ 0.01 USD หรือเรียก 1 USD ว่า 1 จุด ก่อนคุยตัวเลขกับใคร ให้ถามก่อนว่านับแบบไหน หรือพูดเป็นระยะราคา USD ไปเลยจะชัดที่สุด

ทำไม Spread ใน MT5 ดูเป็นตัวเลขใหญ่?

เพราะ Market Watch แสดง Spread เป็น Point ไม่ใช่ Pip ตัวเลข 25 ของทองที่มีทศนิยม 2 ตำแหน่ง หมายถึงส่วนต่างราคา 0.25 USD ถ้าแสดง 25 ของ EURUSD หมายถึง 2.5 Pip

Point กับ Tick size ต่างกันไหม?

Point คือหลักทศนิยมเล็กที่สุดที่ราคาแสดง ส่วน Tick size คือขั้นที่ราคาขยับได้จริงในการซื้อขาย สำหรับคู่เงินและทองในบัญชีส่วนใหญ่สองค่านี้เท่ากัน แต่บางสินค้า Tick size ใหญ่กว่า Point ได้ ให้ดูทั้งสองช่องในหน้า Specification ก่อนคำนวณเงินต่อการขยับของราคา

คำเตือนความเสี่ยง: การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ความผิดพลาดในการนับหน่วยทำให้ขาดทุนมากกว่าที่ตั้งใจได้หลายเท่า และราคาที่กระโดดอาจข้ามระยะที่คำนวณไว้ ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ตัวเลขในบทความนี้เป็นตัวอย่างสมมติ อ่านคำเตือนความเสี่ยงฉบับเต็มก่อนใช้เงินจริง

อ่านต่อ

  • Money Management คืออะไร: คู่มือบริหารเงินฉบับเต็ม
  • Lot คืออะไร: ขนาดสัญญาใน Forex และทองคำ
  • คำนวณกำไรขาดทุนทองคำทีละขั้น
  • Slippage คืออะไร ทำไมราคาไม่ตรงที่กด

เมื่อรู้แล้วว่าระยะที่ตั้งใจคือกี่ Pip และ 1 Pip มีค่าเท่าไร ลองใส่ตัวเลขในเครื่องคำนวณ Lot ตามเงินที่ยอมเสีย เพื่อหาขนาดไม้ที่สอดคล้องกัน ถ้าใช้ EA WING และอยากเช็กว่าทองในบัญชีของคุณแสดงทศนิยมกี่ตำแหน่ง ส่งภาพหน้า Specification มาถามทีมงานได้
