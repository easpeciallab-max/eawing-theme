ลืมรหัส MT5 แก้ได้เสมอ แต่ขั้นตอนขึ้นกับว่าลืมรหัสชุดไหน เพราะบัญชีเดียวเกี่ยวข้องกับรหัสหลายชุดที่ออกโดยคนละที่ คนส่วนใหญ่เสียเวลาไปกับการพยายามกู้ผิดชุด หรือรีบออกจากระบบบนเครื่องที่ยังใช้ได้อยู่ คู่มือนี้ช่วยแยกให้ชัด แล้วพาตั้งรหัสใหม่ทีละขั้นโดยไม่ทำให้ EA หยุดโดยไม่ตั้งใจ ถ้ายังไม่แน่ใจว่าบัญชี โปรแกรม และเซิร์ฟเวอร์เชื่อมกันอย่างไร อ่านพื้นฐาน MetaTrader 5 สำหรับมือใหม่ก่อน

สรุปสั้น: รหัสผ่านหลัก (Master) ตั้งใหม่ได้ผ่านพื้นที่สมาชิกของโบรกเกอร์หรือฝ่ายบริการลูกค้าเท่านั้น · รหัส Investor ตั้งใหม่เองได้ใน MT5 ถ้ายังรู้รหัสหลัก ที่ Tools → Options แท็บ Server ปุ่ม Change · รหัสพื้นที่สมาชิกรีเซ็ตทางอีเมลบนเว็บของโบรกเกอร์ · หลังเปลี่ยน ต้องล็อกอินใหม่ทุกเครื่อง โดยเฉพาะ VPS ที่รัน EA · ไม่มีใครจำเป็นต้องรู้รหัสหลักของคุณ

ลืมรหัส MT5 ต้องรู้ก่อนว่าลืมชุดไหน

คำว่า "รหัส MT5" ใช้เรียกรวมรหัสหลายชุด ตารางนี้แยกว่าแต่ละชุดใช้ทำอะไร และตั้งใหม่ได้ที่ไหน

รหัสใช้ทำอะไรตั้งใหม่ที่ไหน
รหัสผ่านหลัก (Master หรือ Trading password)ล็อกอินบัญชีเทรดและส่งคำสั่งซื้อขายพื้นที่สมาชิกของโบรกเกอร์ หรือฝ่ายบริการลูกค้า
รหัส Investorล็อกอินเพื่อดูอย่างเดียว เทรดไม่ได้ตั้งใหม่เองใน MT5 ถ้ารู้รหัสหลัก บางโบรกเกอร์ทำได้ในพื้นที่สมาชิกด้วย
รหัสพื้นที่สมาชิกของโบรกเกอร์ฝากถอน เปิดบัญชีเพิ่ม จัดการบัญชีเทรดปุ่มลืมรหัสที่หน้าเข้าสู่ระบบบนเว็บของโบรกเกอร์
บัญชี MQL5.communityใช้บริการของเว็บ MQL5 ไม่เกี่ยวกับการล็อกอินบัญชีเทรดหน้าเข้าสู่ระบบของเว็บ MQL5
รหัสเข้า VPSรีโมตเข้าเครื่อง Windows ที่เช่าไว้ผู้ให้บริการ VPS

อีกอย่างที่มักถูกเข้าใจผิดคือ MetaQuotes ID ในแอปมือถือ ตัวนี้ไม่ใช่รหัสผ่าน แต่เป็นรหัสสำหรับรับแจ้งเตือนจาก MT5 บนคอมหรือ VPS ไม่ต้องกู้หรือเปลี่ยนเมื่อลืมรหัสบัญชีเทรด

ความต่างของสิทธิ์ระหว่างรหัสหลักกับรหัส Investor อธิบายไว้ในคู่มือการเชื่อมต่อบัญชีของ MetaTrader 5 (ภาษาอังกฤษ) สรุปสั้น ๆ คือรหัสหลักให้สิทธิ์เต็ม ส่วนรหัส Investor ดูสถานะบัญชีได้แต่เทรดไม่ได้

ยังล็อกอินค้างอยู่บนเครื่องไหน อย่าเพิ่งออก

ถ้าเคยติ๊ก Save password ไว้ MT5 บนเครื่องนั้นจะล็อกอินเองทุกครั้งที่เปิดโปรแกรม แม้คุณจะจำรหัสไม่ได้แล้วก็ตาม โปรแกรมไม่แสดงรหัสที่บันทึกไว้ให้อ่านออกมา จึงกู้รหัสจากเครื่องนั้นไม่ได้ แต่ยังใช้งานต่อได้ตามปกติ

ข้อนี้สำคัญมากกับ VPS ที่รัน EA อยู่ ถ้าคุณกดออกจากระบบ สลับไปบัญชีอื่น หรือลบบัญชีออกจาก Navigator ระหว่างที่ยังไม่มีรหัสใหม่ EA จะหยุดทันทีและล็อกอินกลับไม่ได้ ให้ปล่อยเครื่องนั้นไว้ตามเดิม ตั้งรหัสใหม่ให้เสร็จก่อน แล้วค่อยล็อกอินด้วยรหัสใหม่ในจังหวะที่ไม่มีออเดอร์ค้างหรือช่วงตลาดปิด

ตั้งรหัสผ่านหลักใหม่ผ่านโบรกเกอร์

รหัสผ่านหลักถูกสร้างและดูแลโดยโบรกเกอร์ คนที่ตั้งใหม่ให้ได้จึงมีแค่โบรกเกอร์ ขั้นตอนทั่วไปเป็นแบบนี้ ชื่อเมนูจริงต่างกันไปตามแต่ละโบรกเกอร์

  1. เข้าพื้นที่สมาชิกของโบรกเกอร์

    ใช้อีเมลและรหัสของพื้นที่สมาชิก ถ้าลืมรหัสชุดนี้ด้วย กดลืมรหัสที่หน้าเข้าสู่ระบบ แล้วรอลิงก์ตั้งรหัสใหม่ในอีเมลที่สมัครไว้

  2. เลือกบัญชีเทรดที่ต้องการ

    หาเมนูรายการบัญชีเทรด แล้วเลือกบัญชี MT5 ให้ตรงเลข ถ้ามีหลายบัญชี ตรวจทั้งเลขบัญชีและชื่อเซิร์ฟเวอร์ จะได้ไม่เปลี่ยนผิดบัญชี

  3. เลือกเปลี่ยนรหัสบัญชีเทรด

    บางแห่งให้ตั้งรหัสเองบนหน้าเว็บ บางแห่งส่งรหัสใหม่ไปทางอีเมล ถ้าหาเมนูไม่เจอ ติดต่อฝ่ายบริการลูกค้าจากอีเมลที่ลงทะเบียนไว้ อาจต้องยืนยันตัวตนก่อน

  4. ล็อกอิน MT5 ด้วยรหัสใหม่

    เปิด File แล้วเลือก Login to Trade Account กรอกเลขบัญชีและรหัสใหม่ เลือกเซิร์ฟเวอร์ให้ตรง และติ๊ก Save password ถ้าเป็นเครื่องที่รัน EA

  5. อัปเดตทุกเครื่องที่ใช้บัญชีนี้

    ไล่ตามรายการในหัวข้อถัดไป ก่อนเครื่องใดเครื่องหนึ่งจะหลุดเองตอนเชื่อมต่อใหม่

ลืมรหัส Investor: ตั้งใหม่เองได้ถ้ารู้รหัสหลัก

รหัส Investor ไม่ต้องรอโบรกเกอร์ ถ้าคุณล็อกอินด้วยรหัสหลักได้ ก็ตั้งรหัส Investor ใหม่บน MT5 เวอร์ชันคอมพิวเตอร์ได้ทันที

  • ล็อกอินบัญชีด้วยรหัสผ่านหลัก
  • เปิด Tools → Options แล้วไปแท็บ Server กดปุ่ม Change
  • กรอกรหัสผ่านหลักปัจจุบัน แล้วเลือกเปลี่ยนรหัส Investor
  • ตั้งรหัสใหม่ให้มีตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ ตัวเลข และอักขระพิเศษ แล้วกด OK

เงื่อนไขของรหัสใหม่ระบุไว้ในหน้า Platform Settings ของ MetaTrader 5 (ภาษาอังกฤษ) อีกเรื่องที่ควรรู้คือ ถ้าโบรกเกอร์บังคับให้เปลี่ยนรหัสหลัก รหัส Investor จะถูกรีเซ็ตไปด้วย ต้องตั้งใหม่แล้วแจ้งคนที่คุณให้รหัสดูพอร์ตไว้ ส่วนการเปลี่ยนรหัสเป็นระยะทั้งที่ยังจำได้ มีขั้นตอนแยกในเปลี่ยนรหัสผ่าน MT5 ทำยังไง

หลังตั้งรหัสใหม่: เครื่องไหนต้องอัปเดตบ้าง

เครื่องที่ยังบันทึกรหัสเก่าไว้อาจยังเชื่อมต่ออยู่สักพัก แต่เมื่อไรที่ต้องเชื่อมต่อใหม่ เช่น เน็ตสะดุดหรือเปิดโปรแกรมใหม่ จะล็อกอินไม่ผ่านและขึ้นว่าบัญชีไม่ถูกต้อง ไล่อัปเดตให้ครบตามรายการนี้

  • VPS หรือคอมที่รัน EA สำคัญที่สุด ล็อกอินใหม่แล้วตรวจว่าปุ่ม Algo Trading ยังเป็นสีเขียว และ EA ยังอยู่บนกราฟ
  • แอปมือถือ แตะบัญชีแล้วกรอกรหัสใหม่ หรือลบบัญชีแล้วเพิ่มกลับ
  • MT5 ชุดอื่นบนคอมที่บ้านหรือที่ทำงาน ถ้าเคยล็อกอินไว้
  • คนที่ถือรหัส Investor ของคุณ ถ้าคุณเปลี่ยนรหัส Investor ด้วย
  • ที่เก็บรหัสของคุณเอง เช่น โปรแกรมจัดการรหัสผ่าน ลบรหัสเก่าทิ้ง

ตัวอย่างสมมติ: เปลี่ยนรหัสแล้วลืม VPS

เจ้าของบัญชีคนหนึ่งตั้งรหัสหลักใหม่จากมือถือตอนเย็นวันศุกร์ แล้วล็อกอินแอปมือถือด้วยรหัสใหม่เรียบร้อย ส่วน MT5 บน VPS ยังเชื่อมต่ออยู่เขาจึงคิดว่าไม่มีอะไรต้องทำ ช่วงสุดสัปดาห์ VPS รีสตาร์ตหลังอัปเดต Windows พอเปิด MT5 ขึ้นมาใหม่ก็ล็อกอินด้วยรหัสเก่าไม่ผ่าน EA จึงไม่ได้ทำงานตั้งแต่ตลาดเปิดเช้าวันจันทร์ เรื่องนี้แต่งขึ้นเพื่ออธิบายวิธีคิด บทเรียนคืออัปเดตเครื่องที่รัน EA เป็นอย่างแรกทุกครั้งที่เปลี่ยนรหัส แล้วลองปิดเปิด MT5 หนึ่งครั้งเพื่อยืนยันว่าล็อกอินกลับเองได้

ถ้าเครื่องใดยังขึ้นว่าบัญชีไม่ถูกต้องหลังกรอกรหัสใหม่ ให้ตรวจชื่อเซิร์ฟเวอร์และแป้นพิมพ์ภาษา แล้วไล่ต่อตามMT5 ขึ้น No connection หรือ Invalid account

สำหรับผู้ใช้ [eawing_brand] สิทธิ์ใช้งานผูกกับเลขบัญชีและชื่อเซิร์ฟเวอร์ ไม่ได้ผูกกับรหัสผ่าน การเปลี่ยนรหัสจึงไม่ต้องขอสิทธิ์ใหม่ แค่ให้ MT5 บนเครื่องที่รัน EA ล็อกอินด้วยรหัสใหม่ให้เรียบร้อย แล้วดูว่าการ์ดล็อกอินบนแดชบอร์ดยังเป็นสีเขียว

ตั้งรหัสใหม่ให้ปลอดภัยและจำได้

  • ใช้โปรแกรมจัดการรหัสผ่าน จำรหัสยาวและไม่ซ้ำได้โดยไม่ต้องจดในกระดาษหรือแชต
  • ไม่ใช้รหัสซ้ำกับอีเมลหรือพื้นที่สมาชิก ถ้าชุดหนึ่งรั่ว อีกชุดยังปลอดภัย
  • ไม่แคปหน้าจอที่เห็นรหัส ภาพในแกลเลอรีมือถือมักถูกสำรองขึ้นคลาวด์โดยไม่รู้ตัว
  • แยกรหัส VPS ออกจากรหัสบัญชีเทรด และตั้งให้แข็งแรงเท่ากัน แนวทางดูแลเครื่องอยู่ในตั้งรหัสและความปลอดภัย VPS สำหรับเทรด

มิจฉาชีพที่อาศัยเรื่องรหัส MT5

คนที่เพิ่งลืมรหัสมักร้อนใจ และนั่นคือจังหวะที่มิจฉาชีพชอบเข้ามา สัญญาณที่ควรหยุดทันทีมีดังนี้

  • มีคนทักมาเสนอ "กู้รหัส" หรือ "ปลดล็อกบัญชี" ให้โดยคิดค่าบริการ
  • คนอ้างตัวเป็นฝ่ายซัพพอร์ตขอรหัสผ่านหลัก หรือรหัสยืนยันที่ส่งเข้าอีเมลหรือมือถือของคุณ
  • ลิงก์พื้นที่สมาชิกที่ส่งมาทางแชต แต่โดเมนสะกดต่างจากเว็บจริงของโบรกเกอร์
  • ไฟล์ติดตั้ง MT5 หรือแอปที่ส่งต่อกันในกลุ่ม แทนที่จะดาวน์โหลดจากแหล่งทางการ

สัญญาณเตือนแบบเดียวกันนี้ใช้กับคนขายบอทเทรดด้วย อ่านเพิ่มในบอทเทรดหลอก: 10 สัญญาณเตือน ทีมงานที่ช่วยเรื่องสิทธิ์ใช้งาน EA ต้องการแค่เลขบัญชีและชื่อเซิร์ฟเวอร์ ไม่เคยต้องใช้รหัสผ่านหลักของคุณ

ลืมเลขบัญชีหรือชื่อเซิร์ฟเวอร์ด้วย

ข้อมูลสองอย่างนี้หาได้ง่ายกว่ารหัสผ่าน ลองดูตามลำดับ

  • อีเมลแจ้งข้อมูลบัญชี ที่โบรกเกอร์ส่งมาตอนเปิดบัญชี ค้นด้วยคำว่า MT5 หรือ login
  • พื้นที่สมาชิกของโบรกเกอร์ หน้ารายการบัญชีเทรดแสดงเลขบัญชีและชื่อเซิร์ฟเวอร์ครบ
  • หน้าต่าง Navigator ใน MT5 กด Ctrl+N แล้วเปิดหัวข้อ Accounts จะเห็นบัญชีที่เคยล็อกอินบนเครื่องนั้น

คำถามที่พบบ่อย

ลืมรหัส MT5 ของบัญชีเดโม ต้องทำยังไง?

ทางที่เร็วที่สุดคือเปิดบัญชีเดโมใหม่ เพราะบัญชีเดโมไม่มีเงินจริงอยู่ข้างใน ถ้าเปิดผ่านพื้นที่สมาชิกของโบรกเกอร์ ลองดูก่อนว่ามีเมนูเปลี่ยนรหัสของบัญชีเดโมหรือไม่

ใช้รหัส Investor ล็อกอินบนเครื่องที่รัน EA แทนได้ไหม?

ไม่ได้ รหัส Investor ดูได้อย่างเดียว EA จะขึ้นบนกราฟตามปกติแต่ทุกคำสั่งซื้อขายถูกปฏิเสธ ต้องตั้งรหัสหลักใหม่ผ่านโบรกเกอร์แล้วล็อกอินด้วยรหัสนั้น

เปลี่ยนรหัสแล้ว EA WING ต้องขอสิทธิ์ใหม่ไหม?

ไม่ต้อง สิทธิ์ผูกกับเลขบัญชีและชื่อเซิร์ฟเวอร์ ให้ล็อกอินด้วยรหัสใหม่บนเครื่องที่รัน EA แล้วดูการ์ดล็อกอิน ถ้าไม่เป็นสีเขียวภายในไม่กี่นาที ส่งภาพการ์ดให้ทีมงานทาง LINE

ทีมงานหรือโบรกเกอร์จะขอรหัสผ่านหลักไหม?

ไม่ควรมีใครขอ โบรกเกอร์ตั้งรหัสใหม่ให้ได้โดยไม่ต้องรู้รหัสเดิม ส่วนทีมงาน EA ใช้แค่เลขบัญชีและชื่อเซิร์ฟเวอร์ ใครขอรหัสหลักให้ถือว่าผิดปกติไว้ก่อน

คำเตือนความเสี่ยง: คนที่ได้รหัสผ่านหลักของคุณไปสามารถเปิดและปิดออเดอร์ในบัญชีได้ทันที เก็บรหัสนี้ไว้กับตัวเองเท่านั้น นอกจากเรื่องความปลอดภัย การเทรด Forex ทองคำ และ CFD เองก็มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด และผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่านข้อมูลความเสี่ยงของการเทรดด้วย EAก่อนใช้เงินจริง

อ่านต่อ

  • เปลี่ยนรหัสผ่าน MT5 ทำยังไง
  • MT5 ขึ้น Invalid account หรือ No connection
  • ความปลอดภัย VPS สำหรับเทรด
  • สัญญาณเตือนบอทเทรดหลอก

ได้รหัสใหม่แล้วแต่ยังเข้าบัญชีบนมือถือหรือคอมไม่ผ่าน ดูภาพหน้าจอล็อกอินของแต่ละอุปกรณ์ในคู่มือล็อกอิน MT5 มือถือและคอม ผู้ใช้ EA WING ที่ไม่แน่ใจว่าต้องทำอะไรต่อบน VPS ทักทีมงานคนไทยทาง LINE ได้ โดยไม่ต้องส่งรหัสผ่านใด ๆ
