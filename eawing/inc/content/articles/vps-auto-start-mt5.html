การตั้งให้ MT5 เปิดอัตโนมัติหลัง VPS รีสตาร์ท คือสิ่งที่แยกระหว่าง EA ที่หยุดไปไม่กี่นาที กับ EA ที่เงียบไปทั้งคืนเพราะไม่มีใครเปิดโปรแกรมให้ เรื่องนี้ไม่ได้มีปุ่มเดียว แต่มีสามชั้นที่ต้องครบ คือ MT5 ต้องจำทุกอย่าง Windows ต้องเปิด MT5 ให้ และต้องมีคนหรือระบบล็อกอินเข้า Windows หลังบูต งานดูแลเครื่องด้านอื่นสรุปไว้ในคู่มือ เลือกและดูแล VPS สำหรับ EA

สรุปสั้น: ชั้นที่ 1 ให้ MT5 จำรหัสผ่าน กราฟ และ EA ไว้ในโปรไฟล์ · ชั้นที่ 2 วางทางลัด MT5 ในโฟลเดอร์ Startup ของผู้ใช้ที่รัน MT5 · ชั้นที่ 3 ให้ Windows ล็อกอินเองหลังบูต หรือรีโมตเข้าไปเองทุกครั้งที่รีสตาร์ท · ทดสอบด้วยการรีสตาร์ทจริงช่วงตลาดปิด แล้วไล่เช็กลิสต์หลังบูต

VPS รีสตาร์ท เพราะอะไรบ้าง

ต่อให้ไม่เคยกดรีสตาร์ทเอง เครื่องก็มีโอกาสบูตใหม่จากหลายสาเหตุ ยิ่งรู้ว่ามาจากไหน ยิ่งเตรียมรับได้ถูก

สาเหตุเกิดบ่อยแค่ไหนป้องกันได้ไหม
Windows ติดตั้งอัปเดตแล้วรีสตาร์ทบ่อยที่สุด เป็นรอบตามรอบอัปเดตของ Microsoftเลือกเวลาได้ ให้ไปตรงช่วงตลาดปิด
ผู้ให้บริการบำรุงรักษาเครื่องแม่นาน ๆ ครั้ง มักแจ้งล่วงหน้าป้องกันไม่ได้ แต่เตรียมรับได้
เครื่องค้างหรือหน่วยความจำเต็มขึ้นกับสเปกและสิ่งที่เปิดไว้ลดได้ด้วยสเปกที่พอและเปิดเฉพาะที่จำเป็น
คุณสั่งรีสตาร์ทเองตามที่ตั้งใจเลือกเวลาได้เต็มที่

สาเหตุแรกคุมได้มากที่สุด การตั้งเวลาอัปเดตไม่ให้ชนตลาดเปิดอธิบายไว้ในบทความคุม Windows Update บน VPS ส่วนบทความนี้ดูแลอีกฝั่ง คือเมื่อรีสตาร์ทไปแล้ว ทำยังไงให้ MT5 กลับมาเองเร็วที่สุด

สามชั้นที่ทำให้ MT5 เปิดอัตโนมัติแล้ว EA ทำงานต่อ

ถ้าขาดชั้นใดชั้นหนึ่ง ผลลัพธ์คือ EA ไม่กลับมาเหมือนกัน แต่สาเหตุต่างกัน ตารางนี้ช่วยให้เห็นภาพก่อนลงมือ

ชั้นหน้าที่ถ้าขาดชั้นนี้
1. MT5 จำทุกอย่างรหัสผ่านบัญชี กราฟ EA และปุ่ม Algo TradingMT5 เปิดขึ้นมาแต่ไม่ล็อกอิน หรือไม่มี EA บนกราฟ
2. Windows เปิด MT5 ให้ทางลัดในโฟลเดอร์ Startupล็อกอิน Windows แล้วแต่ไม่มีใครเปิด MT5
3. มีการล็อกอินเข้า Windowsล็อกอินอัตโนมัติ หรือคุณรีโมตเข้าไปเองเครื่องบูตเสร็จแล้วค้างอยู่ที่หน้าล็อกอิน ชั้นที่ 2 ไม่เคยเริ่ม

ชั้นที่ 1: เตรียม MT5 ให้จำทุกอย่าง

ชั้นนี้ทำครั้งเดียวและไม่มีความเสี่ยงอะไร ควรทำทุกเครื่อง แม้จะยังไม่ตั้งชั้นอื่น

  • ติ๊ก Save password ตอนล็อกอิน ใช้รหัสผ่านหลัก ไม่ใช่รหัส Investor ถ้าเคยล็อกอินโดยไม่ติ๊ก ให้ File → Login to Trade Account ใหม่อีกครั้ง
  • ให้กราฟที่มี EA อยู่ในโปรไฟล์ปัจจุบัน MT5 บันทึกการเปลี่ยนแปลงของกราฟที่เปิดอยู่ลงโปรไฟล์ปัจจุบันให้เอง เมื่อเปิดโปรแกรมใหม่จึงได้กราฟและ EA ชุดเดิม
  • สำรองโปรไฟล์ไว้อีกชุด เมนู File → Profiles → Save As ตั้งชื่อ เช่น "EA-หลัก" ถ้าวันหนึ่งกราฟหาย เปิดโปรไฟล์นี้กลับมาได้ทันที
  • ปุ่ม Algo Trading เป็นสีเขียวก่อนปิดโปรแกรม และดูใน Tools → Options แท็บ Expert Advisors ว่าไม่มีตัวเลือกที่ปิดการเทรดอัตโนมัติเองเมื่อสลับบัญชีหรือโปรไฟล์โดยไม่ได้ตั้งใจ รายละเอียดอยู่ในบทความปุ่ม Algo Trading และเหตุที่ดับเอง
  • ปิด MT5 ด้วยเมนู File → Exit หนึ่งครั้งหลังตั้งค่าเสร็จ แล้วเปิดใหม่ เพื่อยืนยันว่ากลับมาครบตั้งแต่ยังไม่ได้ทดสอบรีสตาร์ทจริง

ชั้นที่ 2: ใส่ MT5 ในโฟลเดอร์ Startup

Windows มีโฟลเดอร์พิเศษที่โปรแกรมข้างในจะถูกเปิดเมื่อผู้ใช้ล็อกอิน ตามคู่มือตั้งค่าแอปที่เปิดตอนเริ่มระบบของ Microsoft ใช้ได้ทั้ง Windows 11 และ Windows Server ที่ใช้งานผ่านหน้าจอปกติ

  1. รีโมตเข้า VPS ด้วยผู้ใช้ที่รัน MT5

    โฟลเดอร์ Startup แยกตามผู้ใช้ ต้องตั้งในผู้ใช้เดียวกับที่ใช้เปิด MT5 ทุกวัน

  2. เปิดโฟลเดอร์ Startup

    คลิกขวาที่ปุ่ม Start เลือก Run พิมพ์ shell:startup แล้วกด Enter หน้าต่างโฟลเดอร์จะเปิดขึ้นมา

  3. คัดลอกทางลัดของ MT5 มาวาง

    คลิกขวาที่ไอคอน MT5 บนเดสก์ท็อปแล้วเลือก Copy จากนั้นวางในโฟลเดอร์ Startup หรือเปิดหน้าต่าง Run อีกครั้ง พิมพ์ shell:appsfolder แล้วลากไอคอน MT5 จากรายการแอปมาวางก็ได้

  4. ตรวจว่าเป็นตัวที่ถูก

    ถ้ามี MT5 หลายตัว ให้ดูว่าทางลัดชี้ไปโฟลเดอร์ติดตั้งที่ถูกต้อง คลิกขวาที่ทางลัด เลือก Properties แล้วดูช่อง Target

คำสั่ง shell:common startup จะเปิดโฟลเดอร์ที่ใช้กับทุกผู้ใช้ในเครื่อง ถ้า VPS มีผู้ใช้คนเดียว เลือกแบบไหนก็ได้ผลเหมือนกัน แต่ถ้ามีหลายผู้ใช้ ใช้ shell:startup ของผู้ใช้ที่รัน MT5 จะชัดเจนกว่า

มี MT5 หลายตัว: เว้นจังหวะการเปิด

ถ้าวางทางลัดหลายตัวไว้ใน Startup ทุกตัวจะเปิดพร้อมกันและแย่งทรัพยากรช่วงบูต สำหรับเครื่องสเปกพอดี ๆ ทางเลือกคือใช้ Task Scheduler สร้างงานแยกต่อหนึ่งตัว ตั้ง Trigger เป็น At log on ของผู้ใช้นั้น แล้วกำหนดให้หน่วงเวลาต่างกัน เช่น ตัวแรก 30 วินาที ตัวถัดไป 1 นาที วิธีติดตั้งหลายตัวให้ถูกโฟลเดอร์อยู่ในบทความเปิด MT5 หลายตัวบน VPS

ชั้นที่ 3: ใครล็อกอิน Windows หลังบูต

ชั้นนี้คนมักมองข้าม โปรแกรมในโฟลเดอร์ Startup จะเริ่มก็ต่อเมื่อมีผู้ใช้ล็อกอิน แต่หลัง VPS บูตเสร็จ ไม่มีใครนั่งพิมพ์รหัสที่หน้าเครื่อง ถ้าไม่ได้ตั้งอะไรไว้ เครื่องจะรออยู่ที่หน้าล็อกอินจนกว่าคุณจะรีโมตเข้าไป มีสองทางเลือก

ทางเลือกข้อดีข้อควรระวัง
ก. รีโมตเข้าไปเองทุกครั้งที่รีสตาร์ทไม่ต้องเก็บรหัสไว้ในเครื่อง ตั้งค่าน้อยที่สุดEA หยุดจนกว่าคุณจะรู้ตัวและเข้าไป ต้องรู้เวลารีสตาร์ทล่วงหน้า
ข. ให้ Windows ล็อกอินเองหลังบูตMT5 กลับมาเองภายในไม่กี่นาที แม้คุณหลับอยู่รหัสผ่านถูกเก็บในเครื่อง ต้องดูแลความปลอดภัยของเครื่องและแผงควบคุมให้ดี

ผู้ให้บริการ VPS สำหรับเทรดบางรายตั้งการล็อกอินอัตโนมัติมาให้แล้ว บางรายไม่ได้ตั้ง ถามก่อนจะได้ไม่ตั้งซ้ำ

ตั้งล็อกอินอัตโนมัติด้วย Autologon ของ Microsoft

Microsoft มีเครื่องมือชื่อ Autologon จากชุด Sysinternals ใช้ตั้งกลไกล็อกอินอัตโนมัติที่มีอยู่ใน Windows ใส่ชื่อผู้ใช้และรหัสผ่านแล้วกด Enable ครั้งถัดไปที่เครื่องบูต Windows จะล็อกอินผู้ใช้นั้นให้เอง กด Disable เมื่อต้องการยกเลิก

หน้าคู่มือของเครื่องมือนี้เตือนไว้ตรง ๆ ว่ารหัสผ่านถูกเข้ารหัสเก็บไว้ใน Registry แต่ผู้ที่มีสิทธิ์ผู้ดูแลระบบของเครื่องถอดรหัสออกมาได้ไม่ยาก แปลว่าถ้าเลือกทางนี้ ความปลอดภัยของ VPS ทั้งเครื่องสำคัญขึ้นอีกขั้น ใช้รหัสที่ไม่ซ้ำกับบริการอื่น และป้องกันบัญชีแผงควบคุมของผู้ให้บริการด้วยรหัสแข็งแรงและการยืนยันสองขั้นตอน รายละเอียดอยู่ในบทความความปลอดภัย VPS สำหรับเทรด

ทดสอบด้วยการรีสตาร์ทจริง

ตั้งเสร็จแล้วอย่าเพิ่งเชื่อว่า MT5 เปิดอัตโนมัติได้จริง ทดสอบหนึ่งครั้งในช่วงที่ไม่มีอะไรเสีย

  1. เลือกช่วงตลาดปิด

    เช่น เช้าวันเสาร์ตามเวลาไทยหลังตลาดปิดสัปดาห์ ถ้ามีออเดอร์ค้างข้ามสัปดาห์ การรีสตาร์ทไม่ได้ปิดออเดอร์ แต่ช่วงตลาดปิดคือช่วงที่ EA หยุดสั้น ๆ แล้วไม่มีผล

  2. สั่ง Restart จากเมนู Start ของ VPS

    Remote Desktop จะหลุดไปเป็นเรื่องปกติ

  3. รอ 3 ถึง 5 นาที แล้วรีโมตกลับเข้าไป

    ถ้าตั้งล็อกอินอัตโนมัติ MT5 ควรเปิดรออยู่แล้ว ถ้าเลือกทางเลือก ก. MT5 จะเปิดหลังคุณล็อกอิน

  4. ไล่เช็กลิสต์หลังบูต

    ตามรายการในหัวข้อถัดไป ถ้าผ่านครบ ถือว่าระบบพร้อมรับการรีสตาร์ทครั้งต่อไป

เช็กลิสต์หลัง VPS รีสตาร์ท

  • MT5 ทุกตัวเปิดอยู่ และมุมขวาล่างแสดงตัวเลขการเชื่อมต่อ ไม่ใช่ข้อความว่าไม่มีการเชื่อมต่อ
  • ล็อกอินถูกบัญชี ดูเลขบัญชีในหน้าต่าง Navigator
  • กราฟที่มี EA อยู่ครบ ชื่อ EA ที่มุมขวาบนของกราฟพร้อมไอคอนสีฟ้า
  • ปุ่ม Algo Trading เป็นสีเขียว
  • แท็บ Experts และ Journal ไม่มีข้อความผิดพลาดหลังเปิดโปรแกรม
  • ผู้ใช้ EA WING ดูการ์ดล็อกอินบนแดชบอร์ด EA จะตรวจสิทธิ์ใหม่หลังเปิดโปรแกรม สีเขียวคือผ่าน สีเหลืองคือกำลังตรวจหรืออยู่ในช่วงผ่อนผัน ถ้าติดต่อเซิร์ฟเวอร์สิทธิ์ไม่ได้ชั่วคราว EA ยังทำงานต่อได้ 72 ชั่วโมง

ระบบสิทธิ์ที่ผูกกับเลขบัญชีทำงานยังไง และทำไมสลับบัญชีแล้วต้องตรวจใหม่ อธิบายไว้ในบทความระบบสิทธิ์ EA ผูกเลขบัญชี

อาการที่พบหลังตั้งค่า และวิธีแก้

อาการสาเหตุที่พบบ่อยวิธีแก้
MT5 ไม่เปิดเลยยังไม่มีใครล็อกอิน Windows หรือทางลัดอยู่ในโฟลเดอร์ Startup ของผู้ใช้อื่นทบทวนชั้นที่ 2 และ 3 ตั้งในผู้ใช้ที่ถูกต้อง
MT5 เปิด แต่ไม่ล็อกอินบัญชีไม่ได้ติ๊ก Save password หรือเพิ่งเปลี่ยนรหัสบัญชีเทรดล็อกอินใหม่และติ๊ก Save password
MT5 เปิด แต่กราฟหรือ EA หายโปรไฟล์ถูกเปลี่ยน หรือปิดกราฟไปก่อนรีสตาร์ทเปิดโปรไฟล์สำรองจาก File → Profiles
EA อยู่บนกราฟ แต่ปุ่ม Algo Trading เป็นสีแดงตัวเลือกใน Options ปิดการเทรดอัตโนมัติเอง หรือปุ่มถูกกดปิดไว้ก่อนรีสตาร์ทกดเปิดปุ่ม แล้วตรวจตัวเลือกในแท็บ Expert Advisors
MT5 ขึ้นหน้าต่างอัปเดตแล้วรีสตาร์ทตัวเองมีเวอร์ชันใหม่ของแพลตฟอร์มปล่อยให้เสร็จ แล้วไล่เช็กลิสต์อีกรอบ

คำเตือนความเสี่ยง: การตั้งให้ MT5 กลับมาเองช่วยลดเวลาที่ EA หยุด แต่ไม่ได้ทำให้ไม่หยุดเลย และไม่ได้ลดความเสี่ยงของตลาด ช่วงที่ EA ไม่ทำงาน ออเดอร์ที่เปิดค้างยังได้หรือเสียตามราคา การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ความเสี่ยงก่อนเริ่มใช้ EA ก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่อง MT5 เปิดอัตโนมัติ

จำเป็นต้องตั้งล็อกอินอัตโนมัติไหม?

ไม่บังคับ ถ้าคุณตั้งเวลารีสตาร์ทไว้ช่วงตลาดปิดและรีโมตเข้าไปตรวจทุกครั้งได้ ทางเลือก ก. ก็เพียงพอ แต่ถ้าอยากให้เครื่องกลับมาเองตอนรีสตาร์ทโดยไม่คาดคิด ทางเลือก ข. ช่วยได้มาก แลกกับการดูแลความปลอดภัยที่เข้มขึ้น

ใช้ Task Scheduler แบบรันตอนเครื่องบูตโดยไม่ต้องล็อกอินแทนได้ไหม?

ไม่แนะนำสำหรับผู้ใช้ทั่วไป งานที่ตั้งให้รันแม้ไม่มีผู้ใช้ล็อกอินจะทำงานแบบไม่มีหน้าจอให้เห็น คุณจะรีโมตเข้าไปดูหรือแก้ค่า MT5 ตัวนั้นไม่ได้ และเสี่ยงเปิดซ้ำกับตัวที่คุณเปิดเอง ใช้ Task Scheduler แบบ At log on ตามหัวข้อด้านบนจะปลอดภัยกว่า

MT5 เปิดกลับมาเองแล้ว ทำไม EA WING ยังไม่เทรด?

ดูการ์ดล็อกอินบนแดชบอร์ดก่อน ถ้ายังเป็นสีเหลือง EA กำลังตรวจสิทธิ์ รอสักครู่ ถ้าเป็นสีเขียวแล้วและปุ่ม Algo Trading เปิดอยู่ ระบบอาจแค่รอเงื่อนไขของตลาด ถ้าไม่แน่ใจ ส่งภาพกราฟกับแท็บ Experts ให้ทีมงานทาง LINE

อ่านต่อ

  • VPS สำหรับ EA ทั้งระบบ
  • ตั้งเวลา Windows Update บน VPS
  • ทำไมปุ่ม Algo Trading ดับเอง
  • ขั้นตอนติดตั้ง EA WING

ถ้ายังไม่ได้ติดตั้ง MT5 บนเครื่อง VPS เริ่มจากขั้นตอนเข้า Windows VPS และติดตั้ง MT5 แล้วกลับมาตั้งสามชั้นในหน้านี้ ติดตรงไหน ส่งภาพหน้าจอให้ทีมงานช่วยดูได้
