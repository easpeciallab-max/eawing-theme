Daily Loss Limit คือเพดานขาดทุนสูงสุดที่คุณยอมให้พอร์ตเสียได้ในหนึ่งวัน และเมื่อแตะเส้นนี้ต้องหยุด EA ตามกฎที่เขียนไว้ล่วงหน้าทันที ตัวเลขนี้ไม่ได้ทำให้ทุกวันขาดทุนน้อยลง แต่ช่วยไม่ให้วันที่แย่ที่สุดลากพอร์ตลงลึกเกินรับไหว ซึ่งเป็นหัวใจของการจัดการความเสี่ยงการใช้ EA

สรุปสั้น: ตั้งเพดานเป็น % ของ Equity ตอนเริ่มวันแล้วจดเป็นตัวเลข USD · นับแบบ Equity ที่รวมขาดทุนลอยเข้มงวดกว่า · กำหนดให้ชัดว่า "วัน" เริ่มตามเวลาเซิร์ฟเวอร์หรือเวลาไทย · MT5 ไม่มีช่องตั้งเพดานนี้ให้ คุณต้องบังคับกฎเองด้วยการเช็กตามเวลาและแจ้งเตือนมือถือ

Daily Loss Limit คืออะไร และทำไมพอร์ต EA ควรมี

EA ทำงานตามเงื่อนไขที่ถูกเขียนไว้ มันไม่รู้ว่าเจ้าของเงินเสียไปเท่าไรแล้วตั้งแต่เช้า วันที่ตลาดผิดปกติ เช่น ข่าวแรง สเปรดถ่าง หรือราคาวิ่งทางเดียวทั้งวัน ไม้ขาดทุนอาจเกิดติดกันภายในไม่กี่ชั่วโมง

เพดานขาดทุนรายวันจึงแยก "วันแย่" ออกจาก "เดือนแย่" สมมติพอร์ตปกติขยับวันละไม่ถึง 1% แต่วันที่ตลาดเหวี่ยงแรงอาจลบไป 8% ถ้ามีเพดาน 3% วันนั้นจะจบที่ราว 3% และยังเหลือทุนให้ทบทวนอย่างใจเย็น อีกข้อคือเมื่อกฎถูกเขียนไว้ก่อน คุณไม่ต้องตัดสินใจใหม่กลางความเครียด

เลือกตัวเลข: คิดเป็น % ของ Equity ตอนเริ่มวัน

การตั้งเพดานเป็น % ของ Equity ตอนเริ่มวันทำให้ตัวเลขโตและหดตามขนาดพอร์ต และถูกล็อกไว้ทั้งวัน คำนวณครั้งเดียวตอนเช้าแล้วจดไว้ สูตรคือ เพดาน = Equity ตอนเริ่มวัน × % ที่เลือก ส่วนเส้นหยุด = Equity ตอนเริ่มวัน - เพดาน

เทียบกับความเสี่ยงต่อออเดอร์

ถ้าแต่ละไม้เสี่ยงราว 1% ของ Equity เพดาน 3% ก็คือยอมแพ้ติดกันได้ประมาณ 3 ไม้ต่อวัน ถ้าบอกความเสี่ยงต่อไม้ได้ยาก ให้ดูจากบัญชีทดลองของคุณเองว่าวันที่แย่ตามปกติเสียราวเท่าไร แล้วตั้งเพดานให้สูงกว่านั้นเล็กน้อย เพดานแคบเกินจะหยุด EA บ่อยเกินจำเป็น กว้างเกินก็แทบไม่มีความหมาย

นับขาดทุนลอยด้วยไหม: แบบ Equity กับแบบ Balance

Balance คือเงินในบัญชีที่ยังไม่รวมผลของออเดอร์ที่เปิดอยู่ ส่วน Equity คือ Balance บวกกำไรหรือขาดทุนลอย ใครที่ยังสับสนว่าEquity กับ Balance ต่างกันอย่างไร ควรเคลียร์ให้ชัดก่อน เพราะสองวิธีนับนี้ให้ผลต่างกันมาก

แบบ Balance: นับเฉพาะไม้ที่ปิดแล้ว

เช็กง่ายจากแท็บ History แต่มีช่องโหว่ คือออเดอร์ที่ยังเปิดอยู่อาจติดลบหนักโดยไม่ถูกนับเลย

วันเริ่มตอนไหน: เวลาเซิร์ฟเวอร์ MT5 ไม่ใช่เวลาไทยเสมอไป

MT5 แสดงเวลาของเซิร์ฟเวอร์โบรกเกอร์ทั้งบนกราฟและในแท็บ History ซึ่งมักไม่ตรงกับเวลาไทย สมมติเซิร์ฟเวอร์ใช้ GMT+2 เที่ยงคืนตามเซิร์ฟเวอร์จะตรงกับ 05:00 น. เวลาไทย ถ้าเป็น GMT+3 ก็คือ 04:00 น. และบางโบรกเกอร์ปรับเวลาตามช่วง Daylight Saving ส่วนต่างจึงเปลี่ยนได้ปีละสองครั้ง วิธีหาส่วนต่างคือดูเวลาของดีลที่เพิ่งปิดในแท็บ History แล้วเทียบกับนาฬิกาบนมือถือ

  • ยึดเวลาเซิร์ฟเวอร์ 00:00: ตรงกับวันที่ในประวัติและรายงานของ MT5 แต่ต้องแปลงเวลาในหัว
  • ยึดเวลาไทยคงที่ เช่น 07:00 น.: จำง่าย และเพราะตลาด Forex เปิดสัปดาห์ราวตีสี่ถึงตีห้าเช้าวันจันทร์ตามเวลาไทย การเริ่มนับเจ็ดโมงจึงไม่ตัดกลางช่วงเปิดตลาด แต่เวลาดูประวัติต้องกำหนดช่วงเวลาเอง

เลือกแบบไหนก็ได้ ขอแค่เขียนไว้ในแผนการเทรดสำหรับ EA และใช้แบบเดิมทุกวัน

MT5 ไม่มีช่องตั้งเพดานให้ คุณต้องบังคับกฎเอง

MT5 บนคอมพิวเตอร์ไม่มีช่องให้ตั้งว่า "วันนี้ขาดทุนถึง 150 USD แล้วหยุด" สำหรับบัญชีเทรดทั่วไป เครื่องมือเสริมบางตัวอาจมีฟังก์ชันลักษณะนี้ แต่อย่าสมมติว่ามี ดังนั้น Daily Loss Limit ในทางปฏิบัติคือกฎที่คุณบังคับเอง ตามขั้นตอนนี้

  1. จดตัวเลขตอนเริ่มวัน

    เปิดแอป MT5 บนมือถือตามเวลาเริ่มวันที่กำหนด จด Equity เพดาน และเส้นหยุดลงโน้ต

  2. เช็ก Equity ตามเวลาที่กำหนด

    เลือกจุดเช็กที่เข้ากับชีวิต เช่น 12:30 น. 18:00 น. และ 22:00 น. ดูในแท็บ Trade ว่า Equity ยังอยู่เหนือเส้นหยุดหรือไม่

  3. ให้มือถือช่วยเตือนระหว่างวัน

    เมื่อตั้งแจ้งเตือน MT5 เข้ามือถือไว้แล้ว MT5 บนเครื่องที่รัน EA จะส่งข้อความทุกครั้งที่มีคำสั่งเทรดสำเร็จ ข้อความเด้งเมื่อไรให้เปิดดู Equity เทียบกับเส้นหยุด เพราะแจ้งเตือนไม่ได้คำนวณเพดานให้

  4. ตัดสินใจล่วงหน้าว่าจะหยุด EA ด้วยวิธีไหน

    วิธีแรกคือปิดปุ่ม Algo Trading บนแถบเครื่องมือ (ดูคู่มือ Algo Trading ของ MetaTrader 5) วิธีที่สองคือถอด EA ออกจากกราฟ ทั้งสองวิธีทำให้ EA ส่งคำสั่งไม่ได้ รวมถึงคำสั่งปิดหรือแก้ไขออเดอร์ และต้องทำบนเครื่องที่รัน EA หรือเข้า VPS จากมือถือ เพราะแอป MT5 มือถือทำไม่ได้

  5. ตัดสินใจล่วงหน้าว่าจะปิดออเดอร์ที่ค้างหรือไม่

    ปิดทันทีคือล็อกขาดทุนไว้ใกล้เพดาน ปล่อยไว้คือออเดอร์อาจฟื้นหรือลึกขึ้นจน Equity เลยเพดานไปไกล ไม่มีคำตอบเดียวที่ถูก แต่ต้องเลือกและเขียนไว้ก่อน ไม่ใช่ตัดสินใจตอนเห็นตัวเลขแดง

วันถัดไปหลังชนเพดาน: ทบทวนก่อนเปิด EA อีกครั้ง

ก่อนเปิด Algo Trading หรือแนบ EA กลับเข้ากราฟ ใช้เวลาสิบนาทีเช็กรายการนี้

  • ดูแท็บ Journal และ Experts บนเครื่องที่รัน EA ว่ามีการหลุดเชื่อมต่อหรือคำสั่งถูกปฏิเสธไหม
  • เทียบกับสภาพตลาดเมื่อวาน มีข่าวแรง สเปรดถ่าง หรือราคากระโดดหรือเปล่า
  • ตรวจว่าการตั้งค่า EA และขนาด Lot ยังตรงกับแผน
  • คำนวณเพดานใหม่จาก Equity ของวันนี้ ซึ่งเล็กลงตามทุน

ห้ามเพิ่ม Lot เพื่อเอาคืน

คำถามที่พบบ่อย

Daily Loss Limit ควรตั้งกี่เปอร์เซ็นต์?

ไม่มีตัวเลขเดียวที่ถูกกับทุกคน ขึ้นกับความเสี่ยงต่อไม้ ความแกว่งปกติของพอร์ต และเงินที่คุณเสียได้โดยไม่กระทบชีวิต ลองสังเกตบนบัญชีทดลองสักสองสามสัปดาห์ก่อนค่อยปรับ

ถ้าชนเพดานตอนตีสองระหว่างหลับ ต้องทำอย่างไร?

กฎที่บังคับด้วยมือมีช่องว่างในช่วงที่คุณไม่ว่างเสมอ ให้ตั้งเส้นหยุดแบบมีระยะเผื่อ และตื่นมาแล้วทำตามขั้นตอนที่เขียนไว้ทันที ไม่ใช่รอดูว่าจะฟื้นไหม

ปิด EA จากแอป MT5 บนมือถือได้ไหม?

ไม่ได้ แอปมือถือรันและควบคุม EA ไม่ได้ ต้องเข้า MT5 บนคอมหรือ VPS เพื่อปิด Algo Trading หรือถอด EA ออกจากกราฟ ถ้าใช้ Windows VPS ใช้แอป Windows App ของ Microsoft บนมือถือเข้าไปจัดการได้

ค่า Swap และค่าคอมมิชชันต้องนับด้วยไหม?

ควรนับ ถ้าใช้วิธีนับแบบ Equity ตัวเลขจะสะท้อนต้นทุนเหล่านี้ไปด้วยเพราะ Equity คือมูลค่าบัญชี ณ ขณะนั้น ไม่ต้องแยกคำนวณเอง

คำเตือนความเสี่ยง: การเทรด Forex และการใช้ EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด เพดานขาดทุนรายวันจำกัดความเสียหายได้เพียงบางส่วน เพราะราคาอาจกระโดดผ่านระดับที่ตั้งใจหยุด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ก่อนใช้เงินจริงควรอ่านประกาศความเสี่ยงฉบับเต็ม
