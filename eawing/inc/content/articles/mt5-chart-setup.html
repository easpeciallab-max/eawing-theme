ตั้งค่ากราฟ MT5 ให้อ่านง่ายทำได้ในสามขั้น คือปรับหน้าตาผ่านหน้าต่าง Properties (กด F8) บันทึกเป็น Template เพื่อใช้กับกราฟอื่นในคลิกเดียว แล้วเก็บทั้งหน้าจอไว้เป็น Profile ให้เปิดกลับมาเหมือนเดิมทุกครั้ง สำหรับคนใช้ EA มีข้อควรระวังหนึ่งข้อที่สำคัญกว่าเรื่องสี คือ Template เปลี่ยนสิ่งที่อยู่บนกราฟได้ทั้งหมด รวมถึง EA ด้วย ถ้ายังไม่คุ้นกับหน้าต่างหลักของโปรแกรม อ่านMT5 คืออะไรสำหรับคนเริ่มต้นประกอบได้

สรุปสั้น: กด F8 บนกราฟเพื่อปรับชนิดกราฟ สี และสิ่งที่แสดง แนะนำให้เปิดเส้น Ask และตัวแบ่งช่วงเวลา · คลิกขวาบนกราฟ → Templates → Save Template เพื่อบันทึก และเลือกจากรายการเดียวกันเพื่อใช้ซ้ำ · Profile เก็บกราฟทุกหน้าต่างที่เปิดอยู่ สลับได้จาก File → Profiles · อย่าใช้ Template กับกราฟที่ EA กำลังทำงาน และอย่าสลับ Profile บนเครื่องที่รัน EA โดยไม่ตั้งใจ

ตั้งค่ากราฟ MT5 ผ่านหน้าต่าง Properties (F8)

คลิกบนกราฟแล้วกด F8 หรือคลิกขวาเลือก Properties หน้าต่างนี้มีสามแท็บ คือ Common (ชนิดกราฟและการเลื่อน) Show (สิ่งที่แสดงบนกราฟ) และ Colors (สี) ตารางนี้สรุปค่าที่ช่วยให้อ่านง่ายสำหรับคนส่วนใหญ่

ทำไมควรเปิดเส้น Ask

แท่งเทียนบนกราฟวาดจากราคา Bid ซึ่งเป็นราคาฝั่งขาย แต่คำสั่งซื้อเปิดที่ราคา Ask ถ้าไม่เปิดเส้นนี้ คุณจะไม่เห็นราคาฝั่งซื้อบนกราฟเลย คู่มือของผู้พัฒนาก็ระบุว่าการแสดงเส้น Ask ช่วยให้คุมการเทรดได้แม่นยำขึ้น ระยะระหว่างเส้น Bid กับเส้น Ask คือ Spread ณ ตอนนั้น ทองคำเป็นสินค้าที่ Spread เปลี่ยนได้มากตามช่วงเวลา การเห็นสองเส้นนี้จึงช่วยให้รู้ทันทีว่าช่วงไหนต้นทุนสูงกว่าปกติ

ตัวแบ่งช่วงเวลาอิงเวลาเซิร์ฟเวอร์

เส้นแบ่งวันบนกราฟลากตามเที่ยงคืนของเวลาเซิร์ฟเวอร์ ไม่ใช่เที่ยงคืนเวลาไทย แท่งของวันใหม่บนกราฟจึงอาจเริ่มตอนเช้ามืดตามเวลาไทย วิธีอ่านส่วนต่างนี้อยู่ในบทความทำไมเวลาบนกราฟ MT5 ไม่ตรงเวลาไทย

ตั้งค่าที่อยู่นอกหน้าต่าง F8

บางค่าเป็นของทั้งโปรแกรม อยู่ใน Tools → Options แท็บ Charts เช่น Show trade levels ระดับโปรแกรม (ต้องเปิดทั้งที่นี่และในแท็บ Show ของกราฟ เส้นออเดอร์จึงจะขึ้น) และ Max bars in chart ซึ่งมีผลหลังรีสตาร์ต ค่านี้กระทบหน่วยความจำและข้อมูลย้อนหลังที่โปรแกรมเก็บไว้ บนเครื่องที่รัน EA อย่าปรับลดโดยไม่ถามผู้พัฒนา EA ก่อน เพราะ EA บางตัวต้องใช้ข้อมูลย้อนหลังในการคำนวณ

Template MT5 คืออะไร และใช้อย่างไร

Template คือไฟล์ที่จำหน้าตาของกราฟหนึ่งกราฟไว้ทั้งหมด ได้แก่ ชนิดกราฟ ชุดสี สเกล อินดิเคเตอร์พร้อมค่าตั้ง วัตถุที่วาดไว้ ตัวแบ่งช่วงเวลา และ EA ที่ติดอยู่พร้อมค่าตั้งของมัน ไฟล์มีนามสกุล .tpl เก็บอยู่ในโฟลเดอร์ MQL5 → Profiles → Templates ของ Data Folder

  1. จัดกราฟต้นแบบหนึ่งกราฟ

    ปรับสีและสิ่งที่แสดงผ่าน F8 ใส่อินดิเคเตอร์ที่ใช้ประจำ บนกราฟที่ไม่มี EA

  2. บันทึกเป็น Template

    คลิกขวาบนกราฟ → Templates → Save Template ตั้งชื่อที่บอกหน้าที่ เช่น ชื่อที่ขึ้นต้นด้วยคำว่า analysis

  3. ใช้กับกราฟอื่น

    เปิดกราฟใหม่ คลิกขวา → Templates แล้วเลือกชื่อจากรายการด้านล่างของเมนู หรือเลือก Load Template เพื่อเปิดไฟล์จากโฟลเดอร์อื่น

  4. ตั้งเป็นค่าเริ่มต้น (ถ้าต้องการ)

    บันทึก Template ชื่อ default จะถูกใช้กับกราฟใหม่ทุกกราฟที่เปิดหลังจากนี้ ส่วน tester คือ Template ของกราฟที่แสดงผลการทดสอบใน Strategy Tester

รายละเอียดของ Template และ Profile ดูเพิ่มได้จากคู่มือ Templates and Profiles ของ MetaTrader 5

Template กับกราฟที่มี EA: จุดที่ต้องระวังที่สุด

การใช้ Template กับกราฟ คือการแทนที่ทุกอย่างบนกราฟนั้นด้วยสิ่งที่อยู่ใน Template เอกสาร MQL5 ระบุว่าการใช้ Template ใหม่เป็นหนึ่งในเหตุผลที่โปรแกรมบนกราฟถูกหยุดการทำงาน (REASON_TEMPLATE) ผลในทางปฏิบัติคือ

  • ใช้ Template ที่ไม่มี EA กับกราฟที่ EA ทำงานอยู่ EA จะหลุดออกจากกราฟ
  • ใช้ Template ที่มี EA ติดอยู่ EA ตัวนั้นจะถูกใส่พร้อมค่าตั้งที่บันทึกไว้ในไฟล์ ซึ่งอาจไม่ใช่ค่าที่คุณใช้อยู่ตอนนี้
  • บันทึก default จากกราฟที่มี EA ติดอยู่ กราฟใหม่ที่เปิดหลังจากนั้นอาจมี EA ติดมาด้วย และกลายเป็น EA ทำงานซ้อนหลายกราฟ

Template จึงไม่ใช่วิธีเก็บค่าตั้งของ EA ที่ดี และต่างจากไฟล์ค่าตั้งที่ EA บางตัวใช้ อ่านความต่างได้ในSet File ของ EA และวิธีใช้ สำหรับ [eawing_brand] ไม่ใช้ไฟล์ .set และไม่จำเป็นต้องใช้ Template ใด ๆ โหมด Lite และ Full อยู่ในไฟล์ EA ไฟล์เดียว

Profile คืออะไร ต่างจาก Template อย่างไร

บันทึกอย่างไรสั่งบันทึกเองทุกครั้งการเปลี่ยนแปลงบันทึกลง Profile ปัจจุบันอัตโนมัติ และ Save As เป็นชื่อใหม่ได้

ลูกเล่นที่หลายคนไม่รู้คือ Profile ที่ตั้งชื่อเป็นเลขบัญชีเทรด จะถูกเปิดใช้อัตโนมัติเมื่อสลับไปบัญชีนั้น เหมาะกับคนที่มีหลายบัญชีบนเครื่องเดียวและอยากให้หน้าจอของแต่ละบัญชีแยกกัน

สลับ Profile บนเครื่องที่รัน EA: ระวังให้มาก

กราฟที่มี EA ทำงานอยู่ถูกเก็บใน Profile ด้วย ถ้าสลับไป Profile อื่นที่ไม่มีกราฟนั้น EA ก็หยุดทำงานไปพร้อมกับกราฟ และใน Tools → Options แท็บ Expert Advisors ยังมีตัวเลือกปิด Algo Trading เองเมื่อเปลี่ยน Profile อีกชั้นหนึ่ง อ่านผลของตัวเลือกนี้ได้ในปุ่ม Algo Trading ดับเอง วิธีที่พลาดยากกว่าคือใช้ Profile เดียวบนเครื่องที่รัน EA แล้วเปิดกราฟเพิ่มสำหรับดูตลาดใน Profile เดิม หรือดูกราฟจากอีกเครื่องหนึ่ง

ย้าย Template และ Profile ไปเครื่องใหม่หรือ VPS

  1. เปิดโฟลเดอร์ของเครื่องเดิม

    File → Open Data Folder แล้วเข้า MQL5 → Profiles

  2. คัดลอกไฟล์ที่ต้องการ

    Template อยู่ในโฟลเดอร์ Templates เป็นไฟล์ .tpl ส่วน Profile อยู่ในโฟลเดอร์ Charts แยกเป็นโฟลเดอร์ตามชื่อ Profile

  3. วางในตำแหน่งเดียวกันบนเครื่องใหม่

    เปิด Data Folder ของ MT5 บนเครื่องใหม่ด้วยวิธีเดียวกัน แล้ววางไฟล์ในโฟลเดอร์ชื่อเดียวกัน

  4. รีสตาร์ต MT5 แล้วตรวจ

    ดูว่า Template ขึ้นในรายการ และกราฟของ Profile เปิดได้ ถ้ากราฟเป็นทองคำแต่ชื่อสัญลักษณ์ของโบรกเกอร์ใหม่ต่างจากเดิม ต้องเปิดกราฟของสัญลักษณ์ที่ถูกต้องใหม่ ดูวิธีหาได้ในวิธีเพิ่มทองคำใน Market Watch

ถ้าย้ายทั้งเครื่องรวมถึง EA ด้วย ให้ทำตามลำดับงานในย้าย EA และ MT5 ไป VPS ใหม่ ซึ่งรวมการตั้งสวิตช์และการล็อกอินไว้แล้ว การคัดลอก Profile ที่มี EA ติดอยู่ไม่ได้แทนการตั้งค่าเหล่านั้น

กราฟที่ EA WING ทำงาน: ตั้งค่าแค่ไหนพอ

EA WING ทำงานบนกราฟ XAUUSD กรอบเวลา M1 (บางโบรกเกอร์มีตัวต่อท้ายชื่อ) และแสดงแดชบอร์ดกับการ์ดล็อกอินบนกราฟนั้น หลักการตั้งค่ากราฟ MT5 สำหรับกราฟนี้คือให้เรียบที่สุด

  • ปรับสีและเปิดเส้น Ask ผ่าน F8 ได้ การเปลี่ยนสีไม่ได้รบกวน EA
  • เปิดกราฟทองคำอีกหน้าต่างสำหรับดูกรอบเวลาอื่นหรือใส่อินดิเคเตอร์
  • บันทึก Profile สำรองไว้ หลังจัดหน้าจอเรียบร้อย
  • ใช้ Template ใด ๆ กับกราฟที่มี EA
  • เปลี่ยนกรอบเวลาหรือสัญลักษณ์ของกราฟที่มี EA
  • ใส่ EA ตัวอื่นซ้อนบนบัญชีเดียวกันโดยไม่ได้ปรึกษาทีมงาน

ถ้าเผลอใช้ Template แล้ว EA หลุดจากกราฟ ให้ลาก EA_WING_V4.2.ex5 ลงกราฟ XAUUSD M1 ใหม่ ติ๊ก Allow Algo Trading ในแท็บ Common และ Allow DLL imports ในแท็บ Dependencies แล้วดูว่าการ์ดล็อกอินกลับเป็นสีเขียว ถ้าไม่แน่ใจ ส่งภาพกราฟให้ทีมงานดูทาง LINE ก่อนทำต่อ

คำถามที่พบบ่อยเรื่องตั้งค่ากราฟ MT5

ทำไมเปิดกราฟใหม่แล้วมีอินดิเคเตอร์ติดมาเอง?

เพราะ Template ชื่อ default ถูกใช้กับกราฟใหม่ทุกกราฟ ถ้าเคยบันทึก default จากกราฟที่มีอินดิเคเตอร์หรือ EA สิ่งเหล่านั้นจะติดมาด้วย ให้จัดกราฟเปล่าตามต้องการแล้วบันทึกทับเป็น default ใหม่

ใช้ Template ที่คนอื่นแชร์มาได้ไหม?

ได้ถ้ามาจากแหล่งที่ไว้ใจ และควรเปิดกับกราฟว่างบนบัญชีเดโมก่อน เพราะ Template เก็บ EA และค่าตั้งของมันไว้ได้ ถ้ามี EA ติดมา มันจะถูกใส่ลงกราฟทันทีที่ใช้ Template

เปลี่ยนสีหรือเปิดเส้น Ask บนกราฟที่มี EA ทำให้ EA เริ่มใหม่ไหม?

การปรับสีและสิ่งที่แสดงผ่าน F8 ไม่ได้อยู่ในรายการเหตุผลที่ทำให้ EA หยุดทำงานตามเอกสาร MQL5 สิ่งที่ทำให้ EA หยุดหรือเริ่มใหม่คือการเปลี่ยนสัญลักษณ์หรือกรอบเวลา การใช้ Template การปิดกราฟ และการเปลี่ยนบัญชี

Profile หายหลัง VPS ดับกะทันหัน ทำอย่างไร?

ถ้าบันทึก Profile สำรองไว้ด้วย Save As เลือกเปิดจาก File → Profiles ได้ทันที ถ้าไม่มี ต้องจัดกราฟใหม่และใส่ EA กลับลงกราฟ แล้วตรวจสวิตช์ทุกจุดก่อนปล่อยให้ทำงาน

คำเตือนความเสี่ยง: กราฟที่ตั้งค่าไว้อ่านง่ายช่วยให้เห็นข้อมูลชัดขึ้น แต่ไม่ได้ลดความเสี่ยงของตลาด และการใช้ Template ผิดกราฟอาจทำให้ EA หยุดหรือทำงานด้วยค่าตั้งที่ไม่ได้ตั้งใจ การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ข้อมูลความเสี่ยงของการใช้ EA ก่อนใช้เงินจริง
