เปลี่ยนรหัส MT5 ทำได้เองในโปรแกรมภายในหนึ่งนาที ขอแค่ยังจำรหัสผ่านหลักปัจจุบันได้และเครื่องเชื่อมต่อกับเซิร์ฟเวอร์อยู่ ที่ต้องคิดก่อนกดคือจะเปลี่ยนรหัสชุดไหน และหลังเปลี่ยนแล้วมีเครื่องไหนบ้างที่ยังจำรหัสเก่าไว้ โดยเฉพาะ VPS ที่รัน EA ถ้ายังไม่คุ้นกับหน้าต่างต่าง ๆ ของโปรแกรม อ่านMT5 คืออะไรและมีหน้าต่างอะไรบ้างประกอบได้

สรุปสั้น: บนคอม: คลิกขวาที่บัญชีในหน้าต่าง Navigator เลือก Change Password หรือไปที่ Tools → Options แท็บ Server กด Change · ใส่รหัสผ่านหลักปัจจุบัน เลือกว่าจะเปลี่ยนรหัสหลักหรือรหัส Investor แล้วตั้งรหัสใหม่ที่มีตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ ตัวเลข และสัญลักษณ์ · บนมือถือมีเมนู Change Password ในหน้าจัดการบัญชี · หลังเปลี่ยน ให้ล็อกอินด้วยรหัสใหม่บนทุกเครื่อง เริ่มจากเครื่องที่รัน EA

รหัส MT5 มีสองชุด: จะเปลี่ยนตัวไหน

บัญชี MT5 ทุกบัญชีมีรหัสผ่านหลัก (Master) ที่เทรดได้เต็มรูปแบบ และรหัส Investor ที่ดูได้อย่างเดียว การเปลี่ยนทั้งสองชุดทำจากหน้าต่างเดียวกัน แต่ใช้ในสถานการณ์ต่างกัน

สถานการณ์เปลี่ยนชุดไหนเหตุผล
ได้รหัสมาจากอีเมลเปิดบัญชีและยังไม่เคยเปลี่ยนรหัสหลักรหัสที่ส่งทางอีเมลถูกเก็บไว้ในกล่องจดหมาย ควรเปลี่ยนเป็นรหัสที่มีแต่คุณรู้
สงสัยว่ามีคนอื่นรู้รหัสหลักรหัสหลัก ทันทีรหัสหลักส่งคำสั่งซื้อขายได้
เคยแชร์รหัส Investor ให้คนอื่นดูพอร์ต แล้วอยากเลิกให้ดูรหัส Investorตัดสิทธิ์ดูพอร์ตโดยไม่กระทบเครื่องที่เทรดอยู่
เซิร์ฟเวอร์บังคับให้เปลี่ยนตอนล็อกอินรหัสหลัก แล้วตั้ง Investor ใหม่คู่มือของผู้พัฒนาระบุว่าเมื่อถูกบังคับเปลี่ยนรหัสหลัก รหัส Investor จะถูกรีเซ็ตด้วย

ทุกกรณีต้องใช้รหัสผ่านหลักปัจจุบันยืนยันตัวตน แม้จะเปลี่ยนแค่รหัส Investor ก็ตาม

เปลี่ยนรหัส MT5 บนคอมพิวเตอร์ทีละขั้น

  1. ตรวจว่าเชื่อมต่ออยู่

    มุมขวาล่างของ MT5 ต้องแสดงค่าความหน่วงเป็นมิลลิวินาที การเปลี่ยนรหัสต้องทำผ่านเซิร์ฟเวอร์ ถ้าไม่ได้เชื่อมต่อจะเปลี่ยนไม่สำเร็จ

  2. เปิดหน้าต่างเปลี่ยนรหัส

    กด Ctrl+N เปิด Navigator คลิกขวาที่เลขบัญชีในหมวด Accounts แล้วเลือก Change Password หรือไปที่ Tools → Options แท็บ Server แล้วกดปุ่ม Change ข้างช่องรหัสผ่าน

  3. ใส่รหัสผ่านหลักปัจจุบัน

    ช่อง Login เป็นเลขบัญชีที่แก้ไม่ได้ ช่องถัดมาให้ใส่รหัสผ่านหลักที่ใช้อยู่

  4. เลือกชุดที่จะเปลี่ยน

    เลือก Change master password หรือ Change investor password ให้ตรงกับที่ตั้งใจ

  5. ตั้งรหัสใหม่และยืนยัน

    พิมพ์รหัสใหม่สองครั้งให้ตรงกัน แล้วกด OK ถ้าไม่ผ่านเงื่อนไข หน้าต่างจะไม่ยอมบันทึก

  6. บันทึกรหัสใหม่ไว้ในที่ปลอดภัย

    เก็บในโปรแกรมจัดการรหัสผ่าน ไม่จดในไฟล์บนเดสก์ท็อปของ VPS

คำอธิบายของแต่ละช่องดูเพิ่มได้ในคู่มือการตั้งค่าแพลตฟอร์ม MetaTrader 5 หัวข้อ Server และ Password (ภาษาอังกฤษ)

เงื่อนไขของรหัสใหม่

  • ยาวไม่น้อยกว่าที่หน้าต่างกำหนด (ตัวเลขขั้นต่ำแสดงในหน้าต่างเปลี่ยนรหัส)
  • มีครบสี่ประเภท: ตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ ตัวเลข และอักขระพิเศษ
  • ไม่ซ้ำกับรหัสเดิม

วิธีที่จำง่ายกว่าตัวอักษรสุ่มคือใช้วลีสั้น ๆ ที่มีความหมายกับคุณ แล้วผสมตัวพิมพ์ใหญ่ ตัวเลข และสัญลักษณ์เข้าไป อย่าใช้รหัสเดียวกับอีเมล ธนาคาร หรือ VPS

เปลี่ยนรหัสผ่าน MT5 บนมือถือ

อุปกรณ์ทางไปตัวเลือกที่มี
Androidเข้าหน้า Accounts แตะปุ่มเมนูมุมขวาบน แล้วเลือก Change Passwordเปลี่ยนรหัสหลัก หรือรหัส Investor
iPhone และ iPadเข้าส่วนจัดการบัญชีปัจจุบันในหน้า Settings แล้วแตะ Change PasswordChange Master Password, Change Investor Password และ Clear Saved Password

บนมือถือ การเปลี่ยนรหัสมีผลกับบัญชีที่กำลังเชื่อมต่ออยู่เท่านั้น ถ้ามีหลายบัญชี ให้สลับไปบัญชีที่ต้องการก่อน ตัวเลือก Clear Saved Password ไม่ได้เปลี่ยนรหัส แค่ลบรหัสที่แอปจำไว้ ครั้งหน้าต้องพิมพ์ใหม่ รายละเอียดฝั่ง Android อยู่ในคู่มือจัดการรหัสผ่านของ MT5 Android

เปลี่ยนผ่านหน้าเว็บของโบรกเกอร์ได้ไหม

หลายโบรกเกอร์มีเมนูเปลี่ยนหรือรีเซ็ตรหัสบัญชีเทรดในพื้นที่สมาชิกบนเว็บ (Portal) วิธีนี้ใช้ได้แม้ไม่ได้เปิด MT5 อยู่ แต่ชื่อเมนูและขั้นตอนต่างกันไปตามโบรกเกอร์ ให้ดูเงื่อนไขล่าสุดที่หน้า Portal ของโบรกเกอร์ที่ใช้

จุดที่ควรรู้คือ รหัสเข้าเว็บ Portal กับรหัสบัญชีเทรด MT5 เป็นคนละชุดกัน การเปลี่ยนรหัสเข้าเว็บไม่ได้เปลี่ยนรหัส MT5 และกลับกัน คนที่สับสนสองชุดนี้มักล็อกอิน MT5 ไม่ผ่านแล้วคิดว่าบัญชีมีปัญหา

หลังเปลี่ยนรหัส MT5: เช็กทุกเครื่องที่เคยล็อกอิน

เครื่องอื่นที่บันทึกรหัสเก่าไว้จะล็อกอินไม่ผ่าน อาจหลุดทันทีหรือหลุดเมื่อเชื่อมต่อใหม่ครั้งถัดไป เช่น หลังเน็ตกระตุก หลังรีสตาร์ต หรือหลังเปิดแอปใหม่ ให้ไล่ทีละเครื่อง

  • VPS หรือคอมที่รัน EA สำคัญที่สุด ล็อกอินใหม่ผ่าน File → Login to Trade Account ด้วยรหัสใหม่และติ๊กบันทึกรหัส
  • แอป MT5 บนมือถือและแท็บเล็ต เปิดแอปแล้วใส่รหัสใหม่เมื่อถูกถาม
  • คอมเครื่องอื่นหรือ MT5 ชุดที่สอง ที่เคยเปิดบัญชีนี้ไว้
  • บริการที่ใช้รหัส Investor ถ้าเปลี่ยนรหัส Investor บริการติดตามพอร์ตที่ผูกไว้จะดึงข้อมูลไม่ได้จนกว่าจะอัปเดตรหัสใหม่

ตัวอย่างสมมติ: เปลี่ยนรหัสจากมือถือ แล้ว VPS หลุดตอนตี 3

เทรดเดอร์คนหนึ่งเปลี่ยนรหัสหลักจากแอปบนมือถือช่วงพักเที่ยง ทุกอย่างดูปกติ เพราะ MT5 บน VPS ยังเชื่อมต่อค้างอยู่ คืนนั้นเน็ตของ VPS กระตุกสั้น ๆ โปรแกรมพยายามล็อกอินใหม่ด้วยรหัสเก่าที่จำไว้และไม่ผ่าน EA จึงหยุดส่งคำสั่งไปจนถึงเช้า เขามารู้ตัวตอนเปิดแอปแล้วเห็นว่าไม่มีความเคลื่อนไหวเลย เรื่องนี้แต่งขึ้นเพื่ออธิบาย บทเรียนคือเปลี่ยนรหัสจากเครื่องไหนก็ตาม ต้องตามไปล็อกอินใหม่บนเครื่องที่รัน EA ในวันเดียวกันเสมอ

ถ้าเซิร์ฟเวอร์บังคับให้เปลี่ยนรหัส

ผู้ดูแลเซิร์ฟเวอร์ของโบรกเกอร์เปิดระบบบังคับเปลี่ยนรหัสหลักได้ เมื่อถึงเงื่อนไขที่โบรกเกอร์กำหนด หน้าต่างเปลี่ยนรหัสจะเด้งขึ้นเองตอนล็อกอิน ให้ทำตามขั้นตอนเดียวกัน แล้วอย่าลืมว่ารหัส Investor ถูกรีเซ็ตไปด้วย ถ้าเคยแชร์ให้ใครดูพอร์ตหรือผูกกับบริการติดตามผล ต้องตั้งรหัส Investor ใหม่แล้วอัปเดตปลายทางเหล่านั้น

ถ้าเครื่องไหนขึ้นข้อความเชื่อมต่อไม่ได้หรือบัญชีไม่ถูกต้องหลังเปลี่ยนรหัส ให้ตรวจว่าพิมพ์รหัสใหม่ถูก แล้วไล่ต่อตามบทความวิธีแก้ MT5 ขึ้น No connection

เปลี่ยนรหัสบนบัญชีที่รัน EA: ลำดับที่แนะนำ

EA ไม่ได้ผูกกับรหัสผ่าน แต่ต้องการให้ MT5 เชื่อมต่ออยู่ตลอด ถ้า VPS ยังจำรหัสเก่าและหลุดกลางดึก EA จะหยุดส่งคำสั่งจนกว่าคุณจะเข้าไปแก้ ลำดับนี้ช่วยลดช่วงที่ระบบหลุด

  1. เลือกเวลา

    ทำช่วงตลาดปิดสุดสัปดาห์ หรือช่วงที่ไม่มีออเดอร์ค้าง และมีเวลานั่งตรวจต่อสักสิบนาที

  2. รีโมตเข้า VPS ก่อน

    เปิดหน้าจอ VPS ไว้ให้พร้อม จะได้ล็อกอินใหม่ได้ทันทีหลังเปลี่ยน

  3. เปลี่ยนรหัสจาก MT5 บน VPS

    ใช้ขั้นตอนในหัวข้อคอมพิวเตอร์ด้านบน แล้วล็อกอินซ้ำด้วยรหัสใหม่และติ๊กบันทึกรหัส

  4. ตรวจสถานะหลังล็อกอิน

    ดูค่าความหน่วงมุมขวาล่าง กราฟที่มี EA ยังอยู่ และปุ่ม Algo Trading ยังเป็นสีเขียว ถ้าปุ่มดับ อ่านสาเหตุได้ในปุ่ม Algo Trading ดับเอง

  5. อัปเดตมือถือและเครื่องอื่น

    ล็อกอินใหม่บนแอปมือถือที่ใช้ดูพอร์ต แล้วจดไว้ว่าเปลี่ยนรหัสเมื่อไร

สำหรับผู้ใช้ [eawing_brand] สิทธิ์ใช้งานผูกกับเลขบัญชี MT5 ไม่ได้ผูกกับรหัสผ่าน การเปลี่ยนรหัสจึงไม่ต้องขอสิทธิ์ใหม่ และไม่ต้องแจ้งรหัสให้ทีมงาน หลังล็อกอินใหม่ให้ดูว่าการ์ดล็อกอินบนแดชบอร์ดกลับเป็นสีเขียว ถ้าเปลี่ยนไปใช้เลขบัญชีอื่นเมื่อไร จึงต้องส่งเลขบัญชีใหม่ไปขอสิทธิ์ รายละเอียดอยู่ในกลไกสิทธิ์ EA แบบผูกเลขบัญชี

ลืมรหัสปัจจุบัน เปลี่ยนเองได้ไหม

ไม่ได้ หน้าต่างเปลี่ยนรหัสใน MT5 ต้องใช้รหัสผ่านหลักปัจจุบันเสมอ ถ้าลืม ต้องขอรีเซ็ตผ่านโบรกเกอร์ ส่วนใหญ่ทำได้จากพื้นที่สมาชิกบนเว็บหรือผ่านฝ่ายบริการลูกค้า ขั้นตอนและข้อควรระวังอ่านต่อได้ที่ลืมรหัส MT5 ต้องรีเซ็ตอย่างไร

ดูแลรหัสบัญชีเทรดให้ปลอดภัย

  • ใช้รหัสบัญชีเทรดที่ไม่ซ้ำกับบริการอื่น และไม่ซ้ำกับรหัสเข้า VPS
  • แชร์ได้เฉพาะรหัส Investor เมื่อจำเป็น และเปลี่ยนเมื่อเลิกแชร์
  • ไม่ส่งรหัสผ่านทางแชต ไม่ว่าจะอ้างว่าเป็นโบรกเกอร์ ทีมงาน EA หรือผู้ดูแลระบบ
  • ถ้าโบรกเกอร์รองรับการยืนยันตัวตนด้วยรหัสใช้ครั้งเดียว (OTP) ในแอป MT5 ให้พิจารณาเปิดใช้
  • จดรหัสไว้ในไฟล์ข้อความบนเดสก์ท็อปของ VPS
  • ใช้รหัสที่ส่งมาทางอีเมลตอนเปิดบัญชีไปตลอด

ความปลอดภัยของเครื่องที่รัน EA สำคัญพอกับรหัสบัญชี เพราะใครเข้า VPS ได้ก็เปิด MT5 ที่บันทึกรหัสไว้ได้ อ่านต่อในความปลอดภัยของ VPS ที่ใช้เทรด

คำถามที่พบบ่อยเรื่องเปลี่ยนรหัส MT5

เปลี่ยนรหัสแล้ว EA หยุดทำงานไหม?

ตัว EA ไม่ได้ใช้รหัสผ่าน แต่ถ้า MT5 บนเครื่องที่รัน EA หลุดเพราะยังจำรหัสเก่า EA ก็ส่งคำสั่งไม่ได้ ให้ล็อกอินใหม่ด้วยรหัสใหม่บนเครื่องนั้นทันทีหลังเปลี่ยน แล้วตรวจปุ่ม Algo Trading และกราฟที่มี EA

เปลี่ยนรหัส Investor ต้องใส่รหัสอะไรยืนยัน?

ต้องใส่รหัสผ่านหลักปัจจุบัน ไม่ใช่รหัส Investor เดิม คนที่มีแค่รหัส Investor จึงเปลี่ยนรหัสใด ๆ ของบัญชีไม่ได้

กด OK แล้วไม่ผ่าน เพราะอะไร?

สาเหตุที่พบบ่อยคือรหัสใหม่สั้นเกินไป ขาดอักขระบางประเภท ซ้ำกับรหัสเดิม หรือใส่รหัสปัจจุบันผิด ถ้าครบทุกข้อแล้วยังไม่ผ่าน ให้ตรวจว่าเชื่อมต่อกับเซิร์ฟเวอร์อยู่

สำหรับ EA ที่ผูกสิทธิ์กับเลขบัญชีอย่าง EA WING ไม่ต้องแจ้ง เพราะเลขบัญชีเท่าเดิม และไม่ควรส่งรหัสผ่านให้ใครอยู่แล้ว แจ้งทีมงานเฉพาะเมื่อเปลี่ยนเลขบัญชี

คำเตือนความเสี่ยง: ถ้าเครื่องที่รัน EA หลุดการเชื่อมต่อหลังเปลี่ยนรหัส ออเดอร์ที่เปิดอยู่จะไม่ได้รับการดูแลจาก EA จนกว่าจะล็อกอินใหม่ ให้เปลี่ยนรหัสในช่วงที่ตรวจต่อได้ทันที การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน หน้าคำเตือนความเสี่ยง ก่อนใช้เงินจริง
