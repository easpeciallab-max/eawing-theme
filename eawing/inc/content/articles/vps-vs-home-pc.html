รัน EA คอมที่บ้านได้ ถ้าเครื่องเปิดทิ้งไว้ได้จริงและตั้งค่าถูก เพราะ EA ต้องการแค่ MT5 บน Windows ที่เปิดอยู่และต่อเน็ตได้ ปัญหาอยู่ที่คอมที่บ้านมีหลายทางที่หยุดไปเองโดยไม่มีใครรู้ บทความนี้อธิบายว่าปิดคอมแล้วอะไรยังทำงาน อะไรหยุด เทียบกับ VPS ทีละหัวข้อ และบอกวิธีเตรียมเครื่องถ้าคุณเลือกใช้คอมเอง ส่วนเรื่องการเลือกและตั้งค่า VPS ทั้งหมดอยู่ในคู่มือ VPS สำหรับบอทเทรด

สรุปสั้น: ได้ แต่ EA ทำงานเฉพาะตอนที่ MT5 บนเครื่องเปิดอยู่ · ปิดคอมแล้วออเดอร์ที่เปิดไว้ยังอยู่ที่โบรกเกอร์ และระดับ Stop Loss หรือ Take Profit ที่แนบไว้กับออเดอร์ยังมีผล แต่ Trailing Stop ของ MT5 และทุกอย่างที่ EA ต้องสั่งต่อจะหยุด · ถ้าใช้คอมเอง ให้ปิด Sleep คุมเวลา Windows Update มีไฟสำรอง และให้ MT5 เปิดเองหลังบูต · สำหรับบัญชีเงินจริงระยะยาว VPS มีจุดหยุดน้อยกว่า

EA ปิดคอมแล้วยังทำงานไหม

ไม่ทำงาน EA เป็นโปรแกรมที่รันอยู่ใน MT5 บนเครื่องของคุณ เมื่อคอมดับ เข้าโหมด Sleep หรือ MT5 ถูกปิด EA ก็หยุดคิดและหยุดส่งคำสั่งทันที แต่ไม่ได้แปลว่าทุกอย่างในบัญชีหยุดตาม เพราะบางส่วนอยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์

สิ่งที่เกี่ยวข้องอยู่ที่ไหนเมื่อปิดคอม
ออเดอร์ที่เปิดอยู่เซิร์ฟเวอร์ของโบรกเกอร์ยังเปิดอยู่ กำไรขาดทุนลอยยังขยับตามราคา
ระดับ Stop Loss และ Take Profit ที่แนบกับออเดอร์ (ถ้ามี)เซิร์ฟเวอร์ของโบรกเกอร์ยังมีผล ถ้าราคาถึงก็ถูกปิดตามระดับนั้น
คำสั่งรอเปิด (Pending order)เซิร์ฟเวอร์ของโบรกเกอร์ยังรออยู่ และทำงานเมื่อราคาถึง
Trailing Stop ที่ตั้งจาก MT5ตัวโปรแกรม MT5 บนเครื่องหยุดเลื่อน
ตรรกะของ EA เช่น เปิดออเดอร์ใหม่หรือจัดการออเดอร์ตามเงื่อนไขตัวโปรแกรม MT5 บนเครื่องหยุดทั้งหมดจนกว่า MT5 จะกลับมา

คู่มือของ MT5 ระบุชัดว่าTrailing Stop ทำงานในตัวแพลตฟอร์ม ไม่ได้ทำงานบนเซิร์ฟเวอร์ จึงไม่ทำงานเมื่อปิดแพลตฟอร์ม ต่างจากระดับ Stop Loss และ Take Profit ที่ส่งไปอยู่กับออเดอร์แล้ว ส่วนแอป MT5 บนมือถือยังเห็นบัญชีและออเดอร์ได้ตามปกติ แต่รัน EA แทนคอมไม่ได้ เหตุผลอยู่ในเรื่องEA มือถือ: ทำไมต้องมีคอมหรือ VPS

รัน EA คอมที่บ้าน: อะไรทำให้เครื่องหยุดโดยไม่รู้ตัว

คนที่รัน EA บนคอมที่บ้านส่วนใหญ่ไม่ได้ตั้งใจปิดเครื่อง เครื่องหยุดเพราะเหตุเล็ก ๆ ที่เกิดตอนไม่มีใครอยู่หน้าจอ

  • โหมด Sleep หรือ Hibernate: Windows ตั้งให้เครื่องหลับเองเมื่อไม่มีใครใช้ตามเวลาที่กำหนด MT5 หยุดตามทันที
  • Windows Update รีสตาร์ต: ลงอัปเดตแล้วบูตใหม่นอกช่วง Active hours ซึ่งมักเป็นกลางดึก เครื่องกลับมาที่หน้าล็อกอินโดยไม่มีใครเปิด MT5
  • ไฟดับหรือไฟตก: แค่ไม่กี่วินาทีก็พอให้เครื่องตั้งโต๊ะที่ไม่มีไฟสำรองดับ
  • เน็ตบ้านหลุด: เราเตอร์รีเซ็ตตัวเอง ผู้ให้บริการอินเทอร์เน็ตซ่อมสาย หรือ Wi-Fi สัญญาณตก MT5 ยังเปิดอยู่แต่ส่งคำสั่งไม่ได้ ถ้าขึ้นข้อความว่าไม่มีการเชื่อมต่อ ไล่ตามเรื่องMT5 ขึ้น No connection
  • คนในบ้านใช้เครื่อง: ปิดโปรแกรมที่ไม่รู้จัก สั่ง Sign out หรือปิดเครื่องหลังเล่นเสร็จ
  • โน้ตบุ๊กพับจอ: ค่าเริ่มต้นของโน้ตบุ๊กหลายเครื่องคือพับจอแล้ว Sleep

ทุกข้อแก้หรือลดโอกาสได้ แต่ต้องตั้งเอง และต้องเช็กซ้ำหลังอัปเดต Windows ครั้งใหญ่ เพราะบางค่ากลับไปเป็นค่าเริ่มต้นได้

เทียบคอมที่บ้านกับ VPS ทีละหัวข้อ

หัวข้อคอมที่บ้านWindows VPS
ค่าใช้จ่ายไม่มีค่าเช่า แต่มีค่าไฟของเครื่องที่เปิดตลอด และค่าเสื่อมของอุปกรณ์ค่าเช่ารายเดือนหรือรายปี
ไฟฟ้าดับตามไฟบ้าน เว้นแต่มีเครื่องสำรองไฟศูนย์ข้อมูลมีไฟสำรองในตัว
อินเทอร์เน็ตขึ้นกับเน็ตบ้านและเราเตอร์เครือข่ายของศูนย์ข้อมูล หลุดน้อยกว่า
ระยะถึงเซิร์ฟเวอร์โบรกเกอร์ขึ้นกับที่ตั้งบ้าน มักไกลถ้าเซิร์ฟเวอร์อยู่ต่างประเทศเลือกศูนย์ข้อมูลใกล้เซิร์ฟเวอร์ได้
คนอื่นใช้เครื่องมีโอกาส ถ้าเป็นเครื่องของครอบครัวเข้าได้เฉพาะคนที่รู้รหัส
ดูจากข้างนอกต้องตั้งรีโมตเข้าคอมที่บ้านเพิ่มเองรีโมตจากคอมหรือมือถือได้ตั้งแต่แรก
ใช้งานอื่นพร้อมกันใช้ทำงานหรือเล่นเกมได้ แต่เสี่ยงไปรบกวน MT5ใช้เฉพาะงานเทรด

ถ้าค่าใช้จ่ายเป็นตัวตัดสินใจหลัก ลองคิดค่าไฟของคอมที่เปิดทั้งเดือนเทียบกับค่าเช่าทั้งปีของ VPS แบบละเอียด วิธีคิดอยู่ในเรื่องราคา VPS รายเดือนและรายปี

ถ้าจะรัน EA บนคอมที่บ้าน ต้องตั้งค่าอะไรบ้าง

ถ้าเลือกใช้คอมของตัวเอง ทำตามรายการนี้ให้ครบ ทุกข้อปิดช่องที่ทำให้เครื่องหยุดเองตามหัวข้อก่อนหน้า

  1. ปิด Sleep เมื่อเสียบปลั๊ก

    Windows 11 ไปที่ Settings → System → Power & battery → Screen, sleep & hibernate timeouts แล้วตั้งให้ไม่ Sleep ตอนเสียบปลั๊ก ปิดเฉพาะหน้าจอได้ ไม่กระทบ EA ขั้นตอนของ Windows แต่ละรุ่นอยู่ในคู่มือตั้งค่าพลังงานและ Sleep ของ Microsoft

  2. คุมเวลา Windows Update

    ตั้ง Active hours ใน Windows Update ให้ครอบช่วงที่คุณมักไม่อยู่หน้าเครื่อง เช่น กลางคืนและเวลางาน แล้วลงอัปเดตกับรีสตาร์ตเองช่วงสุดสัปดาห์ หลักการเดียวกับที่ใช้บน VPS ซึ่งอธิบายละเอียดในเรื่องคุม Windows Update ไม่ให้ EA หยุด

  3. ให้ MT5 เปิดเองหลังบูต

    ติ๊ก Save password ตอนล็อกอินบัญชีใน MT5 และใส่ทางลัด MT5 ไว้ในโฟลเดอร์ Startup ถ้าเครื่องรีสตาร์ตเอง อย่างน้อยเมื่อมีคนล็อกอิน Windows โปรแกรมจะกลับมาพร้อมกราฟและ EA ชุดเดิม วิธีละเอียดดูได้ในตั้งให้ MT5 เปิดเองหลังรีสตาร์ต

  4. มีเครื่องสำรองไฟ

    เครื่องสำรองไฟ (UPS) ช่วยให้เครื่องผ่านไฟตกหรือไฟดับสั้น ๆ ได้ เสียบทั้งคอมและเราเตอร์ ถ้าไฟดับนาน UPS ก็ช่วยได้แค่ช่วงหนึ่ง

  5. ใช้สายแลนแทน Wi-Fi

    สายแลนเสถียรกว่า Wi-Fi ที่สัญญาณขึ้นลงตามระยะและสิ่งกีดขวาง

  6. แยกเครื่องหรือแยกบัญชีผู้ใช้

    ถ้าคนอื่นในบ้านใช้คอมเครื่องเดียวกัน ให้สร้างบัญชีผู้ใช้ Windows แยก และบอกให้รู้ว่าห้าม Sign out หรือปิดเครื่องของบัญชีที่รัน MT5

ถ้าเป็นโน้ตบุ๊ก

ตั้งให้พับจอแล้วไม่ทำอะไร (Do nothing) ตอนเสียบปลั๊ก ใน Control Panel → Power Options → Choose what closing the lid does เสียบสายชาร์จตลอด และวางในที่ระบายความร้อนได้ เพราะเครื่องที่ร้อนจัดอาจลดความเร็วหรือดับเอง

เช็กลิสต์ประจำวันสำหรับคนรัน EA คอมที่บ้าน

คอมที่บ้านไม่มีใครเฝ้าแทนคุณ รอบเช็กสั้น ๆ ทุกวันจึงสำคัญกว่าบน VPS ใช้เวลาไม่ถึงสองนาที ทำตอนเช้าก่อนออกจากบ้านและก่อนนอน

  • มุมขวาล่างของ MT5 ขึ้นค่าการเชื่อมต่อ ไม่ใช่ข้อความว่าไม่มีการเชื่อมต่อ
  • ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว และไอคอนข้างชื่อ EA ที่มุมขวาบนของกราฟเป็นสีฟ้า
  • Windows ไม่มีการแจ้งเตือนว่ารอรีสตาร์ตเพื่อจบการอัปเดต ถ้ามี ให้สั่งรีสตาร์ตเองช่วงตลาดปิด
  • แท็บ Journal ไม่มีช่วงหลุดการเชื่อมต่อยาวผิดปกติตั้งแต่ครั้งก่อนที่ดู
  • ไฟสถานะของเครื่องสำรองไฟปกติ ไม่ได้กำลังทำงานด้วยแบตเตอรี่

ถ้าพบว่าต้องแก้ข้อเดิมซ้ำทุกสัปดาห์ การรัน EA คอมที่บ้านอาจกินเวลาคุณมากกว่าค่าเช่าเครื่องที่ประหยัดไป

ใครเหมาะกับคอมที่บ้าน ใครควรใช้ VPS

  • คอมที่บ้านพอ: ซ้อมบนบัญชีเดโม ทดลองตั้งค่าครั้งแรก หรือคนที่มีเครื่องเปิดตลอดอยู่แล้ว มีไฟสำรอง เน็ตเสถียร และอยู่บ้านเป็นส่วนใหญ่
  • ควรใช้ VPS: บัญชีเงินจริงที่รันต่อเนื่องหลายสัปดาห์ เดินทางบ่อย ไฟที่บ้านดับบ่อย หรือคอมเป็นเครื่องที่คนในบ้านใช้ร่วมกัน

หลายคนใช้ทั้งสองแบบร่วมกัน ซ้อมและทดสอบย้อนหลังบนคอมที่บ้าน แล้วรันบัญชีจริงบน VPS ข้อสำคัญคืออย่าเปิด EA ตัวเดียวกันบนบัญชีเดียวกันพร้อมกันสองเครื่อง เพราะทั้งสองที่จะส่งคำสั่งซ้อนกัน เมื่อย้ายขึ้น VPS แล้ว ให้ถอด EA ออกจากกราฟบนคอมที่บ้าน หรือปิดปุ่ม Algo Trading บนเครื่องนั้น

ตัวอย่างสมมติ: ย้ายเมื่อไรดี

เทรดเดอร์คนหนึ่งเริ่มรัน EA บนบัญชีเดโมด้วยคอมที่บ้านสองสัปดาห์ ระหว่างนั้นเห็นจาก Journal ว่าเครื่องหลุดสามครั้ง ครั้งหนึ่งจากรีสตาร์ตหลังอัปเดต อีกสองครั้งจากเน็ตบ้าน เขาจึงตัดสินใจเช่า VPS ก่อนเปลี่ยนไปใช้บัญชีจริง เรื่องนี้แต่งขึ้นเพื่ออธิบาย บทเรียนคือใช้ช่วงเดโมเก็บข้อมูลว่าเครื่องของคุณหยุดบ่อยแค่ไหน แล้วค่อยตัดสินใจจากข้อมูลนั้น

คำถามที่พบบ่อย

ปิดจอคอมแล้ว EA ยังทำงานไหม?

ทำงาน การปิดหน้าจอหรือให้จอดับเองไม่กระทบโปรแกรมที่รันอยู่ สิ่งที่ทำให้ EA หยุดคือเครื่องเข้า Sleep หรือ Hibernate การรีสตาร์ต และการปิด MT5

ล็อกหน้าจอ Windows แล้ว EA หยุดไหม?

ไม่หยุด การล็อกหน้าจอ (เช่น กด Windows + L) ยังเก็บเซสชันและโปรแกรมทั้งหมดไว้ ต่างจาก Sign out ที่ปิดทุกโปรแกรมของผู้ใช้นั้น รวมถึง MT5

ใช้ EA WING บนคอมที่บ้านได้ไหม?

ได้ ถ้าเป็น Windows ที่ติดตั้ง MT5 แล้วตั้งค่าตามคู่มือติดตั้ง แต่ทีมงานแนะนำ Windows VPS สำหรับบัญชีเงินจริง เพราะเครื่องหยุดเองน้อยกว่า และถ้าเชื่อมต่อเซิร์ฟเวอร์สิทธิ์ไม่ได้ชั่วคราว EA WING ยังทำงานต่อได้ 72 ชั่วโมง แต่ช่วงที่คอมดับหรือเน็ตหลุด คำสั่งเทรดก็ส่งไม่ได้อยู่ดี

เน็ตบ้านหลุดไม่กี่นาที ต้องทำอะไรไหม?

MT5 มักต่อกลับเองเมื่อเน็ตกลับมา ให้ดูมุมขวาล่างว่าขึ้นค่าการเชื่อมต่อแล้ว และเปิดแท็บ Journal ดูว่าหลุดนานแค่ไหน ถ้าหลุดบ่อยเป็นประจำ นั่นคือสัญญาณว่าควรย้ายไปรันบน VPS

คำเตือนความเสี่ยง: ไม่ว่ารันบนคอมที่บ้านหรือ VPS การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ช่วงที่เครื่องหยุดโดยไม่รู้ตัว ออเดอร์ที่ค้างอยู่อาจไม่ได้รับการดูแลตามที่ EA ออกแบบไว้ ตรวจเครื่องเป็นประจำ และอ่านความเสี่ยงที่ควรรู้ก่อนใช้ EAก่อนใช้เงินจริง

  • วิธีติดตั้ง EA WING บนคอมหรือ VPS
