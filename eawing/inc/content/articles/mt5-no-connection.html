MT5 No connection คือข้อความที่มุมขวาล่างของโปรแกรมบอกว่าเครื่องของคุณส่งข้อมูลไปไม่ถึงเซิร์ฟเวอร์ของโบรกเกอร์ ระหว่างนั้นราคาไม่ขยับ ส่งคำสั่งไม่ได้ และ EA ก็ทำงานไม่ได้เช่นกัน สาเหตุส่วนใหญ่แก้ได้เองในไม่กี่นาที ถ้าเพิ่งเริ่มใช้โปรแกรม อ่านพื้นฐานการใช้ MT5ไว้ด้วย จะรู้ว่าตัวโปรแกรม เซิร์ฟเวอร์ และบัญชีเชื่อมกันอย่างไร

สรุปสั้น: No connection แปลว่าไปไม่ถึงเซิร์ฟเวอร์ ส่วน Invalid account แปลว่าไปถึงแล้วแต่ข้อมูลบัญชีไม่ตรง · ไล่ตามลำดับ: อินเทอร์เน็ตของเครื่อง → Rescan servers → ชื่อเซิร์ฟเวอร์และรหัสผ่าน → ไฟร์วอลล์ VPN และ proxy → ถามโบรกเกอร์ · ระหว่างหลุด EA ส่งคำสั่งไม่ได้ แต่ Stop Loss และ Take Profit ที่ตั้งไว้ที่เซิร์ฟเวอร์แล้วยังทำงาน

MT5 No connection คืออะไร ต่างจาก Invalid account ยังไง

แถบสถานะมุมขวาล่างคือที่แรกที่ควรดูทุกครั้งที่ราคาไม่ขยับ ข้อความในช่องนี้บอกได้ทันทีว่าปัญหาอยู่ฝั่งเครือข่ายหรือฝั่งข้อมูลบัญชี

สิ่งที่เห็นมุมขวาล่างความหมายเริ่มแก้ที่
ค่าความหน่วงเป็นมิลลิวินาที และปริมาณข้อมูลเป็น kbเชื่อมต่อปกติถ้าราคายังไม่ขยับ ให้ดูว่าตลาดเปิดอยู่ไหม
No connectionส่งข้อมูลไปไม่ถึงเซิร์ฟเวอร์อินเทอร์เน็ต เส้นทางเชื่อมต่อ และไฟร์วอลล์
Invalid accountถึงเซิร์ฟเวอร์แล้ว แต่เลขบัญชี รหัสผ่าน หรือชื่อเซิร์ฟเวอร์ไม่ตรงกันข้อมูลบัญชีที่กรอก
สลับไปมาระหว่างเชื่อมต่อกับหลุดเครือข่ายไม่เสถียรสายเน็ต Wi-Fi หรือเครือข่ายของ VPS

ถ้อยคำอาจต่างกันเล็กน้อยตามรุ่นของโปรแกรม แต่หลักแยกเหมือนกัน คือดูว่าปัญหาอยู่ก่อนถึงเซิร์ฟเวอร์ หรือหลังถึงเซิร์ฟเวอร์แล้ว

ไล่แก้ MT5 No connection ทีละขั้น

ทำตามลำดับจากข้อที่ง่ายที่สุด ส่วนใหญ่จะจบภายในสามข้อแรก

  1. เช็กอินเทอร์เน็ตของเครื่องที่เปิด MT5

    เปิดเว็บไซต์ใดก็ได้บนเครื่องเดียวกัน ถ้า MT5 อยู่บน VPS ให้ลองบน VPS ไม่ใช่บนมือถือหรือคอมที่ใช้รีโมต เพราะเน็ตคนละเส้นทาง

  2. สั่ง Rescan servers

    คลิกที่ช่องสถานะมุมขวาล่าง แล้วเลือก Rescan servers โปรแกรมจะวัดเส้นทางไปยังจุดเชื่อมต่อของโบรกเกอร์ใหม่แล้วเลือกจุดที่ตอบเร็วที่สุด ข้อนี้แก้อาการหลุดหลังเปลี่ยนเครือข่ายได้บ่อย

  3. ล็อกอินใหม่และตรวจชื่อเซิร์ฟเวอร์

    เปิด File แล้ว Login to Trade Account ตรวจเลขบัญชี รหัสผ่าน และชื่อเซิร์ฟเวอร์ให้ตรงกับข้อมูลจากโบรกเกอร์ทุกตัวอักษร บัญชีเดโมกับบัญชีจริงมักใช้เซิร์ฟเวอร์คนละชื่อ ติ๊ก Save password ไว้ถ้าเป็นเครื่องที่รัน EA

  4. ตรวจไฟร์วอลล์และโปรแกรมป้องกันไวรัส

    ถ้าเพิ่งติดตั้งโปรแกรมความปลอดภัยใหม่ มันอาจกั้นไม่ให้ MT5 ออกอินเทอร์เน็ต ให้อนุญาตเฉพาะตัวโปรแกรม MT5 ในรายการแอปที่ได้รับอนุญาต แทนการเปิดพอร์ตหรือปิดการป้องกันทั้งเครื่อง วิธีทำบน Windows อยู่ในคู่มือของ Microsoft เรื่องอนุญาตแอปผ่านไฟร์วอลล์ (ภาษาอังกฤษ)

  5. ปิด VPN และตรวจการตั้ง proxy

    VPN อาจพาเส้นทางไปอ้อมไกลหรือถูกปิดกั้นปลายทาง ลองปิดแล้วเชื่อมต่อใหม่ ใน Tools → Options แท็บ Server ช่อง Enable proxy server ควรว่างไว้ เว้นแต่เครือข่ายของคุณต้องใช้ proxy จริง

  6. ถามโบรกเกอร์

    ถ้าทุกข้อด้านบนปกติ อาจเป็นฝั่งเซิร์ฟเวอร์ เช่น ปิดปรับปรุงระบบ ซึ่งมักทำช่วงสุดสัปดาห์ บัญชีถูกพักเพราะไม่ได้ใช้นาน หรือโบรกเกอร์ย้ายบัญชีไปเซิร์ฟเวอร์ชื่อใหม่ ตรวจอีเมลและประกาศในพื้นที่สมาชิกของโบรกเกอร์ก่อนติดต่อฝ่ายบริการลูกค้า

  7. ติดตั้งรุ่นล่าสุดจากแหล่งทางการ

    ถ้าโปรแกรมเก่ามากหรือไฟล์เสียหาย ลองดาวน์โหลด MT5 รุ่นล่าสุดจากหน้าทางการของ MetaQuotes หรือจากลิงก์ในพื้นที่สมาชิกของโบรกเกอร์ แล้วล็อกอินใหม่ อย่าใช้ไฟล์ติดตั้งที่ส่งต่อกันในแชต

Invalid account: ถึงเซิร์ฟเวอร์แล้ว แต่ข้อมูลไม่ตรง

ข้อความนี้มักทำให้คนตกใจว่าบัญชีถูกปิด แต่ส่วนใหญ่เป็นเรื่องข้อมูลที่กรอกไม่ตรงกัน

เลือกเซิร์ฟเวอร์ผิดตัว

โบรกเกอร์หนึ่งรายมักมีเซิร์ฟเวอร์หลายชื่อ เช่น แยกบัญชีเดโมกับบัญชีจริง หรือแยกตามประเภทบัญชี เลขบัญชีจะใช้ได้กับเซิร์ฟเวอร์ที่สร้างบัญชีนั้นเท่านั้น ให้เปิดอีเมลแจ้งข้อมูลบัญชีแล้วเทียบชื่อทีละตัวอักษร

ใช้รหัสผ่านผิดชุด

รหัสเข้าพื้นที่สมาชิกของโบรกเกอร์ไม่ใช่รหัสบัญชีเทรด สองชุดนี้สลับกันบ่อยมาก อีกสาเหตุคือแป้นพิมพ์ค้างภาษาไทย หรือคัดลอกรหัสมาพร้อมช่องว่าง ถ้าจำรหัสบัญชีเทรดไม่ได้จริง ๆ ดูขั้นตอนตั้งรหัสใหม่ในลืมรหัส MT5 ทำยังไง

บัญชีหมดอายุ ถูกพัก หรือเป็นบัญชี MT4

บัญชีเดโมหลายแห่งมีอายุจำกัด บัญชีจริงที่ไม่ได้ใช้นานอาจถูกพัก และบัญชีที่เปิดไว้สำหรับ MT4 จะล็อกอิน MT5 ไม่ได้เลย สามกรณีนี้แก้จากโปรแกรมไม่ได้ ต้องเปิดบัญชีใหม่หรือติดต่อโบรกเกอร์

สถานะเชื่อมต่อปกติ แต่ MT5 ไม่ขึ้นราคา

ถ้ามุมขวาล่างแสดงค่าความหน่วงปกติ แต่ราคาไม่ขยับ ปัญหาไม่ได้อยู่ที่การเชื่อมต่อ ให้ดูสามเรื่องนี้แทน

  • ตลาดปิด ช่วงสุดสัปดาห์ วันหยุด หรือช่วงพักรายวันของสัญลักษณ์ ราคาจะนิ่งทั้งที่เชื่อมต่ออยู่ ดูช่วงเวลาซื้อขายในหน้า Specification และอ่านต่อในMarket closed ใน MT5
  • สัญลักษณ์ที่ไม่มีราคาเข้า บางเซิร์ฟเวอร์มีชื่อคล้ายกันหลายตัว ตัวที่ไม่ใช่ของบัญชีคุณอาจนิ่งตลอด ให้ใช้ชื่อที่ราคาใน Market Watch ขยับ
  • กราฟถูกเลื่อนหรือโปรแกรมหน่วง ถ้ากราฟเดียวนิ่งแต่ตัวอื่นขยับ หรือทั้งโปรแกรมช้าผิดปกติ ดูวิธีแยกอาการในMT5 ค้าง กราฟไม่ขยับ

No connection บน VPS และบนมือถือ

บน VPS

เครือข่ายของ VPS มักเสถียรกว่าเน็ตบ้าน แต่ก็หลุดได้ช่วงผู้ให้บริการปิดปรับปรุง หรือหลัง Windows รีสตาร์ตแล้ว MT5 ไม่ได้ล็อกอินกลับเอง ถ้าค่าความหน่วงสูงผิดปกติเป็นประจำ ลองดูว่าที่ตั้งของ VPS อยู่ไกลจากเซิร์ฟเวอร์ของโบรกเกอร์แค่ไหน ดูPing และ Latency ของ VPS สำคัญกับ EA แค่ไหน

อย่าสับสนระหว่าง MT5 หลุดจากโบรกเกอร์ กับคุณหลุดจากหน้าต่างรีโมต ถ้าหน้าต่าง Remote Desktop ตัดไป MT5 บน VPS อาจยังเชื่อมต่อและทำงานปกติ ปัญหาฝั่งรีโมตแก้คนละทาง อ่านในRemote Desktop หลุดหรือเข้า VPS ไม่ได้

บนมือถือ

แอปมือถือแจ้งการเชื่อมต่อในหน้าบัญชี ถ้าหลุด ให้สลับ Wi-Fi กับเน็ตมือถือ แล้วแตะบัญชีเพื่อเข้าใหม่ ถ้ายังไม่ได้ ลบบัญชีออกจากแอปแล้วเพิ่มใหม่โดยค้นหาชื่อเซิร์ฟเวอร์ให้ตรง การที่แอปมือถือหลุดไม่กระทบ EA บนคอมหรือ VPS เพราะแต่ละเครื่องเชื่อมต่อกับเซิร์ฟเวอร์แยกกัน

ระหว่างหลุด EA ทำอะไรได้บ้าง

ตลอดช่วงที่ขึ้น No connection EA บนเครื่องนั้นส่งคำสั่งใหม่ แก้ออเดอร์ หรือปิดออเดอร์ไม่ได้ ถ้าพยายามส่ง จะได้รหัสผล 10031 ซึ่งแปลว่าไม่มีการเชื่อมต่อกับเซิร์ฟเวอร์เทรด สิ่งที่ยังทำงานคือคำสั่งที่ฝากไว้ที่เซิร์ฟเวอร์แล้ว ได้แก่ Stop Loss, Take Profit และ Pending Order เพราะเซิร์ฟเวอร์เป็นผู้ดำเนินการเอง

สำหรับ [eawing_brand] ระบบสิทธิ์มีช่วงผ่อนผัน 72 ชั่วโมงเมื่อติดต่อเซิร์ฟเวอร์สิทธิ์ไม่ได้ แต่ช่วงผ่อนผันนี้เกี่ยวกับการตรวจสิทธิ์เท่านั้น การส่งคำสั่งเทรดยังต้องใช้การเชื่อมต่อกับโบรกเกอร์ตามปกติ เมื่อกลับมาเชื่อมต่อได้แล้ว ให้ดูการ์ดล็อกอินบนแดชบอร์ด และเปิดแท็บ Journal ใน Toolbox (Ctrl+T) ดูว่าหลุดไปตั้งแต่เมื่อไรถึงเมื่อไร

ป้องกันไม่ให้หลุดบ่อย

  • ใช้สายแลนแทน Wi-Fi ถ้ารัน EA บนคอมที่บ้าน
  • ปิดโหมดพักเครื่อง ใน Power settings ของ Windows เครื่องที่หลับไปจะตัดการเชื่อมต่อทุกครั้ง
  • ติ๊ก Save password เพื่อให้ MT5 ล็อกอินกลับเองหลังเปิดโปรแกรมใหม่
  • ย้ายไปรันบน VPS ถ้าเน็ตบ้านหรือไฟฟ้าไม่เสถียร ขั้นตอนตั้งเครื่องอยู่ในคู่มือ Windows VPS
  • เปิดดู Journal ทุกวัน บรรทัดที่บอกการหลุดและการเชื่อมต่อใหม่ช่วยให้เห็นรูปแบบ เช่น หลุดทุกคืนเวลาเดียวกัน

ตัวอย่างสมมติ: หลุดทุกคืนเวลาเดิม

เทรดเดอร์คนหนึ่งรัน EA บนโน้ตบุ๊กที่บ้าน ตอนเช้าเห็นว่าไม่มีออเดอร์ใหม่ตั้งแต่ราวเที่ยงคืน พอเลื่อนดูแท็บ Journal ย้อนหลังหลายวัน พบบรรทัดการเชื่อมต่อหลุดในช่วงเวลาใกล้กันทุกคืน แล้วกลับมาเชื่อมต่อเมื่อเขาขยับเมาส์ตอนเช้า สาเหตุคือโน้ตบุ๊กตั้งให้พักเครื่องเมื่อไม่มีการใช้งานสองชั่วโมง เรื่องนี้แต่งขึ้นเพื่ออธิบายวิธีอ่านรูปแบบ บทเรียนคือการหลุดที่เกิดเวลาเดิมซ้ำ ๆ มักมาจากการตั้งค่าเครื่อง ไม่ใช่จากโบรกเกอร์

ข้อมูลที่ควรเตรียมก่อนถามโบรกเกอร์หรือทีมงาน

  • ภาพมุมขวาล่างของ MT5 ที่เห็นข้อความสถานะ
  • ภาพบรรทัดในแท็บ Journal ช่วงที่หลุด โดยขยายช่อง Message ให้อ่านได้ครบ
  • เลขบัญชีและชื่อเซิร์ฟเวอร์ ไม่ต้องส่งรหัสผ่านใด ๆ
  • เวลาไทยที่เริ่มเห็นปัญหา และสิ่งที่เปลี่ยนไปก่อนหน้า เช่น ย้ายเครื่อง เปลี่ยนรหัส หรือติดตั้งโปรแกรมใหม่

คำถามที่พบบ่อย

วันเสาร์อาทิตย์ขึ้น No connection ผิดปกติไหม?

ช่วงสุดสัปดาห์ปกติ MT5 ยังเชื่อมต่อได้แต่ราคาไม่ขยับ ถ้าขึ้น No connection ช่วงนี้ อาจเป็นช่วงที่โบรกเกอร์ปิดปรับปรุงเซิร์ฟเวอร์ ให้รอแล้วลองใหม่ ถ้ายังหลุดเมื่อตลาดเปิดในวันทำการ ค่อยไล่ตามขั้นตอน

เปลี่ยนรหัสผ่านแล้ว อีกเครื่องขึ้น Invalid account เกิดจากอะไร?

เครื่องอื่นที่ยังบันทึกรหัสเก่าไว้จะล็อกอินไม่ผ่านเมื่อเชื่อมต่อใหม่ ให้ล็อกอินด้วยรหัสใหม่ในทุกเครื่องที่ใช้บัญชีนี้ โดยเฉพาะ VPS ที่รัน EA

มือถือดูราคาได้ แต่ MT5 บน VPS ขึ้น No connection ทำไม?

แต่ละเครื่องเชื่อมต่อกับเซิร์ฟเวอร์แยกกัน มือถือที่ใช้ได้จึงบอกแค่ว่าเซิร์ฟเวอร์ของโบรกเกอร์ยังทำงาน ปัญหาอยู่ที่เครือข่ายหรือการตั้งค่าบน VPS ให้รีโมตเข้าไปไล่ตามขั้นตอนบนเครื่องนั้น

No connection นานแค่ไหนถึงควรกังวล?

หลุดไม่กี่วินาทีแล้วกลับมาเองเกิดได้เป็นครั้งคราว แต่ถ้าหลุดนานหลายนาทีระหว่างตลาดเปิด หรือหลุดซ้ำทุกวัน ควรหาสาเหตุทันที เพราะระหว่างนั้น EA ดูแลออเดอร์ไม่ได้

คำเตือนความเสี่ยง: ตลาดไม่หยุดรอเมื่อ MT5 หลุดการเชื่อมต่อ ออเดอร์ที่เปิดค้างยังได้กำไรหรือขาดทุนตามราคาจริง การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด และผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่านสิ่งที่ต้องรู้เรื่องความเสี่ยงก่อนใช้เงินจริง
