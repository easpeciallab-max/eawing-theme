เปิด MT5 หลายตัวบน VPS เครื่องเดียวทำได้ และเป็นวิธีปกติของคนที่รัน EA มากกว่าหนึ่งบัญชี เงื่อนไขสำคัญมีข้อเดียว คือแต่ละตัวต้องติดตั้งอยู่คนละโฟลเดอร์ หน้านี้พาทำตั้งแต่ติดตั้ง วาง EA ให้ถูก Data Folder ไปจนถึงคิดว่าเครื่องต้องแรงแค่ไหน ส่วนเกณฑ์เลือกเครื่องและการดูแลทั่วไปอยู่ในคู่มือ VPS สำหรับบอทเทรด

สรุปสั้น: MT5 หนึ่งตัวเชื่อมต่อได้ทีละบัญชี ถ้าต้องการให้หลายบัญชีทำงานพร้อมกัน ให้ติดตั้ง MT5 แยกโฟลเดอร์ตามจำนวนบัญชี · แต่ละตัวมี Data Folder ของตัวเอง ต้องวางไฟล์ EA ให้ครบทุกตัว · หนึ่งบัญชีควรมี EA ทำงานอยู่ที่เดียว · RAM ต้องพอสำหรับทุกตัวรวมกันบวก Windows

ทำไมต้องเปิด MT5 หลายตัว

MT5 หนึ่งโปรแกรมล็อกอินค้างได้ครั้งละหนึ่งบัญชี จะสลับไปบัญชีอื่นก็ได้ แต่บัญชีเดิมจะหลุดการเชื่อมต่อ และ EA บนกราฟจะทำงานกับบัญชีที่เปิดอยู่ตอนนั้นเท่านั้น ถ้าต้องการให้สองบัญชีมี EA ทำงานพร้อมกัน จึงต้องมี MT5 สองตัว

สถานการณ์MT5 ตัวเดียวพอไหม
หนึ่งบัญชี EA หนึ่งตัวพอ
สองบัญชีขึ้นไป ต้องการให้ EA ทำงานพร้อมกันไม่พอ ต้องหนึ่งตัวต่อหนึ่งบัญชี
บัญชีเดโมทดลองคู่กับบัญชีจริงไม่พอ ถ้าอยากให้ทั้งสองทำงานตลอด
บัญชีของโบรกเกอร์ต่างกันไม่พอ และมักต้องใช้ตัวติดตั้งของแต่ละโบรกเกอร์
แค่อยากดูบัญชีอื่นเป็นครั้งคราวพอ ใช้แอปมือถือดูแทนได้ ไม่ต้องสลับบัญชีบน VPS

ข้อสุดท้ายสำคัญ หลายคนสลับบัญชีใน MT5 บน VPS เพื่อดูยอด แล้วลืมสลับกลับ EA ของบัญชีหลักจึงหยุดทำงานไปโดยไม่รู้ตัว

กฎข้อแรก: หนึ่งโฟลเดอร์ต่อ MT5 หนึ่งตัว

คู่มือของผู้พัฒนาแพลตฟอร์มระบุไว้ในหน้าการเปิดใช้งานแพลตฟอร์มของ MetaTrader 5ว่า MT5 สองชุดเปิดจากโฟลเดอร์เดียวกันพร้อมกันไม่ได้ ถ้าต้องการหลายชุดพร้อมกัน ให้ติดตั้งตามจำนวนที่ต้องการลงคนละโฟลเดอร์ ดับเบิลคลิกไอคอนเดิมซ้ำจึงไม่ได้ MT5 ตัวที่สอง แค่สลับไปหน้าต่างตัวเดิม

ติดตั้ง MT5 หลายตัวทีละขั้น

ทำบน VPS ผ่าน Remote Desktop ทีละตัว เสร็จตัวหนึ่งค่อยเริ่มตัวถัดไป

  1. เตรียมตัวติดตั้ง

    ใช้ตัวติดตั้ง MT5 ของโบรกเกอร์ที่เปิดบัญชีไว้ หรือตัวติดตั้งจากเว็บไซต์ของ MetaTrader 5 ไฟล์เดียวกันใช้ติดตั้งซ้ำได้หลายครั้ง

  2. กด Settings ก่อนกด Next

    หน้าแรกของตัวติดตั้งมีปุ่ม Settings ให้เปลี่ยนโฟลเดอร์ปลายทาง ตั้งชื่อที่บอกได้ว่าเป็นของบัญชีไหน เช่น C:\MT5-A และ C:\MT5-B ถ้าข้ามขั้นนี้ ตัวติดตั้งจะลงทับโฟลเดอร์เดิม

  3. ตั้งชื่อกลุ่มโปรแกรมให้ต่างกัน

    ในหน้าเดียวกันเปลี่ยนชื่อที่จะขึ้นในเมนู Start ให้ไม่ซ้ำ จะได้ไม่สับสนเวลาหาโปรแกรม

  4. เปลี่ยนชื่อไอคอนบนเดสก์ท็อป

    คลิกขวาที่ไอคอนแล้วเลือก Rename เช่น "MT5 บัญชี A จริง" และ "MT5 บัญชี B เดโม" เปิดผิดตัวเมื่อไร จะเห็นได้ทันที

  5. ล็อกอินแต่ละตัวด้วยบัญชีของมัน

    File → Login to Trade Account ใช้รหัสผ่านหลัก ไม่ใช่รหัส Investor และติ๊ก Save password ให้ทุกตัว เพื่อให้กลับเข้าบัญชีเองเมื่อเปิดโปรแกรมใหม่ รายละเอียดอยู่ใน ขั้นตอนล็อกอินบัญชีเทรดใน MT5

  6. ทำซ้ำจนครบ

    ติดตั้งตัวถัดไปด้วยโฟลเดอร์ใหม่ทุกครั้ง แล้วจดลงตารางประจำเครื่องตามตัวอย่างด้านล่าง

ตารางประจำเครื่อง (ตัวอย่าง)

โฟลเดอร์ชื่อไอคอนบัญชีหน้าที่
C:\MT5-AMT5 บัญชี A จริงเลขบัญชี Aรัน EA
C:\MT5-BMT5 บัญชี B เดโมเลขบัญชี Bทดลองก่อนใช้จริง

ตารางนี้ดูเหมือนงานเล็ก แต่ช่วยมากตอนต้องย้ายเครื่องหรือให้ทีมงานช่วยดู เพราะตอบได้ทันทีว่าบัญชีไหนอยู่ตัวไหน

แต่ละตัวมี Data Folder ของตัวเอง

จุดที่คนติดตั้ง MT5 หลายตัวพลาดบ่อยที่สุด คือวางไฟล์ EA ไว้ที่ตัวแรกแล้วไปหาในตัวที่สองไม่เจอ เหตุผลคือ MT5 แต่ละชุดเก็บไฟล์ที่แก้ไขได้ไว้ใน Data Folder แยกกัน ตามค่าเริ่มต้นจะอยู่ใต้โฟลเดอร์ผู้ใช้ของ Windows โดยมีชื่อโฟลเดอร์เป็นรหัสที่สร้างจากที่อยู่ของโฟลเดอร์ติดตั้ง สองชุดจึงไม่เคยใช้โฟลเดอร์ร่วมกัน

  • เปิด Data Folder จากเมนู File → Open Data Folder ของ MT5 ตัวที่ต้องการ อย่าเปิดจากตัวอื่นแล้วเดาเอา
  • วางไฟล์ EA ใน MQL5 → Experts ของแต่ละตัว แล้วคลิกขวาใน Navigator (Ctrl+N) เลือก Refresh
  • ตั้งค่าใน Tools → Options แท็บ Expert Advisors แยกทีละตัว ค่าไม่ได้ส่งต่อถึงกัน
  • ปุ่ม Algo Trading ก็แยกกัน ตัวหนึ่งเขียวไม่ได้แปลว่าอีกตัวเขียวด้วย

MT5 ยังมีโหมด Portable ที่เก็บข้อมูลไว้ในโฟลเดอร์ติดตั้งเลย เปิดได้ด้วยการเพิ่มคำว่า /portable ต่อท้ายคำสั่งเปิดโปรแกรม ข้อดีคือหาไฟล์ง่าย แต่ถ้าติดตั้งไว้ใน Program Files ต้องมีสิทธิ์ผู้ดูแลระบบและเงื่อนไขเพิ่มเติม สำหรับผู้เริ่มต้น ติดตั้งนอก Program Files ตามตัวอย่างข้างบนแล้วใช้โหมดปกติก็พอ

MT5 หลายบัญชีบน VPS: กฎกันออเดอร์ซ้อน

เทคนิคการติดตั้งไม่ยาก ส่วนที่ต้องระวังจริงคือความสัมพันธ์ระหว่างบัญชี MT5 และ EA

  • บัญชีเดียวกันเปิดใน MT5 สองตัว แล้วมี EA ทั้งสองที่ EA สองชุดอาจส่งคำสั่งซ้ำกัน ความเสี่ยงของบัญชีเพิ่มขึ้นโดยไม่ได้ตั้งใจ
  • บัญชีเดียวกันรันทั้งบนคอมที่บ้านและบน VPS ปัญหาเดียวกัน แค่อยู่คนละเครื่อง ถ้าย้ายมา VPS แล้วต้องถอด EA ออกจากเครื่องเดิม
  • ล็อกอินด้วยรหัส Investor บัญชีจะเป็นแบบดูอย่างเดียว EA ส่งคำสั่งไม่ได้

กฎจำง่ายคือ หนึ่งบัญชี มี EA ทำงานอยู่ที่เดียว ส่วนการดูยอดจากมือถือหรือเครื่องอื่นทำได้ตามปกติ เรื่องการแบ่งบัญชี การจัดเงิน และสิทธิ์ใช้งานเมื่อมีหลายบัญชี อธิบายแยกไว้ในบทความแบ่งบัญชีและสิทธิ์เมื่อรัน EA หลายบัญชี

สำหรับผู้ใช้ EA WING

สิทธิ์ใช้งาน EA WING ผูกกับเลขบัญชี MT5 เปิดหลายบัญชีจึงต้องส่งเลขบัญชีและชื่อเซิร์ฟเวอร์ของทุกบัญชีให้ทีมงานทาง LINE แพ็กเกจ Pro ใช้ได้ 1 ถึง 2 บัญชี ส่วนการตั้งค่าบน MT5 แต่ละตัวต้องครบเหมือนกัน คือวางไฟล์ EA_WING_V4.2.ex5 ใน Data Folder ของตัวนั้น ติ๊ก Allow DLL imports แนบบนกราฟ XAUUSD M1 (ชื่ออาจมีตัวต่อท้าย เช่น XAUUSD.c) และดูการ์ดล็อกอินบนแดชบอร์ดของทุกตัวว่าเป็นสีเขียว

VPS ต้องแรงแค่ไหนเมื่อเปิดหลายตัว

คำตอบที่ตรงที่สุดมาจากเครื่องของคุณเอง เปิด MT5 ตัวแรกให้ทำงานตามปกติสักวัน แล้วเปิด Task Manager ดูคอลัมน์ Memory ของ terminal64.exe ช่วงตลาดคึกคัก ใช้ตัวเลขนั้นคูณจำนวนตัวที่จะเปิด แล้วบวก Windows และเผื่อที่ว่าง

จากตัวอย่างนี้ เครื่อง RAM 4 GB จะตึงเกินไป ควรมองหาเครื่องที่ใหญ่กว่านั้น ตัวเลขจริงของคุณอาจต่างไปมากตามจำนวนกราฟ สัญลักษณ์ และ EA ที่ใช้ อย่าลืมดู CPU ด้วย ถ้าแตะเกือบเต็มบ่อย ๆ คำสั่งจะออกช้า วิธีเลือกสเปกให้พอดีอยู่ในบทความเลือกสเปก VPS ให้พอกับ MT5 หลายชุด

ลดภาระเครื่องเมื่อรันหลายบัญชี

ก่อนจะอัปเกรดเครื่อง ลองลดสิ่งที่ไม่จำเป็นในแต่ละตัวก่อน หลายครั้งได้ผลชัดเจน

  • ปิดกราฟที่ไม่ได้ใช้ เหลือเฉพาะกราฟที่มี EA ทำงาน กราฟไว้ดูเฉย ๆ ไปเปิดบนคอมหรือมือถือแทน
  • ซ่อนสัญลักษณ์ที่ไม่ใช้ใน Market Watch กด Ctrl+M คลิกขวาแล้วเลือก Hide All ระบบจะเหลือเฉพาะสัญลักษณ์ที่มีกราฟเปิดหรือมีออเดอร์
  • ลดจำนวนแท่งเทียนบนกราฟ Tools → Options แท็บ Charts ปรับ Max bars in chart ให้ต่ำลง แต่ให้พอกับที่ EA และอินดิเคเตอร์ต้องใช้ ถ้าไม่แน่ใจ ถามผู้พัฒนา EA ก่อน
  • ไม่ทำ Backtest บนเครื่องที่รัน EA จริง Strategy Tester ใช้ CPU และดิสก์หนัก ไปทดสอบบนคอมเครื่องอื่น
  • ไม่เปิดเบราว์เซอร์ค้างไว้ เบราว์เซอร์หลายแท็บกินหน่วยความจำไม่แพ้ MT5 หนึ่งตัว

หลังรีสตาร์ต ต้องกลับมาครบทุกตัว

ยิ่งมี MT5 หลายชุด โอกาสที่ตัวหนึ่งไม่กลับมาหลัง VPS รีสตาร์ตก็ยิ่งมาก และตัวที่หายมักเป็นตัวที่ไม่ค่อยได้เปิดดู ให้ใส่ทางลัดของ MT5 ทุกตัวไว้ในรายการโปรแกรมที่เปิดเองหลังล็อกอิน และเว้นจังหวะไม่ให้เปิดพร้อมกันทั้งหมด วิธีตั้งอยู่ในบทความตั้งให้ MT5 เปิดเองอัตโนมัติ

หลังเครื่องกลับมา ไล่เช็กตามตารางประจำเครื่องทีละแถว ล็อกอินถูกบัญชี กราฟและ EA อยู่ครบ ปุ่ม Algo Trading เป็นสีเขียว ใช้เวลาไม่กี่นาทีแต่กันปัญหา EA เงียบไปหลายวันได้

ข้อผิดพลาดที่พบบ่อย

  • ติดตั้งตัวที่สองโดยไม่กด Settings จึงลงทับตัวแรก
  • วาง EA ใน Data Folder ของตัวแรก แล้วงงว่าทำไมตัวที่สองไม่เห็น
  • ลากไอคอนตัวเดียวกันไปไว้ในรายการเปิดเองสองครั้ง แทนที่จะเป็นคนละตัว
  • เปิด EA บนบัญชีเดโมและบัญชีจริงด้วยค่าที่ต่างกัน แล้วสรุปผลเทียบกันโดยไม่ได้จด
  • เพิ่มบัญชีจนเกินกำลังเครื่อง แล้ว MT5 ทุกตัวช้าลงพร้อมกัน

คำเตือนความเสี่ยง: การรัน EA หลายบัญชีไม่ได้กระจายความเสี่ยงเสมอไป ถ้าทุกบัญชีใช้กลยุทธ์เดียวกันกับสินทรัพย์เดียวกัน ช่วงที่ขาดทุนมักเกิดพร้อมกันทุกบัญชี การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ความเสี่ยงที่ต้องรู้ก่อนเพิ่มบัญชี ก่อนเพิ่มบัญชี

คำถามที่พบบ่อยเรื่อง MT5 หลายตัว

เปิด MT5 บน VPS ได้สูงสุดกี่ตัว?

ตัวโปรแกรมไม่ได้กำหนดจำนวนตายตัว ตัวจำกัดคือ RAM และ CPU ของเครื่อง ให้วัดการใช้งานจริงของหนึ่งตัวแล้วคำนวณตามตัวอย่างในหน้านี้ และเผื่อที่ว่างไว้เสมอ

ใช้ MT5 ตัวเดียวสลับหลายบัญชีแทนได้ไหม?

สลับได้ แต่ทำงานได้ทีละบัญชี บัญชีที่สลับออกจะหลุดการเชื่อมต่อ และ EA จะทำงานกับบัญชีที่เปิดอยู่เท่านั้น ถ้าต้องการให้ EA ทำงานทุกบัญชีพร้อมกัน ต้องติดตั้งแยกตัว

รันบัญชีเดโมคู่กับบัญชีจริงบน VPS เดียวกันได้ไหม?

ได้ และเป็นวิธีที่ดีในการทดลองค่าใหม่ก่อนใช้จริง ติดตั้ง MT5 แยกโฟลเดอร์และตั้งชื่อไอคอนให้ชัดว่าตัวไหนเดโม วิธีเปิดบัญชีทดลองอยู่ในบทความเปิดบัญชีเดโม MT5

MT5 ของโบรกเกอร์ต่างกันติดตั้งบนเครื่องเดียวกันได้ไหม?

ได้ หลักการเหมือนกันคือคนละโฟลเดอร์ ตัวติดตั้งของแต่ละโบรกเกอร์มักตั้งโฟลเดอร์ตามชื่อบริษัทให้อยู่แล้ว แต่ควรกด Settings ตรวจก่อนติดตั้งทุกครั้ง

อ่านต่อ

  • VPS สำหรับ EA ฉบับเต็ม
  • คิดสเปก VPS ให้พอกับ MT5
  • วางแผนรัน EA หลายบัญชี
  • คู่มือติดตั้ง EA WING

ถ้ายังไม่ได้ตั้ง VPS เครื่องแรก เริ่มจากคู่มือใช้ Windows VPS รัน EA ก่อน แล้วค่อยเพิ่ม MT5 ตัวที่สองตามขั้นตอนในหน้านี้ ถ้าจะเพิ่มบัญชีให้ EA WING ส่งเลขบัญชีกับชื่อเซิร์ฟเวอร์มาที่ทีมงานได้เลย
