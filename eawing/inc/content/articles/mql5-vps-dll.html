MQL5 VPS คือบริการเช่าเครื่องเสมือนที่สั่งได้จากในตัว MT5 โดยตรง ระบบจะย้ายกราฟกับ EA ของคุณขึ้นไปรันบนเซิร์ฟเวอร์ใกล้โบรกเกอร์ให้เอง ถ้า EA ของคุณต้องเปิด Allow DLL imports คำตอบสั้นคือใช้ไม่ได้ เพราะกฎของบริการห้ามเรียก DLL ทุกกรณี บทความนี้อธิบายว่าบริการนี้ทำอะไรได้ ห้ามอะไร และควรเลือกอะไรแทน ส่วนภาพรวมของVPS สำหรับรัน EA ทุกแบบอยู่ในคู่มือหลักของหมวดนี้

MQL5 VPS คืออะไร ต่างจาก Windows VPS ตรงไหน

บริการนี้มีชื่อทางการว่า Virtual Hosting เป็นของ MetaQuotes ผู้พัฒนา MT5 คนไทยมักเรียกว่า MQL5 VPS หรือ VPS MT5 จุดเด่นคือไม่ต้องรีโมตเข้าเครื่องใดเลย คุณกดเช่าจากในโปรแกรม แล้วสั่งย้ายสภาพแวดล้อมการเทรดขึ้นไป เครื่องเสมือนจะรันกราฟและ EA ชุดเดียวกับที่คุณเห็นบนคอมของตัวเอง

ความต่างจาก Windows VPS อยู่ที่ระดับการควบคุม Windows VPS ให้เครื่องทั้งเครื่อง คุณติดตั้งโปรแกรมอะไรก็ได้ เปิด MT5 กี่ชุดก็ได้ตามสเปก ส่วน Virtual Hosting ให้เทอร์มินัลเสมือนหนึ่งตัวสำหรับหนึ่งบัญชีเทรด ไม่มีหน้าจอให้เข้าไปดู และคุณจัดการได้ผ่านแท็บ VPS ใน Toolbox ของ MT5 กับหน้าโปรไฟล์บนเว็บ MQL5 เท่านั้น

ขั้นตอนเช่าโดยย่อ

  1. ล็อกอินบัญชีที่จะใช้

  2. สั่ง Register a Virtual Server

    คลิกขวาใน Navigator แล้วเลือก Register a Virtual Server ระบบจะเลือกเซิร์ฟเวอร์ที่ใกล้โบรกเกอร์ที่สุดให้ พร้อมแสดงการเทียบความหน่วงระหว่างคอมของคุณกับเซิร์ฟเวอร์เช่า

  3. เลือกแผนและชำระเงิน

    เลือกระยะเวลาเช่า ซึ่งคู่มือระบุว่ายิ่งเช่ายาวยิ่งคุ้มต่อเดือน จ่ายผ่านบัญชี MQL5.community หรือช่องทางชำระเงินที่รองรับ บางโบรกเกอร์มีแผนที่ออกค่าเช่าให้ ขั้นตอนเต็มอยู่ในคู่มือเช่า Virtual Hosting ของ MetaTrader 5

  4. ย้ายสภาพแวดล้อม

    เลือกรูปแบบการย้าย All (กราฟ EA อินดิเคเตอร์ และ Signal) Experts (เฉพาะ EA กับอินดิเคเตอร์) หรือ Signal แล้วกดซิงก์ ระหว่างย้าย MT5 บนคอมจะปิดการเทรดอัตโนมัติของตัวเองให้ เพื่อไม่ให้สองที่เทรดด้วย EA ตัวเดียวกันในบัญชีเดียว

กฎเรื่อง DLL บนเทอร์มินัลเสมือน

DLL คือไฟล์โปรแกรมภายนอกที่ EA เรียกใช้เพื่อเพิ่มความสามารถที่ภาษา MQL5 ทำเองไม่ได้ หรือทำได้ไม่สะดวก บน MT5 ปกติ คุณอนุญาตเองได้ด้วยการติ๊ก Allow DLL imports แต่บนเทอร์มินัลเสมือนไม่มีสวิตช์นี้ให้เปิด

ทำไม EA บางตัวต้องใช้ DLL

ผู้พัฒนาเลือกใช้ DLL ด้วยเหตุผลหลายแบบ เช่น เชื่อมต่อกับบริการภายนอก ใช้ไลบรารีที่เขียนด้วยภาษาอื่น หรือทำงานที่ภาษา MQL5 ไม่มีคำสั่งรองรับ การใช้ DLL จึงไม่ได้บอกว่า EA ดีหรือแย่ แต่บอกว่าคุณต้องไว้ใจผู้พัฒนามากขึ้น เพราะ DLL เข้าถึงเครื่องได้กว้างกว่าโค้ด MQL5 ทั่วไป คู่มือ MT5 จึงแนะนำให้เปิด DLL เฉพาะโปรแกรมที่ไว้ใจ ส่วนกฎของ Virtual Hosting ให้เหตุผลไว้สั้น ๆ ว่าเครื่องเสมือนของบริการไม่มีความสามารถรองรับการใช้ DLL

กฎการใช้บริการ Virtual Hosting บน MQL5.com เขียนไว้สองจุดที่เกี่ยวข้อง ข้อแรกบอกว่าไม่อนุญาตให้ใช้ DLL บนเทอร์มินัลเสมือน ข้อที่สองบอกว่าถ้าโปรแกรมที่รันอยู่พยายามเรียกฟังก์ชันจาก DLL ใด ๆ โปรแกรมนั้นจะถูกหยุดทันทีด้วยข้อผิดพลาดร้ายแรง (critical error) ส่วนคู่มือการย้ายของ MT5 ก็ระบุตรงกันว่าการเรียก DLL ถูกห้ามโดยสิ้นเชิงบนแพลตฟอร์มเสมือน

ผลในทางปฏิบัติคือ EA ที่ขาด DLL ไม่ได้จะไม่ทำงานบนบริการนี้ ไม่ว่าจะตั้งค่าอย่างไร และไม่มีวิธีขออนุญาตเป็นกรณีพิเศษ [eawing_brand] อยู่ในกลุ่มนี้ เพราะต้องเปิด Allow DLL imports จึงจะทำงานได้ ความหมายของสวิตช์นี้และเหตุผลที่ควรเปิดให้เฉพาะ EA ที่ไว้ใจ อยู่ในเรื่องสวิตช์ Allow DLL imports ใน MT5

ย้ายอะไรขึ้นไปได้ และอะไรไม่ได้

นอกจากเรื่อง DLL บริการนี้ยังมีกติกาอื่นที่คนใช้ EA ควรรู้ก่อนจ่ายเงิน ตารางนี้สรุปจากคู่มือและกฎของบริการ

เรื่องสิ่งที่บริการกำหนด
สิ่งที่ย้ายขึ้นไปข้อมูลการเชื่อมต่อบัญชี กราฟที่เปิดอยู่ EA และอินดิเคเตอร์ที่รันบนกราฟเหล่านั้น การคัดลอก Signal และการตั้งค่าอีเมล
สิ่งที่ไม่ย้ายสคริปต์ กราฟที่ไม่มี EA ติดอยู่ และกราฟที่ใช้กรอบเวลาหรือสัญลักษณ์ที่ไม่เป็นมาตรฐาน
จำนวนกราฟแบบเสียเงินย้ายได้สูงสุด 32 กราฟ แบบฟรีสูงสุด 16 กราฟ
บัญชีเทรดเทอร์มินัลเสมือนหนึ่งตัวทำงานได้กับบัญชีเทรดเดียว
DLLห้ามทุกกรณี โปรแกรมที่เรียก DLL ถูกหยุดทันที
การเทรดอัตโนมัติเปิดเสมอบนเทอร์มินัลเสมือน แม้จะปิดไว้ในการตั้งค่าของ MT5 บนคอม
ระยะเช่าและการยกเลิกเช่าขั้นต่ำ 1 เดือน ยกเลิกได้ตลอดแต่ไม่มีการคืนเงิน
การดูแลไม่มีหน้าจอให้รีโมต ดูสถานะ CPU หน่วยความจำ และ Log ผ่านแท็บ VPS ใน Toolbox

ข้อที่คนพลาดบ่อยคือเรื่องการแก้ค่า ทุกครั้งที่เปลี่ยนค่า EA หรือเพิ่มกราฟบนคอม ต้องสั่งย้ายใหม่ เพราะเทอร์มินัลเสมือนไม่ได้อ่านค่าจากคอมของคุณตลอดเวลา และควรเช็กใน VPS → Journal ว่าการย้ายครั้งล่าสุดสำเร็จ

เช็กอย่างไรว่า EA ของคุณใช้ DLL

ก่อนตัดสินใจเช่า ใช้วิธีเหล่านี้ตรวจ EA ที่จะรัน ทำบน MT5 ในคอมของคุณได้เลย

  • ดูหน้าต่างคุณสมบัติตอนลาก EA ลงกราฟ: คู่มือ MT5 ระบุว่าแท็บ Dependencies จะปรากฏเมื่อ EA นำเข้าฟังก์ชันจากไฟล์ EX5 อื่นหรือ DLL ในรายการนั้นไอคอนสีแดงคือการเรียกฟังก์ชันใน DLL ถ้าเห็นสีแดง EA ตัวนั้นใช้ Virtual Hosting ไม่ได้
  • อ่านคู่มือติดตั้งของ EA: ถ้าคู่มือบอกให้ติ๊ก Allow DLL imports แปลว่า EA ต้องใช้ DLL
  • ลองปิด DLL บนคอม: ถ้าปิด Allow DLL imports แล้ว EA โหลดไม่ขึ้น หรือแท็บ Experts แจ้งข้อผิดพลาดเรื่อง DLL แปลว่าขาดไม่ได้
  • ถามผู้พัฒนาหรือผู้ขายโดยตรง: ถามให้ชัดว่า EA ใช้ DLL หรือไม่ และรองรับ Virtual Hosting ของ MT5 หรือไม่

กฎของ Market บน MQL5 ห้ามสินค้าเรียก DLL อยู่แล้ว EA ที่ซื้อจาก Market จึงมักย้ายขึ้นไปได้ และคู่มือระบุว่าการย้ายไม่ลดจำนวนการเปิดใช้งาน (activation) ที่เหลือ ส่วน EA ที่ซื้อจากผู้ขายนอก Market ต้องตรวจเป็นตัว ๆ

ถ้าย้าย EA ที่ใช้ DLL ขึ้นไปแล้ว จะเกิดอะไรขึ้น

การย้ายอาจดูเหมือนสำเร็จ เพราะกราฟถูกส่งขึ้นไปครบ แต่ทันทีที่ EA พยายามเรียก DLL บนเทอร์มินัลเสมือน โปรแกรมจะถูกหยุด ขณะเดียวกัน MT5 บนคอมของคุณถูกปิดการเทรดอัตโนมัติไประหว่างย้าย ผลคือไม่มีที่ไหนเทรดให้เลย ทั้งที่คุณคิดว่า EA ย้ายไปทำงานบนเซิร์ฟเวอร์แล้ว

ตัวอย่างสมมติ: เช้าวันจันทร์ที่บัญชีเงียบ

เทรดเดอร์คนหนึ่งเช่า VPS ในตัว MT5 คืนวันศุกร์ ย้ายกราฟขึ้นไป เห็นข้อความว่าซิงก์สำเร็จจึงปิดคอม วันจันทร์บัญชีไม่มีความเคลื่อนไหว พอเปิด VPS → Journal จึงเห็นว่า EA ถูกหยุดตั้งแต่โหลดครั้งแรกเพราะเรียก DLL เรื่องนี้แต่งขึ้นเพื่ออธิบาย บทเรียนคือหลังย้ายทุกครั้ง ให้เปิด Journal ของ VPS ยืนยันว่า EA รันอยู่จริง และถ้าต้องกลับมารันบนคอมหรือ Windows VPS อย่าลืมเปิดปุ่ม Algo Trading กลับด้วย

คำถามที่พบบ่อย

ใช้ MQL5 VPS กับ EA WING ได้ไหม?

ไม่ได้ EA WING ต้องใช้ DLL ในการทำงาน ซึ่งบริการนี้ห้ามทุกกรณี ให้รันบน Windows VPS ที่ติดตั้ง MT5 เองได้ แล้วเปิด Allow DLL imports ตามคู่มือติดตั้ง

เปิด EA บนคอมกับบนเทอร์มินัลเสมือนพร้อมกันได้ไหม?

ไม่ควร ระบบจึงปิดการเทรดอัตโนมัติบนคอมให้ตอนย้าย ถ้าคุณเปิดปุ่ม Algo Trading บนคอมกลับมาเอง EA สองที่อาจส่งคำสั่งซ้อนกันในบัญชีเดียว ให้เลือกรันที่เดียวเสมอ

ยกเลิก MQL5 VPS กลางคันได้เงินคืนไหม?

กฎของบริการระบุว่ายกเลิกได้ตลอดเวลาแต่ไม่มีการคืนเงิน และระยะเช่าขั้นต่ำคือ 1 เดือน ให้ตรวจก่อนว่า EA ทำงานบนเทอร์มินัลเสมือนได้จริง แล้วค่อยเลือกแผนระยะยาว

มี EA ทั้งแบบใช้ DLL และไม่ใช้ DLL ในบัญชีเดียว ทำอย่างไรดี?

เทอร์มินัลเสมือนจะหยุดเฉพาะโปรแกรมที่เรียก DLL แต่การแยกรันบัญชีเดียวกันสองที่ทำให้ดูแลยากและเสี่ยงสับสน ทางที่ง่ายกว่าคือรันทั้งหมดบน Windows VPS เครื่องเดียว

คำเตือนความเสี่ยง: ไม่ว่าจะรันบน VPS แบบไหน การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต และช่วงที่ EA หยุดโดยไม่รู้ตัวอาจทำให้ออเดอร์ที่ค้างอยู่ไม่ได้รับการดูแลตามแผน ตรวจทุกครั้งหลังย้ายเครื่อง และอ่านหน้าเปิดเผยความเสี่ยงก่อนใช้เงินจริง

สำหรับ EA ที่ต้องใช้ DLL ทางที่ตรงที่สุดคือ Windows VPS ขั้นตอนเชื่อมต่อ ย้ายไฟล์ และตั้งให้ MT5 เปิดเองหลังรีสตาร์ต อยู่ในคู่มือ VPS Windows สำหรับรัน EA ถ้ายังไม่แน่ใจว่าบริการที่กำลังดูอยู่เป็นแบบไหน ส่งชื่อแพ็กเกจมาถามทีมงานได้
