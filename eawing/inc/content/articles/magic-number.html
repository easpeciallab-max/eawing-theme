Magic Number คือตัวเลขที่ EA ติดไว้กับทุกออเดอร์ที่ตัวเองส่ง เพื่อแยกให้ออกว่าออเดอร์ไหนเป็นของตัวเอง ออเดอร์ไหนเป็นของ EA ตัวอื่นหรือของคนที่กดเอง สำหรับคนที่เพิ่งเข้าใจว่าExpert Advisor คืออะไร เรื่องนี้อาจดูเป็นรายละเอียดเล็ก แต่เป็นต้นเหตุของปัญหาออเดอร์ถูกปิดผิดตัว หรือถูกทิ้งไว้โดยไม่มีระบบไหนดูแล มานักต่อนักแล้ว

สรุปสั้น: Magic Number คือป้ายชื่อของออเดอร์ ไม่มีผลต่อกำไรหรือขาดทุนโดยตรง แต่ถ้ารัน EA หลายตัวในบัญชีเดียว แต่ละตัวต้องใช้เลขไม่ซ้ำกัน และไม่ควรเปลี่ยนเลขระหว่างที่ยังมีออเดอร์เปิดอยู่ ออเดอร์ที่กดเองด้วยมือจะมี Magic Number เป็น 0

Magic Number คือป้ายชื่อที่ EA แปะไว้กับออเดอร์

ทุกครั้งที่ EA ส่งคำสั่งซื้อขาย มันจะแนบข้อมูลไปกับคำสั่งหลายช่อง หนึ่งในนั้นคือช่อง magic ซึ่งเอกสาร MQL5 เรื่องโครงสร้างคำสั่งเทรดอธิบายว่าเป็นรหัสประจำตัวของ Expert Advisor ที่แต่ละตัวกำหนดเองได้ (ภาษาอังกฤษ) เลขนี้จะติดอยู่กับออเดอร์ สถานะที่เปิดอยู่ และรายการในประวัติการเทรดตลอดไป

ภายหลังเมื่อ EA ต้องนับว่าตัวเองถือออเดอร์อยู่กี่ไม้ จะปิดชุดออเดอร์ หรือจะเลื่อนจุดตัดขาดทุน มันจะกรองรายการทั้งบัญชีเอาเฉพาะออเดอร์ที่มีเลขตรงกับของตัวเอง หลาย EA กรองด้วยชื่อสัญลักษณ์ร่วมด้วย

นึกภาพโกดังที่หลายร้านใช้ร่วมกัน ถ้าทุกกล่องมีป้ายชื่อร้าน พนักงานแต่ละร้านก็หยิบเฉพาะของตัวเอง แต่ถ้าสองร้านใช้ป้ายเดียวกัน หรือป้ายหลุด ของก็จะถูกหยิบผิดหรือถูกลืมไว้ในมุมโกดัง

ทำไม EA ต้องรู้ว่าออเดอร์ไหนเป็นของตัวเอง

ในบัญชีเดียว ออเดอร์ทุกไม้จะอยู่ในรายการเดียวกันหมด ไม่ว่าจะมาจาก EA ตัวไหนหรือมาจากการกดมือ ถ้า EA ไม่แยก มันจะเอาออเดอร์ของคนอื่นมาคิดรวมกับของตัวเอง ตารางนี้เป็นตัวอย่างสมมติของบัญชีที่แยกเลขไว้ถูกต้อง

ใน MT5 หนึ่งกราฟวาง EA ได้ตัวเดียว ถ้าจะรัน EA ตัวเดียวกันสองชุดบนสัญลักษณ์เดียวกันจึงต้องเปิดสองกราฟ และสองชุดนั้นต้องใช้เลขต่างกัน ถ้า EA ตัวนั้นเปิดให้ตั้งได้

ถ้า Magic Number ซ้ำกันจะเกิดอะไร

เมื่อ EA สองตัวใช้เลขเดียวกันบนสัญลักษณ์เดียวกัน ทั้งสองจะมองออเดอร์ของอีกฝ่ายว่าเป็นของตัวเอง ผลที่ตามมาขึ้นกับว่า EA ถูกเขียนมาอย่างไร แต่อาการที่พบบ่อยมีดังนี้

  • นับไม้ผิด EA เห็นว่ามีออเดอร์เปิดอยู่แล้วจึงไม่เข้าเทรด หรือคำนวณขนาดรวมผิดไปจากที่ออกแบบ
  • ปิดของคนอื่น เมื่อ EA ตัวหนึ่งสั่งปิดชุดออเดอร์ของตัวเอง ออเดอร์ของอีกตัวที่ใช้เลขเดียวกันก็ถูกปิดไปด้วย
  • แก้จุดตัดขาดทุนผิดไม้ ฟังก์ชันเลื่อนจุดตัดขาดทุนไปแตะออเดอร์ที่ไม่ใช่ของตัวเอง
  • ทบทวนผลไม่ได้ ดูย้อนหลังแล้วแยกไม่ออกว่าผลส่วนไหนมาจากระบบไหน

บาง EA ใช้ข้อมูลอื่นช่วยแยกด้วย เช่น ชื่อสัญลักษณ์หรือข้อความ Comment แต่ไม่ควรฝากความหวังไว้ตรงนั้น ทางที่ปลอดภัยคือให้เลขไม่ซ้ำกันตั้งแต่แรก

ตัวอย่างสมมติ: EA ตัวเดียวกันสองกราฟ เลขเดียวกัน

สมมติคุณวาง EA ตัวเดียวกันบนกราฟ XAUUSD สองกราฟเพื่อลองค่าตั้งคนละแบบ แต่ลืมเปลี่ยนเลข ทั้งสองชุดใช้ 1001 ชุดแรกเปิดออเดอร์ไปหนึ่งไม้ ชุดที่สองเห็นไม้นั้นแล้วเข้าใจว่าตัวเองมีออเดอร์อยู่แล้วจึงไม่เข้าเทรด พอถึงจังหวะปิด ทั้งสองชุดอาจพยายามจัดการไม้เดียวกัน ผลคือคุณไม่ได้สองระบบที่ทำงานแยกกันอย่างที่ตั้งใจ แต่ได้ระบบเดียวที่ทำงานผิดแบบ และเทียบผลของสองค่าตั้งไม่ได้เลย

ดู Magic Number ใน MT5 ได้ที่ไหน

  1. ชี้เมาส์ที่ออเดอร์ในแท็บ Trade หรือ History

    เปิด Toolbox (Ctrl+T) แล้วชี้เมาส์ค้างไว้ที่ออเดอร์ หน้าต่างเล็กที่เด้งขึ้นมาจะแสดงรหัสที่ EA ตั้งไว้ ความสามารถนี้มีมาตั้งแต่ MT5 build 975 ตามบันทึกการอัปเดตของ MetaTrader 5 (ภาษาอังกฤษ)

  2. ดูแท็บ Inputs ของ EA

    คลิกบนกราฟแล้วกด F7 EA ส่วนใหญ่มีช่องชื่อทำนอง Magic, MagicNumber หรือ Expert ID บาง EA ไม่เปิดให้เห็นหรือให้ปรับ แปลว่าผู้พัฒนากำหนดไว้ในตัว

  3. ดูคอลัมน์ Comment ประกอบ

    EA หลายตัวเขียนชื่อตัวเองไว้ใน Comment ใช้ช่วยดูได้ แต่ไม่แม่นเท่า Magic Number เพราะบางกรณีข้อความนี้ถูกเปลี่ยน เช่น ตอนออเดอร์ถูกปิดด้วยจุดตัดขาดทุน

อย่าสับสนกับรหัสสิทธิ์ใช้งาน

Magic Number เป็นเลขที่ใครเห็นก็ไม่เสียหาย ไม่ใช่รหัสผ่าน ไม่ใช่ License Key และไม่ใช่เลขบัญชี MT5 ส่วน EA ที่มีระบบสิทธิ์ใช้งานจะตรวจสิทธิ์ด้วยข้อมูลอื่น เช่น เลขบัญชีกับชื่อเซิร์ฟเวอร์ และโดยทั่วไปไม่จำเป็นต้องรู้รหัสผ่านบัญชีเทรดของคุณ ผู้ใช้ EA WING ก็ส่งแค่เลขบัญชีและชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE ถ้ามีใครขอรหัสผ่านพร้อมอ้างว่าต้องใช้ตั้ง Magic Number ให้ระวังไว้ก่อน

ตั้ง Magic Number อย่างไรเมื่อรัน EA หลายตัว

ถ้า EA ที่ใช้เปิดให้ตั้งเลขเอง หลักเหล่านี้ช่วยกันปัญหาได้เกือบทั้งหมด

  • หนึ่งกราฟหนึ่งเลข EA ทุกชุดในบัญชีเดียวกันใช้เลขไม่ซ้ำกัน แม้จะเป็นไฟล์ EA เดียวกันก็ตาม
  • ตั้งเลขให้อ่านออก เช่น หลักแรกบอกว่าเป็น EA ตัวไหน สามหลักท้ายบอกลำดับกราฟ แบบในตารางตัวอย่างด้านบน
  • หลีกเลี่ยงเลข 0 เพราะซ้ำกับออเดอร์ที่กดมือ
  • จดไว้ที่เดียว ชื่อ EA เวอร์ชัน กราฟ เลขที่ใช้ และวันที่เริ่ม เวลามีปัญหาจะไล่ได้เร็ว
  • ตรวจหลังตั้ง พอมีออเดอร์แรก ให้ชี้เมาส์ดูว่าเลขตรงกับที่ตั้งไว้
  • ระวังไฟล์ .set ไฟล์ค่าตั้งที่โหลดเข้าไปอาจพาเลขอื่นมาด้วย ดูวิธีตรวจในSet File ของ EA

ถ้า EA ไม่มีช่องให้ตั้งเลข อย่าเพิ่งวางสองชุดบนสัญลักษณ์เดียวกันในบัญชีเดียว ให้ถามผู้พัฒนาก่อนว่ารองรับการรันหลายชุดหรือไม่

เปลี่ยน Magic Number ตอนมีออเดอร์ค้างได้ไหม

ทำได้ในทางเทคนิค แต่เป็นหนึ่งในความผิดพลาดที่ส่งผลมากที่สุด เมื่อกด OK หลังเปลี่ยนค่า EA จะเริ่มทำงานใหม่ด้วยเลขใหม่ ออเดอร์เดิมยังเปิดอยู่ที่โบรกเกอร์ตามปกติ แต่ EA ไม่รู้จักมันแล้ว ไม่มีการปิดตามเงื่อนไข ไม่มีการเลื่อนจุดตัดขาดทุน ออเดอร์เหล่านั้นจะถูกปล่อยให้วิ่งไปตามตลาดจนกว่าจะชนจุดที่ตั้งไว้ฝั่งโบรกเกอร์ หรือจนกว่าคุณจะจัดการเอง

ถ้าเผลอเปลี่ยนไปแล้ว

  1. ตรวจรายการออเดอร์

    ชี้เมาส์ดูทีละไม้ว่าออเดอร์ไหนใช้เลขเก่า ออเดอร์ไหนใช้เลขใหม่

  2. พิจารณาคืนค่าเลขเดิม

    ถ้า EA ถูกเขียนให้กลับมาดูแลออเดอร์ที่ตรงเลขเมื่อเริ่มใหม่ การตั้งเลขกลับเป็นค่าเดิมมักทำให้มันรับช่วงต่อได้ ถ้าไม่แน่ใจให้ถามผู้พัฒนา

  3. ตัดสินใจตามแผน ไม่ใช่ตามอารมณ์

    ถ้ารับช่วงคืนไม่ได้ ให้จัดการออเดอร์ที่ค้างตามกฎในแผนการเทรดของคุณ แล้วครั้งหน้าเปลี่ยนเลขเฉพาะตอนที่ไม่มีออเดอร์เปิดอยู่

ปัญหาเดียวกันเกิดได้ตอนเปลี่ยนไฟล์เป็นเวอร์ชันใหม่ ถ้าเวอร์ชันใหม่ใช้เลขเริ่มต้นไม่เหมือนเดิม ขั้นตอนที่ปลอดภัยอยู่ในเรื่องอัปเดต EA เวอร์ชันใหม่

Magic Number กับการเทรดมือในบัญชีเดียวกัน

EA ที่กรองด้วย Magic Number จะไม่แตะออเดอร์ที่คุณกดเอง แต่ไม่ได้แปลว่าสองฝั่งไม่เกี่ยวกัน ออเดอร์ทุกไม้ใช้ Free Margin ก้อนเดียวกัน ออเดอร์มือที่ติดลบจึงลดพื้นที่ของ EA ลงด้วย และ EA ที่ไม่ได้กรองเลขอาจไปจัดการออเดอร์มือของคุณได้

ถ้ายังจำเป็นต้องใช้บัญชีเดียว อย่างน้อยให้ตกลงกับตัวเองไว้ล่วงหน้าสามข้อ

  • จะไม่ปิดหรือแก้ออเดอร์ที่มีเลขของ EA ด้วยมือ ยกเว้นตามกฎที่เขียนไว้ในแผน
  • ขนาดออเดอร์มือรวมกับของ EA ต้องไม่เกินเพดานความเสี่ยงที่ตั้งไว้สำหรับทั้งบัญชี
  • จดออเดอร์มือแยกไว้ เพื่อทบทวนผลของแต่ละฝั่งได้ตรงตามจริง

ถ้าอยากแยกให้ขาดจริง วิธีที่ชัดที่สุดคือใช้คนละบัญชี อ่านวิธีจัดการในรัน EA หลายบัญชีพร้อมกัน การแยกบัญชียังช่วยให้ทบทวนผลง่ายขึ้นมาก เพราะรายงาน MT5 History ของแต่ละบัญชีจะสะท้อนระบบเดียว ผู้ใช้ EA WING ที่อยากเทรดมือหรือรัน EA ตัวอื่นในบัญชีเดียวกัน ควรถามทีมงานก่อนเริ่ม

คำเตือนความเสี่ยง: การตั้ง Magic Number ให้ถูกช่วยให้ EA ดูแลออเดอร์ของตัวเองได้ครบ แต่ไม่ได้ลดความเสี่ยงของกลยุทธ์ EA ที่ตั้งค่าถูกทุกช่องก็ยังขาดทุนได้ และการรันหลายระบบในบัญชีเดียวทำให้ความเสี่ยงรวมสูงขึ้น การเทรด Forex ทองคำ และ CFD อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลในอนาคต อ่านข้อมูลความเสี่ยงก่อนใช้ EAก่อนใช้เงินจริง

คำถามที่พบบ่อย: Magic Number คืออะไร และต้องตั้งไหม

Magic Number มีผลต่อกำไรขาดทุนไหม?

ไม่มีผลโดยตรง เลขนี้เป็นแค่ป้ายชื่อ เปลี่ยนจาก 1001 เป็น 5555 ก็ไม่ได้ทำให้ระบบเทรดดีขึ้นหรือแย่ลง ผลจะเปลี่ยนก็ต่อเมื่อเลขซ้ำหรือถูกเปลี่ยนกลางทางจน EA ดูแลออเดอร์ผิดตัว

ออเดอร์ที่ Magic Number เป็น 0 คืออะไร?

ส่วนใหญ่คือออเดอร์ที่กดเองจากหน้าจอ MT5 ทั้งบนคอมและมือถือ หรือจากโปรแกรมที่ไม่ได้ตั้งเลขไว้ ถ้าเห็นออเดอร์เลข 0 ที่คุณไม่ได้กดเอง ให้ตรวจว่ามีสคริปต์หรือ EA ตัวไหนรันอยู่ และใครเข้าถึงบัญชีได้บ้าง

รัน EA ตัวเดียวกันคนละบัญชี ต้องใช้เลขต่างกันไหม?

ไม่จำเป็น แต่ละบัญชีมีรายการออเดอร์ของตัวเอง EA บนบัญชีหนึ่งมองไม่เห็นออเดอร์ของอีกบัญชี เลขซ้ำข้ามบัญชีจึงไม่มีปัญหา จะซ้ำไม่ได้เฉพาะภายในบัญชีเดียวกัน

EA ไม่มีช่องให้ตั้ง Magic Number ผิดปกติไหม?

ไม่ผิดปกติ ผู้พัฒนาหลายรายกำหนดเลขไว้ในตัวเพื่อกันผู้ใช้เปลี่ยนผิด ข้อจำกัดคืออาจรันหลายชุดบนสัญลักษณ์เดียวกันในบัญชีเดียวไม่ได้ ควรถามผู้พัฒนาก่อนลอง

ตั้ง Magic Number เป็นเลขอะไรก็ได้ไหม?

ได้ในช่วงที่ EA ยอมรับ ในภาษา MQL5 ช่องนี้เก็บจำนวนเต็มที่ไม่ติดลบได้กว้างมาก แต่ช่องใน Inputs ของ EA แต่ละตัวอาจจำกัดไว้แคบกว่า ใช้เลขบวกที่จำง่าย ไม่ใช่ 0 และไม่ซ้ำกับระบบอื่นในบัญชีเดียวกันก็พอ

อ่านต่อ

  • ไฟล์ .set ของ EA ต้องใช้ไหม
  • อัปเดต EA เวอร์ชันใหม่ยังไงไม่ให้ออเดอร์ค้าง
  • รัน EA หลายบัญชีพร้อมกันทำยังไง
  • รายงาน MT5 History: ดึงประวัติการเทรดมาทบทวน

ถ้าอยากรู้ว่า EA ทองคำบน MT5 ที่ทีมงานคนไทยดูแลตั้งแต่ติดตั้งจนใช้งานเป็นแบบไหน ดูภาพรวมที่EA WING แล้วส่งคำถามเรื่องการรันหลายระบบในบัญชีเดียวมาทาง LINE ได้
