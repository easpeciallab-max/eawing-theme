EX5 กับ MQ5 คือไฟล์สองสถานะของโปรแกรมตัวเดียวกันใน MetaTrader 5 ไฟล์ .mq5 เป็นโค้ดต้นฉบับที่คนเขียนและแก้ได้ ส่วน .ex5 เป็นไฟล์ที่ผ่านการ Compile แล้วและเป็นตัวที่ MT5 รันจริง ถ้ายังไม่คุ้นกับการทำงานของบอทเทรดบนกราฟ อ่านพื้นฐานในEA คืออะไรก่อน แล้วกลับมาดูว่าไฟล์แต่ละแบบใช้ทำอะไร วางไว้ตรงไหน และคนมักพลาดกันตรงจุดใด

สรุปสั้น: ผู้ใช้ทั่วไปต้องการแค่ไฟล์ .ex5 วางใน MQL5 → Experts ก็ใช้งานได้ ส่วน .mq5 จำเป็นเฉพาะคนที่จะแก้โค้ด และต้องกด Compile ใน MetaEditor ก่อนจึงจะได้ .ex5 ที่รันได้ การได้รับแค่ .ex5 จากผู้ขาย EA เป็นเรื่องปกติ ไม่ได้แปลว่าไฟล์ไม่ครบ

MQ5 คือโค้ดต้นฉบับ EX5 คือไฟล์ที่ MT5 รัน

EA อินดิเคเตอร์ และสคริปต์ของ MT5 เขียนด้วยภาษา MQL5 ตอนที่ผู้พัฒนาเขียนอยู่ งานจะถูกเก็บเป็นไฟล์ข้อความนามสกุล .mq5 เปิดด้วย MetaEditor หรือแม้แต่ Notepad ก็เห็นโค้ดเป็นบรรทัด ๆ อ่านออกถ้ารู้ภาษา

แต่ตัวโปรแกรม MT5 ไม่ได้รันไฟล์ .mq5 โดยตรง ต้องผ่านขั้นตอนที่เรียกว่า Compile ก่อน MetaEditor จะตรวจโค้ดทั้งไฟล์ ถ้าไม่มีข้อผิดพลาดจะแปลงออกมาเป็นไฟล์ .ex5 ซึ่งเป็นรูปแบบที่เทอร์มินัลโหลดขึ้นกราฟได้ทันที

เทียบให้เห็นภาพ ไฟล์ .mq5 เหมือนแบบแปลนที่วิศวกรยังขีดแก้ได้ ส่วน .ex5 เหมือนเครื่องที่ประกอบเสร็จตามแบบแล้ว กดเปิดใช้ได้เลย แต่ถอดดูแบบแปลนจากตัวเครื่องไม่ได้ เปิดไฟล์ .ex5 ด้วย Notepad จะเห็นแต่ตัวอักษรอ่านไม่ออก ซึ่งเป็นเรื่องปกติ ไม่ได้แปลว่าไฟล์เสีย

mq5 to ex5: Compile ใน MetaEditor ทีละขั้น

ถ้าคุณได้ไฟล์ .mq5 มา เช่น โค้ดตัวอย่าง หรือ EA ที่เขียนเอง ขั้นตอนแปลงเป็น .ex5 มีดังนี้

  1. วางไฟล์ไว้ในโฟลเดอร์ของ MT5

    ใน MT5 เลือก File → Open Data Folder แล้วเข้า MQL5 → Experts คัดลอกไฟล์ .mq5 ลงไป ถ้าโค้ดเรียกใช้ไฟล์ .mqh เพิ่มเติม ให้วางไฟล์เหล่านั้นใน MQL5 → Include ตามที่ผู้เขียนโค้ดระบุ

  2. เปิด MetaEditor

    กด F4 ใน MT5 โปรแกรม MetaEditor จะเปิดขึ้นพร้อมหน้าต่าง Navigator ของตัวเอง ดับเบิลคลิกชื่อไฟล์ .mq5 เพื่อเปิด

  3. กด Compile

    กดปุ่ม Compile หรือปุ่ม F7 ใน MetaEditor ระวังสับสน เพราะใน MT5 ปุ่ม F7 ใช้เปิดหน้าต่างคุณสมบัติของ EA แต่ใน MetaEditor ปุ่มเดียวกันคือคำสั่ง Compile

  4. อ่านแท็บ Errors

    ผลจะแสดงในแท็บ Errors ด้านล่าง ถ้ามี error จะไม่มีไฟล์ .ex5 เกิดขึ้น ต้องแก้ก่อน ถ้ามีแค่ warning ไฟล์จะถูกสร้าง แต่ควรอ่านคำเตือนก่อนใช้งานจริง

  5. รีเฟรช Navigator ใน MT5

    ไฟล์ .ex5 จะอยู่ในโฟลเดอร์เดียวกับไฟล์ .mq5 กลับไปที่ MT5 เปิด Navigator (Ctrl+N) คลิกขวาแล้วเลือก Refresh ชื่อ EA จะขึ้นใต้หัวข้อ Expert Advisors

รายละเอียดอย่างเป็นทางการอยู่ในคู่มือการ Compile ของ MetaEditor (ภาษาอังกฤษ)

Error ที่เจอบ่อยตอน Compile

  • หาไฟล์ include ไม่เจอ โค้ดอ้างถึงไฟล์ .mqh ที่ไม่ได้อยู่ในเครื่อง ต้องขอไฟล์ครบชุดจากผู้เขียน
  • Error เป็นร้อยบรรทัด มักเป็นโค้ดของ MT4 (.mq4) ที่ถูกเปลี่ยนนามสกุลมา ภาษา MQL4 กับ MQL5 สั่งงานต่างกันหลายจุด อ่านเพิ่มในEA MT4 ใช้กับ MT5 ได้ไหม
  • Compile ผ่านแต่ใช้งานไม่ได้ ผ่านแปลว่าไวยากรณ์ถูก ไม่ได้แปลว่าตรรกะการเทรดถูก ยังต้องทดสอบใน Strategy Tester (Ctrl+R) และบัญชีเดโมเสมอ

ทำไมผู้ขาย EA ส่งมาแค่ไฟล์ EX5

คนที่ซื้อ EA ครั้งแรกบางคนกังวลว่าได้ไฟล์ไม่ครบ เพราะไม่มี .mq5 มาด้วย ความจริงคือ EA เชิงพาณิชย์เกือบทั้งหมดส่งเฉพาะ .ex5 ด้วยเหตุผลเหล่านี้

  • ปกป้องตรรกะของระบบ รูปแบบไฟล์ .ex5 ถูกออกแบบให้ซ่อนอัลกอริทึม ผู้พัฒนาจึงแจกจ่ายได้โดยไม่ต้องเปิดเผยโค้ด
  • ระบบสิทธิ์ใช้งานอยู่ในไฟล์ EA ที่ผูกสิทธิ์กับเลขบัญชีจะตรวจสิทธิ์จากโค้ดข้างใน ถ้าแจกโค้ดต้นฉบับ ระบบนี้ก็ไม่มีความหมาย
  • ทุกคนใช้เวอร์ชันเดียวกัน เวลาผู้ใช้ติดปัญหา ทีมซัพพอร์ตรู้แน่ชัดว่าไฟล์ในเครื่องลูกค้าคือเวอร์ชันไหน ไม่มีใครแก้โค้ดไปคนละทาง

ข้อเสียฝั่งผู้ซื้อคือตรวจโค้ดเองไม่ได้ จึงต้องประเมินจากสิ่งที่ตรวจสอบได้แทน เช่น การทดสอบย้อนหลัง การรันบัญชีเดโม ความชัดเจนของคู่มือ และการตอบคำถามเรื่องความเสี่ยงของผู้ขาย ดูขั้นตอนได้ที่หน้าแนวทางทดสอบ EA ย้อนหลัง

สินค้าของเราเองก็เป็นแบบนี้ [eawing_brand] ส่งเป็นไฟล์ EA_WING_V4.2.ex5 ไฟล์เดียว โหมด Lite และ Full อยู่ในไฟล์นั้น ไม่ต้องใช้ไฟล์ .set เพิ่ม

แปลง EX5 กลับเป็น MQ5 ได้ไหม

คำตอบสั้น ๆ คือไม่มีทางที่ถูกต้องและใช้ได้จริง รูปแบบ .ex5 ไม่ได้ออกแบบมาให้ย้อนกลับ ข้อเสนอ "ถอดโค้ด EA" หรือ "EA แคร็ก ไม่ต้องใช้ License" ที่วนอยู่ในกลุ่มแชตจึงควรมองเป็นสัญญาณอันตราย

  • ไฟล์ที่ถูกดัดแปลงอาจฝังโค้ดอันตราย ยิ่งถ้าต้องติ๊กอนุญาต DLL ไฟล์นั้นเข้าถึงเครื่องได้กว้างกว่า EA ทั่วไป
  • ตรรกะที่ถูกแก้แบบเดาสุ่มอาจเปิดออเดอร์ผิดจากที่ระบบเดิมออกแบบไว้ โดยที่คุณไม่รู้เลย
  • ละเมิดเงื่อนไขการใช้งานของผู้พัฒนา และไม่มีใครดูแลเมื่อเกิดปัญหา
  • ใช้รหัสบัญชีเทรดล็อกอินบนเครื่องที่รันไฟล์แบบนี้ เท่ากับเอาเงินในบัญชีไปเสี่ยงเพิ่มอีกชั้น

ถ้าอยากได้ EA ที่ปรับตรรกะเองได้ ทางที่ตรงกว่าคือเขียนเองหรือจ้างเขียนโดยตกลงสิทธิ์ในโค้ดต้นฉบับให้ชัดตั้งแต่แรก

ไฟล์ EX5 MQ5 และนามสกุลอื่นในโฟลเดอร์ MQL5

เปิด File → Open Data Folder แล้วเข้าโฟลเดอร์ MQL5 จะเห็นโฟลเดอร์ย่อยหลายชุด แต่ละชุดเก็บไฟล์คนละประเภท ตารางนี้สรุปเฉพาะที่คนใช้ EA เจอบ่อย

มีข้อสังเกตหนึ่งข้อ EA บางตัวต้องใช้อินดิเคเตอร์ที่ผู้พัฒนาทำแยกไว้ ถ้าคู่มือบอกให้วางไฟล์ .ex5 บางไฟล์ใน Indicators ต้องวางตามนั้น วางรวมใน Experts แล้ว EA จะหาอินดิเคเตอร์ไม่เจอ

วางไฟล์ .ex5 ให้ MT5 มองเห็น และจุดที่พลาดบ่อย

หลักการง่ายมาก คัดลอกไฟล์ .ex5 ไปที่ MQL5 → Experts ของ MT5 ตัวที่จะใช้ แล้วรีเฟรช Navigator แต่ในทางปฏิบัติมีจุดที่ทำให้ "วางแล้วไม่เห็น" อยู่หลายจุด

  • วางผิด MT5 เครื่องที่ติดตั้ง MT5 หลายตัว แต่ละตัวมี Data Folder ของตัวเอง ต้องเปิดผ่าน File → Open Data Folder ของ MT5 ตัวที่ใช้จริงทุกครั้ง เรื่องนี้เจอบ่อยกับคนที่เปิด MT5 หลายตัวบน VPS เครื่องเดียว
  • ยังไม่แตกไฟล์ zip ไฟล์ที่ยังอยู่ใน zip หรือค้างในโฟลเดอร์ Downloads MT5 มองไม่เห็น
  • ดับเบิลคลิกไฟล์ .ex5 ใน Windows Windows ไม่รู้จักไฟล์นี้ วิธีใช้คือลากชื่อ EA จาก Navigator ลงกราฟ
  • วางไว้ใน Indicators EA จะไปโผล่ผิดหมวด หรือไม่ทำงานตามที่ควร
  • เวอร์ชันเก่าค้างอยู่ด้วย มีไฟล์ชื่อคล้ายกันสองไฟล์ ลากผิดตัวลงกราฟโดยไม่รู้ตัว วิธีเปลี่ยนไฟล์อย่างเป็นระบบอยู่ในเรื่องอัปเดต EA เวอร์ชันใหม่
  • MT5 เก่าเกินไป ถ้าแท็บ Journal แจ้งว่าโหลดโปรแกรมไม่ได้ ให้อัปเดต MT5 เป็น build ล่าสุดแล้วลองใหม่

ถ้าย้ายไปรันบนเครื่องเสมือน ไฟล์ .ex5 ต้องคัดลอกไปไว้ใน MT5 บนเครื่องนั้นด้วย เพราะ VPS คือคอมอีกเครื่องหนึ่ง ภาพรวมการเลือกและตั้งค่าอยู่ในเลือกและตั้งค่า VPS สำหรับรัน EA ส่วนผู้ใช้ EA WING ทำตามหน้าขั้นตอนติดตั้ง EA WINGได้ทีละขั้น

คำเตือนความเสี่ยง: นามสกุลไฟล์บอกแค่ว่าโปรแกรมอยู่ในรูปแบบไหน ไม่ได้บอกคุณภาพของระบบเทรด EA ทุกตัวไม่ว่าจะเป็น .ex5 จากผู้ขายหรือ .mq5 ที่เขียนเอง ทำให้ขาดทุนได้ การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลในอนาคต อ่านคำเตือนความเสี่ยงฉบับเต็มก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่องไฟล์ EX5 กับ MQ5

ได้ไฟล์ .ex5 มาอย่างเดียว ใช้งานได้ครบไหม?

ได้ครบ ไฟล์ .ex5 คือตัวโปรแกรมที่ MT5 ใช้รันอยู่แล้ว ไฟล์ .mq5 จำเป็นเฉพาะคนที่จะแก้โค้ด ถ้าผู้ขายให้ไฟล์อื่นมาด้วย เช่น อินดิเคเตอร์หรือ DLL ให้วางตามคู่มือของผู้ขาย

เปิดไฟล์ .ex5 ด้วย Notepad แล้วอ่านไม่ออก ไฟล์เสียหรือเปล่า?

ไม่เสีย ไฟล์ .ex5 ถูกเก็บในรูปแบบที่ไม่ใช่ข้อความ จึงเห็นเป็นตัวอักษรแปลก ๆ วิธีเช็กว่าไฟล์ใช้ได้คือวางใน MQL5 → Experts รีเฟรช Navigator แล้วลากลงกราฟ ดูผลในแท็บ Experts และ Journal

อยากเปลี่ยนขนาด Lot ต้องมีไฟล์ .mq5 ไหม?

ไม่ต้อง ถ้าผู้พัฒนาเปิดให้ปรับค่านั้น จะอยู่ในแท็บ Inputs ของหน้าต่างคุณสมบัติ EA (กด F7 บนกราฟ) ถ้าไม่มีช่องให้ปรับ แปลว่าผู้พัฒนาตั้งใจให้ระบบคุมเอง ควรถามผู้ขายก่อนหาทางอื่น

ไฟล์ EX5 ของ MT5 เอาไปใช้กับ MT4 ได้ไหม?

ไม่ได้ MT4 ใช้ไฟล์ .ex4 ที่ Compile จากภาษา MQL4 ซึ่งเป็นคนละรูปแบบ EA ที่จะใช้บนสองแพลตฟอร์มต้องมีไฟล์แยกกันของแต่ละฝั่ง

ซื้อ EA แล้วขอโค้ด .mq5 ได้ไหม?

ขึ้นกับข้อตกลงของผู้ขาย แต่ส่วนใหญ่ขายเฉพาะสิทธิ์ใช้งานไฟล์ .ex5 ส่วนโค้ดต้นฉบับถือเป็นทรัพย์สินของผู้พัฒนา ถ้าคุณต้องการโค้ดจริง ๆ ควรเลือกการจ้างเขียนที่ระบุเรื่องนี้ไว้ในสัญญาตั้งแต่ต้น

อ่านต่อ

  • EA คืออะไร: คู่มือ Expert Advisor และบอทเทรดบน MT5
  • Set File ของ EA คืออะไร ต้องใช้ไหม
  • EA MT4 ใช้กับ MT5 ได้ไหม
  • คู่มือติดตั้ง EA WING ทีละขั้น

ถ้ากำลังมองหา EA ทองคำบน MT5 ที่ส่งมาเป็นไฟล์เดียวพร้อมคู่มือและทีมงานคนไทยดูแล ดูภาพรวมได้ที่หน้าแรก EA WING หรือส่งคำถามเรื่องไฟล์และการติดตั้งมาทาง LINE
