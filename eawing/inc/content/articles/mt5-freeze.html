MT5 ค้างมีสองแบบที่หน้าตาคล้ายกันจนแยกไม่ออก แบบแรกคือกราฟไม่ขยับทั้งที่โปรแกรมยังคลิกได้ปกติ แบบที่สองคือตัวโปรแกรมไม่ตอบสนองเลย สองแบบนี้แก้คนละทาง คู่มือนี้ช่วยแยกอาการภายในหนึ่งนาที แล้วไล่แก้ทีละขั้นทั้งบนคอม VPS และมือถือ ถ้ายังไม่คุ้นกับหน้าต่างต่าง ๆ ของโปรแกรม ดูแผนที่หน้าจอในคู่มือ MetaTrader 5 สำหรับมือใหม่ประกอบ

สรุปสั้น: ถ้ากราฟนิ่งแต่ยังเปิดเมนูได้ ให้ดูว่าตลาดเปิดไหม มุมขวาล่างยังเชื่อมต่อไหม และกราฟถูกเลื่อนไปดูอดีตหรือเปล่า · ถ้าโปรแกรมขึ้น Not Responding ให้รอสักครู่ ดู CPU กับ RAM ใน Task Manager แล้วค่อยปิดเปิดใหม่ · ลดจำนวนกราฟ อินดิเคเตอร์ และค่า Max bars in chart เพื่อกันค้างซ้ำ · หลังเปิดใหม่ ตรวจว่า EA ยังอยู่บนกราฟและปุ่ม Algo Trading ยังเขียว

MT5 ค้างแบบไหน: แยกอาการก่อนแก้

ลองคลิกเมนู File หรือเลื่อนกราฟดูหนึ่งครั้ง แล้วจับคู่สิ่งที่เห็นกับตารางนี้

สิ่งที่เห็นสาเหตุที่น่าจะเป็นไปที่หัวข้อ
ราคาใน Market Watch นิ่ง กราฟไม่มีแท่งใหม่ แต่คลิกเมนูได้ตลาดปิด หรือการเชื่อมต่อหลุดกราฟไม่ขยับ แต่โปรแกรมยังใช้งานได้
กราฟเดียวนิ่ง กราฟอื่นขยับปกติกราฟถูกเลื่อนไปดูอดีต หรือเปิดสัญลักษณ์ที่ไม่มีราคาเข้ากราฟไม่ขยับ แต่โปรแกรมยังใช้งานได้
กดอะไรไม่ได้ หัวหน้าต่างขึ้น Not Respondingโปรแกรมทำงานหนักเกินกำลังเครื่องโปรแกรมไม่ตอบสนอง
หน้าจอ VPS ทั้งหน้านิ่ง เมาส์ไม่ขยับการรีโมตหลุด หรือ VPS ทรัพยากรไม่พอปัญหาบน VPS
แอปบนมือถือราคานิ่งสัญญาณอินเทอร์เน็ตของมือถือ หรือแอปค้างแอปบนมือถือค้าง

กราฟไม่ขยับ แต่โปรแกรมยังใช้งานได้

กรณีนี้พบบ่อยกว่าโปรแกรมค้างจริงมาก และส่วนใหญ่ไม่ต้องปิดโปรแกรมเลย

ตลาดปิดหรืออยู่ในช่วงพัก

ช่วงสุดสัปดาห์ วันหยุด และช่วงพักรายวันของบางสัญลักษณ์ ราคาจะไม่มีการเปลี่ยนแปลง กราฟจึงนิ่งเป็นเรื่องปกติ ดูเวลาซื้อขายได้จาก Market Watch คลิกขวาที่ชื่อสัญลักษณ์ เลือก Specification หัวข้อ Sessions ซึ่งแสดงเป็นเวลาเซิร์ฟเวอร์ ถ้าลองส่งคำสั่งช่วงนี้จะถูกปฏิเสธว่าตลาดปิด รายละเอียดอยู่ในMarket closed ใน MT5: ทำไมเปิดออเดอร์ไม่ได้

การเชื่อมต่อหลุด

มองมุมขวาล่างของโปรแกรม ถ้าปกติจะเห็นค่าความหน่วงเป็นมิลลิวินาที ถ้าขึ้นว่าไม่มีการเชื่อมต่อ ราคาจะไม่เข้าทุกกราฟพร้อมกัน วิธีไล่แก้ตั้งแต่อินเทอร์เน็ตจนถึงไฟร์วอลล์อยู่ในMT5 ขึ้น No connection แก้ยังไง

กราฟถูกเลื่อนไปดูอดีต

ถ้าเคยลากกราฟย้อนไปดูแท่งเก่าแล้วปิดปุ่ม Auto Scroll ไว้ กราฟจะไม่ตามแท่งใหม่ ทั้งที่ราคาเข้าปกติ สังเกตได้จากราคาใน Market Watch ที่ยังขยับ ให้คลิกบนกราฟแล้วกดปุ่ม End บนคีย์บอร์ดเพื่อกลับไปแท่งล่าสุด และเปิดปุ่ม Auto Scroll บนแถบเครื่องมือกลับ

เปิดกราฟผิดสัญลักษณ์

บางเซิร์ฟเวอร์มีสัญลักษณ์ชื่อคล้ายกันหลายตัวสำหรับบัญชีคนละประเภท ตัวที่บัญชีของคุณไม่ได้ใช้อาจไม่มีราคาเข้าเลย กราฟของตัวนั้นจึงนิ่งตลอด ให้เทียบชื่อบนกราฟกับชื่อใน Market Watch ที่ราคาขยับ ถ้าหาตัวที่ถูกไม่เจอ ดูวิธีในเพิ่มสัญลักษณ์ใน Market Watch

สั่งโหลดข้อมูลกราฟใหม่

ถ้ากราฟมีช่องว่างหรือแท่งผิดรูปหลังเน็ตหลุด คลิกขวาบนกราฟแล้วเลือก Refresh เพื่อให้โปรแกรมโหลดข้อมูลราคาจากเซิร์ฟเวอร์ใหม่ ไม่กระทบออเดอร์และไม่ถอด EA ออกจากกราฟ

โปรแกรมไม่ตอบสนอง: แก้ MT5 ค้างทีละขั้น

ถ้าคลิกอะไรก็ไม่ได้ และหัวหน้าต่างขึ้นคำว่า Not Responding ให้ทำตามลำดับนี้ อย่าข้ามไปบังคับปิดทันที

  1. รอ 1 ถึง 2 นาที

    MT5 มักหน่วงชั่วคราวตอนเพิ่งเปิดโปรแกรม ตอนโหลดข้อมูลราคาย้อนหลังจำนวนมาก หรือตอนตลาดเปิดหลังสุดสัปดาห์ หลายครั้งโปรแกรมกลับมาเองโดยไม่ต้องทำอะไร

  2. เปิด Task Manager ดูสาเหตุ

    กด Ctrl+Shift+Esc แล้วดูแถวของ MetaTrader 5 ถ้าใช้ CPU เกือบเต็มหรือ RAM สูงผิดปกติ แปลว่าโปรแกรมแบกงานเกินกำลังเครื่อง ถ้าตัวที่กินเครื่องเป็นโปรแกรมอื่น เช่น Windows Update หรือโปรแกรมสแกนไวรัส ให้รอให้งานนั้นจบก่อน

  3. ปิดโปรแกรมอย่างถูกวิธี

    ถ้าโปรแกรมกลับมาตอบสนอง ให้ปิดผ่าน File แล้ว Exit เพื่อให้บันทึกหน้าจอและค่าตั้งครบ ถ้ายังค้างอยู่ จึงค่อยเลือก End task ใน Task Manager โดยรู้ว่าการเปลี่ยนแปลงหลังการบันทึกครั้งล่าสุดอาจหายไป

  4. เปิดใหม่และรอข้อมูลโหลด

    หลังเปิด ให้รอจนมุมขวาล่างแสดงการเชื่อมต่อ และกราฟมีแท่งล่าสุดครบ ก่อนเริ่มคลิกหรือเปลี่ยนค่าใด ๆ

  5. ค้างซ้ำทันทีที่เปิด

    ถ้าเปิดเมื่อไรก็ค้างเมื่อนั้น ต้นเหตุมักอยู่ที่กราฟจำนวนมาก หรืออินดิเคเตอร์และ EA ตัวใดตัวหนึ่งบนกราฟ ลองเปลี่ยนไปใช้โปรไฟล์ที่มีกราฟน้อยกว่า แล้วเพิ่มกลับทีละกราฟเพื่อหาตัวที่เป็นปัญหา

บังคับปิดแล้วออเดอร์หายไหม: ไม่หาย ออเดอร์อยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ และ Stop Loss กับ Take Profit ที่ตั้งไว้แล้วยังทำงานแม้ MT5 ปิดอยู่ สิ่งที่หยุดคือ EA บนเครื่องนั้น จนกว่าจะเปิดโปรแกรมกลับมา

ลดภาระให้ MT5 ไม่ค้างซ้ำ

ถ้าค้างบ่อย ให้ลดงานที่โปรแกรมต้องแบกก่อนคิดเปลี่ยนเครื่อง จุดที่ได้ผลมากที่สุดมีดังนี้

  • ลดค่า Max bars in chart ที่ Tools → Options แท็บ Charts ค่านี้คือจำนวนแท่งที่แต่ละกราฟเก็บไว้แสดง ยิ่งสูงยิ่งใช้หน่วยความจำ ค่าต่ำสุดที่ตั้งได้คือ 5000 และต้องเปิดโปรแกรมใหม่จึงจะมีผล
  • ปิดกราฟที่ไม่ได้ดู ทุกกราฟที่เปิดไว้ต้องรับราคาและวาดใหม่ตลอดเวลา
  • ถอดอินดิเคเตอร์ที่ไม่ใช้ โดยเฉพาะตัวที่ดาวน์โหลดมาและคำนวณย้อนหลังหลายพันแท่ง
  • ซ่อนสัญลักษณ์ที่ไม่ใช้ใน Market Watch สัญลักษณ์ที่มีออเดอร์เปิดอยู่หรือมีกราฟเปิดอยู่จะซ่อนไม่ได้ ซึ่งเป็นการกันพลาดของโปรแกรม
  • ปิดข่าวถ้าไม่ได้อ่าน ที่ Tools → Options แท็บ Server เอาติ๊ก Enable news ออก
  • ซ่อนบริการที่ไม่ใช้ แท็บ Community ใน Options ซ่อนบริการของ MQL5.community ที่ไม่ได้ใช้ได้ ช่วยประหยัดทรัพยากร
  • อย่าเปิด MT5 หลายชุดเกินกำลังเครื่อง แต่ละชุดใช้หน่วยความจำของตัวเอง

คำอธิบายของแต่ละตัวเลือกจากผู้พัฒนา ดูได้ที่หน้า Platform Settings ของ MetaTrader 5 (ภาษาอังกฤษ)

ปัญหาบน VPS: หน้าต่างรีโมตค้างหรือโปรแกรมค้าง

บน VPS มีสองเรื่องที่มักถูกเหมาเป็นอาการเดียวกัน คือหน้าต่างรีโมตค้าง กับ MT5 บน VPS ค้างจริง วิธีแยกคือปิดหน้าต่างรีโมตแล้วเชื่อมต่อเข้าไปใหม่ ถ้าเข้าแล้ว MT5 ทำงานปกติ ปัญหาอยู่ที่การรีโมต ไม่ใช่ตัวโปรแกรม แนวทางแก้ฝั่งรีโมตอยู่ในRemote Desktop หลุดหรือเข้า VPS ไม่ได้

ถ้า MT5 บน VPS ค้างจริง สาเหตุที่พบบ่อยคือหน่วยความจำไม่พอ เปิด MT5 หลายชุดบนเครื่องเล็ก หรือ Windows Update ทำงานหนักอยู่เบื้องหลัง ลองดู Task Manager บน VPS แบบเดียวกับบนคอม ถ้าหน่วยความจำเต็มเป็นประจำ แปลว่าสเปกไม่พอกับงาน วิธีประเมินสเปกที่เหมาะอยู่ในVPS สเปกเท่าไหร่พอสำหรับ MT5

ออกจาก VPS ให้ถูกวิธี: เวลาเลิกใช้งาน ให้ปิดหน้าต่างรีโมตเฉย ๆ (Disconnect) ไม่ใช่ Sign out เพราะ Sign out จะปิดทุกโปรแกรมของผู้ใช้นั้นรวมถึง MT5 และ EA จะหยุดทันที

แอปบนมือถือค้างหรือราคานิ่ง

อาการ MT5 ค้างบนมือถือส่วนใหญ่มาจากสัญญาณอินเทอร์เน็ต ลองสลับระหว่าง Wi-Fi กับเน็ตมือถือก่อน ถ้ายังนิ่ง ให้ปิดแอปให้สนิทจากหน้าสลับแอปแล้วเปิดใหม่ ตรวจว่าแอปเป็นเวอร์ชันล่าสุดจาก App Store หรือ Google Play และลบกราฟหรือสัญลักษณ์ที่ไม่ได้ดูออกจากแอปเพื่อลดภาระ

สิ่งสำคัญที่ต้องจำคือแอปมือถือรัน EA ไม่ได้ แอปค้างจึงไม่ได้แปลว่า EA หยุด EA ยังทำงานอยู่บนคอมหรือ VPS ที่เปิด MT5 ไว้ ถ้าอยากรู้สถานะจริงของ EA ต้องรีโมตเข้าไปดูที่เครื่องนั้น ขั้นตอนอยู่ในคู่มือเข้า VPS จาก Android และเข้า VPS จาก iPhone

ตอนโปรแกรมค้าง EA ยังทำงานอยู่ไหม

EA ทำงานอยู่ภายในโปรแกรม MT5 ถ้าโปรแกรมไม่ตอบสนอง EA ก็รับราคาใหม่และส่งคำสั่งใหม่ไม่ได้เช่นกัน ออเดอร์ที่เปิดอยู่ไม่ได้หายไปไหน แต่จะไม่มีใครดูแลตามเงื่อนไขของ EA จนกว่าโปรแกรมจะกลับมา เหตุนี้คนที่รัน EA จึงควรจับอาการค้างให้ได้เร็ว ไม่ใช่รอเจอตอนเย็น

เมื่อเปิด MT5 ใหม่ EA ที่ติดอยู่บนกราฟในโปรไฟล์จะเริ่มทำงานอีกครั้งเอง ถ้าโปรไฟล์ถูกบันทึกไว้ก่อนค้าง สำหรับ [eawing_brand] ให้ดูการ์ดล็อกอินบนแดชบอร์ดว่ากลับเป็นสีเขียว ถ้าเป็นสีเหลือง แปลว่ากำลังตรวจสิทธิ์หรืออยู่ในช่วงผ่อนผัน รอสักครู่แล้วดูอีกครั้ง

เช็กลิสต์หลังเปิด MT5 ใหม่

ใช้ทุกครั้งหลังบังคับปิดโปรแกรม หลังรีสตาร์ตเครื่อง หรือหลัง VPS กลับมาจากการซ่อมบำรุง

  • มุมขวาล่างแสดงค่าความหน่วงเป็นมิลลิวินาที และบัญชีที่ล็อกอินคือบัญชีที่ตั้งใจใช้
  • กราฟที่มี EA ยังเปิดอยู่ สัญลักษณ์และกรอบเวลาตรงตามคู่มือของ EA
  • ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว และไอคอนข้างชื่อ EA ที่มุมขวาบนของกราฟเป็นสีฟ้า
  • แท็บ Experts และ Journal ใน Toolbox (Ctrl+T) ไม่มีข้อความผิดพลาดใหม่
  • บันทึกโปรไฟล์ซ้ำผ่าน File → Profiles เมื่อทุกอย่างกลับมาครบ

คำถามที่พบบ่อย

กราฟ MT5 ไม่ขยับทุกวันเสาร์อาทิตย์ ผิดปกติไหม?

ไม่ผิดปกติ ตลาด Forex และทองคำปิดช่วงสุดสัปดาห์ ราคาจึงไม่เปลี่ยน กราฟจะกลับมาขยับเมื่อตลาดเปิดในสัปดาห์ถัดไป ถ้าเป็นวันทำการแล้วยังนิ่ง ค่อยไล่เช็กการเชื่อมต่อ

ลบ MT5 แล้วติดตั้งใหม่ช่วยแก้อาการค้างไหม?

ช่วยได้บางกรณี แต่ควรเป็นทางเลือกท้าย ๆ เพราะต้องตั้งค่า วางไฟล์ EA และเปิดสิทธิ์ต่าง ๆ ใหม่หมด ลองลดจำนวนกราฟ อินดิเคเตอร์ และค่า Max bars in chart ก่อน ถ้าจำเป็นต้องติดตั้งใหม่ ให้สำรองไฟล์ในโฟลเดอร์ข้อมูลที่ต้องใช้ไว้ก่อน

ปิดหน้าต่าง Remote Desktop แล้ว MT5 บน VPS จะค้างหรือหยุดไหม?

ถ้าแค่ปิดหน้าต่างหรือกด Disconnect โปรแกรมบน VPS ยังทำงานต่อ แต่ถ้าเลือก Sign out ทุกโปรแกรมของผู้ใช้นั้นจะถูกปิด รวมถึง MT5 และ EA

MT5 ค้างบ่อยเพราะคอมสเปกต่ำใช่ไหม?

เป็นไปได้ แต่ส่วนใหญ่มาจากงานที่เปิดไว้มากเกินจำเป็น ลองดู Task Manager ระหว่างใช้งานปกติ ถ้าหน่วยความจำเกือบเต็มตลอดแม้เปิดกราฟไม่กี่กราฟ จึงค่อยพิจารณาเพิ่มสเปกหรือย้ายไปรันบน VPS ที่ใหญ่ขึ้น

คำเตือนความเสี่ยง: ช่วงที่ MT5 ค้างหรือปิดอยู่ EA จะดูแลออเดอร์ไม่ได้ ขณะที่ราคาในตลาดยังเคลื่อนไหวต่อ การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด และผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่านความเสี่ยงของการใช้ EA บน MT5ก่อนใช้เงินจริง

อ่านต่อ

  • MT5 ขึ้น No connection หรือไม่ขึ้นราคา
  • Market closed ใน MT5: ทำไมเปิดออเดอร์ไม่ได้
  • VPS สเปกเท่าไหร่พอสำหรับ MT5
  • Remote Desktop หลุดหรือเข้า VPS ไม่ได้

ถ้าเปิด MT5 ใหม่แล้ว EA ไม่กลับมาอยู่บนกราฟ หรือไม่แน่ใจว่าตั้งค่าครบหรือยัง ไล่ตรวจตามขั้นตอนในคู่มือติดตั้ง EA WING บน MT5 หรือส่งภาพหน้าจอให้ทีมงานคนไทยช่วยดูทาง LINE
