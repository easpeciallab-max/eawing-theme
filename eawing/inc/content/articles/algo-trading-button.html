ปุ่ม Algo Trading บนแถบเครื่องมือของ MT5 คือสวิตช์หลักที่ตัดสินว่า EA ทุกตัวในโปรแกรมส่งคำสั่งซื้อขายได้หรือไม่ ถ้าปุ่มนี้ดับ บอทเทรดจะยังอยู่บนกราฟและดูเหมือนปกติ แต่ไม่มีออเดอร์ใดออกไปถึงโบรกเกอร์เลย บทความนี้อธิบายว่าปุ่มนี้ต่างจากช่องอนุญาตอีกสองจุดอย่างไร ทำไมบางวันมันดับเอง และไล่แก้อย่างไรให้จบในไม่กี่นาที

สรุปสั้น: EA จะเทรดได้ต้องผ่านสามด่านพร้อมกัน คือสวิตช์หลักบนแถบเครื่องมือ (กด Ctrl+E สลับเปิดปิด) ช่อง Allow algorithmic trading ใน Tools → Options แท็บ Expert Advisors และช่อง Allow Algo Trading ในแท็บ Common ของ EA ตัวนั้น (กด F7 บนกราฟ) · ปุ่มดับเองได้เมื่อเปลี่ยนบัญชี เปลี่ยนโปรไฟล์ หรือเปลี่ยนสัญลักษณ์และไทม์เฟรมของกราฟ ถ้าติ๊กตัวเลือกกันพลาดไว้ · ดูผลรวมได้จากไอคอนเล็กมุมขวาบนของกราฟ

ปุ่ม Algo Trading คืออะไร

ใน MT5 รุ่นปัจจุบัน ปุ่มนี้อยู่บนแถบเครื่องมือด้านบน มีคำว่า Algo Trading กำกับ (MT5 รุ่นเก่าและ MT4 เรียกว่า AutoTrading) เมื่อเปิดอยู่ไอคอนบนปุ่มจะเป็นสีเขียว เมื่อปิดจะเปลี่ยนเป็นสีแดง คีย์ลัดคือ Ctrl+E กดหนึ่งครั้งสลับสถานะหนึ่งครั้ง

ให้นึกภาพเป็นเบรกเกอร์ไฟหลักของบ้าน ถ้าสับลง ทุกห้องดับพร้อมกัน ไม่ว่าสวิตช์ในห้องจะเปิดไว้หรือไม่ สวิตช์นี้ก็เช่นกัน มันคุม EA ทุกตัวในหน้าต่าง MT5 นั้นพร้อมกัน ไม่ได้แยกรายตัว และไม่เกี่ยวกับการเทรดด้วยมือ คุณยังกดซื้อขายเองได้ตามปกติแม้ปุ่มดับอยู่

ปุ่มนี้กับช่อง Allow algorithmic trading ในเมนู Options เป็นค่าเดียวกัน กดปุ่มดับ ช่องในเมนูก็ถูกเอาติ๊กออกด้วย รายละเอียดอ่านได้ที่ คู่มือ Algo Trading ของ MetaTrader 5 (ภาษาอังกฤษ)

สามจุดที่ต้องเปิดให้ตรงกันก่อน EA จะเทรดได้

ปัญหาส่วนใหญ่เกิดเพราะเปิดครบสองจุดแต่ลืมจุดที่สาม ตารางนี้แยกให้เห็นว่าแต่ละจุดคุมอะไร และเข้าไปดูได้จากที่ไหน

จุดอยู่ตรงไหนคุมอะไร
ปุ่ม Algo Tradingแถบเครื่องมือด้านบน หรือกด Ctrl+Eสวิตช์หลักของทั้งโปรแกรม ดับแล้ว EA ทุกตัวส่งคำสั่งไม่ได้
Allow algorithmic tradingTools → Options (Ctrl+O) แท็บ Expert Advisorsค่าเดียวกับปุ่มด้านบน และเป็นที่รวมตัวเลือกกันพลาดที่สั่งดับปุ่มเองได้
Allow Algo Trading ของ EA แต่ละตัวหน้าต่างคุณสมบัติ EA แท็บ Common (คลิกขวาบนกราฟ → Expert Advisors → Properties หรือกด F7)อนุญาตเฉพาะ EA บนกราฟนั้น ใช้ปิดบางตัวโดยไม่กระทบตัวอื่น

สรุปคือสวิตช์หลักของโปรแกรมและสวิตช์ประจำ EA ต้องเปิดพร้อมกัน ส่วนช่อง Allow DLL imports ที่อยู่ใกล้ ๆ กันคุมเรื่องการเรียกใช้ไฟล์ DLL ไม่ได้คุมการส่งคำสั่ง อ่านแยกได้ใน Allow DLL imports คืออะไร

อ่านสถานะจากปุ่มและไอคอนบนกราฟ

วิธีเช็กที่เร็วที่สุดคือมองปุ่มบนแถบเครื่องมือ กับไอคอนเล็กข้างชื่อ EA ที่มุมขวาบนของกราฟ

ปุ่มบนแถบเครื่องมือไอคอนมุมขวาบนของกราฟความหมาย
สีเขียวสีฟ้าพร้อมส่งคำสั่ง ทั้งโปรแกรมและ EA ตัวนั้นได้รับอนุญาต
สีเขียวสีเทาสวิตช์หลักเปิด แต่แท็บ Common ของ EA ตัวนี้ยังไม่ได้ติ๊ก Allow Algo Trading
สีแดงสีเทาสวิตช์หลักดับ EA ทุกตัวในโปรแกรมหยุดส่งคำสั่ง
สีเขียวไม่มีชื่อ EA ที่มุมกราฟEA ไม่ได้อยู่บนกราฟนี้ หรือหลุดออกไปแล้ว ให้ดูข้อความในแท็บ Experts

MT5 รุ่นเก่าแสดงเป็นหน้ายิ้มกับหน้าบึ้งแทน หลักการอ่านเหมือนกัน ไอคอนบนกราฟต้องเป็นสีฟ้า ถ้ายังเทาแปลว่ามีด่านใดด่านหนึ่งปิด

ทุกครั้งที่สลับสถานะ แท็บ Journal ใน Toolbox (Ctrl+T) จะบันทึกไว้ จึงย้อนดูได้ว่าปุ่มดับไปตั้งแต่เมื่อไร วิธีอ่านทีละบรรทัดอยู่ในบทความ MT5 Journal และแท็บ Experts

ทำไมปุ่ม Algo Trading ดับเอง

ปุ่มนี้ไม่ได้ดับแบบสุ่ม เกือบทุกครั้งมีเหตุให้ย้อนหาได้ ต่อไปนี้คือสาเหตุที่พบบ่อยเรียงจากเจอมากไปน้อย

ตัวเลือกกันพลาดใน Options ทำงาน

ใน Tools → Options แท็บ Expert Advisors มีกลุ่มตัวเลือกขึ้นต้นด้วย Disable algorithmic trading when... ได้แก่ เมื่อเปลี่ยนบัญชี (the account has been changed) เมื่อเปลี่ยนโปรไฟล์ (the profile has been changed) และเมื่อเปลี่ยนสัญลักษณ์หรือไทม์เฟรมของกราฟ (the chart symbol or period has been changed) ถ้าติ๊กไว้ MT5 จะดับปุ่มให้เองทันทีที่เกิดเหตุนั้น เพื่อกันไม่ให้ EA ไปเทรดในบัญชีหรือกราฟที่ไม่ได้ตั้งใจ

ตัวอย่างสมมติ: เจ้าของบัญชีสลับไปดูบัญชีเดโมบน VPS ที่รัน EA แล้วสลับกลับ จอดูเหมือนเดิม แต่ปุ่มกลายเป็นสีแดงไปแล้ว EA จึงเงียบทั้งคืน

เปิด MT5 ชุดใหม่หรือเครื่องใหม่

ค่าตั้งของ MT5 เก็บแยกตามแต่ละการติดตั้ง ย้ายไป VPS ใหม่หรือลง MT5 ชุดที่สอง ค่าเดิมไม่ได้ตามไปด้วย ต้องเปิดสวิตช์ใหม่ทุกครั้ง

MT5 ปิดตัวไม่ปกติ

MT5 บันทึกค่าตั้งตอนปิดโปรแกรมตามปกติ ถ้าเครื่องดับกะทันหันหรือโปรแกรมถูกบังคับปิด ค่าที่เพิ่งเปลี่ยนอาจไม่ถูกบันทึก สถานะปุ่มหลังเปิดใหม่จึงอาจไม่ตรงกับที่จำได้

เผลอกดเอง

ตัว E อยู่ติดกับตัว R และ Ctrl+R คือคีย์ลัดเปิด Strategy Tester กดพลาดครั้งเดียวก็ดับสวิตช์หลักได้ โดยเฉพาะตอนพิมพ์ผ่านแอปรีโมตบนมือถือ

วิธีแก้ทีละขั้นเมื่อ EA ไม่ส่งคำสั่ง

ส่วนใหญ่จะเจอสาเหตุภายในสามขั้นแรก ถ้าครบทุกขั้นแล้วยังไม่ทำงาน ปัญหาอาจไม่ได้อยู่ที่ปุ่ม ไล่ต่อได้ในบทความ EA ไม่เปิดออเดอร์

  1. ดูปุ่มบนแถบเครื่องมือ

    ถ้าเป็นสีแดง คลิกหนึ่งครั้งหรือกด Ctrl+E ให้เป็นสีเขียว

  2. ดูไอคอนมุมขวาบนของกราฟ

    ต้องเป็นสีฟ้า ถ้ายังเทา กด F7 บนกราฟ ไปที่แท็บ Common ติ๊ก Allow Algo Trading แล้วกด OK

  3. ตรวจตัวเลือกใน Options

    กด Ctrl+O ไปแท็บ Expert Advisors ดูว่าช่อง Allow algorithmic trading ติ๊กอยู่ และดูว่ากลุ่ม Disable algorithmic trading when... ติ๊กข้อไหนไว้

  4. ดูการเชื่อมต่อ

    มุมขวาล่างของ MT5 ต้องแสดงค่าความหน่วงเป็นมิลลิวินาที ถ้าไม่มีการเชื่อมต่อ คำสั่งก็ไปไม่ถึง

  5. ดูว่าล็อกอินด้วยรหัสผ่านหลัก

    ถ้าเข้าบัญชีด้วยรหัสสำหรับดูอย่างเดียว (Investor) ปุ่มจะเขียวได้ตามปกติ แต่คำสั่งทุกคำสั่งถูกปฏิเสธ ต้องออกแล้วเข้าใหม่ด้วยรหัสผ่านหลัก ขั้นตอนอยู่ในคู่มือ ติดตั้งและล็อกอิน MT5

  6. อ่านรหัสผลคำสั่ง

    รหัส 10027 แปลว่าเทอร์มินัลปิด Algo Trading อยู่ ให้ย้อนไปขั้นที่ 1 ถึง 3 ส่วนรหัส 10026 แปลว่าฝั่งเซิร์ฟเวอร์ไม่อนุญาตให้บัญชีนี้ใช้ EA ซึ่งแก้จากปุ่มไม่ได้ ต้องสอบถามโบรกเกอร์

ปิด Algo Trading แล้ว ออเดอร์ที่เปิดอยู่เป็นอย่างไร

การดับปุ่มไม่ได้ปิดออเดอร์ใดเลย ออเดอร์ที่เปิดอยู่ยังอยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ และคำสั่งที่ฝากไว้แล้ว เช่น Stop Loss, Take Profit หรือ Pending Order ยังทำงานตามปกติ

สิ่งที่หยุดคือคำสั่งใหม่ของ EA เช่น เปิดออเดอร์ใหม่ หรือปิดออเดอร์ตามเงื่อนไขของมันเอง จนกว่าจะเปิดปุ่มกลับ จึงไม่ควรปล่อยให้ปุ่มดับโดยไม่รู้ตัว โดยเฉพาะตอนที่ EA ยังมีออเดอร์ค้าง ถ้าตั้งใจหยุด EA เช่น ก่อนเปลี่ยนเวอร์ชัน ให้เลือกช่วงที่ไม่มีออเดอร์ค้างหรือตลาดปิดสุดสัปดาห์

ปุ่ม Algo Trading บน VPS

บน Windows VPS ปุ่มมักดับบ่อยกว่าบนคอม เพราะ MT5 ถูกรีสตาร์ตหรือสลับบัญชีบ่อยกว่า

  • หลัง VPS รีสตาร์ตจาก Windows Update หรืองานซ่อมบำรุง ให้รีโมตเข้าไปดูปุ่มและไอคอนบนกราฟทุกครั้ง
  • อย่าใช้ MT5 ชุดที่รัน EA สลับไปดูบัญชีอื่น ถ้าต้องดูหลายบัญชี ติดตั้ง MT5 แยกอีกชุด หรือดูจากแอปบนมือถือแทน

ขั้นตอนรีโมตเข้า VPS แยกตามอุปกรณ์อยู่ในคู่มือ ใช้ Windows VPS รัน EA เข้า VPS จาก Android และ เข้า VPS จาก iPhone หรือ iPad ส่วนเหตุผลที่ควรมีเครื่องที่เปิดตลอดเวลา และวิธีเลือก VPS สำหรับ EA อธิบายแยกไว้

ตั้งค่าสำหรับ EA WING ให้ครบในครั้งเดียว

สำหรับ [eawing_brand] ต้องติ๊ก Allow DLL imports เพิ่มด้วย เพราะ EA WING ต้องใช้ DLL ในการทำงาน ขั้นตอนเต็มอยู่ในคู่มือ ติดตั้ง EA WING บน MT5 ทีละขั้น สรุปจุดที่ต้องเปิดมีดังนี้

  • Tools → Options แท็บ Expert Advisors: ติ๊ก Allow algorithmic trading และ Allow DLL imports
  • ลาก EA_WING_V4.2.ex5 ลงกราฟ XAUUSD กรอบเวลา M1 (บางโบรกเกอร์มีตัวต่อท้ายชื่อสัญลักษณ์) แล้วในแท็บ Common ติ๊ก Allow Algo Trading และ Allow DLL imports
  • ปุ่มบนแถบเครื่องมือเป็นสีเขียว และไอคอนข้างชื่อ EA บนกราฟเป็นสีฟ้า
  • การ์ดล็อกอินบนแดชบอร์ดของ EA เป็นสีเขียว ถ้ายังไม่ผ่าน ส่งเลขบัญชีกับชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE

เช็กลิสต์ก่อนปล่อย EA ทำงาน

ใช้ทุกครั้งหลังติดตั้งใหม่ หลังรีสตาร์ต VPS หรือหลังเปลี่ยนอะไรก็ตามใน MT5

  • ปุ่มบนแถบเครื่องมือเป็นสีเขียว
  • ไอคอนข้างชื่อ EA ที่มุมขวาบนของกราฟเป็นสีฟ้า
  • มุมขวาล่างแสดงค่าความหน่วงเป็นมิลลิวินาที
  • บัญชีที่ล็อกอินคือบัญชีที่ตั้งใจให้ EA เทรด และใช้รหัสผ่านหลัก
  • รู้ว่าตัวเลือก Disable algorithmic trading when... ข้อไหนติ๊กไว้ และพร้อมเปิดปุ่มกลับเองเมื่อมันทำงาน
  • เปลี่ยนไทม์เฟรมของกราฟที่ EA ทำงานอยู่ ถ้าอยากดูภาพรวมตลาด ให้เปิดกราฟใหม่อีกหน้าต่าง

คำถามที่พบบ่อยเรื่องปุ่ม Algo Trading

ปุ่ม Algo Trading กับ AutoTrading คือปุ่มเดียวกันไหม?

ใช่ MT5 รุ่นใหม่เปลี่ยนชื่อจาก AutoTrading เป็น Algo Trading หน้าที่ยังเหมือนเดิม คือสวิตช์หลักที่อนุญาตให้ EA ทุกตัวในโปรแกรมส่งคำสั่ง

เปิดปุ่มแล้ว แต่ไอคอนบนกราฟยังเป็นสีเทา ต้องทำอะไร?

แปลว่า EA ตัวนั้นยังไม่ได้รับอนุญาตรายตัว กด F7 บนกราฟ ไปแท็บ Common ติ๊ก Allow Algo Trading แล้วกด OK ถ้ายังเทาอยู่ ลองถอด EA ออกแล้วลากลงกราฟใหม่ และอ่านบรรทัดล่าสุดในแท็บ Experts

ควรเอาติ๊กตัวเลือก Disable algorithmic trading when... ออกไหม?

ขึ้นกับวิธีใช้งาน ถ้าสลับบัญชีบ่อย ตัวเลือกเหล่านี้ช่วยกัน EA เทรดผิดบัญชี ถ้าเครื่องนั้นรัน EA บัญชีเดียวและไม่มีใครแตะ จะเอาติ๊กออกก็ได้ แต่จะไม่มีอะไรกันความผิดพลาดจากการสลับบัญชี

แอป MT5 บนมือถือมีปุ่ม Algo Trading ไหม?

ไม่มีปุ่มนี้ในแอปมือถือ เพราะแอป MT5 บนมือถือรัน EA ไม่ได้ ปุ่มที่ต้องดูอยู่บน MT5 เวอร์ชันคอมพิวเตอร์ที่รัน EA จริง ถ้าเครื่องนั้นเป็น VPS ให้ใช้แอป Windows App รีโมตเข้าไปดู ส่วนการดูผล EA บนมือถือเหมาะกับการดูยอดและออเดอร์

คำเตือนความเสี่ยง: ปุ่มสีเขียวและไอคอนสีฟ้าบอกแค่ว่า EA ได้รับอนุญาตให้ส่งคำสั่ง ไม่ได้บอกว่าคำสั่งเหล่านั้นจะได้กำไร การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ความเสี่ยงการใช้ EA ก่อนใช้เงินจริง

อ่านต่อ

  • ติดตั้ง EA WING บน MT5 ทีละขั้น
  • MT5 Journal และแท็บ Experts
  • Allow DLL imports คืออะไร
  • VPS สำหรับ EA เลือกอย่างไร

เปิดครบทุกจุดแล้ว EA ยังไม่ทำงาน หรืออยากให้ทีมงานคนไทยช่วยดูหน้าจอ MT5 ของคุณ ส่งภาพปุ่ม ไอคอนบนกราฟ และแท็บ Journal มาทาง LINE ได้เลย
