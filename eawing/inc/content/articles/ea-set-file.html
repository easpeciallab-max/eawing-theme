EA Set File คือไฟล์นามสกุล .set ที่เก็บชุดค่าในแท็บ Inputs ของ EA ไว้ เช่น ขนาด Lot ระยะต่าง ๆ หรือการเปิดปิดฟังก์ชัน เพื่อโหลดกลับมาใช้ได้ในไม่กี่คลิก ตัวไฟล์ไม่มีโปรแกรมอยู่ข้างใน ถ้ายังไม่แน่ใจว่า Inputs คืออะไรและ EA เอาค่าเหล่านี้ไปใช้อย่างไร เริ่มจากคู่มือ Expert Advisor ฉบับเต็ม แล้วกลับมาดูว่าเมื่อไหร่ควรใช้ไฟล์ .set และใช้อย่างไรไม่ให้ค่าเพี้ยน

สรุปสั้น: Set File คือชุดค่าตั้ง ไม่ใช่ตัว EA ต้องมีไฟล์ .ex5 ของ EA ตัวนั้นก่อนเสมอ จำเป็นเฉพาะ EA ที่ผู้พัฒนาออกแบบให้ใช้ค่าคนละชุดตามสินค้าหรือประเภทบัญชี ถ้า EA มีโหมดในตัวและคู่มือไม่ได้สั่งให้โหลดไฟล์ .set ก็ไม่ต้องใช้

EA Set File คืออะไร ข้างในเก็บอะไรไว้

เวลาลาก EA ลงกราฟ หน้าต่างคุณสมบัติจะมีแท็บ Inputs ที่รวมค่าที่ผู้พัฒนาเปิดให้ปรับ ค่าแต่ละบรรทัดในแท็บนั้นคือหนึ่งบรรทัดในไฟล์ .set เมื่อกดปุ่ม Save MT5 จะเขียนค่าที่ตั้งอยู่ตอนนั้นลงไฟล์ และเมื่อกด Load ก็อ่านค่ากลับมาใส่ให้ครบทุกช่อง

ไฟล์ .set เป็นไฟล์ข้อความธรรมดา เปิดด้วย Notepad จะเห็นหน้าตาประมาณนี้ (ชื่อค่าเป็นตัวอย่างสมมติ แต่ละ EA ตั้งชื่อเองต่างกัน)

บรรทัดในไฟล์ความหมาย
Lots=0.01ช่อง Lots ในแท็บ Inputs ตั้งไว้ 0.01
MaxSpread=40ช่อง MaxSpread ตั้งไว้ 40 (หน่วยขึ้นกับที่ผู้พัฒนากำหนด มักเป็น point)
TradeOnFriday=falseปิดฟังก์ชันนี้ไว้

บางบรรทัดอาจมีตัวเลขต่อท้ายอีกหลายชุดคั่นด้วยเครื่องหมาย || ซึ่งเป็นช่วงค่าที่ Strategy Tester ใช้ตอน Optimize ผู้ใช้ทั่วไปไม่ต้องแก้ส่วนนี้

โดยค่าเริ่มต้น MT5 เก็บไฟล์ที่บันทึกจากหน้าต่าง EA ไว้ในโฟลเดอร์ MQL5 → Presets ตามที่คู่มือ MetaTrader 5 เรื่องการตั้งค่า EAอธิบายไว้ (ภาษาอังกฤษ) ส่วนค่าที่ใช้ทดสอบล่าสุดของแต่ละ EA ใน Strategy Tester จะถูกเก็บแยกไว้ที่ MQL5 → Profiles → Tester

Set File กับไฟล์ EA ต่างกันอย่างไร

คนที่เพิ่งเริ่มบางคนได้ไฟล์ .set มาแล้วคิดว่าได้ EA มาด้วย ความจริงสองไฟล์นี้ทำหน้าที่คนละอย่าง

  • ไฟล์ .ex5 คือตัวโปรแกรม มีตรรกะการเทรดทั้งหมด วางใน MQL5 → Experts
  • ไฟล์ .set คือรายการค่าที่ป้อนให้โปรแกรมนั้น ไม่มีตรรกะใด ๆ อยู่ข้างใน

ไฟล์ .set ของ EA ตัวหนึ่งจึงเอาไปใช้กับ EA อีกตัวไม่ได้ เพราะชื่อค่าไม่ตรงกัน และ EA ที่ไม่มีไฟล์ .set ก็ยังทำงานได้ด้วยค่าเริ่มต้นที่ผู้พัฒนาฝังไว้ ความต่างของไฟล์ .ex5 กับ .mq5 อธิบายไว้ในไฟล์ EX5 กับ MQ5 ต่างกันยังไง

ต้องใช้ EA Set File ไหม ดูจากสถานการณ์

คำถามนี้ไม่มีคำตอบเดียวสำหรับทุก EA ให้ดูว่าคุณอยู่ในกรณีไหน

สถานการณ์ต้องใช้ไหมเหตุผล
ผู้พัฒนาแจกไฟล์ .set แยกตามสินค้าหรือประเภทบัญชี และคู่มือสั่งให้โหลดใช้ค่าเริ่มต้นในตัวอาจไม่ตรงกับบัญชีของคุณ
EA มีโหมดหรือค่าเริ่มต้นในตัว คู่มือไม่พูดถึงไฟล์ .setไม่ต้องผู้พัฒนาตั้งใจให้ใช้ค่าในตัว
คุณปรับค่าเองหลายช่องบันทึกไว้เป็นสำรองย้ายเครื่องหรืออัปเดตแล้วกลับมาใช้ค่าเดิมได้ทันที
ทดสอบหลายชุดค่าใน Strategy Testerใช้สลับชุดค่าได้แม่น ไม่ต้องจำหรือพิมพ์ใหม่
ได้ไฟล์ .set จากคนในกลุ่มแชตอย่าเพิ่งใช้ไม่รู้ว่าทำมาเพื่อบัญชีแบบไหนและเสี่ยงแค่ไหน

โหลดไฟล์ .set ใน MT5 ทีละขั้น

  1. วางไฟล์ให้หาง่าย

    ใน MT5 เลือก File → Open Data Folder แล้วเข้า MQL5 → Presets คัดลอกไฟล์ .set ไว้ที่นี่ ไม่บังคับ แต่หน้าต่าง Load มักเปิดมาที่โฟลเดอร์นี้ก่อน หาไฟล์ได้เร็วกว่า

  2. เปิดหน้าต่างคุณสมบัติของ EA

    ถ้ายังไม่ได้วาง EA ให้ลากจาก Navigator (Ctrl+N) ลงกราฟ ถ้าวางอยู่แล้วให้คลิกบนกราฟแล้วกด F7

  3. แท็บ Inputs กด Load

    เลือกไฟล์ .set ที่ต้องการ ค่าทุกช่องจะถูกแทนที่ด้วยค่าในไฟล์

  4. ไล่อ่านค่าก่อนกด OK

    ดูเป็นพิเศษที่ช่องเกี่ยวกับขนาด Lot ความเสี่ยง และตัวเลขประจำ EA ถ้ามีช่องไหนดูแปลก ให้หยุดถามผู้ให้ไฟล์ก่อน

  5. กด OK แล้วดูแท็บ Experts

    เมื่อเปลี่ยนค่า Inputs แล้วกด OK MT5 จะเริ่มการทำงานของ EA ใหม่ด้วยค่าชุดใหม่ ไม่ต้องลากลงกราฟซ้ำ เปิด Toolbox (Ctrl+T) แท็บ Experts เพื่อดูว่าโหลดสำเร็จ

ใน Strategy Tester (Ctrl+R) ก็ทำได้คล้ายกัน คลิกขวาในแท็บ Inputs ของหน้าต่างทดสอบ จะมีคำสั่ง Load และ Save ให้ใช้

ตรวจว่าค่าโหลดครบจริง

วิธีง่ายที่สุดคือหลังกด Load ให้กด Save เป็นไฟล์ชื่อใหม่ทันที แล้วเปิดไฟล์ทั้งสองด้วย Notepad วางเทียบกัน ถ้าบรรทัดไหนในไฟล์ใหม่มีค่าไม่ตรงกับไฟล์ต้นฉบับ แปลว่าช่องนั้นไม่ได้ถูกโหลด สาเหตุที่พบบ่อยคือชื่อค่าเปลี่ยนไปใน EA เวอร์ชันใหม่

บันทึก Set File ของตัวเองไว้เป็นสำรอง

ต่อให้ EA ที่ใช้ไม่ต้องโหลดไฟล์ .set ตอนเริ่ม แต่ถ้าคุณปรับค่าไปจากค่าเริ่มต้น การกด Save เก็บไว้เป็นนิสัยที่ดี ช่วงที่ควรกดบันทึกมีดังนี้

  • ก่อนแก้ค่าใด ๆ เพื่อย้อนกลับได้ถ้าผลไม่เป็นอย่างที่คิด
  • ก่อนเปลี่ยนไฟล์ EA เป็นเวอร์ชันใหม่ ขั้นตอนเต็มอยู่ในเรื่องอัปเดต EA เวอร์ชันใหม่ไม่ให้ออเดอร์ค้าง
  • ก่อนย้ายไปรันบนเครื่องใหม่หรือ VPS ใหม่
  • เมื่อได้ชุดค่าที่ทดสอบผ่านแล้วและตั้งใจใช้จริง

ตั้งชื่อไฟล์ให้บอกเรื่องราวได้ เช่น ชื่อ EA ตามด้วยสัญลักษณ์ ประเภทบัญชี และวันที่ แล้วจดสั้น ๆ ว่าเปลี่ยนอะไรเพราะอะไร หกเดือนผ่านไปคุณจะขอบคุณตัวเอง

ตัวอย่างสมมติ: ย้ายเครื่องแล้วค่าหาย

เทรดเดอร์คนหนึ่งปรับค่า EA ไว้ห้าช่องบนคอมที่บ้าน พอเช่า VPS ก็คัดลอกไปแค่ไฟล์ .ex5 ลากลงกราฟแล้วกด OK ทันที EA บนเครื่องใหม่จึงทำงานด้วยค่าเริ่มต้นทั้งหมด กว่าจะรู้ตัวก็ผ่านไปหลายวัน ถ้าเขากด Save ไว้ก่อนย้ายแล้วคัดลอกไฟล์ .set ไปด้วย ปัญหานี้จะไม่เกิด เรื่องนี้แต่งขึ้นเพื่ออธิบายวิธีคิด ไม่ใช่เหตุการณ์ของผู้ใช้รายใด

ข้อผิดพลาดที่ทำให้ค่าเพี้ยนโดยไม่รู้ตัว

ไฟล์ .set ดูเรียบง่าย แต่ความผิดพลาดส่วนใหญ่ไม่มีข้อความเตือน EA ทำงานต่อด้วยค่าที่ผิดเงียบ ๆ

  • ไฟล์ของเวอร์ชันอื่น ถ้าผู้พัฒนาเปลี่ยนชื่อค่าใน EA เวอร์ชันใหม่ บรรทัดที่ชื่อไม่ตรงจะไม่ถูกโหลด ช่องนั้นกลับไปใช้ค่าเริ่มต้นโดยไม่มีใครบอก
  • ทำมาเพื่อบัญชีอีกประเภท ค่า Lot ที่ตั้งไว้สำหรับบัญชี Cent มีความหมายต่างจากบัญชีมาตรฐานมาก ดูความต่างในบัญชี Cent คืออะไร
  • จำนวนทศนิยมของราคาไม่เท่ากัน ทองคำบางโบรกเกอร์แสดงราคาสองตำแหน่ง บางแห่งสามตำแหน่ง ระยะที่ตั้งเป็น point จึงสั้นหรือยาวต่างกันได้สิบเท่า
  • ตัวเลขประจำ EA ไม่ตรงกับออเดอร์ที่เปิดอยู่ ถ้าไฟล์ .set เปลี่ยนค่านี้ระหว่างที่มีออเดอร์ค้าง EA อาจไม่รู้จักออเดอร์เดิมของตัวเอง อ่านเหตุผลในMagic Number ใน EA คืออะไร
  • แก้ไฟล์ใน Notepad แล้วพิมพ์ผิด ค่าที่อ่านไม่ออกอาจถูกข้ามไป ทางที่ปลอดภัยกว่าคือแก้ในแท็บ Inputs แล้วกด Save ใหม่

เช็กลิสต์ก่อนใช้ไฟล์ .set ที่ได้มาจากคนอื่น

ไฟล์ .set ที่ส่งต่อกันในกลุ่มแชตมักมาพร้อมคำโฆษณาว่าเป็น "ชุดค่าทำกำไร" ก่อนโหลดไฟล์แบบนี้บนบัญชีจริง ให้ตอบคำถามเหล่านี้ให้ได้ทุกข้อ

  • ไฟล์มาจากผู้พัฒนา EA ตัวนั้นโดยตรงหรือไม่
  • ทำมาสำหรับ EA เวอร์ชันเดียวกับที่คุณใช้หรือไม่
  • ตรงกับสัญลักษณ์ ประเภทบัญชี และโบรกเกอร์ของคุณหรือไม่
  • ขนาด Lot และค่าความเสี่ยงเหมาะกับเงินทุนของคุณ ไม่ใช่ของคนที่ส่งมา
  • ทดสอบใน Strategy Tester และบัญชีเดโมแล้วหรือยัง ขั้นตอนอยู่ในทดสอบย้อนหลังและทดสอบล่วงหน้า
  • เก็บไฟล์ชุดเดิมของคุณไว้ย้อนกลับแล้วหรือยัง

ชุดค่าเดียวกันบนบัญชีคนละแห่งให้ผลต่างกันได้มาก เพราะสเปรด ความเร็วในการส่งคำสั่ง จังหวะที่เริ่ม และขนาดทุนไม่เหมือนกัน ภาพผลกำไรของคนอื่นจึงไม่ใช่หลักฐานว่าไฟล์นั้นเหมาะกับคุณ

EA WING ใช้ไฟล์ .set ไหม

ไม่ต้องใช้เลย ตัว [eawing_brand] มาเป็นไฟล์ EA_WING_V4.2.ex5 ไฟล์เดียว โหมด Lite และ Full อยู่ในไฟล์ หลังติดตั้งจะเริ่มที่โหมด Lite ซึ่งเป็นโหมดความเสี่ยงต่ำกว่า ส่วนโหมด Full มีความเสี่ยงสูงกว่าและเหมาะกับคนที่เข้าใจระบบแล้ว ควรคุยกับทีมงานก่อนสลับ และการสลับโหมดจะมีผลหลังชุดออเดอร์ที่เปิดอยู่ปิดครบแล้ว ทั้งสองโหมดขาดทุนได้

ดังนั้นถ้าเจอไฟล์ที่อ้างว่าเป็น "Set File ของ EA WING" จากแหล่งอื่น ไฟล์นั้นไม่ได้มาจากทีมงาน ขั้นตอนติดตั้งที่ถูกต้องอยู่ในหน้าติดตั้ง EA WING บน MT5

คำเตือนความเสี่ยง: ไฟล์ .set ไม่ได้ทำให้ระบบเทรดดีขึ้นหรือปลอดภัยขึ้น มันแค่เปลี่ยนค่าที่ EA ใช้ ชุดค่าที่เคยได้ผลดีในอดีตอาจขาดทุนในอนาคต การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด อ่านความเสี่ยงที่ต้องรู้ก่อนใช้ EAก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่อง EA Set File

ไฟล์ .set เปิดด้วยโปรแกรมอะไร?

เปิดอ่านด้วย Notepad ได้เพราะเป็นไฟล์ข้อความ แต่ถ้าจะแก้ค่า แนะนำให้โหลดเข้าแท็บ Inputs ใน MT5 แก้ตรงนั้น แล้วกด Save เป็นไฟล์ใหม่ จะลดโอกาสพิมพ์ผิดรูปแบบ

Set File ของ MT4 ใช้กับ MT5 ได้ไหม?

ไม่ควรใช้ แม้ EA จะชื่อเดียวกัน แต่เวอร์ชัน MT4 กับ MT5 เป็นคนละโปรแกรม ชื่อค่าและรูปแบบไฟล์อาจต่างกัน ให้ขอไฟล์ที่ทำสำหรับเวอร์ชัน MT5 จากผู้พัฒนาโดยตรง

ใช้ไฟล์ .set เดียวกับคนอื่นแล้วผลจะออกมาเหมือนกันไหม?

ไม่จำเป็น ผลขึ้นกับโบรกเกอร์ สเปรด ความเร็วของเครื่องที่รัน เวลาที่เริ่ม และขนาดทุนด้วย ชุดค่าเดียวกันบนสองบัญชีจึงให้ผลต่างกันได้ทั้งทางกำไรและขาดทุน

โหลดไฟล์ .set แล้วต้องลาก EA ลงกราฟใหม่ไหม?

ไม่ต้อง เปิดหน้าต่างคุณสมบัติด้วย F7 กด Load แล้วกด OK EA จะเริ่มทำงานใหม่ด้วยค่าชุดนั้นเอง ถ้ามีออเดอร์เปิดอยู่ ควรถามผู้พัฒนาก่อนว่า EA จัดการออเดอร์เดิมอย่างไรเมื่อถูกเริ่มใหม่

ลบไฟล์ .set ทิ้งแล้ว EA บนกราฟจะหยุดทำงานไหม?

ไม่หยุด ค่าที่ใช้อยู่ถูกเก็บไว้กับ EA บนกราฟแล้ว ไฟล์ .set เป็นแค่สำเนาสำหรับโหลดกลับมาใช้ภายหลัง แต่ถ้าลบไปแล้วต้องตั้งค่าใหม่บนเครื่องอื่น คุณจะต้องจำและพิมพ์ทุกช่องเอง

อ่านต่อ

  • Magic Number ใน EA คืออะไร
  • ไฟล์ EX5 กับ MQ5 ต่างกันยังไง
  • Backtest กับ Forward Test: ทำไมต้องใช้ทั้งคู่
  • EA คืออะไร: คู่มือฉบับเต็ม

ถ้าอยากใช้ EA ที่ไม่ต้องจัดการไฟล์ .set และอยากให้ทีมงานช่วยติดตั้งให้ ดูรายละเอียดในแพ็กเกจ EA WING แล้วทักมาถามก่อนตัดสินใจได้
