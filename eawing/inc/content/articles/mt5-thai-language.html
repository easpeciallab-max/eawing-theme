MT5 ภาษาไทยตั้งได้จากเมนู View → Languages บนเวอร์ชันคอมพิวเตอร์ แล้วรีสตาร์ตโปรแกรมหนึ่งครั้ง ส่วนแอปมือถือเลือกภาษาได้ในหน้า Settings โดยไม่ต้องเปลี่ยนภาษาของเครื่อง ก่อนเปลี่ยนควรรู้ไว้ว่าคู่มือ EA และบทความส่วนใหญ่ รวมถึงเว็บนี้ อ้างชื่อเมนูเป็นภาษาอังกฤษ บทความนี้จึงรวมวิธีใช้หน้าจอภาษาไทยโดยยังทำตามคู่มือได้ไม่หลง ถ้ายังไม่คุ้นกับส่วนต่าง ๆ ของโปรแกรม อ่านคู่มือเริ่มต้นใช้ MetaTrader 5ก่อนได้

สรุปสั้น: คอมพิวเตอร์: View → Languages → เลือกภาษาไทย → รีสตาร์ต MT5 · Android: Settings → Language · iPhone และ iPad: Settings → Interface · การเปลี่ยนภาษามีผลแค่ชื่อเมนูและข้อความบนหน้าจอ ไม่กระทบบัญชี ราคา กราฟ หรือการทำงานของ EA · ถ้าทำตามคู่มือที่ใช้ชื่อเมนูภาษาอังกฤษ ให้จำตำแหน่งเมนูและคีย์ลัด ซึ่งเหมือนกันทุกภาษา

MT5 รองรับภาษาไทยไหม

รองรับ ผู้พัฒนาเพิ่มคำแปลภาษาไทยให้ตัวโปรแกรมบนคอมพิวเตอร์มาตั้งแต่ build 1150 ในปี 2015 ตามที่ระบุใน release notes ของ MetaTrader 5 และแอปบนมือถือก็มีภาษาไทยให้เลือกเช่นกัน ภาษาของแต่ละที่ตั้งแยกกัน คอมเป็นภาษาไทย มือถือเป็นภาษาอังกฤษก็ได้

เปลี่ยนภาษาแล้วอะไรเปลี่ยน อะไรไม่เปลี่ยน

ส่วนของโปรแกรมเปลี่ยนตามภาษาไหม
ชื่อเมนูหลัก เมนูคลิกขวา ชื่อหน้าต่าง และชื่อแท็บส่วนใหญ่เปลี่ยน
ข้อความในหน้าต่างตั้งค่าและหน้าต่างคำสั่งเปลี่ยน
เลขบัญชี รหัสผ่าน และชื่อเซิร์ฟเวอร์ไม่เปลี่ยน
ชื่อสัญลักษณ์ เช่น XAUUSD และตัวต่อท้ายของโบรกเกอร์ไม่เปลี่ยน
ราคา กราฟ ออเดอร์ และประวัติการเทรดไม่เปลี่ยน
ชื่อ EA ค่าตั้งของ EA และข้อความที่ EA พิมพ์ในแท็บ Expertsขึ้นกับผู้พัฒนา ส่วนใหญ่ไม่เปลี่ยน
คีย์ลัดบนคีย์บอร์ด และรหัสผลคำสั่งที่เป็นตัวเลขไม่เปลี่ยน

ข้อความของ EA ขึ้นกับผู้พัฒนาว่าเขียนไว้เป็นภาษาอะไร บางตัวปรับตามภาษาของโปรแกรม บางตัวไม่ปรับ การเปลี่ยนภาษาของ MT5 จึงไม่ได้ทำให้แดชบอร์ดหรือค่าตั้งของ EA เป็นภาษาไทยตามไปด้วยเสมอ อ่านพื้นฐานได้ในEA คืออะไร ทำงานอย่างไรใน MT5

ตั้ง MT5 ภาษาไทยบนคอมพิวเตอร์ทีละขั้น

  1. เปิดเมนู View

    เป็นเมนูที่สองจากซ้ายบนแถบเมนูด้านบน ถัดจาก File

  2. เลือก Languages

    จะเห็นรายชื่อภาษาที่โปรแกรมรองรับ

  3. คลิกภาษาไทย

    โปรแกรมจะแจ้งว่าต้องรีสตาร์ตก่อนภาษาใหม่จะมีผล เลือกให้รีสตาร์ตเลย หรือปิดแล้วเปิดใหม่เอง

  4. ตรวจหลังเปิดใหม่

    เมนูควรเป็นภาษาไทย บัญชีล็อกอินอยู่เหมือนเดิม และกราฟที่เคยเปิดกลับมาครบ

เปลี่ยนกลับเป็นภาษาอังกฤษ

ใช้เมนูเดียวกัน คือเมนูที่สองจากซ้าย แล้วเลือกรายการภาษา มองหาคำว่า English ในรายการ คลิก แล้วรีสตาร์ตอีกครั้ง ตำแหน่งเมนูไม่เปลี่ยนตามภาษา จึงกลับทางเดิมได้เสมอ

MT5 หลายชุดและ VPS

ค่าภาษาเก็บแยกตามการติดตั้งแต่ละชุด ถ้าบน VPS มี MT5 สองชุด ต้องตั้งทีละชุด และ MT5 ที่ติดตั้งใหม่บนเครื่องใหม่จะกลับมาเป็นภาษาเริ่มต้นอีกครั้ง ถ้ากำลังเตรียมเครื่องสำหรับรัน EA ดูภาพรวมการตั้งเครื่องได้ในการเตรียม VPS สำหรับรัน EA

ตั้งภาษาไทยบนแอป MT5 มือถือ

อุปกรณ์ทางไปหมายเหตุ
Androidเปิดหน้า Settings ของแอป แล้วเลือก Languageเปลี่ยนเฉพาะในแอป ไม่ต้องเปลี่ยนภาษาของโทรศัพท์
iPhone และ iPadเปิดหน้า Settings ของแอป แล้วเลือก Interfaceเลือกภาษาของแอปแยกจากภาษาของเครื่อง

คู่มือของผู้พัฒนาระบุว่าแอป Android สลับได้หลายสิบภาษาโดยไม่ต้องเปลี่ยนภาษาของเครื่อง ดูได้ที่หน้าตั้งค่าของ MT5 สำหรับ Android ส่วนฝั่ง iPhone อยู่ที่หน้า Settings ของ MT5 สำหรับ iPhone ถ้าไม่เห็นภาษาไทยในรายการ ให้อัปเดตแอปเป็นเวอร์ชันล่าสุดก่อน

ภาษาบนมือถือไม่เกี่ยวกับภาษาบนคอมหรือ VPS และแอปมือถือใช้ดูพอร์ตได้ แต่รัน EA ไม่ได้ เครื่องที่ EA ทำงานจริงยังต้องเป็นคอม Windows หรือ Windows VPS

ภาษาไทยหรือภาษาอังกฤษ: แบบไหนเหมาะกับคุณ

ผู้ใช้แนะนำเหตุผล
มือใหม่ที่เทรดเองและอ่านจากหน้าจอเป็นหลักภาษาไทยเข้าใจหน้าต่างตั้งค่าและหน้าต่างคำสั่งได้เร็วกว่า
คนที่ติดตั้ง EA ตามคู่มือหรือคลิปที่ใช้ชื่อเมนูอังกฤษภาษาอังกฤษ อย่างน้อยระหว่างติดตั้งชื่อเมนูตรงกับคู่มือทุกคำ ลดโอกาสติ๊กผิดช่อง
คนที่ส่งภาพหน้าจอให้ทีมซัพพอร์ตช่วยดูแบบไหนก็ได้ทีมงานดูจากตำแหน่งและสถานะได้ แต่ภาษาอังกฤษเทียบกับคู่มือได้ตรงกว่า
คนที่เปิด MT5 บนคอมเป็นประจำอยู่แล้วใช้ภาษาที่ถนัดจำตำแหน่งเมนูและคีย์ลัดได้แล้ว ภาษาไม่ใช่อุปสรรค

ทางสายกลางที่หลายคนใช้คือ ตั้งภาษาอังกฤษบนเครื่องที่รัน EA เพื่อให้ตรงกับคู่มือ และตั้งภาษาไทยบนแอปมือถือที่ใช้ดูพอร์ตทุกวัน

คีย์ลัดที่ใช้ได้ทุกภาษา

คีย์ลัดไม่เปลี่ยนตามภาษาของเมนู ถ้าใช้ MT5 ภาษาไทยแต่คู่มือเขียนชื่อเมนูภาษาอังกฤษ คีย์ลัดคือสะพานที่เร็วที่สุด

คีย์ลัดเปิดอะไรใช้ตอนไหน
Ctrl+MMarket Watchหาสัญลักษณ์และเปิดหน้า Specification
Ctrl+NNavigatorดูบัญชีและรายชื่อ EA
Ctrl+TToolboxดูออเดอร์ แท็บ Journal และแท็บ Experts
Ctrl+OOptionsตั้งค่าแท็บ Expert Advisors, Trade, Charts และ Server
F7คุณสมบัติของ EA บนกราฟดูแท็บ Common และ Inputs ของ EA
F8คุณสมบัติของกราฟปรับสีและสิ่งที่แสดงบนกราฟ
F9หน้าต่างออเดอร์ใหม่เทรดด้วยมือ
Ctrl+RStrategy Testerทดสอบย้อนหลัง
Ctrl+Eสลับปุ่ม Algo Tradingระวังกดโดนโดยไม่ตั้งใจ เพราะทำให้ EA หยุดส่งคำสั่ง

ชื่อเมนูที่คู่มือ EA มักอ้างถึง และหาเจอได้แม้หน้าจอเป็นภาษาไทย

คำแปลภาษาไทยของแต่ละเมนูอาจต่างกันเล็กน้อยตามรุ่นของโปรแกรม วิธีที่ไม่หลงคือจำตำแหน่ง ลำดับเมนูหลักจากซ้ายไปขวาบนคอมคือ File, View, Insert, Charts, Tools, Window และ Help และลำดับนี้ไม่เปลี่ยนตามภาษา

ชื่อในคู่มือหาอย่างไรบนหน้าจอภาษาไทย
File → Open Data Folderเมนูแรกทางซ้าย แล้วหารายการเปิดโฟลเดอร์ข้อมูล จากนั้นเข้า MQL5 แล้ว Experts (ชื่อโฟลเดอร์ไม่เปลี่ยนตามภาษา)
Tools → Optionsเมนูที่ห้าจากซ้าย หรือกด Ctrl+O
แท็บ Expert Advisors ใน Optionsแท็บที่มีช่องอนุญาตการเทรดอัตโนมัติและช่องอนุญาต DLL
ปุ่ม Algo Tradingปุ่มบนแถบเครื่องมือที่ไอคอนเป็นสีเขียวเมื่อเปิด สีแดงเมื่อปิด หรือกด Ctrl+E
แท็บ Journal และ Expertsสองแท็บท้าย ๆ ของ Toolbox (Ctrl+T)

ปุ่มที่เปลี่ยนชื่อไปมาบ่อยที่สุดในคู่มือเก่าและใหม่คือปุ่ม Algo Trading ซึ่งรุ่นเก่าเรียกว่า AutoTrading ความหมายของสีและวิธีอ่านสถานะอยู่ในบทความปุ่ม Algo Trading และสีของสถานะ

ข้อความ Error ยังมีภาษาอังกฤษ ทำอย่างไร

แม้ตั้ง MT5 ภาษาไทยแล้ว ข้อความที่ EA พิมพ์ในแท็บ Experts มักยังเป็นภาษาอังกฤษตามที่ผู้พัฒนาเขียน และบรรทัดใน Journal บางส่วนก็ยังมีคำภาษาอังกฤษปน สิ่งที่ช่วยได้คือรหัสผลคำสั่งที่เป็นตัวเลข เช่น 10018 หรือ 10019 ซึ่งเหมือนกันทุกภาษา ค้นความหมายจากตัวเลขได้ทันที ดูรายการที่เจอบ่อยได้ในรวม Error MT5 และวิธีแก้

ปัญหาที่อาจเจอหลังเปลี่ยนภาษา

  • เลือกแล้วแต่เมนูยังเป็นภาษาเดิม ยังไม่ได้รีสตาร์ต MT5 ให้ปิดโปรแกรมให้สนิทแล้วเปิดใหม่
  • ตัวอักษรไทยแสดงไม่ถูกต้องบน VPS บางเครื่อง Windows อาจยังไม่ได้ติดตั้งภาษาหรือฟอนต์ไทย ให้เพิ่มภาษาไทยในการตั้งค่าภาษาของ Windows หรือใช้ MT5 ภาษาอังกฤษบนเครื่องนั้นแทน
  • หาเมนูตามคู่มือไม่เจอ ใช้ตำแหน่งเมนูและคีย์ลัดในตารางด้านบน หรือสลับเป็นภาษาอังกฤษชั่วคราวระหว่างตั้งค่า
  • กราฟหรือค่าตั้งหายไปหลังรีสตาร์ต ไม่ได้เกิดจากการเปลี่ยนภาษาโดยตรง ให้ตรวจว่าเปิดโปรไฟล์เดิมอยู่ วิธีบันทึกหน้าจอให้กลับมาเหมือนเดิมอยู่ในตั้งค่ากราฟ MT5 ด้วย Template และ Profile

หมายเหตุสำหรับผู้ใช้ EA WING

คู่มือติดตั้ง [eawing_brand] ใช้ชื่อเมนูภาษาอังกฤษ เช่น Tools → Options แท็บ Expert Advisors และช่อง Allow DLL imports ถ้า MT5 ของคุณเป็นภาษาไทย ทำตามได้ด้วยตำแหน่งเมนูและคีย์ลัดในตารางด้านบน หรือสลับเป็นภาษาอังกฤษระหว่างติดตั้งแล้วค่อยเปลี่ยนกลับ การเปลี่ยนภาษาไม่กระทบสิทธิ์ใช้งานที่ผูกกับเลขบัญชี และไม่ต้องลาก EA ลงกราฟใหม่ หลังรีสตาร์ตให้ดูแค่ว่าปุ่ม Algo Trading เป็นสีเขียวและการ์ดล็อกอินบนแดชบอร์ดยังผ่าน

คำถามที่พบบ่อยเรื่อง MT5 ภาษาไทย

เปลี่ยน MT5 เป็นภาษาไทยแล้ว EA ยังทำงานปกติไหม?

ปกติ ภาษามีผลกับหน้าจอเท่านั้น แต่การเปลี่ยนภาษาต้องรีสตาร์ตโปรแกรม ระหว่างนั้น EA หยุดชั่วครู่ ควรทำตอนไม่มีออเดอร์ค้างหรือช่วงตลาดปิด แล้วตรวจปุ่ม Algo Trading หลังเปิดใหม่

ทำไมบางคำยังเป็นภาษาอังกฤษหลังเปลี่ยนเป็นภาษาไทย?

ชื่อสัญลักษณ์ ชื่อ EA ชื่อโฟลเดอร์ และข้อความที่ EA พิมพ์เอง ไม่ได้ถูกแปลโดยโปรแกรม และศัพท์เทคนิคบางคำอาจถูกคงไว้เป็นภาษาอังกฤษ เป็นเรื่องปกติ

ตั้งมือถือเป็นภาษาไทย แต่คอมเป็นภาษาอังกฤษได้ไหม?

ได้ แต่ละเครื่องและแต่ละแอปตั้งภาษาแยกกัน ไม่มีผลต่อกัน และบัญชีเดียวกันเปิดดูพร้อมกันได้ทั้งสองที่

MetaEditor เปลี่ยนเป็นภาษาไทยตามด้วยไหม?

MetaEditor เป็นโปรแกรมแยกสำหรับเขียนและแก้โค้ด มีเมนู View → Languages ของตัวเอง และต้องรีสตาร์ต MetaEditor เช่นกัน ผู้ใช้ EA ทั่วไปไม่จำเป็นต้องเปิดโปรแกรมนี้

คำเตือนความเสี่ยง: ภาษาของโปรแกรมไม่ได้เปลี่ยนความเสี่ยงของการเทรด อ่านหน้าต่างคำสั่งและค่าตั้งให้เข้าใจก่อนกดยืนยันทุกครั้ง ไม่ว่าจะใช้ภาษาใด การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ความเสี่ยงที่ต้องเข้าใจก่อนเปิดใช้ EA ก่อนใช้เงินจริง

ถ้ากำลังจะติดตั้ง EA และอยากทำตามคู่มือให้ตรงทุกขั้น ดูขั้นตอนติดตั้ง EA WING บน MT5 ซึ่งบอกชื่อเมนูภาษาอังกฤษพร้อมตำแหน่ง ติดตรงไหนส่งภาพหน้าจอมาให้ทีมงานคนไทยดูทาง LINE ได้ ไม่ว่า MT5 ของคุณจะเป็นภาษาอะไร
