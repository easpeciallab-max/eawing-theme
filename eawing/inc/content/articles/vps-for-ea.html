VPS สำหรับ EA คือคอมพิวเตอร์ Windows เสมือนที่ตั้งอยู่ในศูนย์ข้อมูลและเปิดอยู่ตลอดเวลา ให้ MT5 กับ EA ทำงานต่อได้แม้คอมที่บ้านปิดอยู่ คู่มือนี้รวมทุกเรื่องที่คนใช้บอทเทรดต้องรู้ไว้ในที่เดียว ตั้งแต่ตัดสินใจว่าต้องใช้ไหม เลือกแบบไหน ตั้งค่าวันแรก เชื่อมต่อจากคอมและมือถือ ไปจนถึงการดูแลรายสัปดาห์และอาการที่เจอบ่อย

ทำไม EA ต้องมีเครื่องที่เปิดอยู่ตลอด

EA หรือ Expert Advisor เป็นโปรแกรมที่ทำงานอยู่ภายใน MT5 เวอร์ชันคอมพิวเตอร์ มันอ่านราคาทุกครั้งที่ราคาขยับ แล้วตัดสินใจตามกติกาที่ผู้พัฒนาเขียนไว้ งานทั้งหมดนี้เกิดบนเครื่องที่เปิด MT5 อยู่ ไม่ได้เกิดบนเซิร์ฟเวอร์ของโบรกเกอร์ ถ้ายังไม่คุ้นกับหลักการนี้ อ่านพื้นฐานในEA คืออะไร และทำงานอย่างไรก่อนได้

เมื่อเครื่องดับ ออเดอร์ที่เปิดไว้ไม่ได้หายไปไหน ยังอยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ และระดับปิดออเดอร์ที่ส่งแนบไปกับออเดอร์แล้ว (ถ้ามี) ก็ยังมีผล แต่งานที่ EA ต้องคิดและสั่งต่อ เช่น เปิดออเดอร์ใหม่ หรือจัดการออเดอร์ตามเงื่อนไขของมันเอง จะหยุดทั้งหมดจนกว่าโปรแกรมจะกลับมา ตลาด Forex และทองคำเปิดเกือบตลอด 24 ชั่วโมงในวันทำการ ช่วงที่เครื่องดับจึงอาจตรงกับช่วงที่ราคาวิ่งแรงพอดี

สาเหตุที่ทำให้เครื่องหยุดมักไม่ใช่เรื่องใหญ่ ไฟตกไม่กี่วินาที เราเตอร์รีเซ็ตตัวเอง เครื่องเข้าโหมด Sleep หรือ Windows สั่งรีสตาร์ตหลังอัปเดตตอนตีสาม ทั้งหมดนี้เกิดได้โดยไม่มีใครรู้ตัว บทความรัน EA คอมที่บ้านได้ไหมอธิบายว่าปิดคอมแล้วเกิดอะไรขึ้นบ้าง และต้องเตรียมเครื่องอย่างไร

ตัวอย่างสมมติ: คืนที่เครื่องรีสตาร์ตเอง

สมมติคุณเปิด EA บนคอมที่บ้านไว้ก่อนนอน ตีสองครึ่ง Windows ลงอัปเดตแล้วรีสตาร์ต เครื่องกลับมาที่หน้าล็อกอินของ Windows แต่ไม่มีใครล็อกอิน MT5 จึงไม่เปิด ตื่นมาตอนเช้าก็เห็นว่าบัญชีเงียบมาหลายชั่วโมง ระหว่างนั้นออเดอร์ที่ค้างอยู่ไม่มีใครดูแลตามเงื่อนไขของ EA เรื่องนี้แต่งขึ้นเพื่ออธิบาย แต่เป็นรูปแบบที่เกิดได้จริงทั้งบนคอมที่บ้านและบน VPS ที่ไม่ได้ตั้งค่า บทเรียนคือเครื่องต้องเปิดอยู่ และต้องเตรียมให้ MT5 กลับมาเองด้วย

อีกคำถามที่เจอบ่อยคือรันบนมือถือแทนได้ไหม คำตอบคือไม่ได้ แอป MT5 บน Android และ iOS ส่งคำสั่งเทรดด้วยมือได้ แต่รัน EA ไม่ได้ มือถือจึงมีไว้ดูผลและรีโมตเข้า VPS เหตุผลเต็มอยู่ในเรื่องทำไม EA รันบนมือถือไม่ได้

VPS สำหรับ EA มีแบบไหนบ้าง

VPS ย่อมาจาก Virtual Private Server คือเซิร์ฟเวอร์จริงหนึ่งเครื่องที่ถูกแบ่งเป็นเครื่องเสมือนหลายเครื่อง แต่ละเครื่องมีระบบปฏิบัติการ หน่วยความจำ และดิสก์ของตัวเอง คุณรีโมตเข้าไปใช้งานได้เหมือนเปิดคอม Windows อีกเครื่องหนึ่ง แต่ในวงการเทรด คำว่า VPS ถูกใช้เรียกทางเลือกที่ต่างกันมากอยู่สามแบบ ตารางนี้เทียบให้เห็นภาพรวมก่อน

ทางเลือกได้อะไรข้อจำกัดที่ต้องรู้เหมาะกับ
Windows VPS ทั่วไปเครื่อง Windows เต็มตัว ติดตั้ง MT5 ได้หลายชุดตามสเปก รีโมตเข้าไปเห็นหน้าจอได้ต้องดูแลเองทั้งรหัสผ่าน การอัปเดต และการเปิด MT5 หลังรีสตาร์ตคนที่รัน EA ต่อเนื่อง โดยเฉพาะ EA ที่ต้องใช้ DLL
VPS ในตัว MT5 (MQL5 Virtual Hosting)เช่าจากในโปรแกรม MT5 แล้วย้ายกราฟกับ EA ขึ้นไปรันให้ไม่มีหน้าจอให้รีโมต ห้ามเรียกใช้ DLL และย้ายกราฟได้จำนวนจำกัดEA ที่ไม่ใช้ DLL และไม่ต้องตั้งค่าอะไรบนเครื่องเพิ่ม
คอมที่บ้านไม่มีค่าเช่า ควบคุมได้ทุกอย่างไฟดับ เน็ตหลุด Sleep และการรีสตาร์ตหลังอัปเดตทำให้ EA หยุดได้ซ้อมบนบัญชีเดโม หรือคนที่มีไฟสำรองและเน็ตเสถียรจริง

ทีมงาน EA WING แนะนำแบบแรก เหตุผลหลักคือ EA WING ต้องเปิด Allow DLL imports จึงจะทำงานได้ ขณะที่คู่มือของ MetaTrader 5 ระบุว่าการเรียก DLL ถูกห้ามทั้งหมดบนแพลตฟอร์มเสมือนของ MT5 บริการนี้ย้ายอะไรขึ้นไปได้บ้าง และใช้กับ EA แบบไหนได้ อธิบายไว้ในบทความMQL5 VPS ใช้กับ EA ที่ต้องเปิด DLL ได้ไหม

เลือก VPS สำหรับ EA: 6 เรื่องที่ต้องดู

ผู้ให้บริการแต่ละรายตั้งชื่อแพ็กเกจไม่เหมือนกัน แต่เกณฑ์ที่ใช้ตัดสินเหมือนกันทุกเจ้า คู่มือนี้ไม่แนะนำยี่ห้อ เพราะราคาและคุณภาพของผู้ให้บริการเปลี่ยนได้ตลอด ให้ใช้เกณฑ์หกข้อด้านล่างเทียบเอง ถ้าอยากได้ตารางให้คะแนนพร้อมคำถามที่ควรถามก่อนจ่ายเงิน ดูบทความVPS Forex เจ้าไหนดี: เกณฑ์เลือกโดยไม่ต้องดูยี่ห้อ

1. Windows รุ่นที่ยังได้รับแพตช์ความปลอดภัย

MT5 เวอร์ชันคอมพิวเตอร์สร้างมาสำหรับ Windows แพ็กเกจราคาถูกบางตัวเป็นระบบอื่นที่ต้องใช้วิธีอ้อมกว่าจะรัน MT5 ได้ ซึ่งดูแลยากและไม่เหมาะกับผู้เริ่มต้น ให้เลือก Windows รุ่นที่ยังอยู่ในระยะที่ Microsoft ออกแพตช์ให้ เพราะเครื่องที่ออนไลน์ทั้งวันทั้งคืนเป็นเป้าของการเจาะระบบมากกว่าคอมทั่วไป

2. RAM, CPU และดิสก์ที่พอสำหรับ MT5 ทุกชุด

MT5 หนึ่งชุดเข้าบัญชีได้ทีละบัญชี ถ้ารันสองบัญชีก็ต้องเปิด MT5 สองชุด หน่วยความจำที่ต้องใช้จึงเพิ่มตามจำนวนชุด จำนวนกราฟ และจำนวนสัญลักษณ์ที่เปิด บวกกับส่วนที่ Windows ใช้เอง ดิสก์ควรเป็น SSD และเหลือที่ว่างพอให้ไฟล์ Log กับการอัปเดตของ Windows วิธีวัดการใช้งานจริงบนเครื่องคุณแล้วคิดย้อนเป็นสเปกที่ต้องเช่า อยู่ในบทความวัดสเปก VPS ที่ MT5 ต้องใช้

3. ที่ตั้งศูนย์ข้อมูลและค่า Ping

ค่า Ping คือเวลาที่ข้อมูลเดินทางจาก MT5 ไปถึงเซิร์ฟเวอร์ของโบรกเกอร์ หน่วยเป็นมิลลิวินาที ปัจจัยหลักคือระยะทาง VPS ที่อยู่เมืองเดียวกับเซิร์ฟเวอร์ของโบรกเกอร์จึงมักได้ค่าต่ำกว่าคอมที่บ้านในไทยมาก ดูค่าปัจจุบันได้ที่แถบสถานะมุมขวาล่างของ MT5 และถามฝ่ายบริการลูกค้าของโบรกเกอร์ได้ว่าเซิร์ฟเวอร์เทรดตั้งอยู่ที่ไหน Ping ต่ำช่วยให้คำสั่งไปถึงเร็วขึ้น แต่ไม่ได้ทำให้กลยุทธ์ดีขึ้น ความสำคัญจริงของมันกับ EA แต่ละแบบอธิบายไว้ในเรื่องPing และ Latency ของ VPS ถ้ายังไม่ได้เลือกโบรกเกอร์ ดูเกณฑ์เลือกโบรก Forex สำหรับ EAไปพร้อมกัน

4. Uptime แผงควบคุม และซัพพอร์ต

ดูว่าผู้ให้บริการบอกเปอร์เซ็นต์ Uptime ไว้ชัด มีแผงควบคุมให้สั่งเปิดเครื่องหรือรีสตาร์ตเองได้ และมีช่องทางแจ้งปัญหาที่ตอบเร็ว เวลาเครื่องค้างตอนตลาดเปิด ซัพพอร์ตที่ตอบไวสำคัญกว่าสเปกที่สูงกว่านิดหน่อย

5. ราคา รอบบิล และราคาต่ออายุ

ราคาเดือนแรกอาจเป็นโปรโมชัน ราคาตอนต่ออายุอาจไม่เท่ากัน ค่าสิทธิ์ Windows อาจรวมหรือแยก และการจ่ายเป็นเงินตราต่างประเทศมีค่าธรรมเนียมบัตรเพิ่ม ค่า VPS เป็นต้นทุนประจำที่ต้องนับรวมกับการเทรดทุกเดือน วิธีคิดต้นทุนทั้งปีและเทียบรายเดือนกับรายปีอยู่ในบทความราคา VPS รายเดือนและรายปี

6. ช่วงทดลองและเงื่อนไขยกเลิก

ถ้าผู้ให้บริการมีช่วงทดลองหรือให้เช่ารายเดือน ให้เริ่มสั้นก่อน ลองวัด Ping จริง ลองรีสตาร์ต ลองรีโมตจากมือถือ แล้วค่อยตัดสินใจเช่ายาว อ่านเงื่อนไขการยกเลิกและการคืนเงินของผู้ให้บริการก่อนจ่ายทุกครั้ง

เตรียมข้อมูล 4 อย่างก่อนเริ่มเทียบแพ็กเกจ

การเลือก VPS จะเร็วขึ้นมากถ้ารู้คำตอบของสี่ข้อนี้ก่อน เพราะแต่ละข้อตัดตัวเลือกที่ไม่เหมาะออกไปได้ทันที

  • จำนวนบัญชีที่จะรันพร้อมกัน: ใช้คิดจำนวน MT5 ที่ต้องเปิด และ RAM ที่ต้องเผื่อ
  • ชื่อเซิร์ฟเวอร์ MT5 ของบัญชี: ใช้ถามโบรกเกอร์ว่าเซิร์ฟเวอร์เทรดตั้งอยู่ที่ไหน แล้วเลือกศูนย์ข้อมูลใกล้ที่สุด
  • อุปกรณ์ที่จะใช้รีโมตเข้าไปดู: คอม Windows, Mac, Android หรือ iPhone แต่ละแบบใช้แอปต่างกัน แต่ใช้กับ Windows VPS ได้ทั้งหมด
  • งบต่อปีที่รับได้: คิดเป็นต่อปีรวมค่าต่ออายุ แล้วเทียบกับขนาดทุนที่ตั้งใจใช้ ไม่ใช่ดูแค่ราคาเดือนแรก

ตั้งค่า VPS วันแรก: ทำตามลำดับนี้

หลังเช่า ผู้ให้บริการจะส่งที่อยู่ IP ชื่อผู้ใช้ และรหัสผ่านมาทางอีเมล ก่อนลง EA ให้ไล่ตามลำดับนี้ในวันแรก ใช้เวลาไม่นาน แต่กันปัญหาส่วนใหญ่ที่คนใช้ VPS เจอในเดือนแรกได้

  1. เปลี่ยนรหัสผ่านเริ่มต้นทันที

    VPS เปิดรับการเชื่อมต่อจากอินเทอร์เน็ตตลอดเวลา และจะมีบัญชีเทรดล็อกอินค้างไว้ ใช้รหัสยาวที่ไม่ซ้ำกับบริการอื่น เก็บในโปรแกรมจัดการรหัสผ่าน และไม่ส่งให้ใครทางแชต รายการตั้งค่าความปลอดภัยที่ควรทำทั้งหมดอยู่ในเรื่องตั้งรหัสและความปลอดภัย VPS สำหรับเทรด

  2. ตั้งโซนเวลาให้อ่านง่าย

    VPS มักตั้งเวลาตามประเทศของศูนย์ข้อมูล เปลี่ยนเป็นเวลาไทย (UTC+7) แล้วไฟล์ Log ของ Windows จะเทียบกับเหตุการณ์จริงได้ง่ายขึ้น ส่วนเวลาบนกราฟ MT5 ยังเป็นเวลาเซิร์ฟเวอร์ของโบรกเกอร์เหมือนเดิม

  3. ติดตั้ง MT5 และล็อกอินด้วยรหัสผ่านหลัก

    ดาวน์โหลดตัวติดตั้งจากเว็บของโบรกเกอร์หรือเว็บทางการของ MetaTrader 5 ล็อกอินด้วยรหัสผ่านหลัก (รหัส Investor ใช้ดูได้อย่างเดียว ส่งคำสั่งเทรดไม่ได้) แล้วติ๊ก Save password ขั้นตอนล็อกอินอยู่ในวิธีติดตั้ง MT5 และล็อกอินบัญชี ถ้ายังใหม่กับตัวโปรแกรม อ่านMT5 คืออะไร และใช้งานอย่างไรประกอบ

  4. วางแผนจำนวน MT5 บนเครื่อง

    ถ้าจะรันหลายบัญชี ให้ติดตั้ง MT5 แยกโฟลเดอร์ บัญชีละหนึ่งชุด และตั้งชื่อทางลัดให้แยกออกง่าย วิธีติดตั้งหลายชุดและเรื่องที่ต้องระวังอยู่ในบทความติดตั้ง MT5 หลายตัวบน VPS

  5. ให้ MT5 เปิดเองหลังรีสตาร์ต

    ใส่ทางลัด MT5 ไว้ในโฟลเดอร์ Startup ของผู้ใช้ Windows บน VPS เมื่อผู้ใช้นั้นล็อกอิน โปรแกรมจะเปิดขึ้นเองพร้อมกราฟและ EA ชุดเดิม รายละเอียดและข้อจำกัดของแต่ละวิธีอยู่ในเรื่องตั้งให้ MT5 เปิดอัตโนมัติหลัง VPS รีสตาร์ต

  6. กำหนดเวลาให้ Windows Update

    อย่าปิดการอัปเดตทิ้ง แต่ตั้ง Active hours ให้กว้างที่สุดเท่าที่ Windows ยอมให้ตั้ง แล้วลงอัปเดตกับรีสตาร์ตเองช่วงสุดสัปดาห์ที่ตลาด Forex ปิด ก่อนที่ Windows จะเลือกเวลาเอง วิธีตั้งทีละขั้นอยู่ในบทความวิธีคุมการอัปเดต Windows บน VPS

  7. ซ้อมรีสตาร์ตหนึ่งครั้ง

    ช่วงตลาดปิด สั่งรีสตาร์ตเครื่องเองหนึ่งรอบ แล้วรีโมตเข้าไปดูว่า MT5 เปิดเอง ล็อกอินบัญชีถูกตัว และกราฟกลับมาครบ ถ้าผ่านรอบนี้ วันที่เครื่องรีสตาร์ตจริงจะไม่มีอะไรน่าตกใจ

เชื่อมต่อ VPS จากคอมและมือถือ

บนคอม Windows ใช้โปรแกรม Remote Desktop Connection ที่มากับ Windows ส่วนมือถือและแท็บเล็ตใช้แอป Windows App ของ Microsoft ซึ่งมาแทนแอป Remote Desktop ตัวเดิม ทั้งสองแบบส่งภาพหน้าจอของ VPS มาให้ดูและส่งการคลิกของคุณกลับไป ตัว MT5 และ EA ยังทำงานอยู่บน VPS ทั้งหมด ขั้นตอนแยกตามอุปกรณ์อยู่ในคู่มือเหล่านี้

  • จากคอม Windows: Windows VPS ผ่าน Remote Desktop รวมวิธีย้ายไฟล์และตัวเลือกที่ช่วยให้ใช้งานง่ายขึ้น
  • จากมือถือ Android: เข้า VPS จาก Android ด้วย Windows App
  • จาก iPhone หรือ iPad: เข้า VPS จาก iPhone หรือ iPad

คนใช้ Mac ก็รีโมตเข้า Windows VPS ได้ด้วย Windows App เวอร์ชัน macOS ข้อดีของวิธีนี้คือไม่ต้องหาทางรัน MT5 บน Mac เอง เพราะตัวโปรแกรมทำงานอยู่บน Windows ของ VPS อยู่แล้ว

กฎข้อเดียวที่ต้องจำ: ตอนออกให้ปิดหน้าต่างรีโมต (Disconnect) เท่านั้น ห้ามเลือก Sign out จากเมนู Start บน VPS เพราะ Windows จะปิดทุกโปรแกรมของผู้ใช้นั้น รวมถึง MT5 และ EA ถ้าต่อไม่ติด รหัสไม่ผ่าน หรือหน้าจอหลุดบ่อย ไล่ตามบทความRemote Desktop หลุดหรือเข้า VPS ไม่ได้

ติดตั้ง EA WING บน VPS

VPS เป็นเครื่องใหม่ ค่าที่ตั้งไว้บนคอมที่บ้านไม่ได้ตามมาด้วย ต้องติดตั้ง [eawing_brand] ใหม่ตั้งแต่ต้น และถ้าเคยรันบัญชีเดียวกันบนเครื่องอื่น ให้ถอด EA ออกจากเครื่องนั้นก่อน กันไม่ให้สองเครื่องส่งคำสั่งซ้อนกันในบัญชีเดียว ลำดับการย้ายที่ปลอดภัย รวมถึงจังหวะที่ควรย้ายตอนยังมีออเดอร์เปิดอยู่ อยู่ในเรื่องลำดับการย้าย EA ขึ้น VPS ส่วนรายละเอียดทุกหน้าจออยู่ในคู่มือขั้นตอนติดตั้ง EA WING แบบละเอียด

  1. ล็อกอินบัญชีที่ได้รับสิทธิ์

    สิทธิ์ใช้งานของ EA WING ผูกกับเลขบัญชี MT5 ให้ล็อกอินบัญชีเดียวกับที่แจ้งทีมงานไว้ ด้วยรหัสผ่านหลัก และติ๊ก Save password

  2. วางไฟล์ EA

    คัดลอก EA_WING_V4.2.ex5 ขึ้น VPS แล้ววางใน File → Open Data Folder → MQL5 → Experts จากนั้นคลิกขวาใน Navigator (Ctrl+N) แล้วเลือก Refresh

  3. เปิดสวิตช์ใน Options

    ไปที่ Tools → Options แท็บ Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports เพราะ EA WING ต้องใช้ DLL ในการทำงาน เหตุผลที่ควรเปิด DLL ให้เฉพาะ EA ที่ไว้ใจอยู่ในเรื่องAllow DLL imports ทำอะไร

  4. ลงกราฟ XAUUSD M1

    เปิดกราฟ XAUUSD กรอบเวลา M1 (บางโบรกเกอร์มีตัวต่อท้ายชื่อ เช่น XAUUSD.c) ลาก EA ลงกราฟ ในหน้าต่างตั้งค่าที่เปิดขึ้นให้ติ๊ก Allow Algo Trading และ Allow DLL imports แล้วกด OK จากนั้นดูว่าปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว

  5. ดูการ์ดล็อกอินบนแดชบอร์ด

    สีเขียวคือผ่าน สีเหลืองคือกำลังตรวจหรืออยู่ในช่วงผ่อนผัน สีแดงคือไม่ผ่าน ถ้ายังไม่ผ่าน ส่งเลขบัญชีกับชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE เมื่อเปิดสิทธิ์แล้ว EA จะเริ่มทำงานเองภายในประมาณ 5 นาที และถ้าเชื่อมต่อเซิร์ฟเวอร์สิทธิ์ไม่ได้ชั่วคราว EA ยังทำงานต่อได้ 72 ชั่วโมง

ส่งให้ทีมงานแค่เลขบัญชีกับชื่อเซิร์ฟเวอร์ก็พอ ไม่ต้องส่งรหัสผ่านบัญชีเทรดหรือรหัสเข้า VPS ไม่ว่ากรณีใด

ความปลอดภัยของ VPS ที่ล็อกอินบัญชีเทรดค้างไว้

VPS ที่รัน EA มีของมีค่าอยู่สองอย่าง คือบัญชีเทรดที่ล็อกอินด้วยรหัสผ่านหลัก และไฟล์ EA ที่คุณได้สิทธิ์ใช้งาน ใครเข้าเครื่องได้ก็สั่งปิดออเดอร์ เปลี่ยนค่า หรือถอด EA ได้ทันที เครื่องนี้จึงต้องดูแลเหมือนกุญแจบ้าน ไม่ใช่คอมสำรองที่ใครใช้ก็ได้

  • ใช้รหัสผ่าน VPS ที่ยาวและไม่ซ้ำกับบริการอื่น เปลี่ยนทันทีถ้าเคยส่งให้ใครดู
  • ติดตั้งเฉพาะโปรแกรมที่จำเป็น คือ MT5 และ EA ที่ได้มาจากแหล่งที่ไว้ใจ
  • ถามผู้ให้บริการเรื่องไฟร์วอลล์และการจำกัดการเชื่อมต่อ ถ้ามีให้ใช้
  • ให้ Windows ได้แพตช์ความปลอดภัยตามรอบ โดยคุมเวลาแทนการปิดอัปเดต
  • เก็บรายชื่อคนที่รู้รหัส VPS ให้สั้นที่สุด และเปลี่ยนรหัสเมื่อเลิกให้ใครช่วยดูแล
  • ส่งรหัสผ่าน VPS หรือรหัสผ่านหลักของบัญชีเทรดให้ใครทางแชต รวมถึงคนที่อ้างว่าเป็นทีมซัพพอร์ต
  • ใช้ VPS เครื่องเดียวกันท่องเว็บ เปิดอีเมล หรือดาวน์โหลดไฟล์ที่ไม่รู้ที่มา
  • ติด EA หรืออินดิเคเตอร์ที่ไม่รู้ที่มาแล้วเปิด DLL ให้มัน บนเครื่องที่ล็อกอินบัญชีเงินจริงอยู่

ถ้าต้องการให้คนอื่นดูผลของบัญชีโดยไม่ให้สิทธิ์เทรด ให้ใช้รหัส Investor แทนการให้รหัส VPS วิธีตั้งค่าเครื่องให้รัดกุมขึ้นทีละข้ออยู่ในเรื่องVPS ปลอดภัยแค่ไหน และต้องตั้งอะไรบ้าง

ดูแล VPS ประจำสัปดาห์

VPS ไม่ต้องเฝ้าทุกชั่วโมง แต่ต้องมีรอบตรวจที่แน่นอน ช่วงที่สะดวกคือเช้าวันเสาร์ตามเวลาไทยหลังตลาดปิด ใช้เวลาราว 10 ถึง 15 นาที

  1. ดูภาพรวมของเครื่อง

    เปิด Task Manager ดูหน่วยความจำ CPU และพื้นที่ดิสก์ ถ้า Memory สูงเกือบเต็มเป็นประจำ หรือดิสก์ใกล้เต็ม ถึงเวลาเก็บกวาดหรือขยับสเปก

  2. ทบทวนสัปดาห์ที่ผ่านมา

    ดูแท็บ Journal และ Experts ว่ามีช่วงหลุดการเชื่อมต่อหรือข้อความผิดปกติไหม วิธีอ่านอยู่ในบทความวิธีอ่าน Journal กับแท็บ Experts

  3. ลงอัปเดตและรีสตาร์ตเอง

    ลงอัปเดตที่ค้างแล้วรีสตาร์ตหนึ่งครั้งช่วงตลาดปิด ดีกว่าปล่อยให้ Windows เลือกเวลาเองกลางสัปดาห์

  4. ยืนยันว่า MT5 กลับมาครบ

    หลังบูต ดูว่า MT5 เปิดเอง ล็อกอินบัญชีถูกตัว มุมขวาล่างขึ้นค่าการเชื่อมต่อ กราฟและ EA อยู่ครบ ปุ่ม Algo Trading เป็นสีเขียว และการ์ดล็อกอินของ EA เป็นสีเขียว

  5. ตรวจรายการเข้าใช้งาน

    ถ้าแผงควบคุมของผู้ให้บริการแสดงประวัติการเข้าระบบ ดูว่ามีการเข้าจากที่ที่คุณไม่รู้จักหรือไม่ ถ้ามี เปลี่ยนรหัสทันทีและแจ้งผู้ให้บริการ

ระหว่างสัปดาห์ การตั้ง Push Notification ของ MT5ช่วยให้รู้ตัวเร็วเมื่อบัญชีเงียบผิดปกติ ส่วนรอบตรวจรายวัน รายสัปดาห์ และรายเดือน อยู่ในเช็กลิสต์ติดตามผล EA ฉบับเต็ม

อาการที่เจอบ่อยกับ VPS และอ่านต่อที่ไหน

ปัญหาเกือบทั้งหมดที่คนใช้ VPS เจอ แบ่งได้เป็นไม่กี่กลุ่ม ใช้ตารางนี้จับคู่อาการกับสาเหตุที่พบบ่อยก่อน แล้วค่อยเปิดบทความที่ลงรายละเอียด

อาการสาเหตุที่พบบ่อยอ่านต่อ
รีโมตเข้า VPS ไม่ได้ หรือหลุดบ่อยพิมพ์ IP หรือรหัสผิด เครื่องกำลังบูต หรือเน็ตฝั่งคุณปิดกั้นการเชื่อมต่อแก้อาการเข้า VPS ไม่ได้
เครื่องรีสตาร์ตแล้ว MT5 ไม่กลับมาไม่ได้ใส่ MT5 ไว้ใน Startup หรือยังไม่มีใครล็อกอิน Windows หลังบูตตั้งให้ MT5 เปิดเอง
VPS รีสตาร์ตเองกลางสัปดาห์Windows Update ลงแพตช์แล้วบูตใหม่นอก Active hoursตั้งเวลา Windows Update
เครื่องอืด กราฟกระตุก MT5 ค้างRAM ไม่พอสำหรับ MT5 ทุกชุดหรือกราฟจำนวนมากประเมินสเปก VPS ใหม่ และแก้ MT5 ค้าง
ค่า Ping สูงตลอดศูนย์ข้อมูลอยู่คนละภูมิภาคกับเซิร์ฟเวอร์ของโบรกเกอร์อ่านค่า Ping ให้ถูก
เครื่องปกติดี แต่ EA ไม่เปิดออเดอร์สวิตช์อนุญาตปิดอยู่ สิทธิ์ใช้งานยังไม่ผ่าน หรือ EA แค่รอเงื่อนไขไล่หาสาเหตุ EA ไม่เปิดออเดอร์

เส้นทางอ่านแนะนำ

ถ้าเพิ่งเริ่มเรื่อง VPS อ่านตามลำดับนี้ แต่ละขั้นต่อยอดจากขั้นก่อนหน้า

  1. ตัดสินใจว่าต้องใช้ไหม: เริ่มจากเทียบคอมที่บ้านกับ VPS เพื่อรู้ว่าคอมของคุณหยุดได้จากอะไรบ้าง
  2. ตัดทางเลือกที่ไม่เหมาะ: อ่านเรื่อง VPS ในตัว MT5 กับ DLL และเรื่อง VPS ฟรี ก่อนไปดูของเสียเงิน
  3. เลือกเครื่อง: ใช้วิธีประเมินสเปก คู่กับวิธีคิดราคาทั้งปี แล้วเทียบผู้ให้บริการด้วยตารางเกณฑ์เลือก VPS
  4. ตั้งค่าวันแรก: ทำตามเรื่องความปลอดภัย การเปิด MT5 อัตโนมัติ และการคุมเวลาอัปเดต ตามลำดับ
  5. ย้ายระบบขึ้นเครื่อง: ใช้ขั้นตอนย้าย EA ถ้ามีบัญชีที่รันอยู่แล้ว หรือดูการเปิด MT5 หลายชุด ถ้ามีหลายบัญชี
  6. เก็บไว้ใช้ตอนมีปัญหา: แก้อาการรีโมตไม่ติด และเรื่อง Ping กับ Latency สำหรับวันที่เครื่องทำตัวแปลก

คำถามที่พบบ่อยเรื่อง VPS สำหรับ EA

จำเป็นต้องใช้ VPS ไหม ถ้าคอมที่บ้านเปิดได้ตลอด?

ไม่บังคับ ถ้าคอมเปิดได้ตลอดจริง ไฟกับเน็ตเสถียร และตั้งเครื่องไม่ให้ Sleep หรือรีสตาร์ตเองกลางสัปดาห์ แต่คนส่วนใหญ่เจอเหตุที่ทำให้เครื่องหยุดโดยไม่รู้ตัว ทีมงานจึงแนะนำ Windows VPS สำหรับบัญชีเงินจริง

ไม่ได้ เพราะ EA WING ต้องใช้ DLL ในการทำงาน และ VPS ในตัว MT5 ไม่อนุญาตให้โปรแกรมเรียก DLL ให้ใช้ Windows VPS ที่รีโมตเข้าไปติดตั้ง MT5 เองได้ ถ้าไม่แน่ใจกับบริการที่กำลังดูอยู่ ถามทีมงานก่อนเช่า

รีสตาร์ต VPS แล้ว EA จะกลับมาเองไหม?

กลับมาได้ถ้าเตรียมไว้ คือให้ MT5 จำรหัสผ่าน และใส่ MT5 ไว้ในรายการโปรแกรมที่เปิดเองเมื่อผู้ใช้ล็อกอิน หลังรีสตาร์ตทุกครั้งควรรีโมตเข้าไปยืนยันว่าปุ่ม Algo Trading และการ์ดล็อกอินของ EA เป็นสีเขียว

VPS หนึ่งเครื่องรันได้กี่บัญชี?

ขึ้นกับ RAM และ CPU ของเครื่อง กับจำนวนกราฟที่แต่ละบัญชีเปิด ไม่มีตัวเลขตายตัว หลักคือหนึ่งบัญชีใช้ MT5 หนึ่งชุด ให้วัดการใช้งานจริงใน Task Manager แล้วเหลือส่วนเผื่อไว้เสมอ

ย้ายไป VPS แล้วผลการเทรดจะดีขึ้นไหม?

VPS ลดโอกาสที่ EA จะหยุดเพราะเครื่องหรือเน็ต และอาจทำให้คำสั่งถึงโบรกเกอร์เร็วขึ้น แต่ไม่ได้เปลี่ยนกลยุทธ์หรือความเสี่ยงของตลาด บัญชีที่รันบน VPS ก็ยังขาดทุนได้เหมือนเดิม

คำเตือนความเสี่ยง: VPS ช่วยให้เครื่องที่รัน EA เปิดอยู่ต่อเนื่อง แต่ไม่ได้ทำให้ผลการเทรดดีขึ้น และไม่ได้ลดความเสี่ยงของตลาด การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ค่าเช่า VPS ก็เป็นต้นทุนที่ต้องนับรวมในแผน อ่านหน้าความเสี่ยงของการเทรดด้วย EAก่อนใช้เงินจริง
