EA ทำงานได้เฉพาะตอนที่โปรแกรม MT5 เปิดอยู่และต่อเน็ตได้ ถ้าคอมดับ เครื่องหลับ หรือเน็ตบ้านหลุด บอทเทรดก็หยุดตามทันที VPS สำหรับ EA คือคอมพิวเตอร์เสมือนในศูนย์ข้อมูลที่เปิดอยู่ตลอดเวลา ให้ MT5 ค้างไว้ได้โดยไม่ต้องมีใครเฝ้า บทความนี้อธิบายว่า VPS ช่วยตรงไหน เลือกอย่างไร อ่านค่า Ping อย่างไร และดูแลอย่างไรให้ EA รันได้ต่อเนื่อง

สรุปสั้น: เลือก Windows VPS ที่มี RAM พอสำหรับ MT5 ทุกชุดที่จะเปิด อยู่ใกล้เซิร์ฟเวอร์ของโบรกเกอร์ (ดูค่า Ping มุมขวาล่างของ MT5) บอก Uptime ชัด และมีช่องทางแจ้งปัญหา · ตั้งรหัสผ่านแข็งแรงและไม่แชร์ · ตั้งเวลาอัปเดต Windows ช่วงตลาดปิด · เช็กเครื่องสัปดาห์ละครั้ง · VPS ช่วยเรื่องเครื่องเปิดตลอด แต่ไม่ได้ลดความเสี่ยงของตลาด

ทำไม EA ต้องมีเครื่องที่เปิดอยู่ตลอด

EA หรือ Expert Advisor เป็นโปรแกรมที่ทำงานอยู่ภายใน MT5 เวอร์ชันคอมพิวเตอร์ มันอ่านราคาทุกครั้งที่ราคาขยับ แล้วตัดสินใจส่งคำสั่งตามกติกาที่ผู้พัฒนาเขียนไว้ พื้นฐานเพิ่มเติมอยู่ในบทความ EA คืออะไร งานทั้งหมดนี้เกิดบนเครื่องของคุณ ไม่ได้เกิดบนเซิร์ฟเวอร์ของโบรกเกอร์ เมื่อเครื่องหยุด EA ก็หยุด

ออเดอร์ที่เปิดไว้แล้วยังอยู่ฝั่งโบรกเกอร์ และ Stop Loss หรือ Take Profit ที่ส่งไปแล้วยังมีผล แต่งานที่ EA ต้องทำต่อ เช่น เปิดออเดอร์ใหม่ หรือปิดออเดอร์ตามเงื่อนไขของมันเอง จะชะงักจนกว่าโปรแกรมจะกลับมา ตลาด Forex และทองคำเปิดเกือบ 24 ชั่วโมงในวันทำการ ช่วงที่เครื่องดับจึงอาจตรงกับช่วงที่ราคาวิ่งแรง

และแอป MT5 บนมือถือรัน EA ไม่ได้ ทั้ง Android และ iOS ตัว EA ต้องอยู่บน Windows เสมอ

VPS สำหรับ EA คืออะไร

VPS ย่อมาจาก Virtual Private Server คือเซิร์ฟเวอร์ที่ถูกแบ่งเป็นคอมพิวเตอร์เสมือนหลายเครื่อง แต่ละเครื่องมีระบบปฏิบัติการ หน่วยความจำ และดิสก์ของตัวเอง ผู้เช่ารีโมตเข้าไปใช้งานได้เหมือนเปิดคอม Windows อีกเครื่อง ติดตั้ง MT5 และลาก EA ลงกราฟได้ทุกอย่าง

คนเทรดด้วย EA ต้องการ Windows VPS เพราะ MT5 เวอร์ชันคอมพิวเตอร์สร้างมาสำหรับ Windows และเครื่องตั้งอยู่ในศูนย์ข้อมูลที่มีไฟสำรองและเครือข่ายหลายเส้นทาง

คอมที่บ้านกับ VPS ต่างกันอย่างไร

รัน EA บนคอมที่บ้านก็ทำได้ ถ้าเครื่องเปิดทั้งวันทั้งคืนและเน็ตเสถียร ตารางนี้ช่วยเทียบ

หัวข้อคอมที่บ้านWindows VPS
ไฟฟ้าไฟดับหรือไฟตกแล้วเครื่องดับ เว้นแต่มีเครื่องสำรองไฟศูนย์ข้อมูลมีไฟสำรองในตัว
อินเทอร์เน็ตขึ้นกับเน็ตบ้านและเราเตอร์เครือข่ายของศูนย์ข้อมูล หลุดน้อยกว่า
ระยะถึงเซิร์ฟเวอร์โบรกเกอร์ขึ้นกับที่ตั้งบ้าน มักไกลจากเซิร์ฟเวอร์ต่างประเทศเลือกศูนย์ข้อมูลใกล้เซิร์ฟเวอร์โบรกเกอร์ได้
ค่าใช้จ่ายค่าไฟของเครื่องที่เปิดตลอด และค่าเสื่อมของอุปกรณ์ค่าเช่ารายเดือนหรือรายปี

ถ้าใช้คอมที่บ้าน ให้ปิดโหมด Sleep ตั้งเวลาอัปเดต Windows ไว้ช่วงตลาดปิด และพิจารณาเครื่องสำรองไฟ

เลือก VPS สำหรับ EA: ดูอะไรบ้าง

ผู้ให้บริการแต่ละรายตั้งชื่อแพ็กเกจต่างกัน แต่หัวข้อที่ควรดูเหมือนกัน

ระบบปฏิบัติการ Windows ที่ยังได้รับแพตช์

เลือก Windows รุ่นที่ยังได้อัปเดตความปลอดภัย แพ็กเกจราคาถูกบางตัวเป็นระบบอื่นที่ต้องใช้วิธีอ้อมกว่าจะรัน MT5 ได้ ไม่เหมาะกับผู้เริ่มต้น

RAM และ CPU พอสำหรับ MT5 ทุกชุด

MT5 ใช้หน่วยความจำมากขึ้นตามจำนวนกราฟและสัญลักษณ์ที่เปิด ถ้ารันหลายบัญชี (มักเป็นหนึ่งบัญชีต่อ MT5 หนึ่งชุด) ต้องเผื่อทุกชุดบวกตัว Windows เอง หลังใช้งานจริงให้เปิด Task Manager ดู Memory และ CPU ถ้าเกือบเต็มเป็นประจำหรือกราฟกระตุก ถึงเวลาขยับสเปก ดิสก์ควรเป็น SSD และเผื่อที่ว่าง เพราะไฟล์ Log โตขึ้นทุกวัน ไม่แน่ใจว่าควรเริ่มขนาดไหน ถามทีมงานได้

Uptime และการดูแลของผู้ให้บริการ

ดูว่าบอกเปอร์เซ็นต์ Uptime ไว้ชัด มีแผงควบคุมให้สั่งรีสตาร์ตเองได้ และมีช่องทางแจ้งปัญหาที่ตอบเร็ว เวลาเครื่องค้างตอนตลาดเปิด ซัพพอร์ตที่ตอบไวสำคัญกว่าสเปก

ตำแหน่งเซิร์ฟเวอร์และค่า Ping ใน MT5

ค่า Ping หรือความหน่วง คือเวลาที่ข้อมูลเดินทางจาก MT5 ถึงเซิร์ฟเวอร์ของโบรกเกอร์ หน่วยเป็นมิลลิวินาที (ms) ยิ่งต่ำคำสั่งยิ่งถึงเร็ว ปัจจัยหลักคือระยะทาง VPS ที่อยู่เมืองเดียวกับเซิร์ฟเวอร์โบรกเกอร์จึงมักได้ค่าต่ำกว่าคอมที่บ้านในไทยมาก

อ่านค่า Ping จากมุมขวาล่างของ MT5

แถบสถานะมุมขวาล่างของ MT5 แสดงตัวเลขความหน่วงของการเชื่อมต่อปัจจุบัน คลิกที่ตัวเลขจะเห็นรายการเซิร์ฟเวอร์ของโบรกเกอร์พร้อมค่า Ping และคำสั่ง Rescan servers ให้วัดใหม่ ถ้าขึ้นข้อความว่าไม่มีการเชื่อมต่อแทนตัวเลข EA จะส่งคำสั่งไม่ได้เลย

หาว่าเซิร์ฟเวอร์ของโบรกเกอร์อยู่ที่ไหน

ถามฝ่ายบริการลูกค้าของ [eawing_broker] ว่าเซิร์ฟเวอร์เทรดของบัญชีคุณตั้งอยู่เมืองไหน แล้วเลือกศูนย์ข้อมูลของ VPS ในเมืองเดียวกันหรือใกล้ที่สุด ถ้ามีให้ทดลองใช้ ลงมือวัดค่า Ping จริงก่อนเช่ายาว

ค่า Ping ต่ำช่วยให้คำสั่งถึงเร็วขึ้น แต่ไม่ได้ทำให้กลยุทธ์ดีขึ้น และไม่ได้กันราคาเลื่อนช่วงตลาดผันผวน ใช้เป็นเกณฑ์หนึ่ง ไม่ใช่เกณฑ์เดียว

คิดค่าใช้จ่ายรายเดือนอย่างไร

ราคา VPS ต่างกันมากและเปลี่ยนตามโปรโมชัน แทนที่จะดูแค่ตัวเลขต่อเดือน ให้คิดตามหัวข้อนี้

  • ค่าสิทธิ์ Windows: รวมอยู่ในราคาแล้วหรือคิดแยก
  • ราคาต่ออายุ: ราคาเดือนแรกอาจเป็นโปรโมชัน ดูราคาตอนต่ออายุด้วย
  • รายเดือนหรือรายปี: รายปีมักถูกกว่าต่อเดือน แต่ถ้าเพิ่งเริ่ม เช่ารายเดือนก่อนเพื่อทดลองค่า Ping และความเสถียร
  • สัดส่วนกับเงินทุน: ค่าเช่า VPS เป็นต้นทุนประจำที่ต้องนับรวมกับการเทรดทุกเดือน ลองเทียบกับขนาดทุนที่ตั้งใจใช้ว่ายังสมเหตุสมผล
  • ต้นทุนแฝง: ตัวที่ถูกที่สุดอาจค้างบ่อยหรือซัพพอร์ตตอบช้า ซึ่งไม่เห็นในใบเสร็จ

เชื่อมต่อ VPS จากคอมและมือถือ

หลังเช่า ผู้ให้บริการจะส่งที่อยู่ IP ชื่อผู้ใช้ และรหัสผ่านมาให้ ขั้นตอนรีโมตแยกตามอุปกรณ์อยู่ในคู่มือเหล่านี้

  • จากคอม Windows ใช้ Remote Desktop Connection ตามคู่มือ ใช้ Windows VPS รัน EA
  • จากมือถือ Android ใช้แอป Windows App ตามคู่มือ เข้า VPS จาก Android
  • จาก iPhone หรือ iPad ใช้แอป Windows App ตามคู่มือ เข้า VPS จาก iPhone หรือ iPad

ตอนออก ให้ปิดหน้าต่างรีโมตเฉย ๆ ห้ามเลือก Sign out เพราะจะปิด MT5 และ EA ไปด้วย

ความปลอดภัยพื้นฐานของ VPS

VPS เปิดรับการเชื่อมต่อจากอินเทอร์เน็ตตลอดเวลาและล็อกอินบัญชีเทรดค้างไว้ จึงต้องดูแลเหมือนกุญแจบ้าน

  • เปลี่ยนรหัสผ่านเริ่มต้นทันที ใช้รหัสยาว ผสมตัวอักษร ตัวเลข และสัญลักษณ์ ไม่ซ้ำกับบริการอื่น
  • เก็บรหัสผ่านในโปรแกรมจัดการรหัสผ่าน ไม่จดไว้ในแชตหรือโน้ตที่แชร์
  • ถามผู้ให้บริการเรื่องไฟร์วอลล์หรือการจำกัดการเชื่อมต่อ ถ้ามีให้ตั้ง
  • ติดตั้งเฉพาะโปรแกรมที่จำเป็น คือ MT5 และ EA ที่ได้มาจากแหล่งที่ไว้ใจ
  • ตั้งเวลาให้ Windows อัปเดตและรีสตาร์ตช่วงตลาดปิดสุดสัปดาห์ แทนที่จะปิดอัปเดตทิ้ง
  • ส่งรหัสผ่าน VPS หรือรหัสผ่านหลักของบัญชีเทรดให้ใครทางแชต รวมถึงทีมซัพพอร์ตของ EA
  • ดาวน์โหลดไฟล์หรือโปรแกรมแปลก ๆ บน VPS ที่ล็อกอินบัญชีเทรดอยู่

ดูแล VPS ประจำสัปดาห์

VPS ไม่ต้องเฝ้าทุกวัน แต่ควรมีรอบตรวจ ช่วงที่สะดวกคือเช้าวันเสาร์ตามเวลาไทยหลังตลาดปิด

  1. ดูภาพรวมของเครื่อง

    เปิด Task Manager ดูหน่วยความจำ CPU และพื้นที่ดิสก์ ถ้าดิสก์ใกล้เต็ม ลบไฟล์ที่ไม่ใช้

  2. ทบทวนสัปดาห์ที่ผ่านมา

    ดูแท็บ Journal และ Experts ว่ามีช่วงหลุดการเชื่อมต่อหรือข้อความผิดปกติไหม วิธีอ่านอยู่ในบทความ MT5 Journal และแท็บ Experts

  3. ให้ Windows อัปเดตและรีสตาร์ต

    ลงอัปเดตที่ค้างแล้วรีสตาร์ตเองหนึ่งครั้ง ดีกว่าปล่อยให้ Windows เลือกเวลาเองกลางสัปดาห์

  4. ยืนยันว่า MT5 กลับมาครบ

    หลังบูต ดูว่า MT5 เปิดเองและล็อกอินบัญชีถูกตัว กราฟและ EA กลับมาครบ ปุ่ม Algo Trading เป็นสีเขียว และไอคอนข้างชื่อ EA บนกราฟเป็นสีฟ้า ถ้าปุ่มดับ ดูเหตุและวิธีแก้ใน ปุ่ม Algo Trading

  5. ตั้งเวลาเครื่องให้อ่านง่าย

    VPS มักตั้งโซนเวลาตามประเทศของศูนย์ข้อมูล ตั้งเป็นเวลาไทยแล้วไฟล์ Log จะเทียบกับเหตุการณ์จริงได้ง่ายขึ้น

ระหว่างสัปดาห์ การตั้งแจ้งเตือน MT5 เข้ามือถือช่วยให้รู้ตัวเร็วเมื่อเงียบผิดปกติ

ติดตั้ง EA WING บน VPS

VPS เป็นเครื่องใหม่ ค่าตั้งจากคอมที่บ้านไม่ได้ตามมา ต้องติดตั้ง [eawing_brand] ใหม่ตั้งแต่ต้น และถ้าเคยรันบัญชีเดียวกันบนคอมที่บ้าน ให้ถอด EA ออกจากเครื่องนั้น กันออเดอร์ซ้อน รายละเอียดทุกขั้นอยู่ในคู่มือ ติดตั้ง EA WING บน MT5 ทีละขั้น

  1. ติดตั้ง MT5 และล็อกอิน

    ล็อกอินบัญชีเทรดด้วยรหัสผ่านหลัก (ไม่ใช่รหัส Investor) และติ๊ก Save password ให้โปรแกรมเข้าบัญชีเองหลังรีสตาร์ต

  2. วางไฟล์ EA

    คัดลอก EA_WING_V4.2.ex5 ขึ้น VPS แล้ววางใน File → Open Data Folder → MQL5 → Experts จากนั้นคลิกขวาใน Navigator (Ctrl+N) แล้วเลือก Refresh

  3. เปิดสวิตช์ใน Options

    Tools → Options แท็บ Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports เพราะ EA WING ต้องใช้ DLL ในการทำงาน อ่านเพิ่มใน Allow DLL imports คืออะไร

  4. ลงกราฟ XAUUSD M1

    เปิดกราฟ XAUUSD กรอบเวลา M1 (บางโบรกเกอร์มีตัวต่อท้ายชื่อสัญลักษณ์) ลาก EA ลงกราฟ ในแท็บ Common ติ๊ก Allow Algo Trading และ Allow DLL imports แล้วกด OK

  5. ดูการ์ดล็อกอิน

    การ์ดบนแดชบอร์ดต้องเป็นสีเขียว ถ้ายังไม่ผ่าน ส่งเลขบัญชีกับชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE เมื่อเปิดสิทธิ์แล้ว EA จะเริ่มทำงานเองภายในประมาณ 5 นาที ถ้าเน็ตหลุดชั่วคราว EA ยังทำงานต่อได้ 72 ชั่วโมงนับจากครั้งล่าสุดที่ตรวจผ่าน

ไม่บังคับ ถ้าคอมเปิดตลอดได้จริงและไฟกับเน็ตเสถียร แต่คนส่วนใหญ่เจอเหตุที่ทำให้เครื่องหยุดโดยไม่รู้ตัว ทีมงานจึงแนะนำ Windows VPS

ใช้บริการโฮสต์ที่ซื้อได้จากในตัว MT5 แทน Windows VPS ได้ไหม?

บริการแบบนั้นย้ายเฉพาะกราฟและ EA ไปรันบนเซิร์ฟเวอร์ของแพลตฟอร์ม และไม่อนุญาตให้ EA เรียกใช้ DLL ขณะที่ EA WING ต้องใช้ DLL ในการทำงาน จึงควรใช้ Windows VPS ที่คุณรีโมตเข้าไปติดตั้ง MT5 เองได้ ถ้าไม่แน่ใจกับบริการที่กำลังดูอยู่ ถามทีมงานก่อนเช่า

รีสตาร์ต VPS แล้ว EA จะกลับมาเองไหม?

กลับมาได้ถ้าเตรียมไว้ คือให้ MT5 จำรหัสผ่าน และใส่ MT5 ในรายการโปรแกรมที่เปิดเองหลังบูต วิธีตั้งอยู่ในคู่มือ Windows VPS แต่ควรรีโมตเข้าไปยืนยันทุกครั้งว่าปุ่ม Algo Trading เป็นสีเขียวและการ์ดล็อกอินของ EA เป็นสีเขียว

คำเตือนความเสี่ยง: VPS ช่วยให้เครื่องที่รัน EA เปิดอยู่ต่อเนื่อง แต่ไม่ได้ทำให้ผลการเทรดดีขึ้น และไม่ได้ลดความเสี่ยงของตลาด การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ความเสี่ยงการใช้ EA ก่อนใช้เงินจริง

อ่านต่อ

  • ใช้ Windows VPS รัน EA ด้วย Remote Desktop
  • ติดตั้ง EA WING บน MT5 ทีละขั้น
  • ปุ่ม Algo Trading และเหตุที่ดับเอง
  • ดูผล EA บนมือถือ

ยังไม่แน่ใจว่าควรเริ่มกับ VPS แบบไหน หรืออยากให้ทีมงานคนไทยช่วยติดตั้ง EA WING บนเครื่องที่เช่าไว้ ดูแพ็กเกจที่หน้า ราคา EA WING แล้วทักทีมงานทาง LINE ได้เลย
