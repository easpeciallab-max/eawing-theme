VPS MT5 สเปกเท่าไหร่พอ ไม่มีตัวเลขเดียวที่ใช้ได้กับทุกคน แม้แต่คู่มือทางการของ MT5 ก็บอกว่าความต้องการฮาร์ดแวร์ขึ้นกับการใช้งาน ทั้งจำนวนโปรแกรม MQL5 ที่รัน สัญลักษณ์ และกราฟที่เปิด บทความนี้จึงให้วิธีวัดจากการใช้งานจริงของคุณ แล้วคิดย้อนเป็นขนาด VPS ที่ต้องเช่า ส่วนเรื่องอื่นของการเลือกและดูแลเครื่องอยู่ในภาพรวม VPS สำหรับ EA บน MT5

สรุปสั้น: RAM คือตัวที่มักหมดก่อน · วัดหน่วยความจำของ MT5 หนึ่งชุดตอนเปิดกราฟและ EA ครบ คูณจำนวนชุด บวกส่วนที่ Windows ใช้ แล้วเผื่อเพิ่ม · CPU ให้ดูช่วงตลาดคึกคัก ไม่ใช่ตอนตลาดเงียบ · ดิสก์ใช้ SSD และเหลือที่ว่างเสมอ · ก่อนจ่ายเพิ่ม ลองลดจำนวนแท่งบนกราฟและปิดกราฟที่ไม่ได้ใช้

สเปกแต่ละตัวมีผลกับ MT5 อย่างไร

หน้าแพ็กเกจ VPS มักแสดงตัวเลขสี่ห้าตัว แต่ละตัวมีผลกับ MT5 ไม่เท่ากัน ตารางนี้ช่วยให้รู้ว่าควรดูตัวไหนก่อน

ส่วนประกอบMT5 ใช้ทำอะไรอาการเมื่อไม่พอ
RAMเก็บข้อมูลราคา กราฟ อินดิเคเตอร์ และตัว EA ของ MT5 ทุกชุดที่เปิดอยู่เครื่องอืด กราฟกระตุก โปรแกรมไม่ตอบสนอง หรือปิดตัวเอง
CPU (vCPU)คำนวณอินดิเคเตอร์และตรรกะของ EA ทุกครั้งที่ราคาขยับช่วงตลาดผันผวน หน้าจอหน่วง การตอบสนองของ EA ช้าลง
ดิสก์ (SSD)เก็บประวัติราคา ไฟล์ Log และไฟล์ของ Windowsดิสก์เต็มจนอัปเดตไม่ผ่าน หรือ MT5 บันทึกข้อมูลไม่ได้
เครือข่ายรับราคาและส่งคำสั่งไปยังเซิร์ฟเวอร์ของโบรกเกอร์MT5 หลุดการเชื่อมต่อ ปริมาณข้อมูลที่ MT5 ใช้ต่อวันไม่มาก แบนด์วิดท์จึงไม่ค่อยเป็นคอขวด
ระบบปฏิบัติการพื้นที่ที่ MT5 รันอยู่ถ้าไม่ใช่ Windows ต้องใช้วิธีอ้อม ซึ่งดูแลยากกว่า

หน้าติดตั้งในคู่มือทางการระบุว่าMT5 รันบน Windows 10 และ 11 และความต้องการฮาร์ดแวร์ขึ้นกับเงื่อนไขการใช้งาน Windows VPS ส่วนใหญ่ใช้ Windows Server ซึ่งผู้ใช้จำนวนมากรัน MT5 ได้ตามปกติ แต่ถ้าไม่แน่ใจ ให้ใช้ช่วงทดลองของผู้ให้บริการลองติดตั้งก่อน

อะไรทำให้ MT5 ใช้ทรัพยากรมากขึ้น

MT5 ชุดเดียวกันอาจใช้หน่วยความจำต่างกันหลายเท่า ขึ้นกับว่าเปิดอะไรไว้บ้าง ตัวแปรที่มีผลมากที่สุดคือ

  • จำนวน MT5 ที่เปิดพร้อมกัน: หนึ่งบัญชีใช้ MT5 หนึ่งชุด ทุกชุดใช้หน่วยความจำของตัวเอง
  • จำนวนกราฟและอินดิเคเตอร์: ทุกกราฟเก็บข้อมูลแท่งเทียนและผลคำนวณของอินดิเคเตอร์ที่ติดอยู่
  • จำนวนแท่งที่แสดงบนกราฟ: ค่า Max. bars in chart ใน Tools → Options แท็บ Charts กำหนดว่าแต่ละกราฟโหลดกี่แท่ง คู่มือ MT5 อธิบายว่าแท่งบนกราฟถูกจำกัดด้วยทรัพยากรของเครื่อง และใช้คำนวณอินดิเคเตอร์ ยิ่งตั้งสูงยิ่งใช้ RAM และ CPU มาก
  • จำนวนสัญลักษณ์ใน Market Watch: สัญลักษณ์ที่แสดงอยู่ทั้งหมดรับข้อมูลราคาตลอด
  • Strategy Tester: ตอนทดสอบย้อนหลัง MT5 อาจใช้ CPU ทุกคอร์ที่มี ถ้ารันบนเครื่องเดียวกับบัญชีจริง จะแย่งทรัพยากรกับ EA ที่กำลังเทรด
  • ตัว EA เอง: EA แต่ละตัวคำนวณหนักเบาต่างกัน จึงต้องวัดกับ EA ที่จะใช้จริง ไม่ใช่ประเมินจาก EA ตัวอื่น

วัดการใช้งานจริงด้วย Task Manager

วิธีที่แม่นที่สุดคือวัดจากคอมของคุณเองหรือจากเครื่องทดลอง โดยเปิดทุกอย่างให้เหมือนตอนใช้งานจริง

  1. จัดสภาพให้เหมือนใช้งานจริง

    เปิด MT5 ล็อกอินบัญชี (ใช้บัญชีเดโมได้) เปิดกราฟ ติด EA และอินดิเคเตอร์ให้ครบเท่าที่จะใช้บน VPS ปล่อยไว้สักพักให้โหลดประวัติราคาครบ

  2. ดูหน่วยความจำของ MT5 หนึ่งชุด

    เปิด Task Manager (Ctrl+Shift+Esc) ไปที่แท็บ Details หา terminal64.exe แล้วดูคอลัมน์ Memory ตัวเลขนี้คือที่ MT5 หนึ่งชุดใช้อยู่

  3. วัดช่วงตลาดคึกคัก

    ตัวเลขตอนตลาดเงียบมักต่ำกว่าความจริง ให้ดูซ้ำช่วงที่ราคาเคลื่อนไหวเร็ว เช่น ช่วงตลาดยุโรปกับสหรัฐฯ ทับกัน ซึ่งเป็นช่วงค่ำถึงดึกตามเวลาไทย จดค่าสูงสุดที่เห็นในหลายวัน

  4. ดูภาพรวมของเครื่อง

    แท็บ Performance แสดง Memory ที่ใช้อยู่ทั้งเครื่อง และกราฟ CPU ถ้า CPU ค้างที่ระดับสูงเป็นเวลานานในช่วงคึกคัก แปลว่าคอร์ไม่พอ ถ้าพุ่งแค่ชั่วครู่แล้วลงเป็นเรื่องปกติ

  5. จดส่วนที่ Windows ใช้เอง

    บนเครื่องทดลองที่เป็น Windows แบบเดียวกับ VPS ให้ดู Memory ทั้งเครื่องหลังบูตเสร็จโดยยังไม่เปิด MT5 ตัวเลขนี้คือฐานที่ต้องบวกเสมอ

VPS MT5 สเปกเท่าไหร่: คิดจากตัวเลขที่วัดได้

เมื่อได้ตัวเลขครบ คำถามว่า VPS MT5 สเปกเท่าไหร่พอ ก็ตอบได้ด้วยข้อมูลของคุณเอง เริ่มจาก RAM VPS ซึ่งมักหมดก่อนส่วนอื่น สูตรตั้งต้นคือ

RAM ที่ต้องการ = ส่วนที่ Windows ใช้ + (หน่วยความจำของ MT5 หนึ่งชุดช่วงคึกคัก × จำนวนชุด) + ส่วนเผื่อ

ส่วนเผื่อมีไว้รองรับการอัปเดตของ Windows การเปิดหน้าต่างรีโมต และช่วงที่ MT5 โหลดข้อมูลเพิ่ม บทความนี้ใช้ราวหนึ่งในสามของผลรวมเป็นตัวตั้งต้น ปรับขึ้นได้ถ้าคุณมักเปิดโปรแกรมอื่นบน VPS ด้วย

ตัวอย่างสมมติ: หนึ่งถึงสามบัญชี

สมมติวัดได้ว่า Windows บนเครื่องทดลองใช้ 1.5 GB หลังบูต และ MT5 หนึ่งชุดที่เปิดกราฟกับ EA ครบใช้สูงสุด 0.6 GB ช่วงคึกคัก ตัวเลขนี้เป็นตัวอย่างเพื่อแสดงวิธีคิดเท่านั้น เครื่องและ EA ของคุณอาจต่างจากนี้มาก

จำนวน MT5Windows + MT5เผื่อราวหนึ่งในสามRAM ที่ควรมีอย่างน้อย
1 ชุด1.5 + 0.6 = 2.1 GB0.7 GBราว 2.8 GB
2 ชุด1.5 + 1.2 = 2.7 GB0.9 GBราว 3.6 GB
3 ชุด1.5 + 1.8 = 3.3 GB1.1 GBราว 4.4 GB

จากนั้นเลือกแพ็กเกจที่มี RAM สูงกว่าตัวเลขในคอลัมน์สุดท้าย เช่น ผลคิดได้ 4.4 GB ก็ไม่ควรเลือกแพ็กเกจ 4 GB พอดี ถ้าจะรันหลายบัญชี วิธีติดตั้ง MT5 แยกโฟลเดอร์และตั้งชื่อให้ไม่สับสน อยู่ในเรื่องเปิด MT5 หลายตัวบน VPS ส่วนการวางแผนเงินทุนของแต่ละบัญชี อ่านได้ในวางแผนรัน EA หลายบัญชี

CPU และดิสก์: เกณฑ์ที่ใช้ได้จริง

CPU

VPS ส่วนใหญ่ขายเป็น vCPU ซึ่งแบ่งใช้คอร์จริงร่วมกับเครื่องเสมือนอื่น ประสิทธิภาพต่อ vCPU จึงต่างกันไปตามผู้ให้บริการ เกณฑ์ที่ใช้ได้คือดูกราฟ CPU ช่วงตลาดคึกคักหลังใช้งานจริงสักสัปดาห์ ถ้าแตะเพดานบ่อย ให้เพิ่ม vCPU หรือลดภาระ และอย่ารัน Strategy Tester บน VPS ที่มีบัญชีจริงทำงานอยู่ ให้ทดสอบบนคอมของคุณแทน

ดิสก์

เลือก SSD เพราะ MT5 อ่านเขียนไฟล์ประวัติราคาและ Log ตลอด ขนาดดิสก์ต้องพอสำหรับ Windows การอัปเดตที่ต้องใช้พื้นที่ชั่วคราว และ MT5 ทุกชุด แล้วยังเหลือที่ว่าง ไฟล์ Log ในโฟลเดอร์ Logs ของ MT5 โตขึ้นทุกวัน ถ้าพื้นที่ใกล้เต็ม ให้ย้ายไฟล์ Log เก่าออกไปเก็บที่อื่น โดยเก็บของช่วงล่าสุดไว้ใช้ไล่หาสาเหตุเวลามีปัญหา

ตัวเลขบนหน้าแพ็กเกจที่ควรถามเพิ่ม

หน้าแสดง VPS สเปคของผู้ให้บริการบอกตัวเลขได้ไม่ครบทุกเรื่อง ก่อนตัดสินใจ ถามเพิ่มอีกสามข้อนี้ เพราะมีผลกับความลื่นของ MT5 มากกว่าที่ตัวเลขบนหน้าเว็บบอก

  • RAM เป็นของเครื่องคุณเต็มจำนวนไหม: บางแพ็กเกจให้ใช้ได้สูงสุดชั่วคราว แต่ปริมาณที่รับประกันจริงต่ำกว่าที่โฆษณา
  • vCPU มีเงื่อนไขการใช้งานต่อเนื่องไหม: บางแพ็กเกจจำกัดเมื่อใช้ CPU สูงนาน ๆ ซึ่งตรงกับช่วงที่ตลาดคึกคักพอดี
  • ดิสก์เป็น SSD ชนิดไหน และขยายได้ไหม: ถ้าวันหนึ่งพื้นที่ไม่พอ การขยายดิสก์ได้โดยไม่ต้องย้ายเครื่องช่วยประหยัดเวลามาก

ลดภาระ MT5 ก่อนจ่ายเพิ่ม

บ่อยครั้งที่เครื่องอืดไม่ใช่เพราะสเปกต่ำ แต่เพราะ MT5 เปิดของที่ไม่ได้ใช้ไว้เยอะ ลองทำรายการนี้ก่อนอัปเกรด

  • ลดค่า Max. bars in chart ให้พอดีกับที่ EA และอินดิเคเตอร์ต้องใช้ แล้วรีสตาร์ต MT5 ให้ค่าใหม่มีผล
  • ปิดกราฟที่เปิดไว้ดูเล่นและไม่มี EA ติดอยู่
  • ซ่อนสัญลักษณ์ที่ไม่ใช้ใน Market Watch (Ctrl+M) คลิกขวาแล้วเลือก Hide
  • ถอดอินดิเคเตอร์ที่ไม่ได้ใช้ตัดสินใจออกจากกราฟ
  • ปิดโปรแกรมอื่นบน VPS เช่น เบราว์เซอร์ที่เปิดค้างไว้

ก่อนลด Max. bars in chart ให้ถามผู้พัฒนา EA ก่อนว่าต้องใช้ข้อมูลย้อนหลังกี่แท่ง ถ้าลดต่ำเกินไป EA หรืออินดิเคเตอร์บางตัวอาจคำนวณไม่ได้

สัญญาณว่าถึงเวลาอัปเกรด

  • Memory ของเครื่องอยู่ใกล้เต็มเป็นประจำ แม้ลดภาระตามรายการข้างบนแล้ว
  • MT5 ขึ้น Not responding หรือกราฟหยุดขยับเป็นพัก ๆ ช่วงตลาดคึกคัก ลองไล่สาเหตุอื่นตามวิธีแก้ MT5 ค้างก่อน ถ้าไม่หายจึงเป็นเรื่องสเปก
  • รีโมตเข้าไปแล้วหน้าจอตอบสนองช้ามาก ทั้งที่เน็ตฝั่งคุณปกติ
  • ดิสก์เหลือน้อยจน Windows Update ลงไม่ผ่าน
  • กำลังจะเพิ่มบัญชี และคิดตามสูตรแล้ว RAM ไม่พอ

ถ้าผู้ให้บริการอัปเกรดสเปกได้โดยไม่ต้องย้ายเครื่อง จะง่ายที่สุด ถ้าต้องย้าย ให้ตั้งเครื่องใหม่ให้พร้อมก่อนแล้วค่อยถอด EA จากเครื่องเดิม ส่วนผลต่อค่าใช้จ่ายรายปี ดูวิธีเทียบในค่าเช่า VPS ต่อปี

คำถามที่พบบ่อย

VPS RAM 1 GB พอสำหรับ MT5 ไหม?

สำหรับ Windows VPS มักตึงมาก เพราะ Windows ใช้หน่วยความจำส่วนหนึ่งไปก่อนเปิดโปรแกรมใด ๆ วิธีตอบให้แน่คือวัดตามขั้นตอนในบทความนี้ ถ้าผลรวมเกินหรือใกล้ 1 GB ก็ไม่พอ

ต้องใช้ CPU กี่ vCPU?

ขึ้นกับจำนวน MT5 และความหนักของ EA ไม่มีตัวเลขกลาง ให้เริ่มจากแพ็กเกจที่ RAM พอ แล้วดูกราฟ CPU ช่วงตลาดคึกคักในสัปดาห์แรก ถ้าค้างที่ระดับสูงบ่อย ค่อยเพิ่ม vCPU

EA WING ต้องใช้ VPS สเปกเท่าไหร่?

ขึ้นกับจำนวนบัญชีและกราฟที่คุณเปิดบนเครื่องเดียวกัน ให้วัดตามขั้นตอนในบทความ หรือส่งภาพแท็บ Performance ของ Task Manager พร้อมจำนวนบัญชีที่จะรันมาให้ทีมงานช่วยดูทาง LINE ได้

สเปกสูงขึ้นทำให้ EA เทรดได้ดีขึ้นไหม?

ไม่ สเปกที่พอทำให้ MT5 ทำงานลื่นและไม่ค้าง เมื่อพอแล้ว การเพิ่มสเปกไม่ได้เปลี่ยนกลยุทธ์หรือผลการเทรด และไม่ได้ลดความเสี่ยงของตลาด

คำเตือนความเสี่ยง: สเปก VPS ที่เหมาะช่วยให้ EA ทำงานต่อเนื่อง แต่ไม่ได้ทำให้ผลการเทรดดีขึ้น การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต การเพิ่มจำนวนบัญชีบนเครื่องเดียวกันก็เพิ่มเงินที่อยู่ในความเสี่ยงรวม อ่านข้อควรรู้เรื่องความเสี่ยงของ EAก่อนใช้เงินจริง

อ่านต่อ

  • VPS สำหรับ EA: เลือก ตั้งค่า ดูแล
  • VPS Forex เจ้าไหนดี: เกณฑ์เลือก
  • เปิด MT5 หลายตัวบน VPS เครื่องเดียว
  • MT5 Journal: อ่าน Log หาสาเหตุ

ได้ขนาดเครื่องที่ต้องการแล้ว ขั้นต่อไปคือเชื่อมต่อและตั้ง MT5 บนเครื่องใหม่ตามคู่มือใช้ VPS รัน EA บน Windows ถ้าวัดแล้วยังไม่แน่ใจกับตัวเลข ส่งภาพ Task Manager มาให้ทีมงานช่วยอ่านได้
