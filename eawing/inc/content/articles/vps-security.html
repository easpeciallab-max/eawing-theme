VPS ปลอดภัยแค่ไหน ขึ้นกับการตั้งค่าของคุณมากกว่ายี่ห้อของผู้ให้บริการ เครื่องที่ใช้รัน EA เปิดรับการเชื่อมต่อจาก Remote Desktop ตลอดเวลา และมี MT5 ที่ล็อกอินบัญชีเทรดค้างไว้ ใครเข้าเครื่องได้ก็ส่งคำสั่งซื้อขายในบัญชีคุณได้ หน้านี้รวมขั้นตอนที่ทำได้เองโดยไม่ต้องเป็นผู้เชี่ยวชาญ ส่วนเรื่องการเลือกเครื่องและดูแลด้านอื่นอยู่ในคู่มือ เลือก ตั้งค่า และดูแล VPS สำหรับ EA

สรุปสั้น: เปลี่ยนรหัสเริ่มต้นเป็นรหัสยาวที่ไม่ซ้ำกับที่อื่น · เปิด Network Level Authentication · ตั้งให้บัญชีล็อกเมื่อใส่รหัสผิดหลายครั้ง · ป้องกันบัญชีแผงควบคุมของผู้ให้บริการด้วยการยืนยันสองขั้นตอน · ติดตั้งเฉพาะโปรแกรมที่จำเป็น · อัปเดต Windows ตามรอบ · แชร์พอร์ตด้วยรหัส Investor ไม่ใช่รหัสหลัก

VPS ที่ใช้เทรดเสี่ยงตรงไหน

ก่อนจะตั้งค่าอะไร ดูภาพรวมก่อนว่าคนร้ายเข้าทางไหนได้บ้าง และแต่ละทางป้องกันด้วยอะไร

ช่องทางสิ่งที่อีกฝ่ายได้ป้องกันหลักด้วย
เดารหัส Remote Desktop ซ้ำ ๆ จากอินเทอร์เน็ตเข้าเครื่องได้ทั้งเครื่องรหัสยาว NLA และการล็อกบัญชี
รหัสรั่วจากแชต อีเมล หรือภาพหน้าจอเข้าเครื่องได้โดยไม่ต้องเดาไม่ส่งรหัสทางแชต เก็บในโปรแกรมจัดการรหัสผ่าน
บัญชีแผงควบคุมของผู้ให้บริการรีเซ็ตรหัส เปิดหน้าจอ Console หรือลงระบบใหม่รหัสไม่ซ้ำและการยืนยันสองขั้นตอน
โปรแกรมหรือ EA จากแหล่งที่ไม่น่าไว้ใจโปรแกรมแฝงทำงานบนเครื่องที่ล็อกอินบัญชีเทรดติดตั้งเฉพาะที่จำเป็นจากแหล่งที่รู้ที่มา
เครื่องเก่าที่เลิกใช้แต่ไม่ได้ล้างรหัสบัญชีเทรดที่บันทึกค้างไว้ลบบัญชีออกจาก MT5 ก่อนยกเลิกเครื่อง

รหัสผ่าน: ข้อแรกที่ทำให้ VPS ปลอดภัย

รหัสที่ผู้ให้บริการส่งมาทางอีเมลควรเปลี่ยนตั้งแต่ครั้งแรกที่เข้าเครื่อง Microsoft แนะนำรหัสยาวอย่างน้อย 12 ตัวอักษร และยิ่งยาวถึง 14 ตัวขึ้นไปยิ่งดี ผสมตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และสัญลักษณ์ ไม่ใช่คำในพจนานุกรม และไม่ซ้ำกับรหัสที่เคยใช้

  1. เปิดหน้าจอความปลอดภัยใน Remote Desktop

    ระหว่างอยู่ในเครื่อง VPS กด Ctrl + Alt + End ซึ่งทำหน้าที่เหมือน Ctrl + Alt + Delete ของเครื่องปลายทาง

  2. เลือก Change a password

    ใส่รหัสเดิมหนึ่งครั้ง รหัสใหม่สองครั้ง แล้วกด Enter

  3. บันทึกรหัสใหม่ในโปรแกรมจัดการรหัสผ่าน

    ก่อนปิดหน้าต่าง ตรวจว่าบันทึกแล้วจริง แล้วลองตัดการเชื่อมต่อและเข้าใหม่ด้วยรหัสใหม่หนึ่งครั้ง

แยกรหัสสามชุดที่คนมักใช้ซ้ำ

รหัสใช้ทำอะไรถ้ารั่ว
รหัสเข้า VPSRemote Desktop เข้าเครื่องควบคุมเครื่องและ MT5 ได้ทั้งหมด
รหัสแผงควบคุมของผู้ให้บริการจัดการเครื่อง รีเซ็ตรหัส ลงระบบใหม่ยึดเครื่องหรือเปิดหน้าจอ Console ได้
รหัสผ่านหลักของบัญชี MT5ล็อกอินเพื่อเทรดส่งคำสั่งซื้อขายในบัญชีได้จากเครื่องไหนก็ได้

สามรหัสนี้ต้องไม่ซ้ำกัน และไม่ซ้ำกับอีเมลหรือโซเชียล ถ้าสงสัยว่ารหัสบัญชีเทรดรั่ว ขั้นตอนเปลี่ยนอยู่ในบทความเปลี่ยนรหัสผ่าน MT5

เปิด Network Level Authentication

Network Level Authentication หรือ NLA บังคับให้ยืนยันตัวตนก่อนเครื่องจะสร้างหน้าจอรีโมตให้ เอกสารการเปิดใช้ Remote Desktop ของ Microsoft แนะนำให้เปิดไว้ในเกือบทุกกรณี และย้ำว่าทุกบัญชีที่เข้ารีโมตได้ต้องมีรหัสที่แข็งแรงและไม่ซ้ำ VPS ส่วนใหญ่เปิด NLA มาแล้ว แต่ควรตรวจเอง

  • Windows 11 และ Windows Server รุ่นใหม่: Settings → System → Remote Desktop กดขยายหัวข้อแล้วดูว่าติ๊ก Require devices to use Network Level Authentication to connect ไว้
  • Windows Server ที่ใช้หน้าต่าง System Properties: แท็บ Remote ต้องเลือก Allow connections only from computers running Remote Desktop with Network Level Authentication
  • ผ่าน SConfig: เมนู Remote desktop เลือกเปิดสำหรับไคลเอนต์ที่รองรับ NLA

แอป Remote Desktop Connection บน Windows และแอป Windows App บนมือถือรองรับ NLA อยู่แล้ว เปิดไว้จึงไม่กระทบการใช้งานปกติ

ให้บัญชีล็อกเมื่อใส่รหัสผิดหลายครั้ง

บอทบนอินเทอร์เน็ตไล่เดารหัส Remote Desktop ของเครื่องที่เปิดอยู่ตลอดเวลา การล็อกบัญชีชั่วคราวหลังใส่ผิดหลายครั้งทำให้การเดาช้าลงจนไม่คุ้ม บทความKB5020282 ของ Microsoft อธิบายว่าอัปเดตตั้งแต่เดือนตุลาคม 2022 ทำให้ล็อกบัญชี Administrator ในตัวเครื่องได้ด้วย และแนะนำค่าพื้นฐาน 10/10/10

  1. ดูค่าปัจจุบัน

    เปิด Command Prompt แล้วพิมพ์ net accounts ดูบรรทัด Lockout threshold ถ้าเป็น Never แปลว่ายังไม่ได้ตั้ง

  2. เปิด Local Security Policy

    กด Windows + R พิมพ์ secpol.msc แล้วไปที่ Account Policies → Account Lockout Policy

  3. ตั้งค่าตามแนวทาง 10/10/10

    Account lockout threshold 10 ครั้ง Account lockout duration 10 นาที และ Reset account lockout counter after 10 นาที ถ้าใช้บัญชี Administrator ในตัวเครื่อง ให้เปิด Allow Administrator account lockout ด้วย

  4. ทดสอบโดยมีทางสำรอง

    เปิดหน้าจอ Console ในแผงควบคุมของผู้ให้บริการไว้ก่อน ตามเอกสารของ Microsoft การล็อกนี้มีผลกับการล็อกอินผ่านเครือข่าย ส่วนการล็อกอินที่หน้าเครื่องยังใช้ได้

ถ้าวันหนึ่งคุณพิมพ์รหัสผิดจนล็อกเอง ไม่ต้องตกใจ รอให้ครบเวลาที่ตั้งไว้แล้วลองใหม่ หรือเข้าผ่าน Console วิธีไล่สาเหตุเมื่อรีโมตไม่ติดอยู่ในบทความเข้า VPS ไม่ได้ แก้ทีละอาการ

จำกัดทางเข้าให้แคบลง

ขั้นนี้เพิ่มความปลอดภัยได้มาก แต่ถ้าตั้งผิดอาจล็อกตัวเองออกจากเครื่อง ทำเมื่อเข้าใจแล้วเท่านั้น และเปิด Console สำรองไว้เสมอ

  • จำกัด IP ที่เข้ารีโมตได้ ถ้าคุณใช้เน็ตที่มี IP คงที่ ให้ผู้ให้บริการหรือไฟร์วอลล์ของ Windows รับการเชื่อมต่อ Remote Desktop เฉพาะจาก IP นั้น เน็ตบ้านส่วนใหญ่ในไทยเปลี่ยน IP เป็นระยะ วิธีนี้จึงอาจไม่สะดวก
  • เปลี่ยนพอร์ต Remote Desktop ช่วยลดการสแกนแบบหว่านแห ซึ่งทำให้ Log สะอาดขึ้น แต่ไม่ได้แทนรหัสที่แข็งแรง ถ้าจะเปลี่ยน ให้ถามผู้ให้บริการก่อน เพราะต้องเปิดพอร์ตใหม่ในไฟร์วอลล์ด้วย
  • ใช้ชื่อผู้ใช้ที่เดายาก บอทมักลองชื่อ Administrator ก่อน ผู้ใช้ที่คล่องแล้วอาจสร้างผู้ใช้ใหม่ชื่ออื่นไว้ใช้งานแทน

ป้องกันบัญชีแผงควบคุมของผู้ให้บริการ

คนส่วนใหญ่ดูแลรหัส VPS ดี แต่ลืมว่าบัญชีที่ใช้เช่าเครื่องมีอำนาจมากกว่านั้น ผ่านแผงควบคุมคนร้ายรีเซ็ตรหัสเครื่อง เปิดหน้าจอ Console หรือสั่งลงระบบใหม่ได้

  • เปิดการยืนยันสองขั้นตอน ถ้าผู้ให้บริการมีให้ใช้
  • ใช้รหัสที่ไม่ซ้ำกับรหัสเข้าเครื่องหรือรหัสอีเมล
  • ดูแลอีเมลที่ผูกกับบัญชีด้วย เพราะใครคุมอีเมลได้ก็ขอรีเซ็ตรหัสแผงควบคุมได้
  • ถ้าตั้งให้ Windows ล็อกอินเองหลังบูต หน้าจอ Console จะแสดงเดสก์ท็อปที่ล็อกอินอยู่ การป้องกันแผงควบคุมจึงสำคัญขึ้นอีก ข้อแลกเปลี่ยนนี้อธิบายไว้ในบทความตั้งให้ MT5 เปิดเองหลังรีสตาร์ต

ติดตั้งเฉพาะสิ่งที่จำเป็น

VPS ที่ใช้เทรดควรมีของน้อยที่สุด ทุกโปรแกรมที่เพิ่มเข้ามาคือประตูอีกบาน

  • เปิดเว็บทั่วไป เช็กอีเมล หรือดาวน์โหลดไฟล์แนบบนเครื่องที่ล็อกอินบัญชีเทรด
  • ลง EA หรืออินดิเคเตอร์ที่ได้มาจากกลุ่มแชตโดยไม่รู้ที่มา โดยเฉพาะตัวที่ขอให้ติ๊ก Allow DLL imports
  • ลงโปรแกรมรีโมตตัวอื่นเพิ่มตามคำแนะนำของคนที่ไม่รู้จัก
  • ปิด Microsoft Defender Antivirus เพื่อให้โปรแกรมบางตัวทำงานได้

EA ที่ดีมาจากผู้ขายที่ตรวจสอบได้ และอธิบายได้ว่าทำไมต้องใช้สิทธิ์อะไร สัญญาณของผู้ขายที่ไม่น่าไว้ใจรวมไว้ในบทความบอทเทรดหลอก: สัญญาณเตือน

อัปเดตและตรวจร่องรอยการล็อกอิน

แพตช์ความปลอดภัยของ Windows ปิดช่องโหว่ที่ถูกเปิดเผยแล้ว เครื่องที่ไม่อัปเดตจึงเสี่ยงขึ้นทุกเดือน ทางที่ดีคือให้อัปเดตเข้ามาครบ แต่จัดเวลาติดตั้งเองช่วงตลาดปิด วิธีตั้งอยู่ในบทความจัดรอบ Windows Update บน VPS

ส่วนการตรวจร่องรอย ทำเดือนละครั้งก็พอ เปิด Event Viewer ไปที่ Windows Logs → Security เลือก Filter Current Log แล้วใส่ Event ID 4625 ซึ่งหมายถึงการล็อกอินที่ล้มเหลว ถ้าเห็นจำนวนมากจาก IP ที่ไม่รู้จัก แปลว่าเครื่องถูกลองเดารหัสอยู่ ให้ตรวจว่ารหัสแข็งแรงและการล็อกบัญชีเปิดอยู่

สัญญาณว่าเครื่องอาจถูกเข้าถึง

  • มีโปรแกรมหรือผู้ใช้ใหม่ที่คุณไม่ได้สร้าง
  • รหัสเข้าเครื่องใช้ไม่ได้ทั้งที่ไม่ได้เปลี่ยน
  • มีออเดอร์ในบัญชีที่ไม่ได้มาจาก EA หรือจากคุณ

ถ้าเจอ ให้เปลี่ยนรหัสผ่านหลักของบัญชีเทรดจากอุปกรณ์อื่นที่ไว้ใจทันที แจ้งผู้ให้บริการ VPS และติดต่อโบรกเกอร์

แชร์พอร์ตโดยไม่ต้องให้รหัสหลัก

ถ้าอยากให้คนในครอบครัวหรือทีมงานดูผลพอร์ต ใช้รหัส Investor ซึ่งดูได้อย่างเดียว ส่งคำสั่งซื้อขายไม่ได้ อย่าให้รหัสผ่านหลักหรือรหัสเข้า VPS กับใคร

สำหรับผู้ใช้ EA WING การขอสิทธิ์ใช้งานใช้แค่เลขบัญชี MT5 และชื่อเซิร์ฟเวอร์ ส่งให้ทีมงานทาง LINE โดยไม่ต้องแนบรหัสผ่านใด ๆ และเวลาขอให้ช่วยดูปัญหา ภาพหน้าจอกราฟกับแท็บ Experts ก็เพียงพอ

คำถามที่พบบ่อยเรื่อง VPS ปลอดภัย

เปลี่ยนพอร์ต Remote Desktop แล้วปลอดภัยพอหรือยัง?

ยังไม่พอ การเปลี่ยนพอร์ตลดการสแกนแบบสุ่ม แต่คนที่ตั้งใจหาเครื่องยังเจอพอร์ตใหม่ได้ สิ่งที่ป้องกันจริงคือรหัสที่ยาวและไม่ซ้ำ NLA และการล็อกบัญชีเมื่อเดาผิด

ต้องลงโปรแกรมแอนตี้ไวรัสเพิ่มบน VPS ไหม?

สำหรับเครื่องที่ใช้รัน MT5 อย่างเดียว Microsoft Defender Antivirus ที่มากับ Windows ก็เพียงพอสำหรับคนส่วนใหญ่ ตรวจใน Windows Security ว่าเปิดอยู่ การไม่ลงโปรแกรมที่ไม่จำเป็นช่วยได้มากกว่าการเพิ่มโปรแกรมป้องกันหลายตัว

ถ้าต้องให้คนอื่นเข้าเครื่องเพื่อช่วยติดตั้ง ควรทำยังไง?

ตั้งรหัสชั่วคราวสำหรับงานนั้น ให้เฉพาะคนที่คุณยืนยันตัวตนได้ และเปลี่ยนรหัสใหม่ทันทีหลังงานเสร็จ อย่าส่งรหัสผ่านหลักของบัญชีเทรดไปด้วย เพราะการติดตั้ง EA ไม่จำเป็นต้องใช้

จะรู้ได้ยังไงว่ามีคนพยายามเข้า VPS ของเรา?

ดู Event ID 4625 ใน Event Viewer ส่วน Security ถ้ามีการล็อกอินล้มเหลวจำนวนมากจาก IP ที่ไม่รู้จัก แปลว่ามีการลองเดารหัส ซึ่งพบได้ทั่วไปกับเครื่องที่เปิดรับ Remote Desktop ให้มั่นใจว่ารหัสแข็งแรงและการล็อกบัญชีเปิดอยู่

อ่านต่อ

  • ภาพรวม VPS สำหรับ EA
  • ตั้งรอบอัปเดต Windows บน VPS
  • แก้เข้า VPS ไม่ได้
  • สัญญาณเตือนบอทเทรดหลอก

ถ้ายังไม่ได้เข้าเครื่องครั้งแรก เริ่มจากวิธีเข้า Windows VPS ด้วย Remote Desktop แล้วเปลี่ยนรหัสและตั้งค่าตามหน้านี้ตั้งแต่วันแรก มีคำถามเรื่องการดูแลเครื่อง ทักทีมงานได้ โดยไม่ต้องส่งรหัสผ่านใด ๆ
