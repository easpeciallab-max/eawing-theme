การย้าย EA VPS จากเครื่องเก่าไปเครื่องใหม่ หรือจากคอมที่บ้านขึ้น VPS ครั้งแรก ใช้เวลาไม่นาน แต่มีสองจุดที่พลาดกันบ่อย คือปล่อยให้ EA ทำงานอยู่สองเครื่องพร้อมกัน และยกเลิกเครื่องเก่าก่อนยืนยันว่าเครื่องใหม่ใช้ได้จริง หน้านี้แบ่งงานเป็นสามช่วง เตรียม สลับ และตรวจ ส่วนเกณฑ์เลือกเครื่องใหม่และการดูแลระยะยาวอยู่ในคู่มือ คู่มือ VPS สำหรับรัน EA ฉบับเต็ม

สรุปสั้น: จดค่าจากเครื่องเก่าก่อน · ตั้งเครื่องใหม่ให้พร้อมทุกอย่าง แต่ปิดปุ่ม Algo Trading ไว้ · ย้ายช่วงตลาดปิด · ปิด EA บนเครื่องเก่าก่อน แล้วค่อยเปิดบนเครื่องใหม่ · ตรวจหลังตลาดเปิดอย่างน้อยหนึ่งถึงสองวัน · ค่อยยกเลิกและล้างข้อมูลเครื่องเก่า

ย้าย EA VPS เพราะอะไร และควรย้ายเมื่อไร

เหตุผลที่คนย้ายเครื่องมีไม่กี่แบบ รู้เหตุผลชัดจะช่วยให้ตรวจได้ว่าเครื่องใหม่แก้ปัญหาเดิมจริง

เหตุผลสิ่งที่ต้องวัดบนเครื่องใหม่
ค่า Ping ถึงเซิร์ฟเวอร์โบรกเกอร์สูงค่า Ping มุมขวาล่างของ MT5 บนเครื่องใหม่ในหลายช่วงเวลา
เครื่องเดิมค้างหรือช้าCPU และ Memory ใน Task Manager ช่วงตลาดคึกคัก
หลุดบ่อยหรือซัพพอร์ตตอบช้าจำนวนครั้งที่หลุดใน Journal หลังย้าย
ย้ายจากคอมที่บ้านขึ้น VPS ครั้งแรกEA ทำงานต่อเนื่องโดยไม่ต้องเปิดคอมที่บ้าน
ค่าเช่าแพงเกินจำเป็นเครื่องใหม่ยังมีทรัพยากรเหลือพอหลังใช้งานจริง

ถ้าย้ายเพราะความหน่วง ให้เข้าใจก่อนว่าตัวเลขไหนวัดอะไร อ่านประกอบได้ในVPS Ping และ Latency สำคัญกับ EA แค่ไหน

ส่วนเวลาที่เหมาะที่สุดคือช่วงตลาดปิดสุดสัปดาห์ เพราะ EA หยุดสั้น ๆ แล้วไม่มีผล และมีเวลาแก้ถ้าติดขัด อย่าเริ่มย้ายตอนใกล้ตลาดเปิดวันจันทร์ หรือในวันที่มีข่าวสำคัญ

ช่วงที่ 1: จดค่าจากเครื่องเก่า

ก่อนแตะอะไร เปิดเครื่องเก่าแล้วเก็บข้อมูลเหล่านี้ไว้ในที่ปลอดภัย

  • เลขบัญชีและชื่อเซิร์ฟเวอร์ ของทุกบัญชีที่รันอยู่ ดูได้จาก Navigator หรือแถบชื่อหน้าต่าง MT5
  • ชื่อสัญลักษณ์และกรอบเวลา รวมตัวต่อท้ายชื่อ เช่น XAUUSD.c และกรอบเวลาของกราฟที่มี EA
  • ชื่อและเวอร์ชันของไฟล์ EA ที่ใช้อยู่จริง ไม่ใช่ไฟล์ที่อยู่ในโฟลเดอร์ดาวน์โหลด
  • ภาพแท็บ Inputs คลิกบนกราฟ กด F7 แล้วถ่ายภาพค่าทุกหน้า สำหรับ EA ที่มีค่าให้ปรับ
  • สถานะออเดอร์ที่เปิดอยู่ ถ่ายภาพแท็บ Trade ไว้เป็นหลักฐาน
  • ค่าใน Tools → Options โดยเฉพาะแท็บ Expert Advisors

ไฟล์ที่ควรคัดลอก และไฟล์ที่ไม่ต้อง

หลายคนคัดลอกทั้ง Data Folder ไปวางเครื่องใหม่ วิธีนี้พาไฟล์ที่ไม่จำเป็นและการตั้งค่าที่อาจขัดกันติดไปด้วย เอกสารโครงสร้างไฟล์และโฟลเดอร์ของ MT5 แสดงว่าแต่ละส่วนเก็บอะไร เลือกคัดลอกเฉพาะส่วนที่ต้องใช้

ไฟล์หรือโฟลเดอร์ (ใน Data Folder)คัดลอกไหมเหตุผล
ไฟล์ EA ใน MQL5 → Expertsคัดลอก หรือใช้ไฟล์จากชุดติดตั้งต้นฉบับตัว EA ที่ต้องใช้
เทมเพลตที่สร้างเอง (.tpl) ใน MQL5 → Profiles → Templatesคัดลอกถ้ามีได้หน้าตากราฟเดิม
โปรไฟล์ใน MQL5 → Profiles → Chartsคัดลอกได้ถ้าอยากได้ชุดกราฟเดิมโปรไฟล์เก็บกราฟและ EA ที่ติดอยู่บนกราฟ
Logs และข้อมูลราคาในโฟลเดอร์ Basesไม่ต้องไฟล์ใหญ่ เครื่องใหม่โหลดราคาเองได้

ส่งไฟล์ขึ้นเครื่องใหม่ได้สองทาง ทางแรกคือคัดลอกแล้ววางผ่าน Remote Desktop ซึ่งใช้ได้เมื่อเปิด Clipboard ไว้ในแท็บ Local Resources ทางที่สองคือแชร์ไดรฟ์ ในหน้าต่าง Remote Desktop Connection กด Show Options แท็บ Local Resources กด More แล้วติ๊กไดรฟ์ที่มีไฟล์ จากนั้นเปิดไฟล์จากไดรฟ์นั้นบน VPS ได้เลย

ช่วงที่ 2: เตรียมเครื่องใหม่ให้พร้อม แต่ยังไม่เปิดเทรด

ทำทั้งหมดนี้ขณะที่เครื่องเก่ายังทำงานตามปกติ เครื่องใหม่จะพร้อมสลับได้ในไม่กี่นาที

  1. ตั้งค่าพื้นฐานของ Windows

    เปลี่ยนรหัสผ่านเริ่มต้น ตั้งโซนเวลาเป็นเวลาไทย และตั้งเวลา Windows Update ไม่ให้รีสตาร์ทกลางตลาดเปิด

  2. ติดตั้ง MT5 และล็อกอิน

    ใช้ตัวติดตั้งของโบรกเกอร์ ล็อกอินด้วยรหัสผ่านหลักและติ๊ก Save password ขั้นตอนละเอียดอยู่ใน วิธีล็อกอินบัญชี MT5

  3. ปิดปุ่ม Algo Trading ก่อน

    กดให้ปุ่มบนแถบเครื่องมือเป็นสีแดงไว้ก่อน ขั้นนี้คือตัวกันไม่ให้ EA บนเครื่องใหม่ส่งคำสั่งซ้อนกับเครื่องเก่า

  4. วางไฟล์ EA และตั้ง Options

    วางไฟล์ใน File → Open Data Folder → MQL5 → Experts คลิกขวาใน Navigator แล้วเลือก Refresh จากนั้น Tools → Options แท็บ Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports ถ้า EA ต้องใช้ DLL เหตุผลที่ควรเปิด DLL เฉพาะ EA ที่ไว้ใจอยู่ในบทความความหมายของ Allow DLL imports

  5. เปิดกราฟและแนบ EA

    เปิดกราฟสัญลักษณ์และกรอบเวลาเดิมตามที่จดไว้ ลาก EA ลงกราฟ ตั้งค่าในแท็บ Inputs ให้ตรงกับภาพที่ถ่ายไว้ ตัว EA จะยังไม่ส่งคำสั่งเพราะปุ่ม Algo Trading ปิดอยู่

  6. ตั้งให้ MT5 เปิดเองหลังรีสตาร์ท

    เครื่องใหม่ควรพร้อมรับการรีสตาร์ทตั้งแต่วันแรก วิธีตั้งอยู่ในบทความMT5 เปิดอัตโนมัติหลัง VPS รีสตาร์ท

ช่วงที่ 3: สลับเครื่องในจังหวะเดียว

หัวใจของการย้าย EA VPS คือช่วงนี้ ลำดับสำคัญกว่าความเร็ว ให้มี EA ทำงานกับบัญชีหนึ่งอยู่ที่เดียวเสมอ

  1. หยุด EA บนเครื่องเก่า

    กดปุ่ม Algo Trading ให้เป็นสีแดง หรือถอด EA ออกจากกราฟ แล้วปิด MT5 บนเครื่องเก่าด้วย File → Exit

  2. ยืนยันว่าเครื่องเก่าหยุดจริง

    ดูแท็บ Journal ของเครื่องเก่าก่อนปิด หรือดูจากแอปมือถือว่าไม่มีคำสั่งใหม่จากเครื่องนั้น

  3. เปิด Algo Trading บนเครื่องใหม่

    ปุ่มเป็นสีเขียว ไอคอนข้างชื่อ EA ที่มุมขวาบนของกราฟเป็นสีฟ้า

  4. ดูแท็บ Experts และ Journal

    ต้องไม่มีข้อความผิดพลาดตอนโหลด EA ถ้าพบ ให้แก้ก่อน อย่าเพิ่งเปิดเครื่องเก่ากลับมาพร้อมกัน

มีออเดอร์ของ EA เปิดค้างอยู่: EA แต่ละตัวจัดการออเดอร์เดิมหลังย้ายเครื่องต่างกัน บางตัวรับช่วงต่อได้ บางตัวต้องเริ่มใหม่หลังออเดอร์ชุดเดิมปิด ถามผู้พัฒนา EA ก่อนย้ายทุกครั้ง ผู้ใช้ EA WING ส่งภาพแท็บ Trade ถามทีมงานทาง LINE ก่อนเริ่มช่วงที่ 3

สำหรับผู้ใช้ EA WING

สิทธิ์ใช้งาน EA WING ผูกกับเลขบัญชี MT5 ถ้าย้ายเครื่องแต่ใช้บัญชีเดิม การ์ดล็อกอินบนแดชบอร์ดควรกลับมาเป็นสีเขียวหลัง EA ตรวจสิทธิ์ ถ้าเปลี่ยนไปใช้เลขบัญชีใหม่ ต้องส่งเลขบัญชีและชื่อเซิร์ฟเวอร์ใหม่ให้ทีมงานก่อน แล้วรอการเปิดสิทธิ์ ซึ่งปกติเสร็จภายในประมาณ 5 นาที วิธีที่ระบบสิทธิ์แบบนี้ทำงานอธิบายไว้ในบทความระบบสิทธิ์ EA ที่ผูกเลขบัญชี

  • ใช้ไฟล์ EA_WING_V4.2.ex5 จากชุดติดตั้งต้นฉบับ ไม่ต้องใช้ไฟล์ .set
  • แนบบนกราฟ XAUUSD M1 ตามชื่อสัญลักษณ์ในบัญชีของคุณ
  • ติ๊ก Allow DLL imports ทั้งใน Options และแท็บ Common ตอนแนบ EA
  • จดไว้ว่าเครื่องเก่าใช้โหมด Lite หรือ Full ถ้าเคยเปลี่ยนจากค่าเริ่มต้น ถามทีมงานก่อนเปิดใช้บนเครื่องใหม่

ขั้นตอนเต็มทุกขั้นอยู่ในหน้า ติดตั้ง EA WING พร้อมภาพหน้าจอ

ตรวจหลังย้าย หนึ่งถึงสองวันแรก

อย่าเพิ่งยกเลิกเครื่องเก่าทันทีที่เห็นปุ่มสีเขียว ให้เครื่องใหม่ผ่านตลาดเปิดจริงก่อน

  • วันแรกหลังตลาดเปิด ดูว่า EA ทำงานตามจังหวะปกติของมัน และ Journal ไม่มีการหลุดบ่อย
  • เทียบค่า Ping และการใช้ CPU กับเหตุผลที่ย้าย ว่าดีขึ้นจริง
  • ลองรีสตาร์ทเครื่องใหม่หนึ่งครั้งช่วงตลาดปิด แล้วดูว่า MT5 และ EA กลับมาเอง
  • ตั้งแจ้งเตือน MT5 บนมือถือใหม่ ถ้าเคยผูกไว้กับเครื่องเก่า

เก็บกวาดเครื่องเก่าให้เรียบร้อย

เครื่องเก่ายังมีรหัสผ่านบัญชีเทรดที่บันทึกไว้ ถ้าปล่อยไว้แล้วลืม เท่ากับมีกุญแจบ้านสำรองวางทิ้งไว้ข้างนอก

  1. ลบบัญชีออกจาก MT5 บนเครื่องเก่า

    ใน Navigator คลิกขวาที่บัญชีแล้วลบออก เพื่อลบรหัสที่จำไว้

  2. ถอนการติดตั้ง MT5 และลบไฟล์ EA

    รวมไฟล์ที่ดาวน์โหลดไว้บนเดสก์ท็อปหรือโฟลเดอร์ดาวน์โหลด

  3. ยกเลิกเครื่องกับผู้ให้บริการ

    ถามว่ามีการลบข้อมูลในดิสก์หลังยกเลิกหรือไม่ ถ้าไม่แน่ใจ พิจารณาเปลี่ยนรหัสผ่านหลักของบัญชีเทรด แล้วอัปเดตรหัสใหม่บนเครื่องใหม่

การดูแลรหัสผ่านและความปลอดภัยของเครื่องใหม่ตั้งแต่วันแรก อ่านต่อได้ในตั้งรหัสและความปลอดภัย VPS สำหรับเทรด

ข้อผิดพลาดที่พบบ่อยตอนย้าย EA

  • เปิด Algo Trading บนเครื่องใหม่ขณะที่เครื่องเก่ายังทำงาน ออเดอร์ซ้อนกันสองชุด
  • ย้ายช่วงตลาดเปิดแล้วติดปัญหา ต้องแก้ไปขณะที่ราคาวิ่ง
  • ลืมติ๊ก DLL หรือ Algo Trading ในแท็บ Common บนเครื่องใหม่ เพราะคิดว่าค่าตามมาจากเครื่องเก่า
  • แนบ EA ผิดสัญลักษณ์ เพราะเครื่องใหม่เปิดกราฟชื่อที่ไม่มีตัวต่อท้าย
  • ยกเลิกเครื่องเก่าวันเดียวกับที่ย้าย แล้วไม่มีที่ถอยถ้าเครื่องใหม่มีปัญหา

คำเตือนความเสี่ยง: ระหว่างย้ายเครื่อง EA อาจหยุดชั่วขณะ และออเดอร์ที่เปิดค้างยังได้หรือเสียตามราคา การปล่อยให้ EA ทำงานสองเครื่องพร้อมกันเพิ่มความเสี่ยงของบัญชีโดยไม่ตั้งใจ การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน หน้าความเสี่ยงการเทรด ก่อนใช้เงินจริง

คำถามที่พบบ่อยเรื่องย้าย EA VPS

ย้ายเครื่องแล้วต้องขอสิทธิ์ใช้งาน EA ใหม่ไหม?

ขึ้นกับระบบสิทธิ์ของ EA ตัวนั้น สำหรับ EA WING สิทธิ์ผูกกับเลขบัญชี MT5 ถ้ายังใช้บัญชีเดิม ให้ดูการ์ดล็อกอินว่าเป็นสีเขียว ถ้าไม่เป็น หรือเปลี่ยนไปใช้บัญชีใหม่ ส่งเลขบัญชีและชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE

เปิด MT5 บัญชีเดียวกันทั้งสองเครื่องระหว่างทดสอบได้ไหม?

ล็อกอินพร้อมกันได้ แต่ให้มี EA ทำงานอยู่ที่เดียว อีกเครื่องปิดปุ่ม Algo Trading ไว้หรือไม่ต้องแนบ EA ถ้าแค่อยากดูยอด ใช้แอปมือถือจะง่ายกว่า

คัดลอกทั้งโฟลเดอร์ MT5 ไปเครื่องใหม่แทนการติดตั้งใหม่ได้ไหม?

ไม่แนะนำ การติดตั้งใหม่จากตัวติดตั้งของโบรกเกอร์แล้วคัดลอกเฉพาะไฟล์ EA เทมเพลต และโปรไฟล์ ทำให้รู้ชัดว่าเครื่องใหม่มีอะไรบ้าง และตัดปัญหาการตั้งค่าเก่าที่อาจไม่เข้ากับเครื่องใหม่

ควรเก็บเครื่องเก่าไว้นานแค่ไหนหลังย้าย?

อย่างน้อยจนเครื่องใหม่ผ่านตลาดเปิดจริงหนึ่งถึงสองวันโดยไม่มีปัญหา และผ่านการทดสอบรีสตาร์ทหนึ่งครั้ง ถ้ารอบบิลของเครื่องเก่าใกล้ครบ วางแผนย้ายล่วงหน้าให้มีช่วงทับซ้อนนี้

อ่านต่อ

  • เลือกและดูแล VPS สำหรับรัน EA
  • ตั้ง MT5 ให้เปิดเองบนเครื่องใหม่
  • ความปลอดภัยของ VPS เครื่องใหม่
  • วิธีติดตั้ง EA WING บน MT5

ขั้นตอนเข้าเครื่องใหม่และติดตั้ง MT5 แบบเห็นทุกหน้าจออยู่ในคู่มือ VPS บน Windows ถ้ามีออเดอร์เปิดค้างหรือไม่แน่ใจลำดับขั้น ทักทีมงานก่อนเริ่มย้ายได้
