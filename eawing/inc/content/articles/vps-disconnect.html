เข้า VPS ไม่ได้ หรือ Remote Desktop หลุดทุกไม่กี่นาที เป็นเรื่องที่ทำให้คนใช้ EA ใจเสียมาก เพราะมองไม่เห็นว่า MT5 บนเครื่องนั้นยังทำงานอยู่หรือเปล่า ข่าวดีคือส่วนใหญ่ปัญหาอยู่ที่เส้นทางระหว่างคุณกับ VPS ไม่ใช่ตัว VPS และแก้ได้เองโดยไล่ตามข้อความที่ขึ้นทีละข้อ ถ้ายังไม่คุ้นกับภาพรวมของการใช้ VPS รัน EA อ่านคู่มือหลักประกอบได้

สรุปสั้น: ก่อนแก้ ให้เช็กจากแอป MT5 บนมือถือและแผงควบคุมของผู้ให้บริการว่าเครื่องยังเปิดและบัญชียังเคลื่อนไหว · ต่อไม่ติดเลยให้ดูสถานะเครื่อง IP พอร์ต และลองเน็ตอีกเครือข่าย · รหัสไม่ผ่านให้ดูภาษาแป้นพิมพ์และชื่อผู้ใช้ · หลุดบ่อยให้ลดคุณภาพภาพและเปิดการต่อใหม่อัตโนมัติ · ออกจาก VPS ด้วยการปิดหน้าต่างเสมอ ไม่ใช่ Sign out

ก่อนแก้: เช็กก่อนว่า EA ยังทำงานอยู่ไหม

Remote Desktop เป็นแค่ "จอ" ที่ใช้มองเข้าไปในเครื่อง VPS ถ้าจอนี้ต่อไม่ติด เครื่องข้างในอาจยังทำงานปกติทุกอย่าง ก่อนจะกดรีสตาร์ตอะไร ให้เช็กสองจุดนี้

  • แอป MT5 บนมือถือ ล็อกอินบัญชีเดียวกันไว้ ดูว่ายอด Equity ยังขยับตามราคา และออเดอร์ของ EA ยังเปิดปิดตามปกติ แอปมือถือรัน EA แทนไม่ได้ แต่ใช้ยืนยันว่าบัญชีมีความเคลื่อนไหว รายละเอียดอยู่ในบทความทำไม EA ต้องรันบนคอมหรือ VPS
  • แผงควบคุมของผู้ให้บริการ VPS ดูว่าเครื่องอยู่ในสถานะทำงาน กราฟ CPU ยังมีการใช้งาน และไม่ได้อยู่ระหว่างรีสตาร์ตหรือติดตั้งระบบใหม่

ถ้าทั้งสองจุดดูปกติ แปลว่าไม่ต้องรีบ ค่อย ๆ แก้ตามหัวข้อด้านล่างได้ แต่ถ้าแผงควบคุมบอกว่าเครื่องดับ หรือบัญชีเงียบผิดปกติทั้งที่ตลาดเปิด ให้ข้ามไปหัวข้อ "รีสตาร์ตจากแผงควบคุม" ได้เลย

อ่านข้อความ error แล้วแยกอาการ

ข้อความที่ Remote Desktop แสดงบอกได้ค่อนข้างชัดว่าปัญหาอยู่ชั้นไหน ตารางนี้ช่วยเลือกหัวข้อที่ต้องอ่านต่อ

สิ่งที่เห็นความหมายที่พบบ่อยเริ่มแก้ที่
Remote Desktop can't connect to the remote computer...ไปไม่ถึงเครื่องเลย เครื่องอาจดับ รีสตาร์ต พอร์ตถูกปิด หรือ IP ผิดหัวข้อต่อไม่ติดเลย
Your credentials did not workถึงเครื่องแล้ว แต่ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกหัวข้อรหัสถูกแต่เข้าไม่ได้
บัญชีถูกล็อกใส่รหัสผิดหลายครั้งติดกัน ระบบล็อกบัญชีไว้ชั่วคราวรอตามเวลาที่ระบบกำหนด หรือขอผู้ให้บริการช่วย
ต่อติดแล้วขึ้นแถบ Reconnecting เป็นระยะเน็ตระหว่างคุณกับ VPS ไม่นิ่งหัวข้อ Remote Desktop หลุดบ่อย
ต่อติดแต่จอดำเครื่องกำลังโหลดหน้าจอหรือทำงานหนักมากรอสักครู่ ตัดแล้วต่อใหม่ ถ้าไม่หายดู CPU ในแผงควบคุม

เข้า VPS ไม่ได้เลย: ไล่ทีละจุด

กรณีที่ขึ้นว่าต่อไปยังเครื่องไม่ได้ เอกสารแก้ปัญหา Remote Desktop ต่อไม่ติดของ Microsoft ระบุสาเหตุหลักไว้สามกลุ่ม คือการรีโมตไม่ได้เปิดไว้ เครื่องปลายทางปิดอยู่ หรือเครื่องไม่อยู่บนเครือข่าย สำหรับคนเช่า VPS ไล่ตามลำดับนี้

  1. ดูสถานะในแผงควบคุม

    ถ้าเครื่องกำลังรีสตาร์ต ติดตั้งอัปเดต หรือถูกระงับเพราะค่าบริการ ต่อเข้าไปไม่ได้แน่นอน หลายเจ้ามีปุ่ม Console หรือ VNC ในแผงควบคุม ใช้ดูหน้าจอเครื่องได้โดยไม่ผ่าน Remote Desktop

  2. รอถ้า Windows กำลังอัปเดต

    ช่วงที่ Windows ติดตั้งอัปเดตและรีสตาร์ต การรีโมตจะใช้ไม่ได้ชั่วคราว ถ้าเห็นในหน้า Console ว่ากำลังอัปเดต ให้รอจนเสร็จ ห้ามสั่งปิดเครื่องกลางคัน วิธีกันไม่ให้เหตุการณ์นี้เกิดตอนตลาดเปิดอยู่ในบทความตั้งเวลา Windows Update ไม่ให้ชนตลาดเปิด

  3. ตรวจ IP และพอร์ต

    เทียบ IP กับอีเมลของผู้ให้บริการอีกครั้ง ถ้าเขาให้เลขพอร์ตมาด้วย ต้องพิมพ์แบบ IP:พอร์ต ในช่อง Computer ถ้าเคยเปลี่ยนพอร์ตเองแล้วลืม นี่คือสาเหตุอันดับต้น ๆ

  4. ลองเน็ตอีกเครือข่าย

    เครือข่ายในออฟฟิศ โรงแรม หรือ Wi-Fi สาธารณะบางแห่งปิดพอร์ตที่ Remote Desktop ใช้ ลองแชร์เน็ตจากมือถือแล้วต่อใหม่ ถ้าติด แปลว่าเครือข่ายเดิมเป็นตัวกั้น

  5. ทดสอบพอร์ตจากคอม

    เปิด PowerShell บนคอม Windows แล้วพิมพ์ Test-NetConnection ตามด้วย IP ของ VPS และ -Port 3389 (หรือพอร์ตที่ได้รับ) ถ้าผลบรรทัด TcpTestSucceeded เป็น True แปลว่าเส้นทางถึงพอร์ตเปิดอยู่ ปัญหาน่าจะอยู่ที่การล็อกอิน ถ้าเป็น False ปัญหาอยู่ที่เครื่องหรือไฟร์วอลล์ระหว่างทาง

  6. ติดต่อผู้ให้บริการ

    ถ้าแผงควบคุมบอกว่าเครื่องทำงานแต่พอร์ตยังปิด ส่งผลทดสอบและเวลาที่เกิดเหตุให้ฝ่ายซัพพอร์ตของ VPS เพราะเป็นส่วนที่คุณมองไม่เห็นจากภายนอก

รหัสถูกแต่เข้าไม่ได้

ถ้าข้อความบอกว่ารหัสไม่ผ่าน ทั้งที่มั่นใจว่าจำถูก ให้ดูจุดเล็ก ๆ ที่มักพลาดเหล่านี้ก่อน

  • แป้นพิมพ์ยังเป็นภาษาไทย ตัวอักษรที่พิมพ์ออกไปจะไม่ใช่รหัสที่ตั้งใจ ช่องรหัสแสดงเป็นจุดจึงมองไม่เห็น สลับเป็นภาษาอังกฤษก่อนพิมพ์
  • Caps Lock เปิดอยู่ รหัสผ่านของ Windows แยกตัวพิมพ์เล็กพิมพ์ใหญ่
  • ชื่อผู้ใช้เป็นของคอมตัวเอง กล่อง Windows Security มักเติมบัญชีของคอมที่คุณใช้อยู่ให้ ต้องกด More choices แล้วเลือก Use a different account ก่อนใส่ชื่อผู้ใช้ของ VPS
  • คัดลอกรหัสพร้อมช่องว่าง การก๊อปจากอีเมลบางครั้งติดช่องว่างท้ายรหัสมาด้วย
  • เพิ่งเปลี่ยนรหัส แต่เครื่องยังจำรหัสเก่าไว้ ลบข้อมูลที่จำไว้แล้วพิมพ์ใหม่

ถ้าลองผิดหลายครั้ง บัญชีอาจถูกล็อกชั่วคราวตามนโยบายของเครื่อง ซึ่งเป็นกลไกป้องกันการเดารหัส ให้หยุดลองแล้วรอ หรือขอผู้ให้บริการรีเซ็ตรหัสผ่านจากแผงควบคุม เรื่องการตั้งรหัสให้แข็งแรงและการเก็บรหัสอย่างปลอดภัยอยู่ในบทความตั้งรหัสและความปลอดภัย VPS

Remote Desktop หลุดบ่อย: สาเหตุและวิธีลด

อาการ remote desktop หลุดต่างจากเข้าไม่ได้ เพราะต่อติดแล้วแต่ไม่นิ่ง สาเหตุส่วนใหญ่อยู่ฝั่งเน็ตของคุณ

สาเหตุสังเกตได้จากวิธีลดอาการ
เน็ตมือถือหรือ Wi-Fi สัญญาณอ่อนหลุดบ่อยตอนเดินทางหรืออยู่ไกลเราเตอร์ต่อสายแลน หรือย้ายไปที่สัญญาณดีกว่า
ภาพละเอียดเกินความเร็วเน็ตภาพกระตุกก่อนหลุดในหน้าต่าง Remote Desktop Connection กด Show Options แท็บ Experience เลือกความเร็วการเชื่อมต่อต่ำลง และปิดภาพพื้นหลัง
เปิดจากอีกอุปกรณ์ด้วยชื่อผู้ใช้เดียวกันคอมหลุดทันทีที่มือถือต่อเข้าเป็นพฤติกรรมปกติ เครื่องใหม่จะรับช่วงหน้าจอเดิมไป ไม่ใช่ปัญหา
VPS ทำงานหนักจน CPU เต็มภาพค้างทั้งที่เน็ตปกติปิดโปรแกรมที่ไม่ใช้ และดูว่าเปิด MT5 มากเกินสเปกหรือไม่
เครือข่ายของผู้ให้บริการมีปัญหาทุกอุปกรณ์หลุดพร้อมกันในช่วงเดียวกันจดเวลาแล้วแจ้งผู้ให้บริการ

ในแท็บ Experience ยังมีช่อง Reconnect if the connection is dropped ให้ติ๊กไว้ เวลาสัญญาณกระตุกสั้น ๆ โปรแกรมจะพยายามต่อกลับให้เอง ไม่ต้องล็อกอินใหม่ ส่วนบนมือถือที่ใช้แอป Windows App ให้ใช้ Wi-Fi ที่นิ่งเวลาต้องทำงานหลายนาที เช่น ติดตั้ง EA หรือเปลี่ยนค่า

ถ้าเครื่องค้างเพราะเปิด MT5 หลายชุดจนทรัพยากรไม่พอ ให้เปิด Task Manager ดูแท็บ Performance ช่วงที่ตลาดคึกคัก ถ้า CPU หรือ Memory เกือบเต็มเป็นประจำ ทางแก้คือลดจำนวนโปรแกรมหรือขยับสเปกเครื่อง ไม่ใช่แก้ที่ Remote Desktop

หลุดแล้ว MT5 ยังอยู่ไหม: Disconnect กับ Sign out

คำถามที่ตามมาทุกครั้งคือ ตอนหลุด MT5 ปิดไปด้วยหรือเปล่า คำตอบขึ้นกับว่าเซสชันจบแบบไหน

สิ่งที่เกิดขึ้นผลกับ MT5 และ EA
เน็ตหลุด หรือกดปิดหน้าต่าง Remote Desktopเป็นการตัดการเชื่อมต่อ (Disconnect) โปรแกรมบน VPS ทำงานต่อตามปกติ
เลือก Sign out ในเมนู Start ของ VPSเซสชันจบ โปรแกรมทุกตัวของผู้ใช้นั้นถูกปิด รวมถึง MT5
สั่ง Restart หรือ Shut downMT5 ปิดจนกว่าเครื่องจะบูตและมีคนหรือระบบเปิดโปรแกรมให้
เครื่องตั้งให้ปิดเซสชันที่ถูกตัดการเชื่อมต่อเกินเวลาที่กำหนดMT5 ถูกปิดหลังครบเวลา แม้คุณแค่ปิดหน้าต่าง

แถวสุดท้ายพบไม่บ่อย แต่ถ้า MT5 หายไปทุกครั้งหลังออกจาก VPS ไปสักพัก ให้เปิด gpedit.msc บน VPS แล้วไปที่ Computer Configuration → Administrative Templates → Windows Components → Remote Desktop Services → Remote Desktop Session Host → Session Time Limits ดูค่า Set time limit for disconnected sessions ค่าเริ่มต้นคือไม่ได้ตั้ง ซึ่งหมายถึงเก็บเซสชันไว้ไม่จำกัดเวลา ถ้ามีการตั้งเวลาไว้ ให้ถามผู้ให้บริการก่อนแก้

รีสตาร์ตจากแผงควบคุม: ทางเลือกสุดท้าย

ถ้าเครื่องค้างจริง Console ก็ไม่ตอบ การสั่งรีสตาร์ตจากแผงควบคุมเป็นทางเดียว สิ่งที่ควรรู้ก่อนกด

  • ออเดอร์ที่เปิดไว้อยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ ไม่หายไปกับการรีสตาร์ต Stop Loss หรือ Take Profit ที่ส่งไปแล้วยังมีผล
  • สิ่งที่หยุดคือ EA ซึ่งจะไม่ทำงานจนกว่า MT5 กลับมาเปิด ถ้าตั้งให้ MT5 เปิดเองหลังบูตไว้แล้ว ช่วงที่หยุดจะสั้นลงมาก วิธีตั้งอยู่ในบทความตั้งให้ MT5 เปิดเองหลัง VPS รีสตาร์ต
  • หลังรีโมตเข้าได้ ตรวจว่าล็อกอินบัญชีถูกตัว ปุ่ม Algo Trading เป็นสีเขียว และ EA กลับมาบนกราฟครบ ผู้ใช้ EA WING ดูการ์ดล็อกอินบนแดชบอร์ดว่าเป็นสีเขียวด้วย

เข้า VPS ได้ แต่ MT5 ขึ้นไม่มีการเชื่อมต่อ

อีกกรณีที่หน้าตาคล้ายกันคือรีโมตเข้าเครื่องได้ปกติ แต่ MT5 บนนั้นต่อเซิร์ฟเวอร์ของโบรกเกอร์ไม่ได้ ราคาไม่ขยับ และ EA ส่งคำสั่งไม่ได้ อาการนี้เป็นเรื่องของ MT5 กับบัญชีเทรด ไม่ใช่ Remote Desktop เช็กชื่อเซิร์ฟเวอร์ รหัสผ่านบัญชีเทรด และการสแกนเซิร์ฟเวอร์ใหม่ตามบทความMT5 ขึ้น No connection หรือไม่ขึ้นราคา

ป้องกันไว้ก่อนวันที่เข้าไม่ได้

เตรียมของเหล่านี้ไว้ตั้งแต่วันแรก วันที่มีปัญหาจะแก้ได้เร็วกว่ามาก

  • เก็บ IP พอร์ต ชื่อผู้ใช้ และรหัสผ่าน VPS ในโปรแกรมจัดการรหัสผ่าน ไม่ใช่ในแชต
  • บันทึกลิงก์แผงควบคุมของผู้ให้บริการ และรู้ว่าปุ่ม Console กับปุ่มรีสตาร์ตอยู่ตรงไหน
  • ล็อกอินบัญชีเทรดในแอป MT5 บนมือถือไว้ เพื่อเช็กความเคลื่อนไหวได้ทันที
  • ตั้งให้ MT5 เปิดเองหลังรีสตาร์ต และจำรหัสผ่านบัญชีเทรดไว้
  • ลองรีโมตจากอุปกรณ์สำรองอีกตัวไว้ล่วงหน้า เช่น มือถือ เพื่อรู้ว่าใช้ได้จริง

คำเตือนความเสี่ยง: ช่วงที่เข้า VPS ไม่ได้หรือ MT5 หยุดทำงาน ตลาดยังเคลื่อนไหวต่อ ออเดอร์ที่เปิดค้างอาจได้หรือเสียตามราคา การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่าน ข้อมูลความเสี่ยงของการใช้ EA ก่อนใช้เงินจริง

คำถามที่พบบ่อยเมื่อเข้า VPS ไม่ได้

กดปิดหน้าต่าง Remote Desktop แล้ว EA จะหยุดไหม?

ไม่หยุด การปิดหน้าต่างคือการตัดการเชื่อมต่อ โปรแกรมบน VPS ยังทำงานต่อ สิ่งที่ทำให้ MT5 ปิดคือการเลือก Sign out การสั่งปิดเครื่อง หรือการรีสตาร์ต

รีสตาร์ต VPS จากแผงควบคุมแล้ว ออเดอร์ที่เปิดอยู่จะหายไหม?

ไม่หาย ออเดอร์อยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ แต่ระหว่างที่ MT5 ยังไม่กลับมา EA จะไม่ได้ดูแลออเดอร์เหล่านั้น จึงควรรีโมตเข้าไปตรวจให้เร็วที่สุดหลังเครื่องบูตเสร็จ

เข้าจากคอมได้ แต่เข้าจากมือถือไม่ได้ ทำยังไง?

เทียบข้อมูลที่กรอกในแอป Windows App กับบนคอมทีละช่อง โดยเฉพาะ IP:พอร์ต และชื่อผู้ใช้ แล้วลองสลับระหว่าง Wi-Fi กับเน็ตมือถือ เพราะบางเครือข่ายปิดพอร์ตที่ Remote Desktop ใช้

ส่งรหัส VPS ให้ทีมงาน EA WING ช่วยเข้าไปดูได้ไหม?

ไม่ควรส่งรหัสผ่านให้ใครทางแชต ทีมงานช่วยไล่สาเหตุได้จากภาพหน้าจอข้อความ error ภาพแผงควบคุม และภาพแท็บ Journal ของ MT5 โดยไม่ต้องรู้รหัสใด ๆ ของคุณ

อ่านต่อ

  • ภาพรวมการเลือกและดูแล VPS สำหรับ EA
  • ให้ MT5 เปิดเองหลังรีสตาร์ต VPS
  • ความปลอดภัยของ VPS สำหรับเทรด
  • เข้า VPS จากมือถือ Android

ขั้นตอนต่อ VPS จากคอมแบบเห็นทุกหน้าจออยู่ในคู่มือตั้งค่า Remote Desktop เข้า Windows VPS ถ้าไล่ครบแล้วยังเข้าไม่ได้ ส่งภาพข้อความ error มาให้ทีมงานช่วยดูได้
