แจ้งเตือน MT5 มือถือตั้งได้ด้วยการนำ MetaQuotes ID จากแอป MT5 บนมือถือไปใส่ในหน้า Tools > Options > Notifications ของ MT5 บนคอมหรือ VPS แล้วกด Test ให้ข้อความทดสอบเด้งขึ้น ถ้ายังไม่มีแอปบนมือถือ ให้ติดตั้ง MT5 บนมือถือและล็อกอินบัญชีให้เรียบร้อยก่อน แล้วทำตามขั้นตอนด้านล่างได้เลย

สรุปสั้น: Push notification ส่งผ่านอินเทอร์เน็ต ไม่ใช่ SMS และเด้งได้แม้ปิดแอปอยู่ · ใส่ MetaQuotes ID ได้สูงสุด 4 ชุดคั่นด้วยจุลภาค · แจ้งเตือนจากเทอร์มินัลในเครื่องต้องให้ MT5 เปิดอยู่ตลอด ส่วนแจ้งเตือนจากเซิร์ฟเวอร์เทรดขึ้นกับโบรกเกอร์ · ข้อความไม่มาส่วนใหญ่เกิดจาก ID ผิด สิทธิ์แจ้งเตือนของมือถือ หรือ MT5 บน VPS ถูกปิด

แจ้งเตือน MT5 มือถือคืออะไร ต่างจาก SMS อย่างไร

Push notification คือข้อความสั้นที่ MT5 บนคอมหรือ VPS ส่งไปยังแอป MT5 บนมือถือ ข้อความวิ่งผ่านอินเทอร์เน็ต ไม่ผ่านเครือข่ายโทรศัพท์แบบ SMS จึงไม่มีค่าส่งต่อข้อความ และเด้งขึ้นที่ศูนย์แจ้งเตือนของมือถือแม้แอปปิดอยู่ ขอแค่มือถือต่ออินเทอร์เน็ต แอปยังเก็บประวัติข้อความไว้ในส่วน Messages ให้ย้อนดูได้ ภาพรวมของฟีเจอร์นี้อยู่ในคู่มือ Push Notifications ของ MT5 Android

สำหรับคนที่รัน EA บน VPS นี่คือวิธีที่ง่ายที่สุดที่จะรู้ว่ามีออเดอร์เปิดหรือปิดโดยไม่ต้องเฝ้าจอ ข้อความแต่ละครั้งเป็นเหมือนสัญญาณให้หยิบมือถือขึ้นมาดูบัญชี

ตั้งค่าทีละขั้น: จาก MetaQuotes ID ถึงปุ่ม Test

ก่อนเริ่ม ให้แน่ใจว่ามือถืออนุญาตการแจ้งเตือนของแอป MetaTrader 5 แล้ว และคุณเข้าถึง MT5 ตัวที่รัน EA ได้ ไม่ว่าจะเป็นคอมที่บ้านหรือ VPS

  1. หา MetaQuotes ID ในแอปมือถือ

    MetaQuotes ID คือรหัสประจำเครื่องที่แอปสร้างให้ตอนติดตั้ง เปิดแอป MT5 แล้วไปที่ส่วน Messages หรือในบางเวอร์ชันอยู่ที่ Settings > Messages ตำแหน่งเมนูบน iPhone กับ Android ต่างกันเล็กน้อย เจอแล้วให้คัดลอกหรือจดไว้

  2. เปิดหน้าตั้งค่าบน MT5 ตัวที่รัน EA

    บนคอมหรือ VPS ไปที่เมนู Tools > Options แล้วเลือกแท็บ Notifications ต้องตั้งบน MT5 ตัวที่ทำงานจริง ไม่ใช่ MT5 อีกเครื่องที่เปิดไว้ดูเฉย ๆ

  3. ติ๊ก Enable Push Notifications แล้วใส่ ID

    วาง MetaQuotes ID ลงในช่อง ใส่ได้สูงสุด 4 ID คั่นด้วยจุลภาค เช่น มือถือของคุณและแท็บเล็ต ทุกเครื่องจะได้รับข้อความพร้อมกัน

  4. เลือกแหล่งของแจ้งเตือน

    เลือกประเภทแจ้งเตือนเรื่องการเทรด ซึ่งมีแบบจากเทอร์มินัลในเครื่อง และแบบจากเซิร์ฟเวอร์เทรด ความต่างของสองแบบอธิบายไว้ในหัวข้อถัดไป

  5. กด Test แล้วกด OK

    เมื่อส่งสำเร็จ MT5 จะแสดงข้อความยืนยัน และมือถือจะได้รับข้อความทดสอบ ถ้าเด้งขึ้นจริงจึงกด OK เพื่อบันทึก ถ้าไม่เด้ง ข้ามไปดูตารางแก้ปัญหาด้านล่าง

รายละเอียดของแต่ละช่องดูได้จากคู่มือการตั้งค่า Notifications ของ MetaTrader 5

แจ้งเตือนสองแหล่ง: จากเทอร์มินัลในเครื่อง กับจากเซิร์ฟเวอร์เทรด

สองตัวเลือกนี้ส่งข้อความเรื่องการเทรดเหมือนกัน แต่ต้นทางต่างกัน และนั่นทำให้พฤติกรรมต่างกันมาก

หัวข้อNotifications from the local terminalNotifications from the trade server
ใครเป็นคนส่งMT5 บนคอมหรือ VPSเซิร์ฟเวอร์ของโบรกเกอร์
ต้องเปิด MT5 ไว้ไหมต้องเปิดตลอดไม่ต้อง ถ้า Take Profit ทำงานตอนคอมปิดก็ยังได้รับแจ้ง
แจ้งเรื่องอะไรคำสั่งเทรดที่สำเร็จ รายการฝากถอน และสถานะ Margin Call ซึ่งส่งซ้ำเป็นระยะตลอดที่ยังอยู่ในสถานะนั้นออเดอร์ ดีล และรายการฝากถอน ตามที่โบรกเกอร์รองรับ
บัญชีที่ครอบคลุมบัญชีที่ MT5 เครื่องนั้นเชื่อมต่ออยู่เฉพาะบัญชีที่เชื่อมต่ออยู่ตอนเปิดตัวเลือก

แบบจากเซิร์ฟเวอร์ขึ้นกับว่าโบรกเกอร์ของคุณรองรับหรือไม่ เมื่อเปิดใช้สำเร็จ แท็บ Journal จะมีบรรทัดลักษณะ "subscribed to deals, orders, balance notifications from trade server" ใช้ยืนยันได้ ถ้าต้องการให้อีกบัญชีได้รับด้วย ต้องล็อกอินบัญชีนั้นแล้วเปิดตัวเลือกนี้ใหม่

ส่วนแบบจากเทอร์มินัลในเครื่องจะเงียบทันทีเมื่อคอมดับหรือเข้าโหมดพัก นี่คือเหตุผลที่คนรัน EA นิยมใช้ Windows VPS สำหรับรัน EA ซึ่งเปิดได้ตลอด 24 ชั่วโมง

ข้อจำกัด: ไม่มีข้อความเมื่อคำสั่งล้มเหลว

แบบจากเทอร์มินัลในเครื่องไม่ส่งข้อความเมื่อคำสั่งเทรดไม่สำเร็จ เช่น ถูกปฏิเสธเพราะพารามิเตอร์ไม่ถูกต้อง ความเงียบจึงไม่ได้แปลว่าทุกอย่างปกติ ข้อผิดพลาดแบบนี้ต้องดูในแท็บ Journal และ Experts บนเครื่องที่รัน EA ตามวิธีดู Journal และ Experts ใน MT5

EA ส่งข้อความของตัวเองได้ไหม

ภาษา MQL5 มีฟังก์ชัน SendNotification ที่ให้โปรแกรมส่ง Push ไปยัง MetaQuotes ID ที่ตั้งไว้ใน MT5 EA ที่ถูกเขียนให้เรียกฟังก์ชันนี้จึงส่งข้อความเฉพาะได้ เช่น แจ้งสถานะหรือเหตุการณ์ที่ผู้พัฒนากำหนด แต่ไม่ใช่ทุก EA ที่ทำแบบนี้ ให้ดูคู่มือของ EA ที่คุณใช้ อย่าสมมติเอาเอง

อีกช่องทางคือแท็บ Alerts ในหน้าต่าง Toolbox ของ MT5 บนคอม ซึ่งสร้างการแจ้งเตือนตามเงื่อนไขของตลาดได้ และเลือกให้ส่งเป็น Push ได้ด้วย

แจ้งเตือนไม่มา แก้อย่างไร

อาการสาเหตุที่พบบ่อยวิธีแก้
กด Test แล้วมือถือเงียบID พิมพ์ผิด หรือเป็น ID ของเครื่องเก่าคัดลอก ID จากส่วน Messages มาใหม่ ถ้าเปลี่ยนเครื่องหรือลงแอปใหม่ให้เช็ก ID อีกครั้ง
กด Test แล้วมือถือเงียบปิดสิทธิ์แจ้งเตือนของแอป MetaTrader 5เปิดสิทธิ์ในหน้าตั้งค่าการแจ้งเตือนของมือถือ
ข้อความมาช้าหรือมาเป็นชุดโหมดประหยัดแบตจำกัดแอปที่ทำงานเบื้องหลังยกเว้นแอป MT5 จากการประหยัดแบตเตอรี่
บางช่วงไม่มีข้อความเลยมือถือไม่มีอินเทอร์เน็ต หรือเปิดโหมดห้ามรบกวนเช็กการเชื่อมต่อและโหมด Focus หรือห้ามรบกวน
เคยมา แล้วหยุดไปเฉย ๆMT5 บน VPS ถูกปิด หรือ VPS รีสตาร์ตแล้วไม่ได้เปิด MT5เข้า VPS เปิด MT5 และเช็กว่ายังติ๊ก Enable Push Notifications อยู่
เคยมา แล้วหยุดไปหลังสลับบัญชีMT5 ตัวที่รัน EA ไปเชื่อมต่อบัญชีอื่นกลับมาบัญชีเดิม ถ้าใช้แจ้งเตือนจากเซิร์ฟเวอร์ ให้ดูบรรทัด subscribed ใน Journal ว่าบัญชีนี้ยังสมัครรับอยู่

ใช้แจ้งเตือนช่วยบังคับกฎของตัวเอง

ข้อความไม่ได้ตัดสินใจแทนคุณ แต่ช่วยเตือนให้ทำตามกฎที่เขียนไว้ วิธีที่ใช้ได้จริงคือกำหนดล่วงหน้าว่าข้อความแต่ละแบบต้องตามด้วยอะไร

  • มีออเดอร์ปิด: เปิดแอปดู Equity เทียบกับเพดานขาดทุนรายวันที่จดไว้ตอนเช้า
  • สถานะ Margin Call: เข้า VPS ทันทีและทำตามแผนรับมือที่เขียนไว้ ไม่ใช่รอดูอีกชั่วโมง
  • รายการฝากถอนที่คุณไม่ได้ทำ: ติดต่อโบรกเกอร์และเปลี่ยนรหัสผ่านทันที
  • เงียบผิดปกติขณะตลาดคึกคัก: เข้าไปเช็กว่า MT5 บน VPS ยังทำงานอยู่ ตามรูทีนดูผล EA มือถือ

ตัวอย่างสมมติ: เทรดเดอร์ที่ทำงานประจำปิดเสียงมือถือช่วงประชุม 14:00 ถึง 15:00 น. ออกจากห้องประชุมเห็นข้อความปิดออเดอร์สามรายการ เขาใช้เวลาหนึ่งนาทีเปิดดู Equity เทียบกับเส้นหยุดของวัน ยังห่างอยู่ จึงกลับไปทำงานต่อโดยไม่แตะออเดอร์ใด ๆ

คำถามที่พบบ่อย

แจ้งเตือน MT5 มือถือเสียค่าบริการไหม?

ไม่มีค่าส่งแบบ SMS เพราะข้อความส่งผ่านอินเทอร์เน็ต สิ่งที่ใช้คือดาต้าหรือ Wi-Fi ของมือถือเท่านั้น

ปิดแอป MT5 บนมือถือแล้วยังได้รับแจ้งเตือนไหม?

ได้ Push เด้งที่ศูนย์แจ้งเตือนของมือถือแม้แอปไม่ได้เปิดอยู่ ขอแค่มือถือต่ออินเทอร์เน็ตและไม่ได้ปิดสิทธิ์แจ้งเตือนของแอป

MetaQuotes ID ต้องเก็บเป็นความลับไหม?

ID ทำหน้าที่คล้ายเบอร์โทรศัพท์ ใครรู้ก็ส่งข้อความหาคุณได้ แต่ใช้เข้าบัญชีเทรดไม่ได้ ไม่ต้องเก็บเข้มเท่ารหัสผ่าน แต่ไม่ควรโพสต์ในที่สาธารณะ และเมื่อเปลี่ยนมือถือควรลบ ID ของเครื่องเก่าออกจากช่องตั้งค่า

ทำไมได้แจ้งเตือนจาก MT5 แต่ไม่รู้ว่า EA ยังเปิดอยู่ไหม?

แจ้งเตือนจากเทอร์มินัลบอกเฉพาะคำสั่งที่สำเร็จ ส่วนแจ้งเตือนจากเซิร์ฟเวอร์ส่งได้แม้ MT5 ปิดอยู่ ข้อความจึงไม่ได้ยืนยันสถานะของ EA โดยตรง ถ้าสงสัย ให้เข้า VPS ดูปุ่ม Algo Trading และแท็บ Experts

คำเตือนความเสี่ยง: การเทรด Forex และการใช้ EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด แจ้งเตือนอาจมาช้าหรือไม่มาเมื่อเครือข่ายมีปัญหา จึงไม่ควรใช้เป็นเครื่องมือป้องกันความเสี่ยงเพียงอย่างเดียว ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่านประกาศความเสี่ยงการใช้ EA ก่อนใช้เงินจริง

อ่านต่อ

  • ดูผล EA มือถือผ่านแอป MT5
  • ตั้งเพดานขาดทุนรายวัน
  • ดู Journal และ Experts ใน MT5
  • Windows VPS สำหรับรัน EA
