Investor Password คือรหัสผ่านสำหรับดูบัญชี MT5 อย่างเดียว ล็อกอินแล้วเห็นยอดเงิน ออเดอร์ และประวัติการเทรดครบ แต่ส่งคำสั่งซื้อขายไม่ได้ รหัสนี้เป็นเครื่องมือหลักของการดูแลพอร์ต EA เวลาต้องการให้มือถือ คนในครอบครัว หรือเว็บติดตามผลเห็นบัญชี โดยไม่เปิดโอกาสให้ใครกดเทรดแทนคุณ

สรุปสั้น: รหัสหลัก (Master) ใช้เทรดได้ รหัส Investor ใช้ดูได้อย่างเดียว · ตั้งหรือเปลี่ยนรหัส Investor ได้ใน MT5 ที่ Tools → Options แท็บ Server โดยต้องใส่รหัสหลักยืนยัน · แชร์ได้เฉพาะรหัส Investor และเปลี่ยนใหม่เมื่อเลิกแชร์ · อย่าใช้รหัส Investor ล็อกอินบนเครื่องที่รัน EA เพราะ EA จะเทรดไม่ได้

Investor Password คืออะไร ต่างจากรหัสหลักอย่างไร

บัญชี MT5 หนึ่งบัญชีมีรหัสผ่านสองชุด ชุดแรกคือรหัสหลักหรือ Master Password ให้สิทธิ์ทำงานกับบัญชีได้เต็มที่ ชุดที่สองคือรหัส Investor หรือที่บางโบรกเกอร์เรียกว่ารหัสนักลงทุน ให้สิทธิ์แค่ดู ทั้งสองชุดใช้กับเลขบัญชีและเซิร์ฟเวอร์เดียวกัน ความต่างอยู่ที่สิ่งที่ทำได้หลังล็อกอิน

รหัสสามชุดที่คนใช้ EA มักสับสน

นอกจากสองรหัสของ MT5 ยังมีรหัสชุดที่สามที่ไม่เกี่ยวกับโปรแกรมเลย หลายคนส่งผิดชุดเพราะชื่อคล้ายกัน

รหัสใช้ที่ไหนทำอะไรได้แชร์ได้ไหม
รหัสหลัก MT5โปรแกรม MT5 ทุกเวอร์ชันเทรดและเปลี่ยนรหัสไม่ควรแชร์
รหัส Investor MT5โปรแกรม MT5 และเว็บติดตามผลดูอย่างเดียวแชร์กับคนหรือบริการที่ไว้ใจได้
รหัสพื้นที่สมาชิกของโบรกเกอร์เว็บหรือแอปของโบรกเกอร์ฝาก ถอน โอนเงิน เปิดบัญชีใหม่ห้ามแชร์เด็ดขาด

การถอนเงินไม่ได้ทำผ่านโปรแกรม MT5 ไม่ว่าจะใช้รหัสชุดไหน แต่ทำในพื้นที่สมาชิกของโบรกเกอร์ ซึ่งเป็นเหตุผลที่รหัสชุดที่สามสำคัญที่สุดและต้องเก็บไว้คนเดียว

ได้ Investor Password มาจากไหน

โบรกเกอร์ส่วนใหญ่ส่งรหัส Investor มาพร้อมรหัสหลักในอีเมลเปิดบัญชี หรือแสดงไว้ในหน้ารายละเอียดบัญชีบนพื้นที่สมาชิก ถ้าหาไม่เจอหรือจำไม่ได้ ไม่ต้องกังวล ตั้งรหัสใหม่เองใน MT5 ได้ตราบที่ยังจำรหัสหลักได้ ถ้าลืมรหัสหลักด้วย ต้องขอรีเซ็ตผ่านพื้นที่สมาชิกหรือฝ่ายบริการลูกค้าของโบรกเกอร์

ตั้งหรือเปลี่ยน Investor Password ใน MT5 บนคอม

  1. ล็อกอินด้วยรหัสหลัก

    เปิด MT5 บนคอมหรือ VPS แล้วตรวจว่าบัญชีที่ล็อกอินอยู่คือบัญชีที่ต้องการเปลี่ยนรหัส

  2. เปิดหน้าตั้งค่า

    ไปที่ Tools → Options แล้วเลือกแท็บ Server จะเห็นเลขบัญชีและปุ่มสำหรับแก้รหัสผ่าน (คู่มือของ MetaTrader เรียกปุ่มนี้ว่า Edit)

  3. ใส่รหัสหลักปัจจุบัน

    ในหน้าต่างเปลี่ยนรหัส ช่อง Login เป็นเลขบัญชีที่แก้ไม่ได้ ใส่รหัสหลักปัจจุบันในช่อง Current password

  4. เลือกเปลี่ยนรหัส Investor

    เลือกตัวเลือก Change investor password ระวังอย่าเลือกตัวเลือกของรหัสหลักโดยไม่ตั้งใจ

  5. ตั้งรหัสใหม่แล้วกด OK

    พิมพ์รหัสใหม่สองครั้งในช่อง New password และ Confirm ใช้รหัสที่ต่างจากรหัสหลักอย่างชัดเจน ผสมตัวพิมพ์เล็ก พิมพ์ใหญ่ ตัวเลข และอักขระพิเศษ

แอป MT5 บนมือถือก็มีเมนูเปลี่ยนรหัสในหน้าบัญชีเช่นกัน แต่ต้องล็อกอินด้วยรหัสหลักก่อน และอีกเรื่องที่ควรรู้คือ ถ้าเซิร์ฟเวอร์บังคับให้เปลี่ยนรหัสหลักตอนล็อกอิน รหัส Investor เดิมจะถูกรีเซ็ตไปด้วย ใครที่เคยได้รหัสเก่าไปจะดูไม่ได้อีก ต้องตั้งและแชร์ใหม่ รายละเอียดการเปลี่ยนรหัสหลักอยู่ในบทความเปลี่ยนรหัสผ่าน MT5

ใช้ Investor Password ทำอะไรได้บ้าง

  • ดูพอร์ตบนมือถือแบบไม่มีปุ่มเทรด เหมาะกับคนที่กลัวเผลอกดปิดออเดอร์ตอนตกใจ วิธีอ่านตัวเลขบนแอปอยู่ในบทความดูผล EA ผ่านแอป MT5
  • ให้คนในครอบครัวดูด้วย คู่ชีวิตหรือหุ้นส่วนที่ร่วมลงเงินเห็นตัวเลขเดียวกับคุณ โดยไม่ต้องรอส่งภาพหน้าจอ
  • ผูกกับเว็บติดตามผล บริการอย่าง Myfxbook ใช้รหัสนี้ดึงประวัติจากโบรกเกอร์ ขั้นตอนอยู่ในบทความMyfxbook ใช้ยังไง
  • พิสูจน์ผลงานให้คนอื่นตรวจ ถ้าคุณอยากให้ใครตรวจผลการทดสอบของคุณ รหัส Investor ดีกว่าภาพหน้าจอเสมอ เพราะแต่งตัวเลขไม่ได้

ล็อกอินด้วย Investor Password MT5 บนมือถือ

ฝั่งคนที่ได้รับรหัสไปดู ขั้นตอนเหมือนล็อกอินบัญชีปกติทุกอย่าง ต่างกันแค่ช่องรหัสผ่าน

  1. เปิดแอป MetaTrader 5 ไปที่หน้าจัดการบัญชี แล้วกดเพิ่มบัญชีที่มีอยู่แล้ว
  2. ค้นหาชื่อโบรกเกอร์ แล้วเลือกชื่อเซิร์ฟเวอร์ให้ตรงกับที่เจ้าของบัญชีส่งมา
  3. กรอกเลขบัญชี และใส่รหัส Investor ในช่องรหัสผ่าน
  4. เมื่อเข้าได้แล้ว ลองเปิดหน้าส่งคำสั่ง ถ้าแอปไม่ยอมให้เทรด แปลว่าล็อกอินแบบดูอย่างเดียวถูกต้อง

ถ้ามีคนถามว่า Investor Password คืออะไรแบบสั้นที่สุด ตอบได้ว่าเป็นกุญแจที่เปิดดูห้องได้ทุกมุม แต่หยิบของออกไปไม่ได้ เจ้าของบัญชีเปลี่ยนกุญแจดอกนี้ได้ทุกเมื่อ

อย่าใช้รหัส Investor บนเครื่องที่รัน EA

ข้อนี้เป็นสาเหตุของอาการ EA ไม่เทรดที่เจอบ่อยหลังย้ายเครื่อง คนที่ได้รหัสสองชุดจากโบรกเกอร์มักหยิบผิดชุดตอนตั้ง MT5 บน VPS ทุกอย่างดูปกติ เห็นราคา เห็นยอดเงิน EA ติดกราฟได้ แต่ทุกคำสั่งเทรดจะถูกปฏิเสธ

วิธีเช็กเร็วที่สุดคือเปิดแท็บ Journal ดูว่ามีข้อความบอกว่าการเทรดถูกปิดเพราะล็อกอินแบบ investor หรือไม่ แล้วล็อกอินใหม่ผ่าน File → Login to Trade Account ด้วยรหัสหลัก ถ้าไล่แล้วยังไม่เจอสาเหตุ ดูสาเหตุอื่นในเช็กลิสต์ EA ไม่เปิดออเดอร์

ผู้ใช้ [eawing_brand] ควรเช็กสองเรื่องแยกกัน การ์ดล็อกอินบนแดชบอร์ดบอกสถานะสิทธิ์ใช้งานของเลขบัญชี ส่วนรหัสที่ใช้ล็อกอิน MT5 เป็นตัวกำหนดว่าบัญชีส่งคำสั่งได้หรือไม่ ทั้งสองอย่างต้องผ่านพร้อมกัน EA จึงเทรดได้

แชร์พอร์ตอย่างปลอดภัย: กฎ 6 ข้อ

  1. แชร์เฉพาะรหัส Investor

    ไม่มีเหตุผลใดที่คนดูผลต้องใช้รหัสหลัก ถ้ามีคนยืนยันว่าต้องใช้ ให้หยุดคุยก่อน

  2. ตั้งรหัส Investor ให้ต่างจากรหัสหลัก

    ถ้าสองรหัสคล้ายกัน คนที่ได้รหัสหนึ่งไปอาจเดาอีกรหัสได้

  3. ส่งเลขบัญชี เซิร์ฟเวอร์ และรหัสแยกช่องทาง

    เช่น ส่งเลขบัญชีกับเซิร์ฟเวอร์ทางแชต ส่วนรหัสบอกทางโทรศัพท์ หรือส่งในข้อความที่ลบได้หลังอีกฝ่ายจดแล้ว

  4. จดว่าให้ใครไปบ้าง

    เมื่อถึงเวลาเลิกแชร์ จะได้รู้ว่าต้องเปลี่ยนรหัสหรือไม่

  5. เปลี่ยนรหัสเมื่อเลิกแชร์

    การเปลี่ยนรหัส Investor ตัดการเข้าถึงของทุกคนที่ถือรหัสเก่าทันที รวมถึงเว็บติดตามผลที่ผูกไว้

  6. อย่าโพสต์ภาพหน้าต่างล็อกอินที่เห็นรหัส

    รวมถึงภาพอีเมลเปิดบัญชีที่มีรหัสทั้งสองชุดอยู่ในข้อความเดียวกัน

สิ่งที่คนถือรหัส Investor ยังเห็นได้

รหัสดูอย่างเดียวไม่ได้แปลว่าไม่มีความเสี่ยงเลย เพราะข้อมูลทางการเงินของคุณเปิดให้อีกฝ่ายเห็นทั้งหมด ก่อนแชร์ให้คิดว่ารับได้ไหมที่อีกฝ่ายจะเห็นสิ่งเหล่านี้

  • ยอดเงินในบัญชีและ Equity ตลอดเวลา
  • ประวัติการฝากถอนทั้งหมด รวมถึงจำนวนเงินและวันที่
  • ทุกออเดอร์ทั้งที่เปิดอยู่และปิดแล้ว ขนาด Lot และผลของแต่ละไม้
  • ชื่อเจ้าของบัญชีในบางรายงานที่ดึงจากโปรแกรม

สำหรับคนแปลกหน้าหรือการแชร์สาธารณะ การผูกกับเว็บติดตามผลแล้วซ่อนยอดเงินจริงและเลขบัญชี ปลอดภัยกว่าการแจกรหัส Investor ให้ทุกคนที่ขอ

สัญญาณอันตรายเมื่อมีคนขอรหัส

  • ขอรหัสหลักโดยอ้างว่าจะช่วยติดตั้ง ช่วยดูผล หรือช่วยแก้ปัญหา EA
  • ขอรหัสพื้นที่สมาชิกของโบรกเกอร์ หรือรหัส OTP ที่ส่งเข้ามือถือ
  • อ้างว่าจะช่วยถอนกำไรหรือคืนเงินขาดทุนให้ ถ้าคุณบอกรหัส
  • เร่งให้ตัดสินใจภายในไม่กี่นาที

ทีมงาน EA WING ใช้แค่เลขบัญชี MT5 และชื่อเซิร์ฟเวอร์ในการเปิดสิทธิ์ใช้งาน ไม่ต้องใช้รหัสผ่านใด ๆ ทั้งรหัสหลัก รหัส Investor และรหัสของโบรกเกอร์ ถ้ามีใครอ้างชื่อทีมงานแล้วขอรหัส ให้ถือว่าไม่ใช่ทีมงานจริง

คำถามที่พบบ่อย

ลืมรหัส Investor ต้องติดต่อโบรกเกอร์ไหม?

ไม่จำเป็น ถ้ายังจำรหัสหลักได้ ตั้งรหัส Investor ใหม่เองใน MT5 ที่ Tools → Options แท็บ Server ได้ทันที ต้องติดต่อโบรกเกอร์เฉพาะกรณีที่ลืมรหัสหลักด้วย

เปลี่ยนรหัส Investor แล้ว EA จะหยุดไหม?

ไม่หยุด ถ้าเครื่องที่รัน EA ล็อกอินด้วยรหัสหลักตามที่ควรเป็น การเปลี่ยนรหัส Investor มีผลกับคนหรือบริการที่ใช้รหัสดูอย่างเดียวเท่านั้น ส่วนการเปลี่ยนรหัสหลักต้องล็อกอินเครื่องที่รัน EA ใหม่ด้วย

ล็อกอินพร้อมกันหลายเครื่องได้ไหม?

โดยทั่วไปได้ เช่น VPS ล็อกอินด้วยรหัสหลักเพื่อรัน EA ขณะที่มือถือและเว็บติดตามผลใช้รหัส Investor ดูบัญชีเดียวกัน แต่ควรมีเครื่องเดียวที่รัน EA บนบัญชีนั้น เพื่อไม่ให้มีคำสั่งซ้ำซ้อน

คนแปลกหน้าขอรหัส Investor เพื่อ "ช่วยวิเคราะห์พอร์ต" ควรให้ไหม?

ถึงจะเทรดแทนไม่ได้ แต่อีกฝ่ายจะเห็นยอดเงินและประวัติฝากถอนทั้งหมด ซึ่งข้อมูลนี้มักถูกใช้เลือกเหยื่อสำหรับการชวนลงทุนต่อ ถ้าไม่รู้จักและไม่มีเหตุผลชัดเจน ไม่ต้องให้ และถ้าให้ไปแล้วรู้สึกไม่สบายใจ เปลี่ยนรหัสได้ทันที

แชร์รหัส Investor ให้คนอื่นผิดเงื่อนไขของโบรกเกอร์ไหม?

รหัสนี้มีไว้เพื่อให้ดูบัญชีโดยเฉพาะ การให้คนที่ไว้ใจดูจึงเป็นการใช้งานปกติ แต่เงื่อนไขของแต่ละโบรกเกอร์ต่างกันได้ ถ้าไม่แน่ใจให้อ่านข้อตกลงของบัญชีหรือถามฝ่ายบริการลูกค้า

คำเตือนความเสี่ยง: การเทรด Forex ทองคำ และ CFD ด้วย EA มีความเสี่ยงสูง อาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลที่คนอื่นแชร์ผ่านรหัสดูอย่างเดียวเป็นผลในอดีตของบัญชีนั้น ไม่ได้รับประกันผลลัพธ์ในอนาคต และไม่ได้บอกว่าคุณจะได้ผลเหมือนกัน อ่าน ข้อควรรู้เรื่องความเสี่ยงของ EA ก่อนใช้เงินจริง

อ่านต่อ

  • ผูกบัญชี MT5 กับ Myfxbook
  • ติดตามพอร์ต EA บนแอป MT5 มือถือ
  • เปลี่ยนรหัสผ่าน MT5 ทำยังไง
  • ติดตามผล EA: เช็กลิสต์ฉบับเต็ม
