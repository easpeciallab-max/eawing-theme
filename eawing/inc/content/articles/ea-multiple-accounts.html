รัน EA หลายบัญชีพร้อมกันทำได้บนคอมหรือ VPS เครื่องเดียว แต่มีข้อจำกัดหนึ่งข้อที่ต้องรู้ก่อน คือ MT5 หนึ่งชุดเชื่อมต่อได้ครั้งละหนึ่งบัญชี วิธีที่ใช้กันจริงจึงเป็นการติดตั้ง MT5 หลายชุดแยกโฟลเดอร์ ชุดละหนึ่งบัญชี แล้วแนบ EA ในแต่ละชุด ถ้ายังใหม่กับเรื่องนี้ เริ่มจากพื้นฐาน EA และบอทเทรดบน MT5ก่อน

สรุปสั้น: หนึ่งบัญชี หนึ่ง MT5 หนึ่งโฟลเดอร์ · ติดตั้งชุดใหม่โดยกด Settings ในตัวติดตั้งเพื่อเลือกโฟลเดอร์อื่น · วางไฟล์ EA และเปิดสวิตช์ในทุกชุด เพราะแต่ละชุดตั้งค่าแยกกัน · ทุกเลขบัญชีต้องได้รับสิทธิ์ใช้งาน · ห้ามเปิด EA บนบัญชีเดียวกันจากสองเครื่อง

ทำไม MT5 ชุดเดียวรันหลายบัญชีพร้อมกันไม่ได้

MT5 จำบัญชีได้หลายบัญชีในหน้าต่าง Navigator แต่เชื่อมต่อกับเซิร์ฟเวอร์จริงได้ทีละบัญชี เมื่อคุณสลับไปบัญชีอื่น EA ที่อยู่บนกราฟจะทำงานกับบัญชีใหม่ต่อทันทีถ้าปุ่ม Algo Trading ยังเปิดอยู่ ใน Tools → Options แท็บ Expert Advisors มีตัวเลือกให้ปิด Algo Trading เองเมื่อเปลี่ยนบัญชี ซึ่งช่วยกันความพลาดนี้ได้

ข้อจำกัดอีกข้อคือ MT5 สองชุดรันจากโฟลเดอร์เดียวกันไม่ได้ คู่มือการเปิดโปรแกรม MetaTrader 5 (ภาษาอังกฤษ) ระบุว่าถ้าต้องการเปิดหลายชุดพร้อมกัน ให้ติดตั้งโปรแกรมแยกโฟลเดอร์ตามจำนวนชุดที่ต้องการ

วางผังก่อนติดตั้ง: หนึ่งบัญชีต่อหนึ่งชุด

ตอบก่อนว่าใช้หลายบัญชีเพื่ออะไร

  • แยกบัญชีทดสอบออกจากทุนหลัก ลองเวอร์ชันหรือค่าใหม่กับเงินก้อนเล็กก่อน
  • จำกัดความเสียหาย ปัญหาของบัญชีหนึ่งไม่ลามไปกิน Margin ของอีกบัญชี
  • อ่านผลแยกกันได้ชัด รายงานของแต่ละบัญชีไม่ปนกัน

ถ้ายังไม่มีเหตุผลข้อใดชัดเจน บัญชีเดียวที่ดูแลสม่ำเสมอดีกว่าหลายบัญชีที่ดูไม่ทั่วถึง ส่วนการจัดสัดส่วนเงินให้แต่ละบัญชีมีขั้นตอนอยู่ในแบ่งทุนเทรดให้ EA หลายบัญชี

ตัวอย่างผังสมมติ

เขียนผังสั้น ๆ ว่าบัญชีไหนอยู่ในโฟลเดอร์ไหน ผังนี้ช่วยมากเวลารีสตาร์ตเครื่อง อัปเดต EA หรือให้ทีมงานช่วยดู

บัญชีโฟลเดอร์ติดตั้งชื่อทางลัดบนหน้าจอหน้าที่
บัญชีหลัก (เลขลงท้าย 101)C:\MT5-AMT5-A หลัก 101ทุนหลักตามแผน
บัญชีทดสอบ (เลขลงท้าย 202)C:\MT5-BMT5-B ทดสอบ 202ลองเวอร์ชันหรือค่าใหม่ก่อน
บัญชีเดโม (เลขลงท้าย 303)C:\MT5-CMT5-C เดโม 303ซ้อมและเทียบพฤติกรรม

ใส่เลขท้ายบัญชีในชื่อทางลัดด้วย เพราะเมื่อเปิดหลายหน้าต่างพร้อมกัน ชื่อที่บอกเลขบัญชีจะกันการแก้ผิดชุดได้ดีกว่าชื่อทั่วไปอย่าง "MT5 ใหม่"

ขั้นตอนรัน EA หลายบัญชีบนเครื่องเดียว

  1. รันตัวติดตั้งซ้ำแล้วเลือกโฟลเดอร์ใหม่

    เปิดไฟล์ติดตั้ง MT5 อีกครั้ง กดปุ่ม Settings ก่อนเริ่มติดตั้ง แล้วเปลี่ยนโฟลเดอร์ปลายทางให้ไม่ซ้ำกับชุดเดิม รายละเอียดอยู่ในหน้าการติดตั้งของคู่มือ MetaTrader 5

  2. ตั้งชื่อทางลัดตามผัง

    เปลี่ยนชื่อไอคอนบนหน้าจอทันทีหลังติดตั้ง ก่อนจะลืมว่าไอคอนไหนเป็นชุดไหน

  3. ล็อกอินบัญชีของชุดนั้น

    File → Login to Trade Account ใช้รหัสผ่านหลัก ไม่ใช่รหัส Investor แล้วดูแถบชื่อหน้าต่างว่าขึ้นเลขบัญชีที่ถูกต้อง

  4. วางไฟล์ EA ใน Data Folder ของชุดนั้น

    เปิด File → Open Data Folder จากหน้าต่างของชุดนั้นเอง แล้ววางไฟล์ใน MQL5 → Experts แต่ละชุดมีโฟลเดอร์ข้อมูลของตัวเอง ไฟล์ที่วางไว้ในชุด A จะไม่โผล่ในชุด B

  5. เปิดสวิตช์ใน Options

    Tools → Options แท็บ Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports ถ้า EA ต้องใช้ ค่าเหล่านี้ตั้งแยกในแต่ละชุด

  6. แนบ EA แล้วตรวจสถานะ

    เปิดกราฟตามที่คู่มือของ EA กำหนด (EA WING ใช้กราฟ XAUUSD M1) ลาก EA ลงกราฟ แล้วดูว่าปุ่ม Algo Trading เป็นสีเขียวและสิทธิ์ใช้งานผ่าน

ถ้าอยากให้ข้อมูลทั้งหมดของแต่ละชุดอยู่ในโฟลเดอร์ติดตั้งของมันเอง MT5 มีโหมด Portable ที่เปิดด้วยคีย์ /portable ตามคู่มือฉบับเดียวกันด้านบน แต่ต้องมีสิทธิ์เขียนไฟล์ในโฟลเดอร์นั้น ถ้าไม่แน่ใจ ใช้แบบปกติก็พอ

สิทธิ์ใช้งาน: ทุกเลขบัญชีต้องได้รับอนุญาต

EA ที่มีระบบสิทธิ์จะตรวจเลขบัญชีของแต่ละชุดแยกกัน การวางไฟล์เดียวกันในสามชุดไม่ได้แปลว่าได้สิทธิ์สามบัญชี กลไกนี้อธิบายไว้ในระบบสิทธิ์ EA ผูกบัญชี

สำหรับ EA WING ให้ส่งเลขบัญชีและชื่อเซิร์ฟเวอร์ของทุกบัญชีที่จะใช้ให้ทีมงานทาง LINE แพ็กเกจ Pro เปิดสิทธิ์ได้ 1 ถึง 2 บัญชี หลังเปิดสิทธิ์ ให้ดูการ์ดล็อกอินในทุกชุดว่าเป็นสีเขียว

ต้องเปลี่ยน Magic Number ไหม

Magic Number คือเลขที่ EA ใช้แยกออเดอร์ของตัวเองออกจากออเดอร์อื่นในบัญชีเดียวกัน เมื่อแต่ละบัญชีรันอยู่ใน MT5 ชุดของตัวเอง ออเดอร์ของบัญชีหนึ่งไม่ปนกับอีกบัญชีอยู่แล้ว เรื่องนี้จึงสำคัญตอนรัน EA หลายตัวหรือหลายกราฟในบัญชีเดียวกัน มากกว่าตอนรันหลายบัญชี อ่านต่อได้ที่Magic Number ใน EA คืออะไร และอย่าแก้ค่านี้ถ้าคู่มือของ EA ไม่ได้บอกให้แก้

ความผิดพลาดที่ทำให้ออเดอร์ซ้ำหรือเทรดผิดบัญชี

  • เปิด EA บนบัญชีเดียวกันจากสองเครื่อง เช่น คอมที่บ้านกับ VPS MT5 ยอมให้ล็อกอินบัญชีเดียวกันหลายที่ จึงไม่มีอะไรเตือน แต่ EA สองตัวจะเปิดออเดอร์ซ้อนกัน ความเสี่ยงกลายเป็นสองเท่าทันที
  • สลับบัญชีในชุดที่ EA กำลังทำงาน EA จะไปเทรดบัญชีที่เพิ่งสลับเข้า ซึ่งอาจเป็นบัญชีที่ไม่ได้ตั้งใจให้รัน
  • ล็อกอินด้วยรหัส Investor ในบางชุด ชุดนั้นจะเงียบเพราะส่งคำสั่งไม่ได้ ทั้งที่หน้าจอดูปกติ
  • ลืมตั้งสวิตช์ในชุดใหม่ ค่าใน Options ไม่ได้คัดลอกตามมาจากชุดแรก
  • อัปเดต EA ไม่ครบทุกชุด สองบัญชีจึงรันคนละเวอร์ชันโดยไม่รู้ตัว
  • รีสตาร์ตเครื่องแล้วเปิด MT5 กลับมาไม่ครบ ใช้ผังตั้งชื่อไล่เช็กทุกครั้งหลังรีสตาร์ต

ทรัพยากรเครื่อง: เปิดกี่ชุดถึงพอดี

ไม่มีตัวเลขตายตัว MT5 แต่ละชุดใช้หน่วยความจำและ CPU ของตัวเอง ยิ่งเปิดกราฟและสัญลักษณ์มาก เครื่องยิ่งหนัก วิธีลดภาระที่ทำได้ทันที

  • ปิดกราฟที่ไม่ได้ใช้ เหลือเฉพาะกราฟที่มี EA
  • ซ่อนสัญลักษณ์ที่ไม่ใช้ใน Market Watch
  • ลดค่า Max bars in chart ใน Tools → Options แท็บ Charts ถ้าคู่มือของ EA ไม่ได้กำหนดไว้เป็นอย่างอื่น
  • เปิด Task Manager ดูว่าหน่วยความจำยังเหลือพอในช่วงตลาดคึกคัก

บน VPS การเพิ่มชุดอาจต้องขยับไปเครื่องที่สเปกสูงขึ้น วิธีจัดเครื่องให้รองรับหลายชุดอยู่ในคู่มือเปิด MT5 หลายตัวบน VPS และค่าใช้จ่ายที่เพิ่มตามจำนวนบัญชีสรุปไว้ในต้นทุนรวมของการใช้ EA

ดูแลหลายชุดให้เป็นระบบ

งานดูแลเพิ่มตามจำนวนชุดเสมอ ถ้าไม่มีรูทีน ชุดที่ดูน้อยที่สุดมักเป็นชุดที่มีปัญหาโดยไม่มีใครเห็น ตารางนี้เป็นจุดเริ่มต้นที่ปรับใช้ได้

รอบสิ่งที่ทำดูอะไร
ทุกวันไล่ดูทุกหน้าต่างตามผังปุ่ม Algo Trading สถานะการเชื่อมต่อมุมขวาล่าง และสถานะสิทธิ์ของแต่ละชุด
ทุกสัปดาห์เปิดแท็บ Experts และ Journal ของแต่ละชุดข้อความผิดปกติ การหลุดเชื่อมต่อ หรือคำสั่งที่ถูกปฏิเสธ
หลังรีสตาร์ตเครื่องเปิดทุกชุดตามลำดับในผังกราฟที่มี EA ยังอยู่ครบ และล็อกอินถูกบัญชี
เมื่อมีเวอร์ชันใหม่ของ EAอัปเดตทีละชุด จดว่าชุดไหนเสร็จแล้วเลขเวอร์ชันบนกราฟตรงกันทุกชุด

ถ้าอยากให้ MT5 ทุกชุดเปิดเองเมื่อเข้าสู่ Windows ให้วางทางลัดของแต่ละชุดในโฟลเดอร์ Startup (พิมพ์ shell:startup ในช่อง Run ของ Windows) วิธีนี้ทำงานเมื่อมีการล็อกอินเข้า Windows ดังนั้นหลังรีสตาร์ตยังต้องเข้าไปเช็กว่าทุกชุดกลับมาครบ

หลายบัญชีไม่ได้แปลว่ากระจายความเสี่ยง

ถ้าทุกบัญชีรัน EA ตัวเดียวกันบนสัญลักษณ์เดียวกัน ออเดอร์มักไปทางเดียวกันในเวลาใกล้กัน ความเสี่ยงจึงซ้อนกัน ไม่ได้กระจายออก

ตัวอย่างสมมติ: สามบัญชี ทางเดียวกัน

สามบัญชีถือทองคำบัญชีละ 0.02 Lot (2 ออนซ์ เมื่อ Contract size เป็น 100 ออนซ์) ไปทางเดียวกัน ราคาสวน 10 USD แต่ละบัญชีเสีย 20 USD ดูทีละบัญชีอาจรู้สึกว่าน้อย แต่ทั้งพอร์ตเสีย 60 USD ในจังหวะเดียว ตัวเลขนี้เป็นตัวอย่างทางคณิตศาสตร์ ไม่ใช่ผลของระบบใด

วิธีคิดที่ถูกคือตั้งงบความเสี่ยงรวมของทุกบัญชีก่อน แล้วค่อยแบ่งให้แต่ละบัญชี และเขียนไว้ว่าถ้าเงินรวมลดถึงระดับไหนจะหยุดทบทวนทั้งหมด ไม่ใช่ดูทีละบัญชีแล้วรอให้แต่ละบัญชีถึงจุดหยุดของตัวเอง

ดูผลทุกบัญชีจากมือถือ

แอป MT5 บนมือถือบันทึกได้หลายบัญชีและสลับดูได้ แต่รัน EA ไม่ได้ ใช้ดูผลและรับแจ้งเตือนเท่านั้น ถ้าตั้ง MetaQuotes ID เดียวกันใน Tools → Options แท็บ Notifications ของทุกชุด ข้อความแจ้งเตือนจากทุกเทอร์มินัลจะเข้ามือถือเครื่องเดียว

  • ตั้งชื่อบัญชีในแอปให้ตรงกับผังบนเครื่อง
  • ไล่ดู Equity, Margin Level และจำนวนออเดอร์ของทุกบัญชีในรอบเดียวกัน
  • ถ้าบัญชีหนึ่งเงียบผิดปกติ ให้รีโมตเข้าเครื่องดูชุดนั้นโดยตรง

รูทีนดูผลแบบละเอียดและจุดที่มือถือบอกไม่ได้ อยู่ในดูผล EA มือถือผ่านแอป MT5

คำเตือนความเสี่ยง: การรันหลายบัญชีเพิ่มเงินที่อยู่ในความเสี่ยงรวม และถ้าทุกบัญชีใช้ระบบเดียวกัน การขาดทุนมักเกิดพร้อมกัน การเทรด Forex ทองคำ และ CFD ด้วย EA อาจทำให้สูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อ่านข้อมูลความเสี่ยงฉบับเต็มก่อนเพิ่มบัญชี

คำถามที่พบบ่อย

คอมเครื่องเดียวเปิด MT5 ได้กี่ชุด?

ไม่มีตัวเลขตายตัว ขึ้นกับหน่วยความจำ CPU จำนวนกราฟ และสัญลักษณ์ที่เปิดในแต่ละชุด เริ่มจากน้อยชุด ดูการใช้ทรัพยากรใน Task Manager ช่วงตลาดคึกคัก แล้วค่อยเพิ่ม

รัน EA หลายบัญชีที่ต่างโบรกเกอร์กันในเครื่องเดียวได้ไหม?

ได้ แต่ละชุดล็อกอินเซิร์ฟเวอร์ของโบรกเกอร์ตัวเอง สิ่งที่ต้องระวังคือชื่อสัญลักษณ์และสเปกสัญญาอาจต่างกันในแต่ละโบรกเกอร์ ให้ตรวจ Specification ของทุกบัญชีแยกกัน

ล็อกอินบัญชีเดียวกันบนคอมและ VPS พร้อมกันได้ไหม?

ล็อกอินได้ แต่ให้ EA ทำงานแค่ที่เดียว อีกเครื่องใช้ดูอย่างเดียว ถ้าต้องการแค่ดูผล ใช้แอปมือถือหรือรหัส Investor จะปลอดภัยกว่า เพราะส่งคำสั่งเทรดไม่ได้

ต้องซื้อ EA หลายชุดถ้าจะใช้หลายบัญชีไหม?

ขึ้นกับเงื่อนไขสิทธิ์ของผู้ขาย บาง EA นับตามจำนวนบัญชี บางตัวนับตามเครื่อง สำหรับ EA WING แพ็กเกจ Pro เปิดสิทธิ์ได้ 1 ถึง 2 บัญชี ถ้าต้องการมากกว่านั้นให้คุยกับทีมงานทาง LINE

อ่านต่อ

  • ระบบสิทธิ์ EA ผูกเลขบัญชีทำงานยังไง
  • เปิด MT5 หลายตัวบน VPS เครื่องเดียว
  • Magic Number ใน EA คืออะไร
  • ดูผล EA มือถือผ่านแอป MT5

ถ้าตั้งใจจะรัน EA WING มากกว่าหนึ่งบัญชี เช็กจำนวนบัญชีในแต่ละแพ็กเกจได้ที่หน้าราคา ถ้าอยากให้ทีมงานช่วยติดตั้งให้ แพ็กเกจ VIP รวมการช่วยติดตั้งไว้แล้ว ทักมาคุยทาง LINE ได้
