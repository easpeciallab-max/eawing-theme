ขั้นตอนหลักด้านบนพาคุณลง EA ใน MT5 จนระบบขึ้นกราฟได้แล้ว ส่วนนี้คือรายละเอียดที่ช่วยให้การติดตั้ง EA WING เรียบร้อยตั้งแต่ครั้งแรก ตั้งแต่ชนิดไฟล์ ตำแหน่งโฟลเดอร์ สวิตช์ที่ซ่อนอยู่ในเมนู Options อาการเสียที่พบบ่อย ไปจนถึงเครื่องที่ใช้รันข้ามวันข้ามคืนและการเปลี่ยนรุ่น คิดเสียว่าเป็นเช็กลิสต์ก่อนบินที่ต้องผ่านให้ครบทุกข้อ

รู้จักไฟล์ก่อนลง EA ใน MT5

[eawing_brand] เป็น EA สำหรับ MetaTrader 5 เท่านั้น ใช้กับ MT4 ไม่ได้ หลังทีมงานยืนยันคุณสมบัติเรียบร้อย คุณจะได้รับไฟล์ EA ทาง LINE ก่อนนำไปวาง ลองเช็กให้แน่ใจว่าไฟล์ที่ถืออยู่เป็นชนิดที่ถูกต้อง เพราะ MetaTrader ใช้นามสกุลไฟล์คล้ายกันหลายแบบ

นามสกุลเป็นไฟล์อะไรเอาไปทำอะไร
.ex5โปรแกรม EA ของ MT5 ที่แปลงเป็นไฟล์พร้อมรันแล้ว เปิดอ่านโค้ดข้างในไม่ได้ใส่ไว้ในโฟลเดอร์ Experts แล้วลากจาก Navigator ขึ้นกราฟ
.mq5โค้ดต้นฉบับภาษา MQL5 ในรูปข้อความต้องเปิดด้วย MetaEditor แล้วสั่ง Compile ให้ได้ .ex5 ก่อนจึงจะใช้งานได้
.setไฟล์เก็บชุดค่าพารามิเตอร์ของแท็บ Inputsเก็บไว้ที่ไหนก็ได้ แล้วเรียกขึ้นมาผ่านปุ่ม Load ตอนเปิดหน้าตั้งค่า EA
.ex4 และ .mq4สองนามสกุลนี้เป็นของ MT4MT5 อ่านไม่ได้ วางลงไปก็ไม่มีชื่อโผล่ในรายการ

ถ้าสิ่งที่ได้รับเป็นไฟล์บีบอัด .zip ให้แตกออกมาก่อน แล้วหยิบเฉพาะไฟล์ .ex5 ไปใส่ในโฟลเดอร์ อย่าวางไฟล์ zip ลงไปทั้งก้อน เพราะ MT5 จะมองไม่เห็น

หาโฟลเดอร์ Experts ให้ถูกตัว

ทางที่ไม่มีวันหลงคือเปิดจากในตัวโปรแกรมเอง: คลิกเมนู File เลือก Open Data Folder แล้วดับเบิลคลิกเข้า MQL5 ต่อด้วย Experts คำสั่งนี้พาไปที่ที่เก็บข้อมูลของหน้าต่าง MT5 ที่คุณกดอยู่เท่านั้น ไม่มีทางไปโผล่ที่ชุดอื่น สำหรับคนที่อยากรู้ตำแหน่งบนดิสก์ บน Windows ทั่วไปจะอยู่ใต้ AppData\Roaming\MetaQuotes\Terminal\ ตามด้วยโฟลเดอร์ที่ตั้งชื่อเป็นรหัสยาว ซึ่งแต่ละการติดตั้งได้รหัสไม่เหมือนกัน

วางไฟล์เสร็จแล้วกลับมาที่หน้าต่าง Navigator (Ctrl+N) คลิกขวาที่หัวข้อ Expert Advisors แล้วเลือก Refresh ชื่อ EA จะปรากฏในรายการทันทีโดยไม่ต้องปิดเปิดโปรแกรมใหม่

เครื่องที่ลง MT5 ไว้หลายชุด เช่น แยกชุดละโบรกเกอร์ แต่ละชุดแยกที่เก็บข้อมูลออกจากกันเด็ดขาด ไฟล์ที่ใส่ไว้ในชุดหนึ่งจะไม่ไปโผล่ในอีกชุด จึงต้องกดคำสั่งเปิดโฟลเดอร์จากหน้าต่าง MT5 ที่จะใช้รัน EA จริงเท่านั้น

สวิตช์ใน Tools → Options → Expert Advisors

แท็บนี้เป็นสวิตช์ระดับโปรแกรมที่คุมว่า EA ทุกตัวใน MT5 ทำอะไรได้บ้าง เข้าได้ด้วยคีย์ลัด Ctrl+O หรือผ่านเมนู Tools แล้วคลิกแท็บ Expert Advisors ตัวเลือกที่ควรรู้จักมีดังนี้

  • Allow algorithmic trading สวิตช์หลักที่ต้องเปิดไว้เสมอ ถ้าปล่อยว่าง EA จะยังแสดงบนกราฟได้ตามปกติ แต่คำสั่งซื้อขายทุกคำสั่งจะถูกตีกลับ (MT5 รุ่นเก่าเรียกตัวเลือกนี้ว่า Allow Automated Trading หรือ Allow Auto Trading)
  • กลุ่ม Disable algorithmic trading when... เป็นเบรกกันพลาด ทุกครั้งที่คุณย้ายไปบัญชีอื่น เปลี่ยนโปรไฟล์หน้าจอ หรือสลับคู่สินทรัพย์และกรอบเวลาบนกราฟ ระบบจะดับ Algo Trading ให้เองทันที ดีในแง่ความปลอดภัย แต่ต้องจำว่าหลังทำสิ่งเหล่านี้ คุณต้องเปิดกลับด้วยตัวเอง
  • Allow DLL imports ปล่อยปิดไว้เป็นค่าปกติ และเปิดก็ต่อเมื่อทีมงานยืนยันว่าจำเป็นจริง
  • Allow WebRequest for listed URL ใส่เฉพาะที่อยู่เว็บที่ได้รับแจ้งเท่านั้น ไม่ต้องเพิ่มเองถ้าไม่มีใครบอก

นอกจากเมนูนี้ ยังมีอีกสองจุดที่ต้องเปิดให้ตรงกัน คือปุ่ม Algo Trading บนแถบเครื่องมือด้านบน และช่องอนุญาตให้ EA เทรด (Allow Algo Trading) ซึ่งอยู่ในแท็บ Common ของหน้าต่างคุณสมบัติ EA (กด F7 บนกราฟเพื่อเรียกขึ้นมา) เมื่อครบทั้งสามจุด ไอคอนเล็กข้างชื่อ EA ที่มุมขวาบนของกราฟจะเป็นสีฟ้า ถ้ายังเป็นสีเทาแปลว่ามีจุดใดจุดหนึ่งปิดอยู่ (MT5 รุ่นเก่าใช้รูปหน้ายิ้มกับหน้าบึ้งแทน) อ่านคำอธิบายจากผู้พัฒนาแพลตฟอร์มได้ที่ คู่มือ Expert Advisors ของ MetaTrader 5 และ หน้าอธิบาย Platform Settings (ภาษาอังกฤษ)

เก็บค่าตั้งและจดเวอร์ชันให้ย้อนกลับได้

วันที่ทุกอย่างทำงานปกติ คือวันที่ควรจดไว้มากที่สุด เพราะถ้าวันหนึ่งมีอะไรเปลี่ยนไป คุณจะมีจุดอ้างอิงให้ย้อนกลับ หลังตั้งค่าในแท็บ Inputs เสร็จ ให้กด Save เก็บเป็นไฟล์ .set ทุกครั้ง แล้วทำตามแนวทางนี้

  • ตั้งชื่อไฟล์ค่าตั้งให้รู้ทันทีว่าเป็นของบัญชีไหนและบันทึกวันไหน เช่น demo-acc1-2026-10.set แทนชื่อกว้าง ๆ อย่าง setting1.set
  • แยกโฟลเดอร์ระหว่างค่าตั้งต้นที่ยังไม่ได้แตะ กับชุดที่คุณปรับเอง จะได้กลับไปเริ่มใหม่ได้เสมอ
  • มีสมุดบันทึกสั้น ๆ ว่าบัญชีไหนรัน EA เวอร์ชันอะไร ใช้ค่าชุดไหน และเริ่มใช้วันไหน
  • เมื่อเปลี่ยนเวอร์ชัน อย่าโหลดไฟล์ค่าตั้งของรุ่นเก่าทับโดยไม่ตรวจ รุ่นใหม่อาจเพิ่ม ตัด หรือเปลี่ยนชื่อช่องในแท็บ Inputs ไปแล้ว

อาการที่เจอบ่อยหลังลง EA และวิธีไล่แก้

เมื่อมีอะไรผิดปกติ ที่แรกที่ควรเปิดคือหน้าต่าง Toolbox (Ctrl+T) แล้วดูแท็บ Experts กับ Journal ข้อความในสองแท็บนี้มักบอกต้นเหตุได้ตรงกว่าการเดา ตารางนี้รวมอาการที่พบบ่อยไว้ให้ไล่ทีละข้อ ส่วนวิธีอ่านข้อความแต่ละแบบอธิบายไว้ใน อ่าน MT5 Journal และแท็บ Experts

สิ่งที่เห็นสาเหตุที่น่าสงสัยลองทำแบบนี้
ชื่อ EA ไม่อยู่ในรายการของ Navigatorไฟล์ไปอยู่ผิดที่ เช่น ใน Indicators หรือใน MT5 คนละชุด หรือเป็นไฟล์ของ MT4เข้าโฟลเดอร์ข้อมูลผ่านเมนู File ของหน้าต่างที่ใช้จริง ย้าย .ex5 ไปไว้ใน Experts แล้วสั่ง Refresh
ไอคอนข้างชื่อ EA บนกราฟเป็นสีเทาสวิตช์ Algo Trading บนแถบด้านบนยังดับอยู่ หรือแท็บ Common ของ EA ยังไม่ได้ติ๊กอนุญาตกดเปิดปุ่มบนแถบเครื่องมือ แล้วกด F7 บนกราฟเพื่อตรวจแท็บ Common
Algo Trading ดับเองหลังสลับบัญชีหรือเปลี่ยนกราฟเบรกกันพลาดในกลุ่ม Disable algorithmic trading when... ทำงานตามที่ตั้งไว้เปิดปุ่มกลับ แล้วพิจารณาว่าจะคงตัวเลือกนั้นไว้หรือไม่
Journal แจ้งว่าบัญชีนี้เทรดไม่ได้เข้าระบบด้วยรหัสสำหรับดูอย่างเดียว (Investor) หรือโบรกเกอร์จำกัดสิทธิ์ซื้อขายของบัญชีไว้ออกแล้วเข้าระบบใหม่ด้วย Master password ถ้ายังไม่หายให้สอบถามโบรกเกอร์
ข้อความ not enough moneyFree Margin ในบัญชีไม่พอรองรับขนาดออเดอร์ที่ระบบพยายามเปิดทบทวนขนาดความเสี่ยงในค่าตั้งเทียบกับเงินในบัญชี แล้วปรึกษาทีมงานก่อนแก้
ข้อความ invalid volumeขนาดไม้เล็กกว่าที่โบรกเกอร์ยอมรับ หรือไม่ลงตัวกับขั้นการเพิ่มทีละช่วงเปิดหน้า Specification แล้วดูสองค่านี้: Minimal volume กับ Volume step
ข้อความ market closedส่งคำสั่งนอกช่วงเวลาซื้อขายของสัญลักษณ์รอตลาดเปิด หรือดูตารางเวลาในหัวข้อ Sessions ของหน้า Specification
ลาก EA ขึ้นกราฟแล้วหลุดออกเองEA เริ่มทำงานไม่สำเร็จด้วยเหตุผลบางอย่างอ่านบรรทัดล่าสุดในแท็บ Experts แคปหน้าจอส่งให้ทีมงานทาง LINE
หลายวันแล้วไม่มีออเดอร์ตลาดยังไม่เข้าเงื่อนไขของระบบ หรือ EA ถูกแนบบนกราฟที่ชื่อสัญลักษณ์ไม่ตรงกับค่าตั้งเทียบชื่อสัญลักษณ์บนกราฟกับรายชื่อใน Market Watch (Ctrl+M) แล้วถามทีมงานพร้อมภาพแท็บ Experts

ยังไม่เคยเปิดหน้า Specification? ไปที่ Market Watch คลิกขวาบนชื่อสัญลักษณ์ที่สนใจ เมนูนี้จะแสดงสเปกสัญญาทั้งหมดที่โบรกเกอร์ตั้งไว้ ทั้งขนาดสัญญา ขนาดไม้ต่ำสุด และเวลาซื้อขาย

รันข้ามวันข้ามคืนบน Windows VPS แล้วดูผลจากมือถือ

EA มีชีวิตอยู่ได้ก็ต่อเมื่อโปรแกรม MT5 บนเครื่อง Windows ยังเปิดและต่อเน็ตอยู่ คอมดับ เครื่องหลับ หรือสายเน็ตหลุดเมื่อไร ระบบก็หยุดตามทันที ทีมงานจึงแนะนำให้รัน [eawing_brand] บน Windows VPS ที่ไม่เคยปิดเครื่อง แล้วใช้แอป MT5 บนมือถือคอยติดตามผล แอปบนมือถือดูออเดอร์และยอดในพอร์ตได้ แต่รัน EA เองไม่ได้

  • VPS เป็นเครื่องใหม่อีกเครื่อง จึงต้องติดตั้งซ้ำตั้งแต่ต้น ทั้งใส่ไฟล์ .ex5 เปิดสวิตช์ในเมนู Options และเรียกค่าตั้งขึ้นมา
  • เลิกใช้งานแต่ละครั้ง แค่กดกากบาทปิดหน้าต่างการเชื่อมต่อก็พอ คำสั่งออกจากระบบ (Sign out) จะปิดโปรแกรมที่ค้างไว้ทั้งหมด MT5 ก็หยุดไปด้วย
  • ตั้งเวลาให้ Windows ลงอัปเดตในช่วงที่ตลาดปิด และใส่ MT5 ไว้ในรายการโปรแกรมที่เปิดอัตโนมัติหลังรีสตาร์ท
  • รัน EA บนบัญชีหนึ่งจากเครื่องเดียวเท่านั้น ถ้าเปิดพร้อมกันทั้งคอมที่บ้านและบน VPS อาจได้ออเดอร์ซ้อนกันโดยไม่ตั้งใจ

ขั้นตอนเช่าและเชื่อมต่อ VPS อยู่ใน คู่มือ VPS รัน EA ส่วนการล็อกอินแอป MT5 บนโทรศัพท์ดูได้ที่ ติดตั้งและล็อกอิน MT5

เปลี่ยนเป็นเวอร์ชันใหม่อย่างปลอดภัย

วันที่ได้รับไฟล์รุ่นใหม่จากทีมงาน ให้ทำตามลำดับด้านล่าง ไม้ที่ยังเปิดอยู่จะได้ไม่โดนผลกระทบระหว่างเปลี่ยน

  1. เลือกจังหวะ ทำตอนไม่มีออเดอร์ค้าง หรือตอนตลาดปิดช่วงสุดสัปดาห์ ถ้ายังมีไม้ค้างอยู่ ถามทีมงานก่อนว่าควรรอหรือเปลี่ยนได้เลย
  2. สำรองของเดิม ก็อปไฟล์รุ่นปัจจุบันไปเก็บไว้อีกโฟลเดอร์ แล้วบันทึกค่าในแท็บ Inputs เป็น .set อีกชุด
  3. ถอดตัวเก่าออก คลิกขวาบนกราฟแล้วถอด EA ออก หรือปิดกราฟนั้นไปเลยก็ได้
  4. ใส่ไฟล์ใหม่ นำรุ่นใหม่ไปไว้ในโฟลเดอร์ Experts จะทับชื่อเดิมหรือตั้งชื่อใหม่ให้ยึดตามที่ทีมงานบอก จากนั้นสั่ง Refresh รายการ
  5. แนบใหม่และตรวจค่า ลากรุ่นใหม่ขึ้นกราฟ อ่านค่าในแท็บ Inputs ให้ครบทุกช่องก่อนยืนยัน
  6. ยืนยันว่าทำงาน เปิดแท็บ Experts ดูว่ารุ่นใหม่โหลดผ่านและไม่มีบรรทัดแจ้งข้อผิดพลาด ใครรันไว้หลายเครื่อง อย่าลืมเปลี่ยนให้ครบทุกที่

ติดขั้นตอนไหน ส่งภาพหน้าจอแท็บ Experts หรือ Journal ให้ทีมงานคนไทยช่วยดูได้ทาง LINE

ไม่ได้ EA WING ออกแบบมาสำหรับ MetaTrader 5 เท่านั้น ถ้าตอนนี้ใช้ MT4 อยู่ ต้องติดตั้ง MT5 และใช้บัญชีที่รองรับ MT5 ก่อน

ไม่เช่า VPS ได้ไหม ใช้คอมที่บ้านแทน?

ได้ แต่คอมเครื่องนั้นต้องเปิดอยู่ทั้งวันทั้งคืนพร้อม MT5 ปิดโหมดประหยัดพลังงานทุกแบบ และต้องพึ่งไฟบ้านกับเน็ตบ้านที่เสถียร เพราะเหตุนี้ทีมงานจึงแนะนำ Windows VPS ซึ่งไม่ต้องมีใครคอยเฝ้าเครื่อง

ถ้าเผลอปิด MT5 ไม้ที่เปิดค้างอยู่จะเป็นอะไรไหม?

ไม้นั้นไม่หายไปไหน เพราะถูกเก็บไว้ฝั่งโบรกเกอร์ และคำสั่งที่ฝากไว้กับเซิร์ฟเวอร์ยังมีผลตามปกติ แต่งานดูแลไม้ที่ EA ทำผ่านตัวโปรแกรมจะชะงักลง จนกว่าโปรแกรมจะถูกเปิดขึ้นมาและ EA กลับมาทำงานบนกราฟ

ให้ทีมงานช่วยติดตั้งได้ไหม?

ได้ ทีมงานคนไทยช่วยเรื่องติดตั้งและตั้งค่าทาง LINE ส่งภาพหน้าจอของจุดที่ติดมาได้เลย จะช่วยให้แก้ได้เร็วขึ้น
