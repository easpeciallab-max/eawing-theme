WING BTC ทำงานอย่างไร

EA เปิดออเดอร์เป็นรอบบนกราฟ BTCUSD เมื่อราคาวิ่งสวนทาง EA เปิดออเดอร์เพิ่มตามระยะกริดและทบขนาด lot แล้วปิดทั้งรอบพร้อมกันเมื่อกำไรลอยรวมถึงเป้า EA ไม่ได้ทายทิศทางของราคา มันทำตามเงื่อนไขที่ตั้งไว้ คุณจึงต้องเข้าใจว่ามันจะทำอะไรเมื่อราคาวิ่งทางเดียวไกล ๆ

  • ชุด SKY ฝังในตัว ใช้ได้ทันทีบนกราฟ BTCUSD M1 ในหน้า Inputs ช่อง "ชุดที่ใช้" เป็น SKY อยู่แล้ว ไม่ต้องแก้ค่าใด ถ้าแก้ ผลจะไม่ตรงกับรายงาน
  • ระยะกริดขยายเองตามแรงตลาด ตลาดปกติระยะกริด 300 ดอลลาร์ ตลาดวิ่งแรงระยะจะกว้างขึ้นอัตโนมัติ

  • ไม่มีการตัดขาดทุน ไม่มี Stop Loss ถ้าราคาวิ่งทางเดียวไกลกว่าที่ระบบรับได้ บัญชีเสียหายหนักได้

ใช้คู่กับ EA ตัวอื่นได้ไหม: WING BTC เทรดบนกราฟ BTCUSD ซึ่งเป็นคนละสินค้ากับทองคำ จึงรันในบัญชีเดียวกับ EA ทองคำได้ แต่อย่ารันระบบกริด BTC ตัวอื่นพร้อมกันในบัญชีเดียวกัน เพราะไม้จะซ้อนกันและความเสี่ยงเพิ่มเป็นเท่าตัว และอย่าลืมว่า EA ทุกตัวใช้มาร์จิ้นจากบัญชีเดียวกัน

ต้องมีอะไรบ้างก่อนใช้

  • บัญชี MT5 แบบ Hedging ที่มีกราฟ BTCUSD.c (บัญชีเซนต์) หรือ BTCUSD.s (บัญชี USD) ผลทดสอบใช้กราฟ BTCUSD.c ของ Zaurix (EA WING เป็นพันธมิตรกับ Zaurix) ยังไม่มีบัญชี เริ่มที่ เปิดบัญชี MT5
  • ทุนไม่น้อยกว่าที่หน้าจอบอก 3,125 ต่อ LOTx1 ใช้ทุนต่ำกว่านี้ไม่แนะนำ
  • เครื่องที่เปิด MT5 ไว้ตลอด ไม้ช่วยปิดตะกร้าค้างและการดูแลรอบทำงานได้เฉพาะตอน MT5 เปิดอยู่ แนะนำ Windows VPS
  • สิทธิ์ใช้งาน ส่งเลขบัญชี MT5 และชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE บัญชีเดโมเปิดสิทธิ์ได้

ติดตั้ง WING BTC ทีละขั้น

  1. วางไฟล์ในโฟลเดอร์ Experts

    แตกไฟล์ .zip แล้วเปิด MT5 ไปที่ File → Open Data Folder → MQL5 → Experts วางไฟล์ [eawing_ea product="btc"] จากนั้นคลิกขวาที่ Expert Advisors ในหน้าต่าง Navigator แล้วเลือก Refresh

  2. เปิดสวิตช์ในตัวโปรแกรม

    Tools → Options → Expert Advisors ติ๊ก Allow DLL imports แล้วกด OK (ใช้ตรวจสิทธิ์การใช้งาน) และกดปุ่ม Algo Trading ด้านบนของ MT5 ให้เป็นสีเขียว

  3. ลาก EA ลงกราฟ BTCUSD M1

    เปิดกราฟ BTCUSD.c หรือ BTCUSD.s ตั้งกรอบเวลา M1 แล้วลาก EA ลงกราฟ แท็บ Common ติ๊ก Allow Algo Trading และ Allow DLL imports แท็บ Inputs ไม่ต้องแก้อะไร

  4. ดูสถานะสิทธิ์

    หน้าจอการ์ดสีขาวฟ้าขึ้นที่มุมซ้ายบนของกราฟ มุมขวาบนของการ์ดบอกสถานะสิทธิ์ ขึ้นว่าผ่านพร้อมวันหมดอายุคือเริ่มทำงาน ขึ้นว่าไม่มีสิทธิ์ให้ติดต่อทีมงาน เมื่อเพิ่มเลขบัญชีแล้ว ระบบเริ่มเองภายใน 5 นาที

  5. ตั้งขนาด LOT

    กดลด LOT หรือเพิ่ม LOT ให้ทุนที่หน้าจอบอกไม่เกินเงินในบัญชี หรือกด "จัด LOT อัตโนมัติจากเงินในบัญชี"

ในไฟล์ .zip มีไฟล์อ่านก่อน รายงานผลทดสอบ LOTx1 และ LOTx32 (PDF) และไฟล์ .set สำหรับ Strategy Tester ติดขั้นไหน ส่งภาพหน้าจอให้ทีมงานทาง LINE ได้ ขั้นตอนทั่วไปของ MT5 พร้อมภาพอยู่ใน คู่มือติดตั้ง EA บน MT5
