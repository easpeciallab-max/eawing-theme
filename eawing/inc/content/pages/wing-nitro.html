WING NITRO คือ EA เทรดทองคำ XAUUSD อัตโนมัติบน MetaTrader 5 ของ [eawing_brand] มีชุดเดียวชื่อ NITRO (บินสูง · เน้นทำกำไร) ฝังอยู่ในตัว EA เปิดไม้เป็นตะกร้า เมื่อราคาสวนทางจะเติมไม้แก้เป็นขั้นบันไดและทบขนาดไม้ (ระบบมาร์ติงเกล) ไม่มีจุดตัดขาดทุน หน้านี้รวมสิ่งที่ควรรู้ก่อนตัดสินใจ ตั้งแต่วิธีทำงาน ระบบคูณกับเงินที่ต้องมี ผลทดสอบย้อนหลังพร้อมเงื่อนไข ความเสี่ยง ไปจนถึงวิธีติดตั้ง

WING NITRO ทำงานอย่างไร

EA เปิดไม้เป็นตะกร้าบนกราฟทองกรอบเวลา M1 ถ้าราคาวิ่งสวนทาง EA จะเติมไม้แก้เป็นขั้นบันไดและทบขนาดไม้ แล้วปิดทั้งตะกร้าพร้อมกันเมื่อกำไรรวมถึงเป้า จากนั้นรอจังหวะเปิดตะกร้าใหม่ EA ไม่ได้ทายทิศราคา มันทำตามกติกาของชุดที่ฝังไว้ในไฟล์ แดชบอร์ดบนกราฟมีไว้ดูสถานะและกดปรับค่าระหว่างวัน

  • ชุด NITRO ชุดเดียว ชุดเดียวกับโหมด Full ของ EA WING รุ่น 4.2 ฝังในตัว EA ไม่ต้องเลือกโหมด ไม่ต้องโหลดไฟล์ .set ไฟดับหรือลากใส่ใหม่ก็ได้ชุดเดิมเสมอ แดชบอร์ดระบุระดับความเสี่ยงของชุดนี้ว่าสูง
  • บันไดไม้แก้ตามความผันผวน ระยะห่างของไม้แก้ปรับตามความผันผวนของตลาด และไม่เติมไม้แก้ถ้าระดับมาร์จิ้นของบัญชีจะต่ำเกินเกณฑ์ของชุด
  • เป้ากำไรวันนี้ ค่าของชุดคือ 5% ของเงินต้นวัน แดชบอร์ดแปลงเป็นเงินให้ ถึงเป้าแล้ว EA หยุดเปิดตะกร้าใหม่จนหมดวัน เป้านี้เป็นจุดหยุดของระบบ ไม่ใช่ผลตอบแทนที่จะได้ทุกวัน
  • หลบข่าวแดง USD งดเปิดตะกร้าใหม่ตั้งแต่ 90 นาทีก่อนข่าว ถึง 720 นาทีหลังข่าว ตะกร้าที่ถืออยู่ยังดูแลต่อตามปกติ
  • ช่วงเวลาเสี่ยง ช่วงที่ชุดกำหนดว่าราคามักลากไกล EA ไม่เปิดตะกร้าใหม่ และตะกร้าที่ค้างจะปิดเมื่อกลับมาเสมอตัว ตะกร้าที่ลึกมาก EA ลดเป้าเหลือแค่เสมอตัวเพื่อรีบออก
  • ความจำกันไฟดับ EA บันทึกสถานะตะกร้าลงเครื่องทุกครั้งที่สถานะเปลี่ยนและทุก 30 วินาที ไฟดับแล้วเปิด MT5 ใหม่ EA ดูแลตะกร้าเดิมต่อเอง
  • ไม่มีจุดตัดขาดทุน ราคาวิ่งสวนยาวกว่าที่บันไดไม้แก้รับไหว บัญชีเสียหายหนักได้ถึงเสียเงินทั้งหมด

ในตัว EA มีปฏิทินวันงดเทรดของปี 2026 จำนวน 25 วัน วันในปฏิทิน EA ไม่เปิดตะกร้าใหม่และปิดตะกร้าที่ค้างทิ้งทันทีโดยยอมรับผลขาดทุน วันสุดท้ายในปฏิทินคือ 5 ส.ค. 2026 หลังจากนั้นไม่มีวันงดเทรดเหลือ รันจริงตอนนี้ EA เทรดทุกวันทำการ และตะกร้าที่ลากจะไม่ถูกปิดตัดแบบในผลทดสอบ

ต้องมีอะไรบ้างก่อนใช้

  • สิทธิ์ใช้งาน ใช้ได้เฉพาะเลขบัญชีที่ทีมงานลงทะเบียนไว้ บัญชีที่ใช้ EA WING 5.0 ได้อยู่แล้วใช้ WING NITRO ได้เลยไม่ต้องขอใหม่ บัญชีเดโมก็ต้องขอสิทธิ์เหมือนกัน
  • กราฟทองกรอบเวลา M1 ผลทดสอบใช้ XAUUSD.c ของ Zaurix (EA WING เป็นพันธมิตรกับ Zaurix) ใช้ทองของโบรกเกอร์คุณได้ แต่ราคาและสเปรดที่ต่างกันทำให้ผลต่างจากที่ทดสอบ
  • เงินในบัญชีถึงเกณฑ์ 15,000 ต่อ x1 และบัญชี USD ต้องมี 100,000 USD ขึ้นไป ตามหัวข้อระบบคูณด้านบน
  • Allow DLL imports และอินเทอร์เน็ต EA ส่งเลขบัญชีและชื่อเซิร์ฟเวอร์ไปตรวจสิทธิ์เอง ไม่ต้องใส่ลิงก์หรือรหัสใดใน MT5
  • คอมหรือ VPS ที่เปิดตลอด EA ดูแลตะกร้าได้เฉพาะตอน MT5 เปิดอยู่ ดู คู่มือ VPS บน Windows
  • ทองตัวนั้นไม่มีไม้อื่น ไม่มีไม้ที่เปิดเอง และไม่มี EA ตัวอื่นบนทองตัวเดียวกันในบัญชีเดียวกัน

ติดตั้ง WING NITRO ทีละขั้น

  1. ขอสิทธิ์ใช้งาน

    ส่งเลขบัญชี MT5 และชื่อเซิร์ฟเวอร์โบรกเกอร์ให้ทีมงานทาง LINE ถ้าบัญชีนี้ใช้ EA WING 5.0 ได้อยู่แล้ว ข้ามขั้นนี้ได้

  2. วางไฟล์ในโฟลเดอร์ Experts

    แตกไฟล์ .zip ก่อน แล้วไปที่ File → Open Data Folder → MQL5 → Experts วางไฟล์ [eawing_ea product="nitro"] จากนั้นคลิกขวาในหน้าต่าง Navigator แล้วเลือก Refresh

  3. เปิดสวิตช์ในตัวโปรแกรม

    ไปที่ Tools → Options → Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports แล้วกด OK

  4. ลาก EA ลงกราฟทอง M1

    เปิดกราฟทองของโบรกเกอร์ (เช่น XAUUSD.c) ตั้งกรอบเวลา M1 แล้วลาก [eawing_ea product="nitro" field="name"] ใส่กราฟ แท็บ Common ติ๊ก Allow Algo Trading ถ้ามีแท็บ Dependencies ให้ติ๊ก Allow DLL imports ด้วย แท็บ Inputs ไม่ต้องแก้ แล้วกด OK

  5. เปิดปุ่ม Algo Trading

    กดปุ่ม Algo Trading ด้านบนของ MT5 ให้เป็นสีเขียว ไม่กี่วินาทีจะขึ้นหน้าต่างล็อกอินสำเร็จ และการ์ดล็อกอินบนแดชบอร์ดเป็นสีเขียว

  6. ตรวจแถวตัวคูณ

    แถวตัวคูณบอกตัวคูณ แบบที่ใช้ ทุนคิดไม้ และเงินในบัญชี ตัวเลขสีแดงแปลว่าเงินไม่ถึง 15,000 ต่อ x1 จากนั้นเปิดคอมหรือ VPS กับ MT5 ทิ้งไว้ตลอด

เปลี่ยนจาก EA ตัวอื่นมาใช้ WING NITRO

รอให้ไม่มีตะกร้าเปิดอยู่ แล้วถอด EA ตัวเดิมออกจากกราฟก่อน WING NITRO ใช้ Magic คนละเลขกับ EA ตัวเดิม จึงไม่รับตะกร้าของตัวเดิมไปดูแล และถ้ามีไม้ของ EA ตัวเดิมค้างบนทองตัวเดียวกัน WING NITRO จะนับรวมในตะกร้าแล้วปิดไปพร้อมกัน หลังลากใส่กราฟให้ดูว่าท้ายแผงขึ้นชื่อ WING NITRO พร้อมเลขรุ่น การ์ดล็อกอินเป็นสีเขียว และแถวตัวคูณตรงกับเงินในบัญชี
