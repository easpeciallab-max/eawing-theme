  • Leverage สูงพอ ผลทดสอบใช้ 1:2000 ระดับมาร์จิ้นต่ำสุดที่ LOTx1 ทุน 20,000 อยู่ที่ 547.19% Leverage ต่ำใช้มาร์จิ้นมากขึ้นตามสัดส่วน ช่วงเดียวกันที่ 1:500 จะเหลือราว 137% และที่ 1:100 เหลือราว 27% ซึ่งโบรกเกอร์ตัดออเดอร์ ช่วงออเดอร์กู้ lot รวมขึ้นได้สูง

ติดตั้ง WING TWIN ทีละขั้น

  1. ล็อกอินบัญชีเทรดและตรวจคำว่า Hedge

  2. เปิดสวิตช์ในตัวโปรแกรม

    ไปที่ Tools → Options → Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports แล้วกด OK

  3. วางไฟล์ในโฟลเดอร์ Experts

    แตกไฟล์ .zip ก่อน แล้วไปที่ File → Open Data Folder → MQL5 → Experts วางไฟล์ [eawing_ea product="twin"] จากนั้นกลับมาที่หน้าต่าง Navigator คลิกขวาที่ Expert Advisors แล้วเลือก Refresh

  4. เปิดกราฟ XAUUSD.s กรอบเวลา M1

    คลิกขวาที่ XAUUSD.s ในหน้าต่าง Market Watch เลือก Chart Window แล้วกดปุ่ม M1

  5. ลาก EA ลงกราฟและตั้งขนาด LOT

    แท็บ Common ติ๊ก Allow Algo Trading และ Allow DLL imports ถ้ามีให้ติ๊ก แท็บ Inputs ช่อง A1 เป็น WING LIFE อยู่แล้ว ตั้งช่อง B21 ขนาด LOT (1 / 2 / 4 / 8 / 16 / 20 / 24 / 28 / 32) แล้วกด OK ขนาด LOT ช่วงออกเที่ยว และเป้ากำไรรายวันปรับภายหลังที่แผงได้

  6. เปิดปุ่ม Algo Trading แล้วตรวจแผง

    ป้ายขวาบนของแผงต้องเป็นยืนยันสิทธิ์สำเร็จ แถบสถานะไม่เป็นสีแดง ปุ่ม WING LIFE เป็นพื้นน้ำเงินเต็ม ช่วงออกเที่ยว 11:00 ถึง 24:00 ขึ้นว่าตามโปรไฟล์ เป้ากำไรรายวันขึ้นว่าปิด ถ้าต้องการให้เหมือนผลทดสอบ ขนาด LOT ตรงที่ตั้งใจ และท้ายแผงขึ้น ID 552193 จากนั้นเปิดคอมหรือ VPS กับ MT5 ทิ้งไว้ตลอด EA ออกเที่ยวเองเมื่อเงื่อนไขครบ

อยากหยุดแค่เที่ยวใหม่ให้แตะปุ่มจอดพักหลังจบเที่ยว EA ไม่เริ่มเที่ยวใหม่แต่ดูแลเที่ยวที่ค้างจนจบ ถ้าจะถอด EA ช่วงที่เหมาะคือหลังเที่ยวปิด หรือช่วงที่ EA ไม่ออกเที่ยวเองอยู่แล้ว (ก่อน 11:00 ศุกร์หลัง 18:00 และสุดสัปดาห์) ถอดตอนมีเที่ยวค้าง ออเดอร์ยังอยู่ในบัญชีแต่ไม่มีใครดูแลจนกว่าจะติด EA กลับ และการปิดปุ่ม Algo Trading ไม่ใช่วิธีพัก

แผงควบคุมบนกราฟ

แผงอยู่มุมซ้ายบนของกราฟ บอกทุกอย่างที่ EA ทำอยู่ ด้านบนเป็นป้ายสิทธิ์ แถบสถานะ (เขียว ปกติ · ส้ม รอหรือเตือน · แดง หยุดหรือมีเรื่องต้องแก้) และแถวเงิน BALANCE EQUITY P/L ค้าง และกำไรที่ปิดแล้ววันนี้ ฝั่งซ้ายเป็นปุ่มควบคุมห้าเรื่อง ฝั่งขวาเป็นข้อมูลเที่ยวบิน กราฟแคบแผงเรียงเป็นคอลัมน์เดียวให้เอง

  • ขนาด LOT ปุ่ม LOT − / LOT + ข้อความด้านขวาบอกขนาดออเดอร์แรก ถ้าขนาดที่เลือกเกิน lot ต่อออเดอร์ที่โบรกรับ แผงขึ้นบรรทัดสีส้มเตือน
  • โปรไฟล์ ปุ่ม WING LIFE (ค่าที่ทดสอบ) และปุ่มกำหนดเอง (ใช้ค่าในหน้า Inputs ไม่มีผลทดสอบรองรับ)
  • ช่วงออกเที่ยว (เวลาไทย) ปุ่มลดและเพิ่มเวลาเริ่มและสิ้นสุดทีละชั่วโมง ใช้ได้ทันทีแม้มีเที่ยวค้าง เพราะมีผลแค่การเริ่มเที่ยวใหม่ เวลาที่ไม่ใช่ของโปรไฟล์ขึ้นว่ากำหนดเองและไม่มีผลทดสอบรองรับ กดกลับไปใช้เวลาตามโปรไฟล์ได้
  • เป้ากำไรรายวัน ปุ่มลดและเพิ่มทีละ 100 ปิดคือค่าที่ทดสอบ กำไรที่ปิดแล้ววันนี้ถึงเป้า EA งดเที่ยวใหม่จนถึง 00:00 เวลาไทย เที่ยวที่ค้างดูแลต่อจนปิด เป้านี้ไม่ใช่ตัวตัดขาดทุน และไม่มีผลทดสอบรองรับ
  • จอดพักหลังจบเที่ยว EA ไม่เริ่มเที่ยวใหม่ แต่เที่ยวที่ค้างยังเพิ่มออเดอร์ ส่งออเดอร์กู้ และปิดที่เป้าจนจบ ใช้ปุ่มนี้แทนการปิด Algo Trading เพราะการปิด Algo Trading ตอนมีเที่ยวค้างทำให้เที่ยวนั้นไม่มีใครดูแล

โปรไฟล์และขนาด LOT ที่กดตอนมีเที่ยวค้างจะถูกจองไว้ใช้หลังจบเที่ยวนั้น ข้อมูลเที่ยวบินฝั่งขวาบอกจำนวนออเดอร์ในเที่ยว lot ที่ถือ จำนวนครั้งที่กลับทิศจาก 4 เป้าปิดเที่ยว ราคาและ lot ของออเดอร์ถัดไป ค่า ADX สเปรด ระดับมาร์จิ้น (สีแดงเมื่อต่ำกว่า 300%) และเที่ยวที่ปิดสะสม คำสถานะที่เห็นบ่อยคือ รอเวลาออกเที่ยว รอแรงตลาด พร้อมออกเที่ยว กำลังบิน และกำลังลงจอด ช่วงออเดอร์กู้สถานะยังเป็นกำลังบิน แต่รายละเอียดเปลี่ยนเป็นกรอบราคา จำนวนครั้งที่แตะขอบ และจำนวนออเดอร์กู้ ความหมายของทุกคำและสิ่งที่ควรทำอยู่ในคู่มือ PDF ในไฟล์ zip
