WING TWIN คือ EA เทรดทองคำ XAUUSD อัตโนมัติบน MetaTrader 5 สินค้าตัวที่สองของ [eawing_brand] ทำงานด้วยเครื่องยนต์ DUAL GRID หรือกริดสองทาง ใช้บัญชีและทุนคนละแบบกับ EA WING 5.0 หน้านี้รวมสิ่งที่ควรรู้ก่อนตัดสินใจ ตั้งแต่หลักการทำงาน 4 ชุดในตัว ทุนที่ต้องมี ผลทดสอบย้อนหลังพร้อมเงื่อนไข ความเสี่ยง ไปจนถึงวิธีติดตั้ง

WING TWIN ทำงานอย่างไร

ตอนเริ่มรอบ EA จำราคาไว้เป็นจุดอ้างอิง ราคาขึ้นครบ 1 กริดเมื่อไหร่ EA เปิด BUY ราคาลงครบ 1 กริดเมื่อไหร่ EA เปิด SELL ไม้แรกขนาด 0.01 lot ที่ขนาด N = 1 ถ้าราคาไปทางเดิมอีก 1 กริด EA เปิดออเดอร์ทิศเดิมขนาดเท่าไม้ล่าสุด ถ้าราคากลับทิศ EA เปิดออเดอร์ฝั่งตรงข้ามที่ใหญ่ขึ้นตามตัวคูณของชุด แล้วปิดทุกออเดอร์พร้อมกันเมื่อกำไรลอยรวมถึงเป้า เท่านี้คือจบหนึ่งรอบ จากนั้น EA ตั้งจุดอ้างอิงใหม่แล้วเริ่มนับใหม่ EA ไม่ได้ทายทิศราคา มันเปิดออเดอร์ตามระยะกริดและกติกาที่ตั้งไว้ตายตัว

  • ไม้สวนทางทบ lot ตัวคูณ 1.70 ถึง 1.75 เท่าแล้วแต่ชุด ทบได้สูงสุด 5 ครั้งต่อรอบ ครบแล้วไม้สวนทางขนาดเท่าไม้ล่าสุด (ชุดที่ 1 ไม้ใหญ่สุด 0.23 lot ที่ N = 1)
  • กริดกว้างขึ้นเมื่อสวนทางหลายครั้ง ตั้งแต่สวนทางครั้งที่ 3 ระยะกริดเพิ่มขึ้นทีละขั้นตามชุด
  • เพดาน 60 ออเดอร์ต่อรอบ ครบแล้วไม่เปิดเพิ่ม รอปิดที่เป้า ช่วงนี้คือที่มาของการติดลบลอยก้อนใหญ่
  • เป้าปิดรอบคิดต่อ lot เป้าเท่ากับค่าต่อ lot ของชุดคูณ lot รวมที่เปิดอยู่ แล้วหารครึ่งทุกครั้งที่สวนทาง ราคากลับมาไม่มากก็ปิดรอบได้
  • เริ่มรอบใหม่เมื่อตลาดมีแรง ไม้แรกของรอบเปิดเฉพาะตอน ADX M30 (14) ได้ตั้งแต่ 25 และอยู่ในเวลาเริ่มรอบของชุด รอบที่เปิดแล้วดูแลต่อทุกเวลา
  • กติกาวันศุกร์ ตั้งแต่ 18:00 เวลาไทยไม่เริ่มรอบใหม่ และรอบที่ค้างจะปิดเมื่อกลับมาเสมอตัว ตั้งแต่ 22:00 ถึงตลาดเปิดวันจันทร์ไม่เปิดออเดอร์ใหม่ รอบที่ราคาไม่กลับยังค้างข้ามสุดสัปดาห์ได้
  • ไม่มีการตัดขาดทุน ไม่มี Stop Loss และไม่มีตัดขาดทุนรวม ราคาลากทางเดียวไกล EA ถือออเดอร์รอราคากลับ

เลือกชุดอย่างไร

  • ผู้เริ่มใหม่ หรือทุน 10,000 ถึง 19,999 USD ชุดที่ 1 WING LIFE1 (แนะนำ) หรือชุดที่ 2 ที่ N = 1
  • ทุน 20,000 ถึง 29,999 USD ชุดที่ 1 ถึง 2 ที่ N = 1 ซึ่งทรุดเป็นเปอร์เซ็นต์น้อยลงราวครึ่งหนึ่ง หรือชุดที่ 3 ถึง 4 ที่ N = 1
  • ทุน 30,000 USD ขึ้นไป ใช้ได้ทุกชุดที่ N = 1 หรือชุดที่ 1 ถึง 2 ที่ N เท่ากับทุนหารด้วย 20,000 แล้วปัดลง

ห้ามรันหลายชุดพร้อมกันในบัญชีเดียว เพราะติดลบลอยของแต่ละชุดจะรวมกัน ถ้าอยากใช้หลายชุดให้แยกบัญชี

ขนาด N

N ใส่ได้เฉพาะจำนวนเต็ม 1 ถึง 20 ไม้แรกเท่ากับ 0.01 × N lot และกำไร ติดลบลอย กับขนาดทุกออเดอร์คูณ N ทั้งหมด N 1.5 ทำไม่ได้เพราะ lot เล็กสุดของทองคือ 0.01 คนที่มีทุน 15,000 USD จึงใช้ N = 1 และให้เงินส่วนเกินเป็นเงินกันชน แดชบอร์ดคิดให้เองว่าเงินในบัญชีตอนนี้แนะนำ N ได้ไม่เกินเท่าไร ตัวเลขผลที่ N มากกว่า 1 คิดจากสูตรคูณ N ไม่ได้ทดสอบแยกทุก N ถ้าใช้ N ตั้งแต่ 3 ให้ตั้งช่อง lot สูงสุดต่อ 1 ไม้ในหน้า Inputs เป็น 0.5

ต้องมีอะไรบ้างก่อนใช้

  • บัญชี Hedging ถือ BUY และ SELL พร้อมกันได้ แถบชื่อหน้าต่าง MT5 ต้องมีคำว่า Hedge ถ้าเป็นบัญชีแบบ Netting EA จะหยุดทำงาน
  • ทองคำ 1 lot = 100 oz สกุล USD ผลทดสอบใช้ XAUUSD.s ของ Zaurix (EA WING เป็นพันธมิตรกับ Zaurix) ไม่แนะนำบัญชีเซนต์ (XAUUSD.c) เพราะผลทดสอบชุดที่ 1 ที่สเกล 10,000 เซนต์แตกภายใน 9 เดือน
  • เงินในบัญชีถึงทุนแนะนำ ตามชุดและขนาด N ที่จะใช้ เงินต่ำกว่าทุนขั้นต่ำเสี่ยงโดนโบรกเกอร์ตัดออเดอร์ (Stop out)
  • Leverage สูงพอ ผลทดสอบใช้ 1:2000 ตอนออเดอร์เต็ม 60 ออเดอร์ใช้มาร์จิ้นราว 2,700 × N USD ที่ 1:2000 แต่ราว 53,700 × N USD ที่ 1:100 ช่วงทรุดหนักสุดของชุดที่ 4 ถ้าใช้ 1:100 ระดับมาร์จิ้นจะเหลือราว 91%
  • คอมหรือ VPS ที่เปิดตลอด EA ปิดรอบที่เป้าได้เฉพาะตอน MT5 เปิดอยู่ ยิ่งช่วงที่มีออเดอร์ค้างยิ่งสำคัญ ดู คู่มือ VPS บน Windows
  • Allow DLL imports และสิทธิ์ใช้งาน EA ตรวจสิทธิ์ผ่านอินเทอร์เน็ต เลขบัญชีต้องได้รับสิทธิ์จากทีมงานก่อนใช้
  • เวลาเซิร์ฟเวอร์ โบรกเกอร์ Zaurix ใส่ช่องเวลาเซิร์ฟเวอร์เป็น 3 (GMT+3) ตลอดปีเหมือนผลทดสอบ ซึ่งเป็นค่าเริ่มต้นอยู่แล้ว ถ้าใช้โบรกเกอร์อื่นต้องตั้งช่องเวลาเซิร์ฟเวอร์ในหน้า Inputs ให้ตรง และผลอาจต่างจากที่ทดสอบ

ติดตั้ง WING TWIN ทีละขั้น

  1. ล็อกอินบัญชีเทรดและตรวจคำว่า Hedge

    เปิด MT5 แล้วล็อกอินด้วยรหัสสำหรับเทรด ไม่ใช่รหัส Investor ที่ดูได้อย่างเดียว แถบชื่อหน้าต่างต้องมีคำว่า Hedge

  2. เปิดสวิตช์ในตัวโปรแกรม

    ไปที่ Tools → Options → Expert Advisors ติ๊ก Allow algorithmic trading และ Allow DLL imports แล้วกด OK

  3. วางไฟล์ในโฟลเดอร์ Experts

    แตกไฟล์ .zip ก่อน แล้วไปที่ File → Open Data Folder → MQL5 → Experts วางไฟล์ [eawing_ea product="twin"] จากนั้นกลับมาที่หน้าต่าง Navigator คลิกขวาที่ Expert Advisors แล้วเลือก Refresh

  4. เปิดกราฟ XAUUSD.s กรอบเวลา M1

    คลิกขวาที่ XAUUSD.s ในหน้าต่าง Market Watch เลือก Chart Window แล้วกดปุ่ม M1

  5. ลาก EA ลงกราฟและเลือกชุด

    แท็บ Common ติ๊ก Allow Algo Trading ถ้ามีแท็บ Dependencies ให้ติ๊ก Allow DLL imports ด้วย ส่วนแท็บ Inputs เลือกชุดที่ช่องบนสุด (ค่าเริ่มต้นคือชุดที่ 1 WING LIFE1) และใส่ขนาด N ตามเงินในบัญชี แล้วกด OK

  6. เปิดปุ่ม Algo Trading แล้วตรวจแดชบอร์ด

    มุมขวาบนของแผงต้องขึ้นล็อกอินสำเร็จสีเขียว ใต้หัวแผงต้องไม่มีแถบสีแดง และแถวเงินในบัญชีตอนนี้ต้องไม่เป็นสีแดง จากนั้นเปิดคอมหรือ VPS กับ MT5 ทิ้งไว้ตลอด EA เริ่มรอบเองเมื่อเงื่อนไขครบ

เคยใช้ไฟล์ EA WING รุ่น 6.0 มาก่อน

EA WING รุ่น 6.0 คือ WING TWIN รุ่นก่อน ที่เปลี่ยนชื่อเมื่อ 19 ต.ค. 2026 โค้ดเทรด ชุดค่า และผลทดสอบเหมือน 6.1 ทุกตัวเลข ให้ถอดตัวเดิมออกจากกราฟ แล้วลาก [eawing_ea product="twin"] ใส่กราฟเดิม มีออเดอร์ค้างอยู่ก็เปลี่ยนได้ เพราะ EA รับออเดอร์ของ Magic เดียวกันมาดูแลต่อ สิทธิ์ใช้งานเดิมใช้ได้เลยไม่ต้องขอใหม่ และห้ามรันสองรุ่นพร้อมกันบนบัญชีเดียวกัน

แดชบอร์ดบนกราฟ

แผงภาษาไทยอยู่มุมซ้ายบนของกราฟ บอกทุกอย่างที่ EA ทำอยู่ และมีปุ่มให้กดสี่เรื่อง

  • ชุดค่า ปุ่ม 1 ถึง 4 และปุ่มตั้งเอง ถ้ามีออเดอร์ค้าง ชุดที่กดจะถูกจองไว้ใช้หลังจบรอบนี้
  • เริ่มรอบใหม่ (ไทย) ปุ่มลดและเพิ่มเวลาตั้งแต่กับถึง ใหม่ในรุ่น 6.1 ใช้กับชุดที่เลือกได้ทันที ค่าเริ่มต้นคือเวลาของชุดที่ใช้ทดสอบ เวลาที่ตั้งเองไม่มีผลทดสอบรองรับ ผลอาจต่างจากรายงานมาก ควรลองในบัญชีเดโมก่อน
  • ขนาด N และเงิน แถวถัดไปบอกเงินขั้นต่ำและเงินแนะนำของชุดกับ N ที่เลือก สีของแถวเงินในบัญชีตอนนี้บอกว่าพอไหม (แดง ต่ำกว่าขั้นต่ำ เหลือง ต่ำกว่าแนะนำ เขียว ถึงทุนแนะนำ) และบอก N ที่เงินนี้แนะนำ
  • พักหลังจบรอบ EA ไม่เริ่มรอบใหม่ แต่รอบที่ค้างยังดูแลจนปิดที่เป้า ใช้ปุ่มนี้แทนการปิด Algo Trading เพราะการปิด Algo Trading ตอนมีออเดอร์ค้างทำให้รอบนั้นไม่มีใครดูแล

คอลัมน์ขวาบอกสถานะ เช่น รอเทรนด์ รอเวลาเริ่ม เดินรอบ หรือตลาดปิด พร้อมค่า ADX จำนวนออเดอร์ในรอบเทียบกับเพดาน 60 กำไรลอยรวมเทียบกับเป้าปิดรอบ ระดับถัดไป สเปรด และระดับมาร์จิ้น ปัญหาที่ทำให้ EA หยุดหรือไม่เริ่มรอบจะขึ้นเป็นแถบสีแดงใต้หัวแผง รายละเอียดทุกแถวอยู่ในคู่มือ PDF ในไฟล์ zip

สิทธิ์ใช้งาน

WING TWIN ใช้ระบบสิทธิ์เดียวกับ EA WING ใช้งานได้เฉพาะเลขบัญชี MT5 ที่ทีมงานเปิดสิทธิ์ให้ ทั้งบัญชีจริง บัญชีเดโม และตอนทดสอบย้อนหลัง ส่งเลขบัญชีกับชื่อเซิร์ฟเวอร์ให้ทีมงานทาง LINE เมื่อเพิ่มสิทธิ์แล้ว EA เริ่มทำงานเองภายใน 5 นาที ไม่ต้องลากลงกราฟใหม่

  • เน็ตหรือระบบสิทธิ์ขัดข้อง EA ใช้ต่อได้ 72 ชั่วโมงนับจากครั้งล่าสุดที่ตรวจผ่าน
  • ไม่ได้เปิดใช้ EA นานเกิน 14 วัน ระบบระงับสิทธิ์ให้อัตโนมัติ แจ้งทีมงานเพื่อเปิดใช้ต่อ ส่วนช่วงที่มีออเดอร์ค้าง EA ตรวจสิทธิ์ทุก 6 ชั่วโมง ถือรอบนานจึงไม่ถูกระงับ
  • ล็อกอินไม่ผ่านตอนมีออเดอร์ค้าง EA ดูแลรอบนั้นจนปิด แค่ไม่เริ่มรอบใหม่
  • สิทธิ์มีวันหมดอายุซึ่งแดชบอร์ดแสดงไว้ เหลือไม่ถึง 30 วันให้ติดต่อทีมงานเพื่อต่ออายุ และเปลี่ยนเลขบัญชีเมื่อไหร่ต้องขอสิทธิ์ของเลขบัญชีใหม่

คำถามที่พบบ่อยเรื่อง WING TWIN

WING TWIN ราคาเท่าไร?

สอบถามราคาและเงื่อนไขของ WING TWIN กับทีมงานทาง LINE ได้โดยตรง แพ็กเกจในหน้า แพ็กเกจและราคา เป็นของ EA WING 5.0

ใช้กับบัญชีเซนต์ได้ไหม?

ไม่แนะนำ บัญชีเซนต์ (XAUUSD.c) ทอง 1 lot เท่ากับ 1 oz EA ปรับสัดส่วนเงินให้เองก็จริง แต่ราคาและ tick ของ XAUUSD.c เดินคนละทางกับ XAUUSD.s ผลทดสอบชุดที่ 1 ที่สเกล 10,000 เซนต์แตกภายใน 9 เดือน ตัวเลขในหน้านี้จึงใช้กับบัญชีเซนต์ไม่ได้

ใช้กับโบรกเกอร์อื่นได้ไหม?

ได้ถ้าเป็นบัญชี Hedging ที่ทอง 1 lot เท่ากับ 100 oz และต้องตั้งช่องเวลาเซิร์ฟเวอร์ (GMT) ให้ตรงกับโบรกเกอร์นั้น แต่ราคาและสเปรดไม่เหมือน Zaurix ผลจึงอาจต่างจากที่ทดสอบ

รัน EA WING กับ WING TWIN ในบัญชีเดียวกันได้ไหม?

ห้ามรันบนทองตัวเดียวกันในบัญชีเดียวกัน เพราะ EA WING 5.0 นับออเดอร์ทุกออเดอร์ของสัญลักษณ์นั้นรวมเป็นชุดเดียวและปิดไปพร้อมกัน ออเดอร์ของ WING TWIN จะถูกปิดกลางรอบ ถ้าต้องการใช้ทั้งสองตัวให้แยกบัญชี

เปลี่ยนเวลาเทรดเองได้ไหม?

ได้ กดปุ่มลดและเพิ่มที่แถวเริ่มรอบใหม่ (ไทย) บนแดชบอร์ด หรือแก้ข้อ 0.3 และ 0.4 ในหน้า Inputs มีผลทันทีแม้มีออเดอร์ค้าง เพราะใช้แค่ตอนเริ่มรอบใหม่ แต่เวลาที่ไม่ใช่ของชุดไม่มีผลทดสอบรองรับ กดใช้เวลาตามชุดเพื่อกลับค่าเดิมได้ทุกเมื่อ

ทำไมบางช่วงไม่มีรอบปิดเลยหลายสัปดาห์?

เมื่อราคาลากทางเดียวไกลจนออเดอร์เต็ม 60 ออเดอร์ EA หยุดเปิดเพิ่มแล้วรอราคากลับมาถึงเป้า ระหว่างนั้นไม่มีรอบปิดและกำไรลอยติดลบ แดชบอร์ดจะขึ้นสถานะไม้เต็ม 60/60 นี่คือความเสี่ยงหลักของระบบที่ไม่มีการตัดขาดทุน
